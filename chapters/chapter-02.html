บทที่ 2 · รู้จักเครื่องมือและภาษา Java

เริ่มต้นกับ Java และโปรแกรมแรก

รู้จักเส้นทางจากไฟล์ที่เราเขียนไปจนถึงผลลัพธ์บนหน้าจอ แล้วสร้างโปรแกรม Java ขนาดเล็กด้วยตัวเอง

เมื่อจบบทนี้ นิสิตจะทำได้
  • อธิบายหน้าที่ของ JDK, JVM และ IDE
  • อ่านโครงสร้างคลาสและเมธอด main
  • ใช้ println, print, comment และ escape sequence
  • คอมไพล์ รัน และแก้ syntax error อย่างเป็นขั้นตอน

2. จากไฟล์ข้อความเป็นโปรแกรมที่ทำงาน

โค้ด Java เป็นข้อความที่มนุษย์เขียนและอ่านได้ ก่อนทำงานต้องแปลงให้อยู่ในรูปที่ Java Virtual Machine (JVM) เข้าใจ ขั้นตอนนี้ช่วยตรวจข้อผิดพลาดด้านไวยากรณ์ก่อนเริ่มรัน บทนี้จะเริ่มจากภาพรวมของเครื่องมือ แล้วค่อย ๆ เขียนโปรแกรมจากบรรทัดเดียวไปจนถึงโปรแกรมที่จัดรูปแบบผลลัพธ์ได้

2.1 JDK, JVM และ IDE ทำหน้าที่อะไร

JDK (Java Development Kit) คือชุดเครื่องมือพัฒนา มี compiler ชื่อ javac และ JVM อยู่ในตัว ส่วน JVM (Java Virtual Machine) ใช้รัน bytecode ในไฟล์ .class ขณะที่ IDE (เช่น IntelliJ IDEA, NetBeans, VS Code) คือโปรแกรมช่วยเขียนโค้ด ไฮไลต์ error และกดปุ่มเดียวเพื่อเรียก javac และ JVM ให้

ภาพรวมการทำงาน
ไฟล์ Hello.java  →  javac (compiler)  →  Hello.class (bytecode)  →  JVM  →  ผลลัพธ์บนจอ
   เราเขียน            ตรวจ+แปล             ไฟล์ที่ได้               รัน

เราแก้เฉพาะไฟล์ .java เท่านั้น ไฟล์ .class ถูกสร้างใหม่ทุกครั้งที่คอมไพล์

ลำดับเหตุการณ์เมื่อกด Run ใน IDE
  1. IDE บันทึกไฟล์ .java
  2. IDE เรียก javac ตรวจไวยากรณ์ ถ้าผิดจะหยุดและแสดง compile error (ยังไม่ได้รันเลย)
  3. ถ้าผ่าน javac สร้างไฟล์ .class ที่มี bytecode
  4. IDE เรียก JVM ให้โหลดคลาสและเริ่มทำงานที่เมธอด main
  5. ผลลัพธ์แสดงในหน้าต่าง Console/Output ถ้าเกิดปัญหาระหว่างรันจะเป็น runtime error
คำคืออะไรเปรียบเทียบ
JDKชุดเครื่องมือสำหรับนักพัฒนา (javac, java, เครื่องมืออื่น)กล่องเครื่องมือช่าง
javaccompiler แปล .java → .class และตรวจไวยากรณ์บรรณาธิการตรวจคำผิดก่อนพิมพ์
JVMเครื่องจำลองที่รัน bytecode ได้บนทุกระบบปฏิบัติการล่ามที่อ่าน bytecode ให้เครื่องเข้าใจ
IDEโปรแกรมช่วยเขียนโค้ดที่รวมทุกอย่างไว้ที่เดียวโต๊ะทำงานที่จัดเครื่องมือไว้ครบ
ทำไม Java รันได้หลายระบบ

bytecode ไม่ผูกกับ Windows/macOS/Linux ระบบใดที่มี JVM ก็รันไฟล์ .class เดียวกันได้ จึงเป็นที่มาของคำว่า “Write once, run anywhere”

ลองคิดก่อน · ใครทำงานเมื่อไร

ถ้าลืม ; แล้วกด Run — ข้อผิดพลาดถูกพบโดย javac หรือ JVM? โปรแกรมได้เริ่มทำงานหรือยัง?

ดูคำตอบ

พบโดย javac ตอนคอมไพล์ โปรแกรมยังไม่ได้เริ่มทำงานเลย เพราะไม่มีไฟล์ .class ใหม่ให้ JVM รัน

2.2 โครงสร้างของโปรแกรม Java และการแสดงผล

โปรแกรมเริ่มจากคลาส ภายในคลาสมีเมธอด main ซึ่งเป็นจุดเริ่มทำงาน คำสั่งแต่ละคำสั่งลงท้ายด้วย ; และบล็อกคำสั่งอยู่ระหว่างวงเล็บปีกกา { }

แยกส่วนประกอบของโปรแกรมแรก
public class Hello {                          // ① ประกาศคลาสชื่อ Hello
    public static void main(String[] args) {  // ② เมธอด main = จุดเริ่มทำงาน
        System.out.println("Hello, Java!");   // ③ คำสั่ง: พิมพ์ข้อความแล้วขึ้นบรรทัดใหม่
    }                                         // ④ ปิดเมธอด main
}                                             // ⑤ ปิดคลาส
  • public class Hello — ชื่อคลาสต้องตรงกับชื่อไฟล์ Hello.java (ตัวพิมพ์เล็ก-ใหญ่ต้องตรงด้วย)
  • public static void main(String[] args) — ต้องเขียนแบบนี้ทุกตัวอักษร ความหมายของแต่ละคำจะเรียนในบทเมธอดและคลาส
  • System.out.println(...) — สั่งพิมพ์ค่าในวงเล็บไปที่ console
  • ข้อความ (String) ต้องอยู่ใน " " เครื่องหมายคำพูดคู่

ตัวอย่าง 2.2.1 · โปรแกรมแรก: Hello, Java! พื้นฐาน

แนวคิด: โปรแกรมที่สั้นที่สุดที่มีครบทุกส่วน: คลาส → main → คำสั่งหนึ่งคำสั่ง

Java source · Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
Output
Hello, Java!
อธิบายทีละขั้น
  1. JVM เริ่มที่ main
  2. ทำคำสั่ง println หนึ่งครั้ง พิมพ์ Hello, Java! และขึ้นบรรทัดใหม่
  3. ถึง } ของ main → โปรแกรมจบ

ตัวอย่าง 2.2.2 · หลายคำสั่ง ทำงานจากบนลงล่าง พื้นฐาน

แนวคิด: คำสั่งใน main ทำงานเรียงตามลำดับบรรทัด (sequence) ทีละคำสั่ง

Java source · AboutMe.java
public class AboutMe {
    public static void main(String[] args) {
        System.out.println("Name: Mali");
        System.out.println("Major: Computer Science");
        System.out.println("Year: 1");
    }
}
Output
Name: Mali
Major: Computer Science
Year: 1
อธิบายทีละขั้น
  1. บรรทัดแรกพิมพ์ชื่อ
  2. บรรทัดที่สองพิมพ์สาขา
  3. บรรทัดที่สามพิมพ์ชั้นปี — ลำดับใน output ตรงกับลำดับในโค้ดเสมอ

สลับบรรทัด Name กับ Year แล้วดูว่า output เปลี่ยนตามหรือไม่

ตัวอย่าง 2.2.3 · print กับ println ต่างกันอย่างไร ต่อยอด

แนวคิด: print พิมพ์แล้วอยู่บรรทัดเดิม ส่วน println พิมพ์แล้วขึ้นบรรทัดใหม่ และ println() เปล่า ๆ ใช้เว้นบรรทัด

Java source · PrintVsPrintln.java
public class PrintVsPrintln {
    public static void main(String[] args) {
        System.out.print("A");
        System.out.print("B");
        System.out.println("C");
        System.out.println("D");
        System.out.println();
        System.out.print("E ");
        System.out.println("F");
    }
}
Output
ABC
D

E F
อธิบายทีละขั้น
  1. print A และ B ต่อกันในบรรทัดเดิม → AB
  2. println C ต่อท้ายแล้วขึ้นบรรทัด → บรรทัดแรกคือ ABC
  3. println D อยู่บรรทัดที่สอง
  4. println() ว่าง ทำให้เกิดบรรทัดว่าง
  5. print "E " (มีช่องว่าง) แล้ว println F → E F

ตัวอย่าง 2.2.4 · Comment: ข้อความที่ compiler ไม่สนใจ ต่อยอด

แนวคิด: comment ใช้อธิบายโค้ดให้คนอ่าน // ใช้บรรทัดเดียว /* ... */ ใช้หลายบรรทัด โค้ดที่อยู่ใน comment จะไม่ทำงาน

Java source · CommentDemo.java
/*
 * โปรแกรมนี้ใช้ทดลอง comment
 * ผู้เขียน: Mali
 */
public class CommentDemo {
    public static void main(String[] args) {
        // พิมพ์บรรทัดแรก
        System.out.println("Line 1");
        // System.out.println("Line 2");  <- บรรทัดนี้ถูกปิดไว้
        System.out.println("Line 3"); // comment ท้ายบรรทัดก็ได้
    }
}
Output
Line 1
Line 3
อธิบายทีละขั้น
  1. ส่วน /* ... */ ด้านบนไม่ถูกคอมไพล์
  2. Line 2 ไม่ถูกพิมพ์เพราะทั้งบรรทัดเป็น comment
  3. comment ท้ายบรรทัดไม่กระทบคำสั่งก่อนหน้า

เทคนิค “comment out” (ปิดบรรทัดชั่วคราว) มีประโยชน์มากเวลาหาว่าบรรทัดไหนทำให้เกิดปัญหา

Escape sequence: อักขระพิเศษในข้อความ

เขียนว่าความหมายตัวอย่างผลลัพธ์
\nขึ้นบรรทัดใหม่"A\nB"A
B
\tแท็บ (เว้นช่องเป็นคอลัมน์)"A\tB"A       B
\"เครื่องหมาย " ในข้อความ"Say \"Hi\""Say "Hi"
\\เครื่องหมาย \ หนึ่งตัว"C:\\java"C:\java

ตัวอย่าง 2.2.5 · จัดรูปแบบผลลัพธ์ด้วย escape sequence ประยุกต์

แนวคิด: ใช้ \t ทำตาราง ใช้ \n ขึ้นบรรทัดในคำสั่งเดียว และใช้ \" เมื่อต้องการแสดงเครื่องหมายคำพูด

Java source · ReceiptHeader.java
public class ReceiptHeader {
    public static void main(String[] args) {
        System.out.println("==== \"Java Cafe\" ====");
        System.out.println("Item\tQty\tPrice");
        System.out.println("Latte\t2\t90");
        System.out.println("Cake\t1\t65");
        System.out.println("Thank you!\nSee you again.");
        System.out.println("Saved at C:\\receipts");
    }
}
Output
==== "Java Cafe" ====
Item	Qty	Price
Latte	2	90
Cake	1	65
Thank you!
See you again.
Saved at C:\receipts
อธิบายทีละขั้น
  1. \" ทำให้ชื่อร้านมีเครื่องหมายคำพูดครอบ
  2. \t ดันข้อความไปคอลัมน์ถัดไป ทำให้ Qty และ Price ตรงกัน
  3. \n แบ่งข้อความเป็น 2 บรรทัดในคำสั่งเดียว
  4. \\ แสดงเป็น \ หนึ่งตัว
ชื่อไฟล์ต้องตรงกับคลาส public

ถ้าประกาศ public class Hello ต้องบันทึกเป็น Hello.java ไม่ใช่ hello.java หรือ Hello.txt และชื่อคลาสนิยมขึ้นต้นด้วยตัวพิมพ์ใหญ่ทุกคำ (PascalCase) เช่น StudentReport

System.out.println(" is");
System.out.print("fun\n!");

2.3 คอมไพล์ รัน และเริ่มอ่าน error

ถ้าใช้ command line ให้เปิด terminal ในโฟลเดอร์ที่มีไฟล์ จากนั้นคอมไพล์ก่อนแล้วจึงรัน คำสั่งที่ขาดเครื่องหมายหรือสะกดชื่อผิดทำให้ compiler แจ้ง ชื่อไฟล์ เลขบรรทัด และชนิดปัญหา ซึ่งเป็นเบาะแสที่ดีที่สุดในการแก้

คำสั่งพื้นฐานบน command line
javac Hello.java     ← คอมไพล์ ได้ไฟล์ Hello.class
java Hello           ← รัน (ไม่ต้องเติม .class)

ตั้งแต่ Java 11 สามารถรันไฟล์เดียวโดยตรงด้วย java Hello.java ได้ด้วย (คอมไพล์ในหน่วยความจำให้อัตโนมัติ)

วิธีอ่าน error อย่างเป็นขั้นตอน
  1. อ่านบรรทัดแรกของ error: Hello.java:3: error: ';' expected → ไฟล์ Hello.java บรรทัด 3 ขาด ;
  2. ดูบรรทัดที่ javac คัดลอกมาและเครื่องหมาย ^ ที่ชี้ตำแหน่ง
  3. ตรวจบรรทัดนั้น และบรรทัดก่อนหน้า เพราะบางครั้งต้นเหตุอยู่ก่อนจุดที่ถูกชี้
  4. แก้ทีละจุดโดยเริ่มจาก error แรก แล้วคอมไพล์ใหม่ — error ตัวหลัง ๆ มักเป็นผลพวงของตัวแรก

ทดลอง error 2.3.1 · ลืม semicolon พื้นฐาน

แนวคิด: ทุกคำสั่งต้องจบด้วย ; javac ชี้ตำแหน่งท้ายคำสั่งที่ขาด

Java source · MissingSemicolon.java
public class MissingSemicolon {
    public static void main(String[] args) {
        System.out.println("Start")
        System.out.println("End");
    }
}
Compile error (จาก javac จริง)
MissingSemicolon.java:3: error: ';' expected
        System.out.println("Start")
                                   ^
อธิบายทีละขั้น
  1. MissingSemicolon.java:3 บอกว่าปัญหาอยู่บรรทัด 3
  2. ';' expected บอกชนิดปัญหา: ขาด semicolon
  3. ^ ชี้ตำแหน่งท้าย "Start") → เติม ; ตรงนั้น

ทดลอง error 2.3.2 · สะกดชื่อผิด (ตัวพิมพ์ใหญ่-เล็ก) ต่อยอด

แนวคิด: Java แยกตัวพิมพ์ใหญ่-เล็ก (case-sensitive) system กับ System คือคนละชื่อ

Java source · WrongCase.java
public class WrongCase {
    public static void main(String[] args) {
        system.out.println("Hello");
        System.out.printn("World");
    }
}
Compile error (จาก javac จริง)
WrongCase.java:3: error: package system does not exist
        system.out.println("Hello");
              ^
WrongCase.java:4: error: cannot find symbol
        System.out.printn("World");
                  ^
  symbol:   method printn(String)
  location: variable out of type PrintStream
อธิบายทีละขั้น
  1. error แรก: package system does not exist — compiler ไม่รู้จัก system ตัวเล็ก ต้องเป็น System
  2. error ที่สอง: cannot find symbol ชี้ที่ printn — ไม่มีเมธอดชื่อนี้ ต้องเป็น println
  3. cannot find symbol เป็น error ที่พบบ่อยที่สุด มักแปลว่า “สะกดผิด” หรือ “ยังไม่ได้ประกาศ”

ทดลอง error 2.3.3 · วงเล็บปีกกาไม่ครบคู่ ประยุกต์

แนวคิด: ทุก { ต้องมี } คู่กัน ถ้าขาด javac จะอ่านไปจนสุดไฟล์แล้วจึงแจ้ง

Java source · MissingBrace.java
public class MissingBrace {
    public static void main(String[] args) {
        System.out.println("Open");
        System.out.println("Close");

}
Compile error (จาก javac จริง)
MissingBrace.java:6: error: reached end of file while parsing
}
 ^
อธิบายทีละขั้น
  1. reached end of file while parsing แปลว่าอ่านถึงท้ายไฟล์แล้วยังปิดบล็อกไม่ครบ
  2. error ถูกรายงานที่บรรทัดสุดท้าย แต่จุดที่ต้องแก้คือ } ของ main ที่หายไป
  3. การจัดย่อหน้า (indent) ให้สม่ำเสมอทำให้เห็นวงเล็บที่ขาดได้ง่าย

ทดลอง error 2.3.4 · ข้อความไม่ปิดเครื่องหมายคำพูด ประยุกต์

แนวคิด: String ต้องเปิดและปิดด้วย " ในบรรทัดเดียวกัน

Java source · UnclosedString.java
public class UnclosedString {
    public static void main(String[] args) {
        System.out.println("Hello);
    }
}
Compile error (จาก javac จริง)
UnclosedString.java:3: error: unclosed string literal
        System.out.println("Hello);
                           ^
อธิบายทีละขั้น
  1. unclosed string literal → เปิด " แล้วไม่ปิด
  2. compiler มองว่า ); เป็นส่วนหนึ่งของข้อความ คำสั่งจึงไม่สมบูรณ์
  3. แก้เป็น "Hello");

สรุป error ที่พบบ่อยในบทนี้

Exercise 2.3print ต่อบรรทัด★ ง่าย

ใช้ System.out.print อย่างน้อย 3 คำสั่งเพื่อพิมพ์คำว่า I, love, Java ให้อยู่ในบรรทัดเดียวกันโดยมีช่องว่างคั่น แล้วใช้ println พิมพ์ Done ในบรรทัดถัดไป

สิ่งที่ต้องทำ
  1. ห้ามเขียนทั้งประโยคในคำสั่งเดียว
  2. ระวังช่องว่างระหว่างคำ
  3. ต้องขึ้นบรรทัดใหม่ก่อนพิมพ์ Done
ตัวอย่างผลลัพธ์
I love Java
Done

ตัวอย่างคำตอบ

public class PrintSameLine {
    public static void main(String[] args) {
        System.out.print("I ");
        System.out.print("love ");
        System.out.print("Java");
        System.out.println();
        System.out.println("Done");
    }
}

println() เปล่า ๆ ทำหน้าที่ขึ้นบรรทัดใหม่หลังจาก print ชุดแรก

Exercise 2.5ข้อความที่มีเครื่องหมายพิเศษ★★ ปานกลาง

เขียนโปรแกรมแสดงผลให้ตรงตามตัวอย่างทุกตัวอักษร ซึ่งมีทั้งเครื่องหมายคำพูดและ backslash

สิ่งที่ต้องทำ
  1. ใช้ \" สำหรับเครื่องหมายคำพูด
  2. ใช้ \\ สำหรับ backslash
  3. บรรทัดที่ 3 และ 4 ต้องเกิดจาก println คำสั่งเดียว โดยใช้ \n
ตัวอย่างผลลัพธ์
Teacher said "Practice every day"
File: C:\java\Hello.java
Line A
Line B

ตัวอย่างคำตอบ

public class SpecialChars {
    public static void main(String[] args) {
        System.out.println("Teacher said \"Practice every day\"");
        System.out.println("File: C:\\java\\Hello.java");
        System.out.println("Line A\nLine B");
    }
}

Exercise 2.6ตารางเวลาเรียนด้วย \t★★ ปานกลาง

แสดงตารางเรียน 3 วิชา โดยใช้ \t จัดคอลัมน์ให้ตรงกัน มีหัวตาราง และเส้นคั่นด้วยเครื่องหมาย -

สิ่งที่ต้องทำ
  1. หัวตารางมี 3 คอลัมน์: Day, Time, Subject
  2. มีเส้นคั่นใต้หัวตาราง
  3. ข้อมูล 3 แถวตามตัวอย่าง (เปลี่ยนวิชาเป็นของตนเองได้)
ตัวอย่างผลลัพธ์
Day	Time	Subject
-------------------------------
Mon	09:00	Programming
Tue	13:00	Math
Wed	10:00	English

ตัวอย่างคำตอบ

public class Timetable {
    public static void main(String[] args) {
        System.out.println("Day\tTime\tSubject");
        System.out.println("-------------------------------");
        System.out.println("Mon\t09:00\tProgramming");
        System.out.println("Tue\t13:00\tMath");
        System.out.println("Wed\t10:00\tEnglish");
    }
}

Exercise 2.7ใบเสร็จอย่างง่าย★★ ปานกลาง

แสดงใบเสร็จร้านค้าที่มีชื่อร้าน เส้นคั่น ชื่อสินค้า 2 รายการพร้อมราคา ราคารวม และคำว่า Thank you! ตามตัวอย่าง (ยังไม่ต้องคำนวณ ให้พิมพ์ตัวเลขตรง ๆ)

สิ่งที่ต้องทำ
  1. ใช้ = ทำเส้นคั่นบนและล่าง
  2. ใช้ \t คั่นชื่อสินค้ากับราคา
  3. มีบรรทัดว่าง 1 บรรทัดก่อน Thank you!
ตัวอย่างผลลัพธ์
===== MINI MART =====
Pen		15
Notebook	35
---------------------
Total		50
=====================

Thank you!

ตัวอย่างคำตอบ

public class SimpleReceipt {
    public static void main(String[] args) {
        System.out.println("===== MINI MART =====");
        System.out.println("Pen\t\t15");
        System.out.println("Notebook\t35");
        System.out.println("---------------------");
        System.out.println("Total\t\t50");
        System.out.println("=====================");
        System.out.println();
        System.out.println("Thank you!");
    }
}

Pen สั้นกว่า Notebook จึงใช้ \t\t เพื่อให้ราคาอยู่คอลัมน์เดียวกัน

Exercise 2.8วาดรูปด้วยตัวอักษร★★★ ท้าทาย

ใช้ println แสดงรูปบ้านด้วยตัวอักษรตามตัวอย่าง รูปมีหลังคา (/ และ \) ผนัง และประตู

สิ่งที่ต้องทำ
  1. ต้องแสดง backslash ให้ถูกต้อง (ใช้ \\)
  2. จัดช่องว่างนำหน้าให้รูปสมมาตร
  3. อธิบายว่าทำไมบรรทัดหลังคาในโค้ดดูยาวกว่าผลลัพธ์
ตัวอย่างผลลัพธ์
     /\
    /  \
   /    \
  /______\
  |      |
  |  []  |
  |______|

ตัวอย่างคำตอบ

public class AsciiHouse {
    public static void main(String[] args) {
        System.out.println("     /\\");
        System.out.println("    /  \\");
        System.out.println("   /    \\");
        System.out.println("  /______\\");
        System.out.println("  |      |");
        System.out.println("  |  []  |");
        System.out.println("  |______|");
    }
}

ในโค้ด \\ สองตัวแสดงผลเป็น \ ตัวเดียว บรรทัดในโค้ดจึงยาวกว่าผลลัพธ์หนึ่งตัวอักษร

Exercise 2.9นามบัตรในกรอบ★★★ ท้าทาย

สร้างนามบัตรในกรอบที่ทำจาก +, - และ | ภายในมีชื่อ ตำแหน่ง อีเมล และคำคมในเครื่องหมายคำพูด ทุกบรรทัดต้องกว้างเท่ากัน (ขอบขวาตรงกัน)

สิ่งที่ต้องทำ
  1. ใช้ภาษาอังกฤษในการ์ดเพื่อให้นับความกว้างได้ง่าย
  2. บรรทัดคำคมต้องมีเครื่องหมาย " ครอบ
  3. นับจำนวนตัวอักษรแต่ละบรรทัดให้เท่ากัน (ในตัวอย่างกว้าง 32 ตัวอักษร)
ตัวอย่างผลลัพธ์
+------------------------------+
| Mali Jaidee                  |
| Junior Java Developer        |
| mali@example.com             |
|                              |
| "Code a little every day."   |
+------------------------------+

ตัวอย่างคำตอบ

public class BusinessCard {
    public static void main(String[] args) {
        System.out.println("+------------------------------+");
        System.out.println("| Mali Jaidee                  |");
        System.out.println("| Junior Java Developer        |");
        System.out.println("| mali@example.com             |");
        System.out.println("|                              |");
        System.out.println("| \"Code a little every day.\"   |");
        System.out.println("+------------------------------+");
    }
}

บรรทัดคำคมในโค้ดมี \" 2 ที่ ดูยาวกว่าบรรทัดอื่น 2 ตัวอักษร แต่ผลลัพธ์กว้างเท่ากัน

Exercise 2.10แก้โปรแกรมที่มีหลาย error★★★ ท้าทาย

โค้ดนี้บันทึกในไฟล์ Report.java แต่มีข้อผิดพลาดอย่างน้อย 4 จุด ให้คอมไพล์ อ่าน error ทีละตัว แก้ทีละจุดจนรันได้ผลตามตัวอย่าง และบันทึกว่าแก้อะไรตามลำดับ

public class report {
    public static void main(String[] args) {
        System.out.println("Student Report")
        System.out.println("Name:	Mali");
        System.out.printline("Score:	85");
        System.out.println("Status: "Pass"");
}
สิ่งที่ต้องทำ
  1. เริ่มแก้จาก error แรกที่ javac รายงาน แล้วคอมไพล์ใหม่ทุกครั้ง
  2. ผลลัพธ์บรรทัดสุดท้ายต้องมีเครื่องหมายคำพูดรอบคำว่า Pass
  3. เขียนสรุปว่าแต่ละ error มีข้อความว่าอะไร
ตัวอย่างผลลัพธ์
Student Report
Name:	Mali
Score:	85
Status: "Pass"

ตัวอย่างคำตอบ

public class Report {
    public static void main(String[] args) {
        System.out.println("Student Report");
        System.out.println("Name:\tMali");
        System.out.println("Score:\t85");
        System.out.println("Status: \"Pass\"");
    }
}

จุดที่แก้: (1) ชื่อคลาส report → Report ให้ตรงชื่อไฟล์ (2) เติม ; บรรทัด 3 (3) printline → println (4) ใช้ \" รอบ Pass (5) เติม } ปิดคลาส
