บทที่ 2 · รู้จักเครื่องมือและภาษา Java

เริ่มต้นกับ Java และโปรแกรมแรก

รู้จักเส้นทางจากไฟล์ที่เราเขียนไปจนถึงผลลัพธ์บนหน้าจอ แล้วสร้างโปรแกรม Java ขนาดเล็กด้วยตัวเอง

เมื่อจบบทนี้ นิสิตจะทำได้
  • อธิบายหน้าที่ของ JDK, JVM และ IDE
  • อ่านโครงสร้างคลาสและเมธอด main
  • ใช้ println, print, comment และ escape sequence
  • คอมไพล์ รัน และแก้ syntax error อย่างเป็นขั้นตอน

2. จากไฟล์ข้อความเป็นโปรแกรมที่ทำงาน

โค้ด Java เป็นข้อความที่มนุษย์เขียนและอ่านได้ ก่อนทำงานต้องแปลงให้อยู่ในรูปที่ Java Virtual Machine (JVM) เข้าใจ ขั้นตอนนี้ช่วยตรวจข้อผิดพลาดด้านไวยากรณ์ก่อนเริ่มรัน บทนี้จะเริ่มจากภาพรวมของเครื่องมือ แล้วค่อย ๆ เขียนโปรแกรมจากบรรทัดเดียวไปจนถึงโปรแกรมที่จัดรูปแบบผลลัพธ์ได้

2.1 JDK, JVM และ IDE ทำหน้าที่อะไร

โค้ดที่เราเขียนต้องผ่าน 2 ขั้นก่อนได้ผลลัพธ์: javac ตรวจและแปลไฟล์ .java เป็น bytecode (.class) แล้ว JVM นำ bytecode ไปรัน

แผนภาพ
ไฟล์ Hello.java  →  javac (compiler)  →  Hello.class (bytecode)  →  JVM  →  ผลลัพธ์บนจอ
   เราเขียน            ตรวจ+แปล             ไฟล์ที่ได้               รัน
คำคืออะไรเปรียบเทียบ
JDKชุดเครื่องมือนักพัฒนา มี javac และ JVM อยู่ในตัวกล่องเครื่องมือช่าง
javaccompiler: ตรวจไวยากรณ์ แล้วแปล .java → .classบรรณาธิการตรวจคำผิดก่อนพิมพ์
JVMรัน bytecode ได้บนทุกระบบปฏิบัติการล่ามที่อ่าน bytecode ให้เครื่องเข้าใจ
IDEโปรแกรมช่วยเขียนโค้ด กดปุ่มเดียวเรียก javac และ JVM ให้โต๊ะทำงานที่จัดเครื่องมือไว้ครบ
ทำไม Java รันได้หลายระบบ

bytecode ไม่ผูกกับ Windows, macOS หรือ Linux เครื่องไหนมี JVM ก็รันไฟล์ .class เดียวกันได้ จึงเป็นที่มาของคำว่า “Write once, run anywhere” เราแก้เฉพาะไฟล์ .java เท่านั้น ไฟล์ .class ถูกสร้างใหม่ทุกครั้งที่คอมไพล์

ลองคิดก่อน · ใครทำงานเมื่อไร

ถ้าลืม ; แล้วกด Run — ข้อผิดพลาดถูกพบโดย javac หรือ JVM? โปรแกรมได้เริ่มทำงานหรือยัง?

ดูคำตอบ

พบโดย javac ตอนคอมไพล์ โปรแกรมยังไม่ได้เริ่มทำงานเลย เพราะไม่มีไฟล์ .class ใหม่ให้ JVM รัน

2.2 โครงสร้างของโปรแกรม Java และการแสดงผล

โปรแกรม Java อยู่ในคลาส ภายในคลาสมีเมธอด main ซึ่งเป็นจุดเริ่มทำงาน ทุกคำสั่งลงท้ายด้วย ; และบล็อกคำสั่งอยู่ใน { }

Hello.java
public class Hello {                          // ① ประกาศคลาสชื่อ Hello
    public static void main(String[] args) {  // ② เมธอด main = จุดเริ่มทำงาน
        System.out.println("Hello, Java!");   // ③ คำสั่ง: พิมพ์ข้อความแล้วขึ้นบรรทัดใหม่
    }                                         // ④ ปิดเมธอด main
}                                             // ⑤ ปิดคลาส
ส่วนต้องรู้
public class Helloชื่อคลาสต้องตรงกับชื่อไฟล์ Hello.java ทุกตัวอักษร
public static void main(String[] args)เขียนแบบนี้ทุกครั้ง ความหมายแต่ละคำจะเรียนในบทเมธอดและคลาส
System.out.println(...)พิมพ์ค่าในวงเล็บไปที่ console แล้วขึ้นบรรทัดใหม่
"Hello, Java!"ข้อความ (String) ต้องอยู่ในเครื่องหมายคำพูดคู่

ตัวอย่าง 2.2.1โปรแกรมแรก

Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
ผลลัพธ์
Hello, Java!
ข้อผิดพลาดที่พบบ่อย

ถ้าประกาศ public class Hello ต้องบันทึกเป็น Hello.java ไม่ใช่ hello.java และชื่อคลาสนิยมขึ้นต้นตัวพิมพ์ใหญ่ทุกคำ (PascalCase) เช่น StudentReport

print กับ println

คำสั่งทำอะไร
System.out.println(x)พิมพ์ x แล้วขึ้นบรรทัดใหม่
System.out.print(x)พิมพ์ x แล้วอยู่บรรทัดเดิม
System.out.println()ไม่พิมพ์อะไร แค่ขึ้นบรรทัดใหม่ (ได้บรรทัดว่าง)

ตัวอย่าง 2.2.2คำสั่งทำงานจากบนลงล่าง

PrintVsPrintln.java
public class PrintVsPrintln {
    public static void main(String[] args) {
        System.out.print("A");          // A
        System.out.print("B");          // AB     ต่อบรรทัดเดิม
        System.out.println("C");        // ABC    แล้วขึ้นบรรทัดใหม่
        System.out.println("D");        // D
        System.out.println();           // (บรรทัดว่าง)
        System.out.print("E ");
        System.out.println("F");        // E F
    }
}
ผลลัพธ์
ABC
D

E F

2.3 คอมไพล์ รัน และเริ่มอ่าน error

บน command line ให้คอมไพล์ก่อนแล้วจึงรัน (ตั้งแต่ Java 11 รันไฟล์เดียวตรง ๆ ด้วย java Hello.java ได้ด้วย)

javac Hello.java     ← คอมไพล์ ได้ไฟล์ Hello.class
java Hello           ← รัน (ไม่ต้องเติม .class)

อ่าน compile error

ถ้าโค้ดผิดไวยากรณ์ javac จะหยุดและบอกชื่อไฟล์ เลขบรรทัด และชนิดปัญหา พร้อมคัดลอกบรรทัดนั้นมาให้ และใช้ ^ ชี้ตำแหน่ง

ทดลอง error 2.3.1ลืม semicolon

MissingSemicolon.java
public class MissingSemicolon {
    public static void main(String[] args) {
        System.out.println("Start")
        System.out.println("End");
    }
}
ข้อความ error จาก javac
MissingSemicolon.java:3: error: ';' expected
        System.out.println("Start")
                                   ^

MissingSemicolon.java:3 = ไฟล์และบรรทัด, ';' expected = ชนิดปัญหา (ขาด semicolon) และ ^ ชี้ท้าย "Start") ซึ่งเป็นจุดที่ต้องเติม ;

แก้ทีละจุด

ตรวจบรรทัดที่ถูกชี้และบรรทัดก่อนหน้า เพราะบางครั้งต้นเหตุอยู่ก่อนจุดที่ถูกชี้ แล้วแก้ error แรกก่อนเสมอ error ตัวหลัง ๆ มักเป็นผลพวงของตัวแรก

ดูตัวอย่าง error อื่น ๆ ที่พบบ่อย

ทดลอง error 2.3.2สะกดชื่อผิด (ตัวพิมพ์ใหญ่-เล็ก)

WrongCase.java
public class WrongCase {
    public static void main(String[] args) {
        system.out.println("Hello");
        System.out.printn("World");
    }
}
ข้อความ error จาก javac
WrongCase.java:3: error: package system does not exist
        system.out.println("Hello");
              ^
WrongCase.java:4: error: cannot find symbol
        System.out.printn("World");
                  ^
  symbol:   method printn(String)
  location: variable out of type PrintStream

Java แยกตัวพิมพ์ใหญ่-เล็ก system ต้องเป็น System และ printn ต้องเป็น println ข้อความ cannot find symbol มักแปลว่า “สะกดผิด” หรือ “ยังไม่ได้ประกาศ”

ทดลอง error 2.3.3วงเล็บปีกกาไม่ครบคู่

MissingBrace.java
public class MissingBrace {
    public static void main(String[] args) {

    }

เปิด " แล้วไม่ปิด compiler จึงมองว่า ); เป็นส่วนหนึ่งของข้อความ แก้เป็น "Hello");
