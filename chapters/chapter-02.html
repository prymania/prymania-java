บทที่ 2 · รู้จักเครื่องมือและภาษา Java

เริ่มต้นกับ Java และโปรแกรมแรก

รู้จักเส้นทางจากไฟล์ที่เราเขียนไปจนถึงผลลัพธ์บนหน้าจอ แล้วสร้างโปรแกรม Java ขนาดเล็กด้วยตัวเอง

เมื่อจบบทนี้ นิสิตจะทำได้
  • อธิบายหน้าที่ของ JDK, JVM และ IDE
  • อ่านโครงสร้างคลาสและเมธอด main
  • คอมไพล์และรันโปรแกรมพื้นฐาน
  • เริ่มตรวจ syntax error อย่างเป็นขั้นตอน

2. จากไฟล์ข้อความเป็นโปรแกรมที่ทำงาน

โค้ด Java เป็นข้อความที่มนุษย์เขียนและอ่านได้ ก่อนทำงานต้องแปลงให้อยู่ในรูปที่ Java Virtual Machine (JVM) เข้าใจ ขั้นตอนนี้ช่วยตรวจข้อผิดพลาดด้านไวยากรณ์ก่อนเริ่มรัน

2.1 JDK, JVM และ IDE ทำหน้าที่อะไร

JDK (Java Development Kit) มีเครื่องมือพัฒนา เช่น compiler ชื่อ javac และ JVM ส่วน JVM (Java Virtual Machine) ใช้รัน bytecode ในไฟล์ .class ขณะที่ IDE คือโปรแกรมช่วยเขียนโค้ดและเรียกใช้เครื่องมือเหล่านี้

ภาพรวมการทำงาน
ไฟล์ Hello.java  →  javac  →  Hello.class  →  JVM  →  ผลลัพธ์

เราแก้ไฟล์ .java; compiler สร้าง .class; จากนั้น JVM จึงรัน bytecode

แยกคำให้ชัด

JDK ใช้พัฒนา, JVM ใช้รัน และ IDE เป็นเครื่องมืออำนวยความสะดวก โปรแกรมเดียวกันอาจใช้ IDE ต่างกันได้

Exercise 2.1เรียงขั้นตอน

เรียงสิ่งต่อไปนี้ให้เป็นลำดับการทำงาน: JVM รันโปรแกรม, เขียนไฟล์ Welcome.java, compiler สร้าง bytecode

ลำดับคำตอบ

1. เขียน Welcome.java
2. compiler แปลงเป็น bytecode ใน Welcome.class
3. JVM โหลดและรัน bytecode

ถ้าคอมไพล์ไม่ผ่าน จะยังไม่มีโปรแกรมที่พร้อมให้ JVM รัน

2.2 โครงสร้างของโปรแกรม Java

โปรแกรมเริ่มจากคลาส ภายในคลาสมีเมธอด main ซึ่งเป็นจุดเริ่มทำงานของตัวอย่างพื้นฐาน คำสั่ง Java แต่ละคำสั่งมักลงท้ายด้วย ; และบล็อกคำสั่งอยู่ระหว่างวงเล็บปีกกา

โปรแกรมแรก: Hello, Java!
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

อ่านจากด้านนอกเข้าด้านใน: คลาส Hello มี main; ภายใน main สั่งพิมพ์ข้อความหนึ่งบรรทัด

ชื่อไฟล์ต้องตรงกับคลาส public

ถ้าประกาศ public class Hello ให้บันทึกเป็น Hello.java ตัวพิมพ์เล็ก-ใหญ่ต้องตรงกันด้วย

Exercise 2.2ทักทายผู้ใช้

สร้างคลาสชื่อ Greeting ให้พิมพ์คำว่า สวัสดี Java หนึ่งบรรทัด ชื่อไฟล์ควรเป็นอะไร?

ตัวอย่างคำตอบ

public class Greeting {
    public static void main(String[] args) {
        System.out.println("สวัสดี Java");
    }
}

บันทึกไฟล์เป็น Greeting.java

2.3 คอมไพล์ รัน และเริ่มอ่าน error

ถ้าใช้ command line ให้เปิด terminal ในโฟลเดอร์ที่มีไฟล์ จากนั้นคอมไพล์ก่อนแล้วจึงรัน คำสั่งที่ขาดเครื่องหมายหรือสะกดชื่อผิดอาจทำให้ compiler แจ้งตำแหน่งที่ควรตรวจ

คำสั่งพื้นฐาน
javac Hello.java
java Hello

คำสั่งแรกสร้างไฟล์ bytecode; คำสั่งที่สองเรียกคลาส Hello มาทำงาน (ไม่ต้องเติม .class)

วิธีอ่าน error อย่างเป็นขั้นตอน
  1. อ่านข้อความเพื่อดูชนิดปัญหา
  2. หาชื่อไฟล์และเลขบรรทัด
  3. ตรวจบรรทัดนั้นและบรรทัดก่อนหน้า เช่น ;, วงเล็บ, ชื่อคลาส
  4. แก้ทีละจุดแล้วคอมไพล์ใหม่

Exercise 2.3พิมพ์สองบรรทัด

เติมคำสั่งใน main ให้แสดง My first program และ I can run Java คนละบรรทัด พร้อมใส่ comment ว่าโปรแกรมนี้ใช้ฝึกพิมพ์ข้อความ

ตัวอย่างคำตอบ

public class Main {
    public static void main(String[] args) {
        // ฝึกแสดงข้อความทางหน้าจอ
        System.out.println("My first program");
        System.out.println("I can run Java");
    }
}

// ทำให้ข้อความที่ตามมาในบรรทัดนั้นเป็น comment ไม่ใช่คำสั่งที่ถูกรัน

แบบฝึกหัดท้ายบท

เขียนและทดลองรันแต่ละข้อ ตรวจชื่อไฟล์ให้ตรงกับชื่อคลาส public

Exercise 2.4ป้ายต้อนรับ

แสดงข้อความ 3 บรรทัด: ชื่อวิชา, ชื่อของคุณ และ Ready to learn Java

ตัวอย่างคำตอบ

public class Welcome {
    public static void main(String[] args) {
        System.out.println("Java Programming");
        System.out.println("Student: Your Name");
        System.out.println("Ready to learn Java");
    }
}

เปลี่ยน Your Name เป็นชื่อของตนเอง และบันทึกเป็น Welcome.java

Exercise 2.5หาข้อผิดพลาด

โค้ดนี้มีจุดผิด ให้ระบุและแก้ไข: public class Start { public static void main(String[] args) { System.out.println("Start") } }

โค้ดที่แก้แล้ว

public class Start {
    public static void main(String[] args) {
        System.out.println("Start");
    }
}

ขาด ; หลังคำสั่ง println และต้องปิดวงเล็บปีกกาให้ครบ

Exercise 2.6ใบเสร็จอย่างง่าย

แสดงชื่อสินค้า 2 รายการ ราคารวม เส้นคั่น และคำว่า Thank you! โดยแต่ละรายการอยู่คนละบรรทัด

ตัวอย่างคำตอบ

public class Receipt {
    public static void main(String[] args) {
        System.out.println("Notebook: 18 baht");
        System.out.println("Pen: 10 baht");
        System.out.println("----------------");
        System.out.println("Total: 28 baht");
        System.out.println("Thank you!");
    }
}

เมื่อคลาสชื่อ Receipt ให้ใช้ชื่อไฟล์ Receipt.java
