บทที่ 12 · ปกป้องข้อมูลและแบ่งหน้าที่

จัดระเบียบคลาสและปกป้องข้อมูล

กำหนดขอบเขตการเข้าถึงข้อมูล ให้ object ตรวจการเปลี่ยน state และต่อยอดชนิดข้อมูลผ่าน composition หรือ inheritance

เมื่อจบบทนี้ นิสิตจะทำได้
  • เลือก access modifier ตามหน้าที่
  • ซ่อน field และเปิดพฤติกรรมผ่าน method
  • ตรวจข้อมูลเพื่อรักษา invariant
  • แยก composition ออกจาก inheritance
  • อธิบาย polymorphism จาก method override

12. ทำให้ class ปกป้องข้อมูลของตัวเอง

ถ้าเปิด field ทุกตัวเป็น public โค้ดส่วนไหนก็เปลี่ยนค่าได้ ทำให้ object กลายเป็นสถานะที่ไม่สมเหตุผลได้ง่าย การออกแบบ class ที่ดีจำกัดจุดเปลี่ยนข้อมูลและให้ method เป็นผู้รักษากฎ

12.1 public, private และ protected

access modifier กำหนดว่าโค้ดส่วนใดมองเห็นสมาชิกได้ บทนี้เน้น private เพื่อซ่อนรายละเอียดภายใน และ public สำหรับสิ่งที่ class อนุญาตให้ผู้ใช้เรียก

modifierแนวคิดใช้เมื่อ
privateใช้ภายใน class เดียวfield/state และ helper ที่ไม่ควรให้ภายนอกเรียก
ไม่มี modifierpackage-privateเข้าถึงได้จาก package เดียวกัน
protectedpackage และ subclassเมื่อออกแบบ inheritance ให้ลูกใช้
publicเปิดให้เรียกจากที่อื่นconstructor และ public API
ไม่เปิด field โดยไม่จำเป็น
class Student {
    private String name;
    private int score;

    public void printSummary() {
        System.out.println(name + ": " + score);
    }
}

ภายนอกเรียก printSummary() ได้ แต่แก้ score ตรง ๆ ไม่ได้ ต้องผ่าน method ที่ class จัดเตรียมให้

Exercise 12.1เลือก field ที่ควร private

class BankAccount เก็บเลขบัญชี, ยอดเงิน และชื่อเจ้าของ ระบุ field ที่ควร private และเหตุผล

แนวคำตอบ

ทั้งสาม field ควรเป็น private เพื่อไม่ให้โค้ดอื่นเปลี่ยนเลขบัญชี, ยอดเงิน หรือชื่อโดยข้ามกฎของ BankAccount เปิด public methods เฉพาะการอ่านหรือทำธุรกรรมที่อนุญาต

12.2 Encapsulation: ให้ method ดูแล state

encapsulation คือซ่อนรายละเอียดข้อมูลและควบคุมการใช้งานผ่าน public method ไม่ใช่แค่สร้าง getter/setter ให้ทุก field แบบอัตโนมัติ แต่เลือกเปิด operation ที่ผู้ใช้ควรทำจริง

ยอดเงินเปลี่ยนผ่าน deposit และ withdraw
class BankAccount {
    private double balance;

    public double getBalance() {
        return balance;
    }

    public void deposit(double amount) {
        if (amount > 0) balance += amount;
    }
}

ไม่มี setBalance() ให้กำหนดยอดเองโดยตรง; ยอดเปลี่ยนผ่านการฝากเงินที่มีเงื่อนไข

getter ไม่จำเป็นต้องมีทุก field

เปิด getter เท่าที่ผู้เรียกจำเป็นต้องรู้ บางข้อมูลเป็นรายละเอียดภายใน ไม่ควรเปิดให้อ่านหรือแก้จากภายนอก

Exercise 12.2เติม method ถอนเงิน

เขียน withdraw(amount) คืน boolean: ถอนสำเร็จเมื่อ amount เป็นบวกและยอดเงินพอ; มิฉะนั้นไม่เปลี่ยน balance และคืน false

ตัวอย่างคำตอบ

public boolean withdraw(double amount) {
    if (amount <= 0 || amount > balance) {
        return false;
    }
    balance -= amount;
    return true;
}

ทุกการเปลี่ยน balance เกิดภายใน method ของ object

12.3 Validation และ invariant

invariant คือกฎที่ object ต้องรักษาไว้เสมอ เช่น คะแนนอยู่ระหว่าง 0–100 หรือยอดคงเหลือไม่ติดลบ การตรวจควรอยู่ตรงจุดที่เปลี่ยน field เพื่อกันข้อมูลผิดตั้งแต่ต้น

setter ที่ปฏิเสธคะแนนนอกช่วง
class ExamResult {
    private int score;

    public boolean setScore(int score) {
        if (score < 0 || score > 100) return false;
        this.score = score;
        return true;
    }

    public int getScore() { return score; }
}

this.score คือ field; parameter ที่ชื่อ score คือค่าที่กำลังตรวจ

ทำไมต้องตรวจที่ setter?

ถ้าตรวจเฉพาะตอนแสดงผล ค่าไม่ถูกต้องอาจถูกเก็บและส่งต่อไปคำนวณแล้ว ให้ตรวจตอนรับเข้าหรือเปลี่ยน state เพื่อคง invariant ให้จริงตลอดอายุ object

Exercise 12.3ควบคุมปริมาณสินค้า

class Product มี quantity ที่ห้ามติดลบ เขียน method setQuantity คืน false เมื่อค่าใหม่ติดลบ และไม่เปลี่ยนค่าเดิม

ตัวอย่างคำตอบ

private int quantity;
public boolean setQuantity(int quantity) {
    if (quantity < 0) return false;
    this.quantity = quantity;
    return true;
}

12.4 Composition: object ประกอบด้วย object อื่น

ใช้ composition เมื่อสิ่งหนึ่ง “มี” อีกสิ่งหนึ่ง เช่น Car มี Engine หรือ Order มีรายการสินค้า class เก็บ reference ของ object ที่เป็นส่วนประกอบและส่งงานให้ object นั้น

รถมีเครื่องยนต์
class Engine {
    void start() { System.out.println("Engine started"); }
}
class Car {
    private Engine engine;
    Car(Engine engine) { this.engine = engine; }
    void start() { engine.start(); }
}

Car ไม่ได้สืบทอดจาก Engine; Car มี Engine เป็นส่วนหนึ่ง

Exercise 12.4Order มีรายการสินค้า

ออกแบบ class Order ที่เก็บรายการ Product หนึ่งรายการและจำนวน แล้วมี method คืนราคารวมของรายการ

ตัวอย่างแบบ

class Order {
    private Product product;
    private int quantity;
    Order(Product product, int quantity) {
        this.product = product;
        this.quantity = quantity;
    }
    double total() {
        return product.getPrice() * quantity;
    }
}

Order ประกอบด้วย Product และใช้ข้อมูลราคาผ่าน public method

12.5 Inheritance และ method override

ใช้ inheritance เมื่อชนิดหนึ่งเป็นชนิดย่อยของอีกชนิด เช่น Dog เป็น Animal; class ลูกใช้ field/method ที่เปิดให้สืบทอดและ override method เพื่อกำหนดพฤติกรรมเฉพาะ

class ลูกเปลี่ยนพฤติกรรม
class Animal {
    void speak() { System.out.println("..."); }
}
class Dog extends Animal {
    @Override
    void speak() { System.out.println("Woof"); }
}

@Override ช่วยให้ compiler ตรวจว่าชื่อและ signature ตรงกับ method แม่จริง

ใช้ inheritance เมื่อ “เป็นชนิดหนึ่งของ”

ถ้า relation เป็น “มีสิ่งหนึ่ง” ใช้ composition; อย่าใช้ inheritance แค่ต้องการ reuse code เพราะจะผูกโครงสร้าง class เข้าด้วยกันแน่นเกินไป

Exercise 12.5ชนิดย่อยของ Employee

สร้าง class Manager extends Employee และ override method describeRole() ให้แสดงบทบาทผู้จัดการ

ตัวอย่างคำตอบ

class Employee {
    void describeRole() { System.out.println("Employee"); }
}
class Manager extends Employee {
    @Override
    void describeRole() { System.out.println("Manager"); }
}

12.6 Polymorphism: reference แม่เรียกพฤติกรรมลูก

ตัวแปรชนิดแม่สามารถอ้าง object ชนิดลูกได้ เมื่อเรียก method ที่ถูก override Java เลือก implementation ตามชนิด object จริงขณะรัน เรียกว่า dynamic dispatch

ชนิดตัวแปรกับชนิด object ต่างกันได้
Animal animal = new Dog();
animal.speak(); // Woof

ตัวแปรประกาศเป็น Animal แต่ object จริงเป็น Dog จึงเรียก speak ของ Dog

Exercise 12.6เรียกหลายรูปแบบผ่านชนิดแม่

สร้าง Cat extends Animal ที่ override speak() แล้วเก็บ Dog และ Cat ลงใน array ชนิด Animal จากนั้นวนเรียก speak

ตัวอย่างคำตอบ

class Cat extends Animal {
    @Override
    void speak() { System.out.println("Meow"); }
}
Animal[] pets = {new Dog(), new Cat()};
for (Animal pet : pets) pet.speak();

แม้ reference ใน array เป็น Animal แต่ method ที่ทำงานตามชนิดจริงคือ Dog.speak และ Cat.speak

แบบฝึกหัดท้ายบท

เลือกความสัมพันธ์ class ให้ถูก: “มี” ใช้ composition; “เป็นชนิดย่อย” จึงพิจารณา inheritance

ออกแบบระบบร้านค้าอย่างย่อ

มี Product ที่ปกป้องราคาไม่ให้ติดลบ และ Order ที่มี Product กับจำนวนเพื่อคำนวณยอดรวม อธิบายว่า class ใดเป็น composition และควรเปิด method ใดให้ผู้ใช้เรียก
