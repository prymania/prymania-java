บทที่ 3 · ข้อมูลที่โปรแกรมนำไปใช้

ตัวแปร ชนิดข้อมูล และการคำนวณ

ตั้งชื่อให้ข้อมูล เก็บค่าที่โปรแกรมต้องใช้ แล้วคำนวณอย่างถูกต้อง เข้าใจความต่างระหว่างจำนวนเต็มกับทศนิยมตั้งแต่ต้น

เมื่อจบบทนี้ นิสิตจะทำได้
  • ประกาศและกำหนดค่าตัวแปร
  • เลือกชนิดข้อมูลพื้นฐานได้เหมาะสม
  • ใช้ตัวดำเนินการและลำดับการคำนวณ
  • หลีกเลี่ยงการหารจำนวนเต็มโดยไม่ตั้งใจ

3. เก็บข้อมูลและคำนวณด้วย Java

ตัวแปรเปรียบเหมือนกล่องที่มีชื่อและชนิด ค่าในตัวแปรอาจเปลี่ยนระหว่างที่โปรแกรมทำงาน แต่ชนิดข้อมูลจะกำหนดว่ากล่องนั้นเก็บอะไรได้และนำไปคำนวณแบบใด

3.1 ตัวแปรและการกำหนดค่า

การประกาศตัวแปรระบุชนิดและชื่อ เช่น int bookCount; จากนั้นใช้เครื่องหมาย = กำหนดค่าให้ตัวแปร ชื่อควรบอกความหมายและใช้รูปแบบ camelCase สำหรับชื่อตัวแปร

ค่าเปลี่ยนได้ตามลำดับคำสั่ง
int bookCount = 3;
bookCount = bookCount + 2;
System.out.println(bookCount); // 5

เครื่องหมาย = ใน Java หมายถึงนำค่าด้านขวามาเก็บด้านซ้าย ไม่ใช่ประโยคบอกว่าทั้งสองข้างเท่ากันตลอดเวลา

ชื่อที่อ่านแล้วเข้าใจ

ใช้ studentScore แทน x; ชื่อตัวแปรเริ่มด้วยตัวอักษรหรือ _ ได้ แต่ไม่เริ่มด้วยตัวเลข และห้ามใช้คำสงวนอย่าง class

Exercise 3.1นับจำนวนหนังสือ

กำหนดให้มีหนังสือ 4 เล่ม แล้วได้รับเพิ่มอีก 3 เล่ม เขียนคำสั่งประกาศตัวแปร อัปเดตจำนวน และพิมพ์ผล

ตัวอย่างคำตอบ

int bookCount = 4;
bookCount = bookCount + 3;
System.out.println(bookCount);

ผลลัพธ์คือ 7 และสามารถย่อบรรทัดที่สองเป็น bookCount += 3; ได้

3.2 ชนิดข้อมูลพื้นฐาน

เลือกชนิดข้อมูลจากลักษณะของค่า: int ใช้กับจำนวนเต็ม, double ใช้กับค่าทศนิยม, char ใช้กับอักขระหนึ่งตัว และ boolean เก็บ true หรือ false ส่วน String ใช้เก็บข้อความและไม่ใช่ชนิด primitive

ชนิดตัวอย่างเหมาะกับ
intint age = 19;จำนวนเต็ม เช่น อายุ จำนวนชิ้น
doubledouble height = 165.5;ตัวเลขที่มีทศนิยม เช่น ส่วนสูง ราคา
charchar grade = 'A';อักขระหนึ่งตัว ใช้ single quote
booleanboolean isReady = true;สถานะจริงหรือเท็จ
StringString name = "Mali";ข้อความ ใช้ double quote
เครื่องหมาย quote สำคัญ

'A' เป็น char; "A" เป็น String แม้หน้าตาจะคล้ายกันแต่คนละชนิด

Exercise 3.2ประกาศข้อมูลนักศึกษา

เลือกชนิดและประกาศตัวแปรสำหรับชื่อ Nida, อายุ 20 ปี, คะแนนเฉลี่ย 3.25 และสถานะลงทะเบียนแล้ว

ตัวอย่างคำตอบ

String studentName = "Nida";
int age = 20;
double averageScore = 3.25;
boolean isRegistered = true;

ใช้ String กับชื่อ, int กับอายุ, double กับคะแนนทศนิยม และ boolean กับสถานะ

3.3 ตัวดำเนินการและลำดับการคำนวณ

Java ใช้ +, -, *, / คำนวณเลข และ % หาเศษจากการหาร วงเล็บช่วยกำหนดส่วนที่ต้องคำนวณก่อน

การหารจำนวนเต็ม
System.out.println(17 / 5);   // 3
System.out.println(17 % 5);   // 2
System.out.println(17.0 / 5); // 3.4

เมื่อทั้งสองข้างของ / เป็นจำนวนเต็ม ผลหารจะตัดเศษทศนิยมทิ้ง หากต้องการทศนิยมอย่างน้อยหนึ่งข้างต้องเป็น double

ลำดับโดยย่อ

วงเล็บก่อน จากนั้นคูณ/หาร/หารเอาเศษ แล้วจึงบวก/ลบ หากระดับเดียวกันคำนวณจากซ้ายไปขวา และห้ามหารด้วยศูนย์

Exercise 3.3แบ่งของให้เท่ากัน

มีส้ม 23 ผล แบ่งให้เพื่อน 4 คนเท่า ๆ กัน จงเขียนนิพจน์หาจำนวนส้มต่อคนและจำนวนที่เหลือ โดยใช้ / และ %

ตัวอย่างคำตอบ

int oranges = 23;
int friends = 4;
int eachPersonGets = oranges / friends;
int remaining = oranges % friends;
System.out.println(eachPersonGets); // 5
System.out.println(remaining);      // 3

แต่ละคนได้ 5 ผล เหลือ 3 ผล

3.4 ค่าคงที่และการแปลงชนิดข้อมูล

ค่าที่ไม่ต้องการให้เปลี่ยนประกาศด้วย final เช่นอัตราภาษี การคำนวณระหว่างจำนวนเต็มอาจได้จำนวนเต็ม แม้เก็บลงใน double ภายหลัง ดังนั้นต้องทำให้การหารมีทศนิยมตั้งแต่ต้น

ค่าเฉลี่ยที่มีทศนิยม
int totalScore = 7;
double average = totalScore / 2.0; // 3.5

ถ้าเขียน totalScore / 2 จะได้ 3 ก่อนนำไปเก็บใน double ผลจึงกลายเป็น 3.0

แปลงชนิดอย่างตั้งใจ
int wholeNumber = 7;
double preciseNumber = (double) wholeNumber / 2;
final double TAX_RATE = 0.07;

การแปลงจาก int เป็น double ทำได้ด้วย cast; การแปลงจากทศนิยมเป็นจำนวนเต็มอาจทิ้งเศษ ควรเลือกทำเมื่อเข้าใจผลแล้ว

Exercise 3.4หาพื้นที่วงกลม

รับค่ารัศมีชนิด double คำนวณพื้นที่ด้วยสูตร area = PI × radius × radius และประกาศ PI เป็นค่าคงที่

ตัวอย่างคำตอบ

final double PI = 3.14159;
double radius = 2.5;
double area = PI * radius * radius;
System.out.println(area);

เมื่อรัศมีเท่ากับ 2.5 พื้นที่ประมาณ 19.6349375 ตารางหน่วย

แบบฝึกหัดท้ายบท

เลือกชนิดข้อมูลให้เหมาะ แล้วตรวจผลคำนวณด้วยค่าตัวอย่างอีกครั้ง

Exercise 3.5ยอดซื้อรวมภาษี

สินค้าราคา 35.50 บาท จำนวน 3 ชิ้น คำนวณยอดก่อนภาษี ภาษี 7% และยอดสุทธิ

ตัวอย่างคำตอบ

double unitPrice = 35.50;
int quantity = 3;
final double TAX_RATE = 0.07;
double subtotal = unitPrice * quantity;
double tax = subtotal * TAX_RATE;
double total = subtotal + tax;
System.out.println(subtotal); // 106.5
System.out.println(tax);      // 7.455
System.out.println(total);    // 113.955

การปัดเป็นจำนวนทศนิยม 2 ตำแหน่งจะเรียนต่อในหัวข้อการจัดรูปแบบผลลัพธ์

Exercise 3.6แปลงวินาทีเป็นเวลา

แปลง 3,665 วินาทีเป็นชั่วโมง นาที และวินาที โดยใช้การหารจำนวนเต็มและเศษจากการหาร

ตัวอย่างคำตอบ

int totalSeconds = 3665;
int hours = totalSeconds / 3600;
int remainingSeconds = totalSeconds % 3600;
int minutes = remainingSeconds / 60;
int seconds = remainingSeconds % 60;
System.out.println(hours + " ชั่วโมง " + minutes + " นาที " + seconds + " วินาที");

ผลลัพธ์คือ 1 ชั่วโมง 1 นาที 5 วินาที

Exercise 3.7ค่าเฉลี่ยแบบทศนิยม

มีคะแนน 8, 9 และ 10 คะแนน คำนวณค่าเฉลี่ยให้ได้ทศนิยมถูกต้อง ห้ามใช้การหารจำนวนเต็มโดยไม่ตั้งใจ

ตัวอย่างคำตอบ

int score1 = 8;
int score2 = 9;
int score3 = 10;
double average = (score1 + score2 + score3) / 3.0;
System.out.println(average); // 9.0

ใช้ 3.0 เพื่อให้การหารเกิดเป็นทศนิยมก่อนเก็บผล
