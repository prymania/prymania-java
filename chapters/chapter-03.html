บทที่ 3 · ข้อมูลที่โปรแกรมนำไปใช้

ตัวแปร ชนิดข้อมูล และการคำนวณ

ตั้งชื่อให้ข้อมูล เก็บค่าที่โปรแกรมต้องใช้ แล้วคำนวณอย่างถูกต้อง เข้าใจความต่างระหว่างจำนวนเต็มกับทศนิยมตั้งแต่ต้น

เมื่อจบบทนี้ นิสิตจะทำได้
  • ประกาศและกำหนดค่าตัวแปร
  • เลือกชนิดข้อมูลพื้นฐานได้เหมาะสม
  • ใช้ตัวดำเนินการและลำดับการคำนวณ
  • หลีกเลี่ยงการหารจำนวนเต็มโดยไม่ตั้งใจ

3. เก็บข้อมูลและคำนวณด้วย Java

ตัวแปรเปรียบเหมือนกล่องที่มีชื่อและชนิด ค่าในกล่องเปลี่ยนได้ระหว่างที่โปรแกรมทำงาน แต่ชนิดข้อมูลจะกำหนดว่ากล่องนั้นเก็บอะไรได้และนำไปคำนวณแบบใด ในบทนี้ทุกตัวอย่างใช้ค่าที่กำหนดในโค้ด ส่วนการรับค่าจากผู้ใช้จะเรียนในบทที่ 4

3.1 ตัวแปรและการกำหนดค่า

การประกาศตัวแปรระบุชนิดและชื่อ เช่น int bookCount; จากนั้นใช้เครื่องหมาย = กำหนดค่า หรือทำทั้งสองอย่างในบรรทัดเดียว int bookCount = 3;

รูปแบบการประกาศตัวแปร
ชนิด ชื่อ;              // ประกาศอย่างเดียว      int age;
ชื่อ = ค่า;             // กำหนดค่าภายหลัง        age = 19;
ชนิด ชื่อ = ค่า;        // ประกาศพร้อมกำหนดค่า    int age = 19;

= ใน Java แปลว่า “นำค่าด้านขวามาเก็บในตัวแปรด้านซ้าย” ไม่ใช่ “เท่ากับ” แบบคณิตศาสตร์ ดังนั้น x = x + 1 จึงถูกต้อง: คำนวณ x + 1 ก่อน แล้วเก็บกลับลงใน x

ตัวอย่าง 3.1.1 · ประกาศ กำหนดค่า และพิมพ์ พื้นฐาน

แนวคิด: ตัวแปรใช้แทนค่าได้ทุกที่ เมื่อพิมพ์ตัวแปร Java พิมพ์ค่าที่อยู่ข้างใน ไม่ใช่ชื่อ

Java source · FirstVariables.java
public class FirstVariables {
    public static void main(String[] args) {
        int age = 19;
        String name = "Mali";
        System.out.println(name);
        System.out.println(age);
        System.out.println("name");
        System.out.println("Name: " + name + ", age " + age);
    }
}
Output
Mali
19
name
Name: Mali, age 19
อธิบายทีละขั้น
  1. println(name) พิมพ์ค่า Mali
  2. println("name") มีเครื่องหมายคำพูด จึงพิมพ์คำว่า name ตรงตัว
  3. + ระหว่างข้อความกับค่า คือการต่อข้อความ

ตัวอย่าง 3.1.2 · ค่าเปลี่ยนได้ตามลำดับคำสั่ง ต่อยอด

แนวคิด: ตัวแปรเก็บได้ทีละค่า ค่าใหม่จะเขียนทับค่าเก่า ต้องไล่ค่าตามลำดับบรรทัด

Java source · ChangingValues.java
public class ChangingValues {
    public static void main(String[] args) {
        int bookCount = 3;
        System.out.println("Start: " + bookCount);
        bookCount = bookCount + 2;
        System.out.println("After +2: " + bookCount);
        bookCount = 10;
        System.out.println("Reset: " + bookCount);
        bookCount = bookCount * 2 - 1;
        System.out.println("Final: " + bookCount);
    }
}
Output
Start: 3
After +2: 5
Reset: 10
Final: 19
อธิบายทีละขั้น
  1. เริ่มที่ 3
  2. bookCount + 2 = 5 แล้วเก็บกลับ → 5
  3. กำหนดใหม่เป็น 10 (ค่า 5 หายไป)
  4. 10 × 2 − 1 = 19

Trace table ของตัวอย่างด้านบน

บรรทัดคำสั่งbookCount
3int bookCount = 3;3
5bookCount = bookCount + 2;5
7bookCount = 10;10
9bookCount = bookCount * 2 - 1;19

ตัวอย่าง 3.1.3 · สลับค่าตัวแปรสองตัว ประยุกต์

แนวคิด: ถ้าเขียน a = b; b = a; ค่าเดิมของ a จะหายก่อน จึงต้องใช้ตัวแปรชั่วคราว (temp) เก็บไว้ก่อน

Java source · SwapValues.java
public class SwapValues {
    public static void main(String[] args) {
        int a = 5;
        int b = 8;
        System.out.println("Before: a=" + a + ", b=" + b);

        int temp = a;   // เก็บค่า a ไว้ก่อน
        a = b;          // a ได้ 8
        b = temp;       // b ได้ค่าเดิมของ a คือ 5

        System.out.println("After:  a=" + a + ", b=" + b);
    }
}
Output
Before: a=5, b=8
After:  a=8, b=5
อธิบายทีละขั้น
  1. temp = 5
  2. a = 8 (ค่า 5 ของ a ถูกทับ แต่ยังอยู่ใน temp)
  3. b = temp = 5
  4. สลับสำเร็จ

ลบบรรทัด temp ออกแล้วเขียน a = b; b = a; — ทั้งสองตัวจะกลายเป็น 8

ทดลอง error 3.1.4 · ใช้ตัวแปรที่ยังไม่มีค่า ประยุกต์

แนวคิด: Java ไม่ยอมให้อ่านค่าตัวแปรที่ประกาศแล้วแต่ยังไม่ได้กำหนดค่า

Java source · VariableErrors.java
public class VariableErrors {
    public static void main(String[] args) {
        int score;
        int bonus = 5;
        System.out.println(score + bonus);
    }
}
Compile error (จาก javac จริง)
VariableErrors.java:5: error: variable score might not have been initialized
        System.out.println(score + bonus);
                           ^
อธิบายทีละขั้น
  1. variable score might not have been initialized — score ประกาศแล้วแต่ยังไม่มีค่า
  2. แก้: กำหนดค่าเริ่มต้น เช่น int score = 0;

ถ้าใช้ตัวแปรที่ไม่เคยประกาศเลย เช่น total = 10; จะได้ error อีกแบบคือ cannot find symbol ... variable total

กฎการตั้งชื่อตัวแปร
  • ประกอบด้วยตัวอักษร ตัวเลข _ หรือ $ แต่ห้ามขึ้นต้นด้วยตัวเลข (2score ผิด)
  • ห้ามมีช่องว่าง และห้ามใช้คำสงวน เช่น class, int, public
  • ตัวพิมพ์ใหญ่-เล็กต่างกัน: score กับ Score คนละตัว
  • นิยมใช้ camelCase: คำแรกตัวเล็ก คำถัดไปขึ้นต้นตัวใหญ่ เช่น studentScore, totalPrice
  • ตั้งชื่อให้สื่อความหมาย: studentScore ดีกว่า x
ลองคิดก่อน · trace ค่า
int x = 4;
int y = x * 2;
x = y + x;
y = y - 1;

สุดท้าย x และ y มีค่าเท่าไร

ดูคำตอบ

y = 8 → x = 8 + 4 = 12 → y = 7 ดังนั้น x = 12, y = 7

3.2 ชนิดข้อมูลพื้นฐาน

เลือกชนิดข้อมูลจากลักษณะของค่า: int สำหรับจำนวนเต็ม, double สำหรับทศนิยม, char สำหรับอักขระหนึ่งตัว และ boolean เก็บ true หรือ false ส่วน String ใช้เก็บข้อความและไม่ใช่ชนิด primitive (เป็นคลาส จึงขึ้นต้นด้วยตัวใหญ่)

ชนิดตัวอย่างเหมาะกับช่วงค่า/หมายเหตุ
intint age = 19;จำนวนเต็ม เช่น อายุ จำนวนชิ้นประมาณ ±2,100 ล้าน
longlong population = 66000000L;จำนวนเต็มขนาดใหญ่ลงท้ายด้วย L
doubledouble height = 165.5;ตัวเลขทศนิยม เช่น ส่วนสูง ราคาความละเอียดประมาณ 15 หลัก
charchar grade = 'A';อักขระหนึ่งตัวใช้ single quote ' '
booleanboolean isReady = true;สถานะจริง/เท็จมีแค่ true, false
StringString name = "Mali";ข้อความใช้ double quote " "
เลือกชนิดข้อมูลด้วยคำถาม 4 ข้อ
  1. เป็นข้อความหรือไม่? → String (ถ้าตัวอักษรเดียวและต้องการแบบอักขระ → char)
  2. เป็นใช่/ไม่ใช่หรือไม่? → boolean
  3. มีทศนิยมได้หรือไม่? → double
  4. เป็นจำนวนนับ/จำนวนเต็มเสมอ → int (ถ้าใหญ่มาก → long)

ตัวอย่าง 3.2.1 · ข้อมูลนักศึกษาหลายชนิด พื้นฐาน

แนวคิด: ข้อมูลแต่ละอย่างมีลักษณะต่างกัน จึงใช้ชนิดต่างกัน

Java source · StudentData.java
public class StudentData {
    public static void main(String[] args) {
        String name = "Nida";
        int age = 20;
        double gpa = 3.25;
        char section = 'B';
        boolean registered = true;

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
        System.out.println("GPA: " + gpa);
        System.out.println("Section: " + section);
        System.out.println("Registered: " + registered);
    }
}
Output
Name: Nida
Age: 20
GPA: 3.25
Section: B
Registered: true
อธิบายทีละขั้น
  1. ชื่อเป็นข้อความ → String
  2. อายุนับเป็นปีเต็ม → int
  3. เกรดเฉลี่ยมีทศนิยม → double
  4. กลุ่มเรียนเป็นตัวอักษรเดียว → char
  5. สถานะลงทะเบียน → boolean

ตัวอย่าง 3.2.2 · int กับ double แสดงผลต่างกัน ต่อยอด

แนวคิด: double แสดงจุดทศนิยมเสมอ (เช่น 5.0) และ int เก็บลง double ได้อัตโนมัติ แต่ double เก็บลง int ตรง ๆ ไม่ได้

Java source · IntVsDouble.java
public class IntVsDouble {
    public static void main(String[] args) {
        int whole = 5;
        double decimal = 5;       // int 5 ถูกขยายเป็น 5.0
        double price = 19.99;
        System.out.println(whole);
        System.out.println(decimal);
        System.out.println(price);
        System.out.println(0.1 + 0.2);
    }
}
Output
5
5.0
19.99
0.30000000000000004
อธิบายทีละขั้น
  1. whole แสดง 5
  2. decimal แสดง 5.0 แม้กำหนดด้วยเลข 5
  3. 0.1 + 0.2 ได้ 0.30000000000000004 เพราะ double เก็บทศนิยมฐานสองแบบประมาณ — ใช้ printf จัดทศนิยมเวลาแสดงผล (บทที่ 4)

ทดลอง error 3.2.3 · ชนิดไม่ตรงกัน ประยุกต์

แนวคิด: ค่าต้องเข้ากับชนิดของตัวแปร Java ตรวจตั้งแต่ตอนคอมไพล์ (strongly typed)

Java source · TypeMismatch.java
public class TypeMismatch {
    public static void main(String[] args) {
        int count = 2.5;
        String code = 'A';
        char letter = "B";
        boolean done = "true";
    }
}
Compile error (จาก javac จริง)
TypeMismatch.java:3: error: incompatible types: possible lossy conversion from double to int
        int count = 2.5;
                    ^
TypeMismatch.java:4: error: incompatible types: char cannot be converted to String
        String code = 'A';
                      ^
TypeMismatch.java:5: error: incompatible types: String cannot be converted to char
        char letter = "B";
                      ^
TypeMismatch.java:6: error: incompatible types: String cannot be converted to boolean
        boolean done = "true";
                       ^
อธิบายทีละขั้น
  1. int count = 2.5 — double ใส่ int ไม่ได้ เพราะจะเสียทศนิยม (lossy conversion)
  2. 'A' เป็น char ใส่ String ไม่ได้
  3. "B" เป็น String ใส่ char ไม่ได้
  4. "true" เป็นข้อความ ไม่ใช่ค่า boolean true
เครื่องหมาย quote สำคัญ

'A' เป็น char; "A" เป็น String; true (ไม่มี quote) เป็น boolean แม้หน้าตาคล้ายกันแต่คนละชนิด

ลองคิดก่อน · เลือกชนิด

เลือกชนิดข้อมูลสำหรับ: (ก) จำนวนพนักงาน (ข) อุณหภูมิ (ค) รหัสไปรษณีย์ 10330 (ง) มีส่วนลดหรือไม่

ดูคำตอบ

(ก) int (ข) double (ค) String — แม้เป็นตัวเลขแต่ไม่ได้นำไปคำนวณ และอาจขึ้นต้นด้วย 0 ได้ (ง) boolean

3.3 ตัวดำเนินการและลำดับการคำนวณ

Java ใช้ +, -, *, / คำนวณเลข และ % (modulo) หาเศษจากการหาร วงเล็บช่วยกำหนดส่วนที่ต้องคำนวณก่อน

ลำดับตัวดำเนินการทิศทาง
1( ) วงเล็บในสุดก่อน
2* / %ซ้าย → ขวา
3+ -ซ้าย → ขวา
4= += -= …ทำสุดท้าย

ตัวอย่าง 3.3.1 · ตัวดำเนินการพื้นฐาน พื้นฐาน

แนวคิด: ลองทุกตัวดำเนินการกับตัวเลขชุดเดียวกัน สังเกต / และ % กับจำนวนเต็ม

Java source · BasicOperators.java
public class BasicOperators {
    public static void main(String[] args) {
        int a = 17;
        int b = 5;
        System.out.println("a + b = " + (a + b));
        System.out.println("a - b = " + (a - b));
        System.out.println("a * b = " + (a * b));
        System.out.println("a / b = " + (a / b));
        System.out.println("a % b = " + (a % b));
        System.out.println("17.0 / 5 = " + (17.0 / 5));
    }
}
Output
a + b = 22
a - b = 12
a * b = 85
a / b = 3
a % b = 2
17.0 / 5 = 3.4
อธิบายทีละขั้น
  1. 17 / 5 เป็นจำนวนเต็มทั้งคู่ → ได้ 3 (ตัดเศษทิ้ง ไม่ปัดเศษ)
  2. 17 % 5 → เศษ 2 (เพราะ 5 × 3 = 15, 17 − 15 = 2)
  3. 17.0 / 5 มี double หนึ่งข้าง → ได้ 3.4
  4. ต้องใส่วงเล็บ (a + b) ไม่เช่นนั้น + จะต่อข้อความแทนการบวก

ตัวอย่าง 3.3.2 · ลำดับการคำนวณและวงเล็บ ต่อยอด

แนวคิด: คูณ/หารก่อนบวก/ลบเสมอ ถ้าต้องการลำดับอื่นให้ใส่วงเล็บ

Java source · Precedence.java
public class Precedence {
    public static void main(String[] args) {
        System.out.println(2 + 3 * 4);
        System.out.println((2 + 3) * 4);
        System.out.println(20 - 6 / 2);
        System.out.println(20 / 4 * 2);
        System.out.println(10 - 4 - 3);
        System.out.println("Sum: " + 2 + 3);
        System.out.println("Sum: " + (2 + 3));
    }
}
Output
14
20
17
10
3
Sum: 23
Sum: 5
อธิบายทีละขั้น
  1. 2 + 3 * 4 → 3 × 4 = 12 ก่อน แล้ว + 2 = 14
  2. (2 + 3) * 4 → 20
  3. 20 / 4 * 2 ระดับเดียวกัน ทำซ้ายไปขวา → 5 × 2 = 10
  4. "Sum: " + 2 + 3 ซ้ายไปขวา: ข้อความ + 2 = “Sum: 2” แล้ว + 3 = “Sum: 23” (ต่อข้อความ!)

ตัวอย่าง 3.3.3 · ใช้ / และ % แยกหลักตัวเลข ประยุกต์

แนวคิด: % 10 ได้หลักหน่วย และ / 10 ตัดหลักหน่วยทิ้ง ใช้ซ้ำเพื่อแยกทุกหลัก

Java source · DigitSplit.java
public class DigitSplit {
    public static void main(String[] args) {
        int number = 4729;
        int ones = number % 10;
        int tens = number / 10 % 10;
        int hundreds = number / 100 % 10;
        int thousands = number / 1000;
        System.out.println("Thousands: " + thousands);
        System.out.println("Hundreds: " + hundreds);
        System.out.println("Tens: " + tens);
        System.out.println("Ones: " + ones);
        System.out.println("Digit sum: " + (thousands + hundreds + tens + ones));
    }
}
Output
Thousands: 4
Hundreds: 7
Tens: 2
Ones: 9
Digit sum: 22
อธิบายทีละขั้น
  1. 4729 % 10 = 9
  2. 4729 / 10 = 472 → 472 % 10 = 2
  3. 4729 / 100 = 47 → 47 % 10 = 7
  4. 4729 / 1000 = 4
  5. ผลรวมหลัก 4 + 7 + 2 + 9 = 22

ตัวอย่าง 3.3.4 · ตัวดำเนินการแบบย่อและ ++ / -- ประยุกต์

แนวคิด: x += 5 คือ x = x + 5 และ x++ คือเพิ่มทีละ 1 ใช้บ่อยมากในลูป (บทที่ 6)

Java source · CompoundAssign.java
public class CompoundAssign {
    public static void main(String[] args) {
        int points = 10;
        points += 5;    // 15
        points -= 3;    // 12
        points *= 2;    // 24
        points /= 5;    // 4
        points %= 3;    // 1
        System.out.println("points = " + points);

        int count = 0;
        count++;
        count++;
        count--;
        System.out.println("count = " + count);
    }
}

3.4 ค่าคงที่และการแปลงชนิดข้อมูล

ค่าที่ไม่ต้องการให้เปลี่ยนประกาศด้วย final เช่นอัตราภาษี นิยมตั้งชื่อด้วยตัวพิมพ์ใหญ่คั่นด้วย _ (TAX_RATE) ส่วนการแปลงชนิด (type casting) ใช้เมื่อต้องการเปลี่ยน int ↔ double อย่างตั้งใจ

การแปลงชนิด 2 แบบ
  • Widening (อัตโนมัติ): ชนิดเล็กไปใหญ่ เช่น int → double ไม่เสียข้อมูล Java ทำให้เอง double d = 7;
  • Narrowing (ต้อง cast): ชนิดใหญ่ไปเล็ก เช่น double → int อาจเสียทศนิยม ต้องเขียน (int) เพื่อยืนยัน int n = (int) 7.9; ได้ 7 (ตัดทิ้ง ไม่ปัด)

ตัวอย่าง 3.4.1 · ค่าคงที่ด้วย final พื้นฐาน

แนวคิด: ตั้งค่าที่ใช้หลายที่ไว้เป็นค่าคงที่ ถ้าอัตราเปลี่ยนก็แก้ที่เดียว และ compiler กันไม่ให้เผลอแก้

Java source · TaxConstant.java
public class TaxConstant {
    public static void main(String[] args) {
        final double TAX_RATE = 0.07;
        double price = 35.50;
        int quantity = 3;

        double subtotal = price * quantity;
        double tax = subtotal * TAX_RATE;
        double total = subtotal + tax;

        System.out.println("Subtotal: " + subtotal);
        System.out.println("Tax: " + tax);
        System.out.println("Total: " + total);
    }
}

Tax: 7.455000000000001
Total: 113.955
อธิบายทีละขั้น
  1. subtotal = 35.50 × 3 = 106.5
  2. tax = 106.5 × 0.07 = 7.455 (Java แสดง 7.455000000000001 เพราะ double เก็บทศนิยมแบบประมาณ)
  3. total = 113.955 (บทที่ 4 จะจัดเป็นทศนิยม 2 ตำแหน่ง)

เพิ่มบรรทัด TAX_RATE = 0.1; แล้วดูว่า compiler แจ้งอะไร (cannot assign a value to final variable)

  3. ใช้ตัวแปร remain ตัวเดียวอัปเดตไปเรื่อย ๆ
  4. ตรวจผล: ผลรวมของ (ชนิด × จำนวน) ต้องเท่ากับเงินทอน

public class ChangeBreakdown {
    public static void main(String[] args) {
        int price = 1263;
        int paid = 2000;
        int change = paid - price;
        System.out.println("Change: " + change);
        int remain = change;
        int b500 = remain / 500; remain %= 500;
        int b100 = remain / 100; remain %= 100;
        int b50 = remain / 50;   remain %= 50;
        int b20 = remain / 20;   remain %= 20;
        int c10 = remain / 10;   remain %= 10;
        int c5 = remain / 5;     remain %= 5;
        int c1 = remain;
        System.out.println("500 x " + b500);
        System.out.println("100 x " + b100);
        System.out.println("50 x " + b50);
        System.out.println("20 x " + b20);
        System.out.println("10 x " + c10);
        System.out.println("5 x " + c5);
        System.out.println("1 x " + c1);
    }
}

  4. ทดลองเปลี่ยนนาทีที่โทรเป็น 120 แล้วตรวจว่าค่าโทรส่วนเกินเป็น 0

public class PhoneBill {
    public static void main(String[] args) {
        final double BASE_FEE = 199;
        final int FREE_MINUTES = 150;
        final double PER_MINUTE = 1.50;
        final double PER_GB = 20;
        final double VAT = 0.07;

        int minutesUsed = 237;
        double gbUsed = 12.5;

        int extraMinutes = Math.max(0, minutesUsed - FREE_MINUTES);
        double callCharge = extraMinutes * PER_MINUTE;
        double dataCharge = gbUsed * PER_GB;
        double beforeVat = BASE_FEE + callCharge + dataCharge;
        double vat = beforeVat * VAT;
        double total = beforeVat + vat;

        System.out.println("Extra minutes: " + extraMinutes);
        System.out.println("Call charge: " + Math.round(callCharge * 100) / 100.0);
        System.out.println("Data charge: " + Math.round(dataCharge * 100) / 100.0);
        System.out.println("Before VAT: " + Math.round(beforeVat * 100) / 100.0);
        System.out.println("VAT: " + Math.round(vat * 100) / 100.0);
        System.out.println("Total: " + Math.round(total * 100) / 100.0);
    }
}
