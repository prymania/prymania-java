บทที่ 1 · เริ่มจากการแก้ปัญหา

คิดแก้ปัญหาและออกแบบ Flowchart

การเขียนโปรแกรมเริ่มก่อนเปิด IDE: ทำความเข้าใจว่าโจทย์ต้องการอะไร วางขั้นตอนให้ชัด แล้วจึงแปลงเป็นคำสั่งของภาษา Java

เมื่อจบบทนี้ นิสิตจะทำได้
  • แยกข้อมูลเข้า วิธีประมวลผล และผลลัพธ์
  • เขียนขั้นตอนวิธีและรหัสเทียม
  • เลือกใช้สัญลักษณ์ Flowchart
  • ติดตามทางเลือกและการทำซ้ำบนผังงาน

1. จากโจทย์ไปสู่ขั้นตอน

โปรแกรมคือชุดคำสั่งที่บอกคอมพิวเตอร์ให้ทำงานเป็นลำดับ คอมพิวเตอร์ทำตามคำสั่งตรงตัวและไม่เดาใจเรา เราจึงต้องกำหนดให้ชัดว่าเริ่มจากข้อมูลใด ต้องประมวลผลอะไร และต้องแสดงคำตอบแบบไหน

กระบวนการแก้ปัญหา 4 ขั้น (ใช้ได้ทุกบท)
  1. เข้าใจโจทย์ — โจทย์ให้อะไรมา และถามอะไร (แยกเป็น Input/Output)
  2. วางแผน — คิดวิธีเปลี่ยน Input ให้เป็น Output เขียนเป็นรหัสเทียมหรือ Flowchart
  3. ลงมือเขียน — แปลงแผนเป็นคำสั่ง Java ทีละขั้น
  4. ทดสอบ — ลองข้อมูลหลายแบบ เทียบผลกับการคำนวณด้วยมือ ถ้าไม่ตรงให้ย้อนกลับไปขั้นที่ 2
เกี่ยวกับตัวอย่าง Java ในบทนี้

บทนี้เน้นการคิด ตัวอย่างหลายชิ้นจึงแสดง รหัสเทียมคู่กับโปรแกรม Java เพื่อให้เห็นว่าแผนที่คิดไว้กลายเป็นโค้ดได้อย่างไร ยังไม่ต้องจำไวยากรณ์ Java ตอนนี้ ให้สังเกตว่าแต่ละขั้นของแผนตรงกับบรรทัดใดของโค้ด ไวยากรณ์จะเรียนอย่างละเอียดตั้งแต่บทที่ 2

1.1 แยกโจทย์ด้วย Input · Process · Output

ขีดเส้นใต้ข้อมูลที่โจทย์ให้มาและสิ่งที่โจทย์ถาม แล้วจัดลง 3 ส่วน: Input คือข้อมูลที่ต้องมีก่อนเริ่มทำงาน, Process คือกฎหรือการคำนวณ, Output คือคำตอบที่ต้องการ

ขั้นตอนการแยก IPO
  1. อ่านโจทย์จนจบหนึ่งรอบ ยังไม่ต้องคิดวิธีทำ
  2. หาคำถามของโจทย์ (มักอยู่ท้ายประโยค เช่น “จงหา…”, “แสดง…”) → นี่คือ Output
  3. หาข้อมูลที่โจทย์ให้มาหรือที่ต้องถามผู้ใช้ → นี่คือ Input
  4. ถามตัวเองว่า “ถ้ามี Input แล้ว ต้องทำอะไรจึงได้ Output?” → นี่คือ Process (สูตร เงื่อนไข หรือขั้นตอน)
  5. ตรวจย้อน: Process ใช้เฉพาะข้อมูลที่อยู่ใน Input หรือค่าคงที่ที่รู้แน่นอนเท่านั้นหรือไม่

ตัวอย่างการแยก IPO จากง่ายไปซับซ้อน

หาพื้นที่สี่เหลี่ยมผืนผ้ากว้าง, ยาวพื้นที่ = กว้าง × ยาวพื้นที่
หาคะแนนเฉลี่ยจากสอบ 3 ครั้งคะแนน 3 ค่าเฉลี่ย = (ค1 + ค2 + ค3) ÷ 3คะแนนเฉลี่ย
ซื้อของแล้วจ่ายเงินสด ต้องทอนเท่าไรราคาสินค้า, เงินที่จ่ายเงินทอน = เงินที่จ่าย − ราคาเงินทอน
ซื้อครบ 500 บาทลด 10% ต้องจ่ายเท่าไรยอดซื้อถ้ายอด ≥ 500 → ลด 10% มิฉะนั้นไม่ลดยอดที่ต้องจ่าย

ตัวอย่าง 1.1.1 · IPO ของราคาสมุด → Java พื้นฐาน

แนวคิด: Input ทั้งสองค่าถูกเก็บในตัวแปร Process คือบรรทัดที่คูณ และ Output คือบรรทัดที่พิมพ์ผล

NotebookPrice.java
public class NotebookPrice {
    public static void main(String[] args) {
        // Input
        int quantity = 3;       // จำนวนเล่ม
        int pricePerBook = 18;  // ราคาต่อเล่ม (บาท)

        // Process
        int total = quantity * pricePerBook;  // 3 × 18 = 54

        System.out.println("Total = " + total + " baht");
    }
}
Output
Total = 54 baht
อธิบายทีละขั้น
  1. บรรทัด Input เก็บจำนวนเล่ม (3) และราคาต่อเล่ม (18)
  2. บรรทัด Process คำนวณ 3 × 18 = 54 แล้วเก็บใน total
  3. บรรทัด Output แสดงข้อความพร้อมค่า 54

เปลี่ยน quantity เป็น 5 แล้วทำนายผลก่อนดูเฉลยในหัว (ควรได้ 90)

ตัวอย่าง 1.1.2 · IPO ที่รับค่าจากผู้ใช้: คะแนนเฉลี่ย ต่อยอด

แนวคิด: โจทย์จริงมัก ถาม Input จากผู้ใช้ แทนการเขียนค่าตายตัวในโปรแกรม ผลลัพธ์จึงเปลี่ยนตามข้อมูลที่ป้อน

AverageScore.java
import java.util.Scanner;

public class AverageScore {
    public static void main(String[] args) {
        // เตรียมรับข้อมูลจากคีย์บอร์ด
        Scanner input = new Scanner(System.in);
        // Input: คะแนน 3 ครั้ง
        System.out.print("Score 1: ");
        double s1 = input.nextDouble();
        System.out.print("Score 2: ");
        double s2 = input.nextDouble();
        System.out.print("Score 3: ");
        double s3 = input.nextDouble();

        // Process
        // วงเล็บ: บวกให้ครบก่อน แล้วจึงหาร
        double average = (s1 + s2 + s3) / 3;

        System.out.println("Average = " + average);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Score 1: 70
Score 2: 85
Score 3: 90
Average = 81.66666666666667
อธิบายทีละขั้น
  1. โปรแกรมถามคะแนนทีละครั้ง ผู้ใช้พิมพ์ 70, 85, 90
  2. Process รวมก่อน (245) แล้วจึงหารด้วย 3 — ต้องมีวงเล็บ เพราะการหารทำก่อนการบวก
  3. Output แสดง 81.666… ซึ่งตรงกับการคำนวณด้วยมือ

ถ้าลบวงเล็บออกเป็น s1 + s2 + s3 / 3 ผลจะกลายเป็น 70 + 85 + 30 = 185 ซึ่งผิด นี่คือเหตุผลที่ต้องเขียน Process ให้ชัดก่อนเขียนโค้ด

ข้อผิดพลาดที่พบบ่อย
  • เอาคำตอบไปใส่ใน Input — คำตอบที่คำนวณเสร็จแล้วไม่ใช่ Input เพราะ Input ต้องมีก่อนเริ่มทำงาน
  • Process คลุมเครือ เช่น “คำนวณราคา” ควรเขียนเป็นสูตรชัด ๆ ว่า “ราคารวม = จำนวน × ราคาต่อหน่วย”
  • ลืมค่าคงที่ เช่น ภาษี 7% เป็นค่าที่รู้อยู่แล้ว ไม่ต้องรับจากผู้ใช้ แต่ต้องระบุใน Process
ลองคิดก่อน · ค่าน้ำประปา

“ค่าน้ำหน่วยละ 12 บาท บวกค่าบริการรายเดือน 30 บาท จงหาค่าน้ำที่ต้องจ่ายเมื่อทราบจำนวนหน่วยที่ใช้” — Input, Process, Output คืออะไร

ดูคำตอบ

Input: จำนวนหน่วยที่ใช้ · Process: ค่าน้ำ = หน่วย × 12 + 30 (12 และ 30 เป็นค่าคงที่ ไม่ใช่ Input) · Output: ค่าน้ำที่ต้องจ่าย

1.2 ขั้นตอนวิธีและรหัสเทียม (Pseudocode)

ขั้นตอนวิธี (algorithm) คือวิธีแก้ปัญหาที่เรียงเป็นขั้น ทุกขั้นชัดเจน และมีจุดจบ ส่วน รหัสเทียม (pseudocode) คือการเขียนขั้นตอนด้วยภาษาคนอย่างเป็นระเบียบ โดยยังไม่ยึดไวยากรณ์ของภาษาใด ช่วยให้คิด logic ได้โดยไม่ต้องกังวลเรื่อง ; หรือวงเล็บ

คุณสมบัติของขั้นตอนวิธีที่ดี
  • ชัดเจน — แต่ละขั้นตีความได้แบบเดียว (“เติมเกลือนิดหน่อย” ไม่ชัด, “เติมเกลือ 1 ช้อนชา” ชัด)
  • มีลำดับ — ทำขั้นใดก่อนหลังต้องแน่นอน
  • มีจุดจบ — ทำครบแล้วต้องหยุดได้เสมอ
  • ให้ผลถูกต้อง — ทุก Input ที่ถูกต้องต้องได้ Output ที่ถูกต้อง
วิธีเขียนรหัสเทียมทีละขั้น
  1. เริ่มด้วยคำว่า เริ่มต้น และจบด้วย จบ
  2. ขั้นแรกเกือบทุกครั้งคือ รับ ... (Input) ตั้งชื่อข้อมูลให้สื่อความหมาย เช่น totalMinutes
  3. ขั้นกลางคือ คำนวณ ... หรือ ตัวแปร = สูตร (Process) หนึ่งบรรทัดทำหนึ่งเรื่อง
  4. ขั้นสุดท้ายคือ แสดง ... (Output)
  5. เยื้องบรรทัดเพื่อบอกว่าคำสั่งใดอยู่ภายใต้เงื่อนไขหรือการทำซ้ำ
  6. ทดสอบรหัสเทียมด้วยมือ (dry run) โดยสมมติค่า Input แล้วเดินทีละบรรทัด
รหัสเทียม: แปลงนาทีเป็นชั่วโมงและนาทีที่เหลือ

import java.util.Scanner;

public class MinutesToHours {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Total minutes: ");
        // รับ totalMinutes
        int totalMinutes = input.nextInt();

        // หารเอาส่วนจำนวนเต็ม
        int hours = totalMinutes / 60;
        int minutes = totalMinutes % 60;  // เศษจากการหาร

        // แสดงผล
        System.out.println(hours + " hours " + minutes + " minutes");
    }
}

public class CelsiusToFahrenheit {

import java.util.Scanner;

public class PassOrFail {

การวนซ้ำ: รวมตัวเลขจนกว่าจะป้อน 0

เมื่อป้อนค่าที่ไม่ใช่ 0 ให้บวกเข้าผลรวม แล้วกลับไปรับค่าถัดไป; เมื่อป้อน 0 จึงออกจากวงซ้ำ

[กำหนด total = 0] → / รับ number / → ◇ number ≠ 0 ?

                         [total = total + number]   / แสดง total /
                                      ↓                 ↓
                                / รับ number /        (จบ)
                                      ↖ กลับไปตรวจเงื่อนไข

วงซ้ำต้องมีทางออก ในตัวอย่างนี้ค่า 0 เป็นค่าหยุด (sentinel) ถ้าไม่มีวันป้อน 0 โปรแกรมก็จะรับข้อมูลต่อไปเรื่อย ๆ

SumUntilZero.java
import java.util.Scanner;

public class SumUntilZero {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int total = 0;  // ผลรวมเริ่มที่ 0
        System.out.print("Number (0 = stop): ");
        int number = input.nextInt();  // รับค่าแรกก่อนเข้าวงซ้ำ

        while (number != 0) {        // ◇ number ≠ 0 ?
            total = total + number;  // บวกสะสม
            System.out.print("Number (0 = stop): ");
            // รับค่าใหม่ แล้ววนกลับไปตรวจ
            number = input.nextInt();
        }
        // ออกจากวงเมื่อป้อน 0
        System.out.println("Total = " + total);
    }
}
