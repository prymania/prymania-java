บทที่ 1 · เริ่มจากการแก้ปัญหา

คิดแก้ปัญหาและออกแบบ Flowchart

การเขียนโปรแกรมเริ่มก่อนเปิด IDE: ทำความเข้าใจว่าโจทย์ต้องการอะไร วางขั้นตอนให้ชัด แล้วจึงแปลงเป็นคำสั่งของภาษา Java

เมื่อจบบทนี้ นิสิตจะทำได้
  • แยกข้อมูลเข้า วิธีประมวลผล และผลลัพธ์
  • เขียนขั้นตอนวิธีและรหัสเทียม
  • เลือกใช้สัญลักษณ์ Flowchart
  • ติดตามทางเลือกและการทำซ้ำบนผังงาน

1. จากโจทย์ไปสู่ขั้นตอน

โปรแกรมคือชุดคำสั่งที่บอกคอมพิวเตอร์ให้ทำงานเป็นลำดับ คอมพิวเตอร์ทำตามคำสั่งตรงตัว เราจึงต้องกำหนดให้ชัดว่าเริ่มจากข้อมูลใด ต้องประมวลผลอะไร และต้องแสดงคำตอบแบบไหน

1.1 แยกโจทย์ด้วย Input · Process · Output

ขีดเส้นใต้ข้อมูลที่โจทย์ให้มาและสิ่งที่โจทย์ถาม แล้วจัดลง 3 ส่วน: Input คือข้อมูลก่อนเริ่มทำงาน, Process คือกฎหรือการคำนวณ, Output คือคำตอบที่ต้องการ

ตัวอย่าง: คำนวณราคารวม

ซื้อสมุด 3 เล่ม ราคาเล่มละ 18 บาท

  • Input: จำนวนเล่ม 3 และราคาต่อเล่ม 18
  • Process: ราคารวม = จำนวนเล่ม × ราคาต่อเล่ม
  • Output: 54 บาท
จำให้แม่น

คำตอบที่คำนวณเสร็จแล้วไม่ใช่ Input เพราะ Input ต้องมีให้ก่อนเริ่มทำงาน ส่วน Process คือวิธีเปลี่ยน Input ให้เป็น Output

Exercise 1.1หาค่าเฉลี่ยคะแนน

รับคะแนนสอบ 3 ครั้ง แล้วรายงานคะแนนเฉลี่ย จงระบุ Input, Process และ Output โดยยังไม่ต้องเขียน Java

แนวคำตอบ

Input = คะแนนทั้ง 3 ครั้ง · Process = รวมคะแนนแล้วหารด้วย 3 · Output = คะแนนเฉลี่ย

average = (score1 + score2 + score3) / 3

เปลี่ยนชื่อตัวแปรได้ แต่ต้องนำคะแนนทั้งสามค่ามารวมแล้วหารด้วย 3

1.2 ขั้นตอนวิธีและรหัสเทียม (Pseudocode)

ขั้นตอนวิธี (algorithm) คือวิธีแก้ปัญหาที่เรียงเป็นขั้นและมีจุดจบ ส่วน รหัสเทียม เขียนขั้นตอนด้วยภาษาคนอย่างเป็นระเบียบ โดยยังไม่ยึดไวยากรณ์ของ Java

ตัวอย่าง: แปลงนาทีเป็นชั่วโมงและนาทีที่เหลือ
เริ่มต้น
    รับ totalMinutes
    hours = totalMinutes หารเอาส่วนจำนวนเต็มด้วย 60
    minutes = totalMinutes เศษจากการหารด้วย 60
    แสดง hours และ minutes
จบ

เมื่อรับ 135 นาที จะได้ 2 ชั่วโมงและเหลือ 15 นาที

รหัสเทียมที่อ่านง่าย

ใช้คำกริยาชัด ๆ เช่น รับ, คำนวณ, เปรียบเทียบ, แสดง และเยื้องบรรทัดเพื่อบอกว่าคำสั่งใดเป็นขั้นย่อย

Exercise 1.2คำนวณเวลาที่เหลือ

เขียนรหัสเทียมรับจำนวนวินาที แล้วแปลงเป็นจำนวนนาทีเต็มและวินาทีที่เหลือ เช่น 130 วินาทีเป็น 2 นาที 10 วินาที

รหัสเทียมตัวอย่าง

เริ่มต้น
    รับ totalSeconds
    minutes = totalSeconds หารเอาส่วนจำนวนเต็มด้วย 60
    seconds = totalSeconds เศษจากการหารด้วย 60
    แสดง minutes, "นาที", seconds, "วินาที"
จบ

ตรวจด้วย 130: หารเอาส่วนจำนวนเต็มได้ 2 และเศษเท่ากับ 10

1.3 สัญลักษณ์และลำดับของ Flowchart

Flowchart คือแผนภาพแสดงลำดับการทำงาน ลูกศรบอกทิศทาง และรูปทรงบอกหน้าที่ของแต่ละขั้น

สัญลักษณ์หน้าที่ตัวอย่าง
วงรีเริ่มต้นหรือสิ้นสุดเริ่มต้น, จบ
สี่เหลี่ยมด้านขนานรับข้อมูลหรือแสดงผลรับความกว้าง, แสดงพื้นที่
สี่เหลี่ยมผืนผ้าประมวลผลหรือกำหนดค่าพื้นที่ = กว้าง × ยาว
สี่เหลี่ยมข้าวหลามตัดตรวจสอบเงื่อนไขคะแนน ≥ 50?
ลูกศรเชื่อมและกำหนดทิศทางบนลงล่างหรือซ้ายไปขวา
ตัวอย่าง: พื้นที่สี่เหลี่ยมผืนผ้า
(วงรี) เริ่มต้น
    ↓
(ด้านขนาน) รับ width, height
    ↓
(สี่เหลี่ยม) area = width × height
    ↓
(ด้านขนาน) แสดง area
    ↓
(วงรี) จบ

Exercise 1.3แปลงอุณหภูมิ

วางลำดับ Flowchart สำหรับรับอุณหภูมิเซลเซียส คำนวณฟาเรนไฮต์ด้วยสูตร F = C × 9 / 5 + 32 แล้วแสดงผล ระบุสัญลักษณ์ของแต่ละขั้น

ลำดับผังงานตัวอย่าง

(วงรี) เริ่มต้น
    ↓
(ด้านขนาน) รับ C
    ↓
(สี่เหลี่ยม) F = C × 9 / 5 + 32
    ↓
(ด้านขนาน) แสดง F
    ↓
(วงรี) จบ

ลำดับคือรับค่า → คำนวณ → แสดงผล

1.4 ทางเลือกและการทำซ้ำในผังงาน

เมื่อมี ทางเลือก ให้ใช้รูปข้าวหลามตัดเขียนคำถามที่มีผลลัพธ์ เช่น ใช่/ไม่ใช่ แล้ววาดลูกศรแยกทาง ส่วน การทำซ้ำ ใช้ลูกศรวนกลับไปยังเงื่อนไขที่ต้องตรวจใหม่

ตัวอย่าง: ตรวจสอบการสอบผ่าน
(เริ่มต้น) → / รับ score / → ◇ score ≥ 50 ?
                                  ↙ ใช่       ไม่ใช่ ↘
                      / แสดง "ผ่าน" /   / แสดง "ไม่ผ่าน" /
                                  ↘             ↙
                                       (จบ)

เงื่อนไขต้องมีทางออกครบทุกกรณี มิฉะนั้นบางค่าอาจไม่มีขั้นตอนรองรับ

การวนซ้ำ: รวมตัวเลขจนกว่าจะป้อน 0

เมื่อป้อนค่าที่ไม่ใช่ 0 ให้บวกเข้าผลรวม แล้วกลับไปรับค่าถัดไป; เมื่อป้อน 0 จึงออกจากวงซ้ำ

[กำหนด total = 0] → / รับ number / → ◇ number ≠ 0 ?
                                      ↙ ใช่          ไม่ใช่ ↘
                         [total = total + number]   / แสดง total /
                                      ↓                 ↓
                                / รับ number /        (จบ)
                                      ↖ กลับไปตรวจเงื่อนไข

วงซ้ำต้องมีทางออก ในตัวอย่างนี้ค่า 0 เป็นค่าหยุด (sentinel) ถ้าไม่มีวันป้อน 0 โปรแกรมก็จะรับข้อมูลต่อไปเรื่อย ๆ

Exercise 1.4คิดค่าจอดรถ

จอดไม่เกิน 1 ชั่วโมงคิด 0 บาท ถ้าเกิน 1 ชั่วโมงคิด 20 บาท จงเขียนเงื่อนไขและผลลัพธ์ทั้งสองทางเป็นรหัสเทียม

รหัสเทียมตัวอย่าง

เริ่มต้น
    รับ hours
    ถ้า hours ≤ 1
        fee = 0
    มิฉะนั้น
        fee = 20
    แสดง fee
จบ

บน Flowchart จุดตรวจ hours ≤ 1? ใช้รูปข้าวหลามตัดและแยกทางใช่/ไม่ใช่

แบบฝึกหัดท้ายบท

ลองทำแต่ละข้อก่อนเปิดเฉลย เขียนคำตอบเป็น IPO, รหัสเทียม หรือผังงานตามที่โจทย์กำหนด

Exercise 1.5รั้วสวนผัก

รับความกว้างและความยาวของสวน แล้วหาความยาวรั้วรอบสวน (ไม่คิดประตู) ระบุ IPO และเขียนรหัสเทียม

คำตอบตัวอย่าง

Input: width, length · Process: perimeter = 2 × (width + length) · Output: ความยาวรั้ว

เริ่มต้น
    รับ width, length
    perimeter = 2 × (width + length)
    แสดง perimeter
จบ

Exercise 1.6ค่าล่วงเวลา

ค่าจ้างปกติชั่วโมงละ 100 บาท ไม่เกิน 40 ชั่วโมง ชั่วโมงที่เกินได้ 150 บาทต่อชั่วโมง จงเขียนรหัสเทียมคำนวณค่าจ้างรวม

คำตอบตัวอย่าง

เริ่มต้น
    รับ hours
    ถ้า hours ≤ 40
        pay = hours × 100
    มิฉะนั้น
        overtime = hours - 40
        pay = 40 × 100 + overtime × 150
    แสดง pay
จบ

คิด 40 ชั่วโมงแรกในอัตราปกติ แล้วคิดเฉพาะชั่วโมงที่เกินในอัตราล่วงเวลา

Exercise 1.7สรุปผลสอบ

รับคะแนน 3 วิชา หาค่าเฉลี่ย และแสดง “ผ่าน” เมื่อค่าเฉลี่ยตั้งแต่ 50 ขึ้นไป มิฉะนั้นแสดง “ไม่ผ่าน” จงเขียนรหัสเทียมพร้อมจุดตัดสินใจใน Flowchart

คำตอบตัวอย่าง

เริ่มต้น
    รับ score1, score2, score3
    average = (score1 + score2 + score3) / 3
    ถ้า average ≥ 50
        แสดง "ผ่าน"
    มิฉะนั้น
        แสดง "ไม่ผ่าน"
จบ

จุดตัดสินใจบนผังงานคือ average ≥ 50? ซึ่งมีผลลัพธ์สองทาง
