บทที่ 1 · เริ่มจากการแก้ปัญหา

คิดแก้ปัญหาและออกแบบ Flowchart

การเขียนโปรแกรมเริ่มก่อนเปิด IDE: ทำความเข้าใจว่าโจทย์ต้องการอะไร วางขั้นตอนให้ชัด แล้วจึงแปลงเป็นคำสั่งของภาษา Java

เมื่อจบบทนี้ นิสิตจะทำได้
  • แยกข้อมูลเข้า วิธีประมวลผล และผลลัพธ์
  • เขียนขั้นตอนวิธีและรหัสเทียม
  • เลือกใช้สัญลักษณ์ Flowchart
  • ติดตามทางเลือกและการทำซ้ำบนผังงาน

1. จากโจทย์ไปสู่ขั้นตอน

โปรแกรมคือชุดคำสั่งที่บอกคอมพิวเตอร์ให้ทำงานเป็นลำดับ คอมพิวเตอร์ทำตามคำสั่งตรงตัวและไม่เดาใจเรา เราจึงต้องกำหนดให้ชัดว่าเริ่มจากข้อมูลใด ต้องประมวลผลอะไร และต้องแสดงคำตอบแบบไหน

กระบวนการแก้ปัญหา 4 ขั้น (ใช้ได้ทุกบท)
  1. เข้าใจโจทย์ — โจทย์ให้อะไรมา และถามอะไร (แยกเป็น Input/Output)
  2. วางแผน — คิดวิธีเปลี่ยน Input ให้เป็น Output เขียนเป็นรหัสเทียมหรือ Flowchart
  3. ลงมือเขียน — แปลงแผนเป็นคำสั่ง Java ทีละขั้น
  4. ทดสอบ — ลองข้อมูลหลายแบบ เทียบผลกับการคำนวณด้วยมือ ถ้าไม่ตรงให้ย้อนกลับไปขั้นที่ 2
เกี่ยวกับตัวอย่าง Java ในบทนี้

บทนี้เน้นการคิด ตัวอย่างหลายชิ้นจึงแสดง รหัสเทียมคู่กับโปรแกรม Java เพื่อให้เห็นว่าแผนที่คิดไว้กลายเป็นโค้ดได้อย่างไร ยังไม่ต้องจำไวยากรณ์ Java ตอนนี้ ให้สังเกตว่าแต่ละขั้นของแผนตรงกับบรรทัดใดของโค้ด ไวยากรณ์จะเรียนอย่างละเอียดตั้งแต่บทที่ 2

1.1 แยกโจทย์ด้วย Input · Process · Output

ขีดเส้นใต้ข้อมูลที่โจทย์ให้มาและสิ่งที่โจทย์ถาม แล้วจัดลง 3 ส่วน: Input คือข้อมูลที่ต้องมีก่อนเริ่มทำงาน, Process คือกฎหรือการคำนวณ, Output คือคำตอบที่ต้องการ

ขั้นตอนการแยก IPO
  1. อ่านโจทย์จนจบหนึ่งรอบ ยังไม่ต้องคิดวิธีทำ
  2. หาคำถามของโจทย์ (มักอยู่ท้ายประโยค เช่น “จงหา…”, “แสดง…”) → นี่คือ Output
  3. หาข้อมูลที่โจทย์ให้มาหรือที่ต้องถามผู้ใช้ → นี่คือ Input
  4. ถามตัวเองว่า “ถ้ามี Input แล้ว ต้องทำอะไรจึงได้ Output?” → นี่คือ Process (สูตร เงื่อนไข หรือขั้นตอน)
  5. ตรวจย้อน: Process ใช้เฉพาะข้อมูลที่อยู่ใน Input หรือค่าคงที่ที่รู้แน่นอนเท่านั้นหรือไม่

ตัวอย่างการแยก IPO จากง่ายไปซับซ้อน

โจทย์InputProcessOutput
ซื้อสมุด 3 เล่ม ราคาเล่มละ 18 บาท จ่ายเท่าไรจำนวนเล่ม, ราคาต่อเล่มราคารวม = จำนวน × ราคาราคารวม
หาพื้นที่สี่เหลี่ยมผืนผ้ากว้าง, ยาวพื้นที่ = กว้าง × ยาวพื้นที่
หาคะแนนเฉลี่ยจากสอบ 3 ครั้งคะแนน 3 ค่าเฉลี่ย = (ค1 + ค2 + ค3) ÷ 3คะแนนเฉลี่ย
ซื้อของแล้วจ่ายเงินสด ต้องทอนเท่าไรราคาสินค้า, เงินที่จ่ายเงินทอน = เงินที่จ่าย − ราคาเงินทอน
ซื้อครบ 500 บาทลด 10% ต้องจ่ายเท่าไรยอดซื้อถ้ายอด ≥ 500 → ลด 10% มิฉะนั้นไม่ลดยอดที่ต้องจ่าย

ตัวอย่าง 1.1.1 · IPO ของราคาสมุด → Java พื้นฐาน

แนวคิด: Input ทั้งสองค่าถูกเก็บในตัวแปร Process คือบรรทัดที่คูณ และ Output คือบรรทัดที่พิมพ์ผล

Java source · NotebookPrice.java
public class NotebookPrice {
    public static void main(String[] args) {
        // Input
        int quantity = 3;
        int pricePerBook = 18;

        // Process
        int total = quantity * pricePerBook;

        // Output
        System.out.println("Total = " + total + " baht");
    }
}
Output
Total = 54 baht
อธิบายทีละขั้น
  1. บรรทัด Input เก็บจำนวนเล่ม (3) และราคาต่อเล่ม (18)
  2. บรรทัด Process คำนวณ 3 × 18 = 54 แล้วเก็บใน total
  3. บรรทัด Output แสดงข้อความพร้อมค่า 54

เปลี่ยน quantity เป็น 5 แล้วทำนายผลก่อนดูเฉลยในหัว (ควรได้ 90)

ตัวอย่าง 1.1.2 · IPO ที่รับค่าจากผู้ใช้: คะแนนเฉลี่ย ต่อยอด

แนวคิด: โจทย์จริงมัก ถาม Input จากผู้ใช้ แทนการเขียนค่าตายตัวในโปรแกรม ผลลัพธ์จึงเปลี่ยนตามข้อมูลที่ป้อน

Java source · AverageScore.java
import java.util.Scanner;

public class AverageScore {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        // Input: คะแนน 3 ครั้ง
        System.out.print("Score 1: ");
        double s1 = input.nextDouble();
        System.out.print("Score 2: ");
        double s2 = input.nextDouble();
        System.out.print("Score 3: ");
        double s3 = input.nextDouble();

        // Process
        double average = (s1 + s2 + s3) / 3;

        // Output
        System.out.println("Average = " + average);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Score 1: 70
Score 2: 85
Score 3: 90
Average = 81.66666666666667
อธิบายทีละขั้น
  1. โปรแกรมถามคะแนนทีละครั้ง ผู้ใช้พิมพ์ 70, 85, 90
  2. Process รวมก่อน (245) แล้วจึงหารด้วย 3 — ต้องมีวงเล็บ เพราะการหารทำก่อนการบวก
  3. Output แสดง 81.666… ซึ่งตรงกับการคำนวณด้วยมือ

ถ้าลบวงเล็บออกเป็น s1 + s2 + s3 / 3 ผลจะกลายเป็น 70 + 85 + 30 = 185 ซึ่งผิด นี่คือเหตุผลที่ต้องเขียน Process ให้ชัดก่อนเขียนโค้ด

ข้อผิดพลาดที่พบบ่อย
  • เอาคำตอบไปใส่ใน Input — คำตอบที่คำนวณเสร็จแล้วไม่ใช่ Input เพราะ Input ต้องมีก่อนเริ่มทำงาน
  • Process คลุมเครือ เช่น “คำนวณราคา” ควรเขียนเป็นสูตรชัด ๆ ว่า “ราคารวม = จำนวน × ราคาต่อหน่วย”
  • ลืมค่าคงที่ เช่น ภาษี 7% เป็นค่าที่รู้อยู่แล้ว ไม่ต้องรับจากผู้ใช้ แต่ต้องระบุใน Process
ลองคิดก่อน · ค่าน้ำประปา

“ค่าน้ำหน่วยละ 12 บาท บวกค่าบริการรายเดือน 30 บาท จงหาค่าน้ำที่ต้องจ่ายเมื่อทราบจำนวนหน่วยที่ใช้” — Input, Process, Output คืออะไร

ดูคำตอบ

Input: จำนวนหน่วยที่ใช้ · Process: ค่าน้ำ = หน่วย × 12 + 30 (12 และ 30 เป็นค่าคงที่ ไม่ใช่ Input) · Output: ค่าน้ำที่ต้องจ่าย

1.2 ขั้นตอนวิธีและรหัสเทียม (Pseudocode)

ขั้นตอนวิธี (algorithm) คือวิธีแก้ปัญหาที่เรียงเป็นขั้น ทุกขั้นชัดเจน และมีจุดจบ ส่วน รหัสเทียม (pseudocode) คือการเขียนขั้นตอนด้วยภาษาคนอย่างเป็นระเบียบ โดยยังไม่ยึดไวยากรณ์ของภาษาใด ช่วยให้คิด logic ได้โดยไม่ต้องกังวลเรื่อง ; หรือวงเล็บ

คุณสมบัติของขั้นตอนวิธีที่ดี
  • ชัดเจน — แต่ละขั้นตีความได้แบบเดียว (“เติมเกลือนิดหน่อย” ไม่ชัด, “เติมเกลือ 1 ช้อนชา” ชัด)
  • มีลำดับ — ทำขั้นใดก่อนหลังต้องแน่นอน
  • มีจุดจบ — ทำครบแล้วต้องหยุดได้เสมอ
  • ให้ผลถูกต้อง — ทุก Input ที่ถูกต้องต้องได้ Output ที่ถูกต้อง
วิธีเขียนรหัสเทียมทีละขั้น
  1. เริ่มด้วยคำว่า เริ่มต้น และจบด้วย จบ
  2. ขั้นแรกเกือบทุกครั้งคือ รับ ... (Input) ตั้งชื่อข้อมูลให้สื่อความหมาย เช่น totalMinutes
  3. ขั้นกลางคือ คำนวณ ... หรือ ตัวแปร = สูตร (Process) หนึ่งบรรทัดทำหนึ่งเรื่อง
  4. ขั้นสุดท้ายคือ แสดง ... (Output)
  5. เยื้องบรรทัดเพื่อบอกว่าคำสั่งใดอยู่ภายใต้เงื่อนไขหรือการทำซ้ำ
  6. ทดสอบรหัสเทียมด้วยมือ (dry run) โดยสมมติค่า Input แล้วเดินทีละบรรทัด
รหัสเทียม: แปลงนาทีเป็นชั่วโมงและนาทีที่เหลือ
เริ่มต้น
    รับ totalMinutes
    hours = totalMinutes หารเอาส่วนจำนวนเต็มด้วย 60
    minutes = totalMinutes เศษจากการหารด้วย 60
    แสดง hours และ minutes
จบ

Dry run ด้วย 135 นาที: 135 ÷ 60 ได้ 2 เศษ 15 → แสดง “2 ชั่วโมง 15 นาที”

ตัวอย่าง 1.2.1 · รหัสเทียมแปลงนาที → Java พื้นฐาน

แนวคิด: แต่ละบรรทัดของรหัสเทียมกลายเป็นคำสั่ง Java หนึ่งบรรทัด “หารเอาส่วนจำนวนเต็ม” คือ / กับจำนวนเต็ม และ “เศษ” คือ %

Java source · MinutesToHours.java
import java.util.Scanner;

public class MinutesToHours {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Total minutes: ");
        int totalMinutes = input.nextInt();      // รับ totalMinutes

        int hours = totalMinutes / 60;           // หารเอาส่วนจำนวนเต็ม
        int minutes = totalMinutes % 60;         // เศษจากการหาร

        System.out.println(hours + " hours " + minutes + " minutes");
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Total minutes: 135
2 hours 15 minutes
อธิบายทีละขั้น
  1. totalMinutes = 135
  2. 135 / 60 กับจำนวนเต็มได้ 2 (ตัดทศนิยมทิ้ง)
  3. 135 % 60 ได้เศษ 15
  4. แสดง 2 hours 15 minutes

ป้อน 59 หรือ 60 แล้วดูว่าได้อะไร — ค่าขอบแบบนี้ควรนำไปทดสอบทุกครั้ง

ตัวอย่าง 1.2.2 · ขั้นตอนวิธีหลายขั้น: ทอนเงินเป็นธนบัตร ประยุกต์

แนวคิด: เมื่อโจทย์ซับซ้อนขึ้น ให้แตกเป็นขั้นที่ซ้ำรูปแบบเดิม: หาจำนวนธนบัตรใบใหญ่ก่อน แล้วนำ “เงินที่เหลือ” ไปคิดใบถัดไป

Java source · BanknoteChange.java
import java.util.Scanner;

public class BanknoteChange {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Amount: ");
        int amount = input.nextInt();

        int thousand = amount / 1000;   // จำนวนใบ 1000
        amount = amount % 1000;         // เงินที่เหลือ
        int hundred = amount / 100;     // จำนวนใบ 100
        amount = amount % 100;
        int twenty = amount / 20;       // จำนวนใบ 20
        amount = amount % 20;

        System.out.println("1000 x " + thousand);
        System.out.println("100 x " + hundred);
        System.out.println("20 x " + twenty);
        System.out.println("coins left: " + amount);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Amount: 1370
1000 x 1
100 x 3
20 x 3
coins left: 10
อธิบายทีละขั้น
  1. รหัสเทียมคือ: รับ amount → ใบ1000 = amount ÷ 1000 → amount = เศษ → ใบ100 = amount ÷ 100 → … → แสดงผล
  2. 1370 ÷ 1000 = 1 ใบ เหลือ 370
  3. 370 ÷ 100 = 3 ใบ เหลือ 70
  4. 70 ÷ 20 = 3 ใบ เหลือ 10 (เป็นเหรียญ)

สังเกตว่าขั้น “หาร แล้วเก็บเศษ” ซ้ำกัน 3 ครั้ง การมองเห็นรูปแบบที่ซ้ำเป็นทักษะสำคัญ ในบทที่ 6 จะใช้ลูปลดโค้ดซ้ำแบบนี้

รหัสเทียมที่อ่านง่าย

ใช้คำกริยาชัด ๆ เช่น รับ, คำนวณ, เปรียบเทียบ, แสดง และเยื้องบรรทัดเพื่อบอกว่าคำสั่งใดเป็นขั้นย่อย หลีกเลี่ยงประโยคยาวที่ทำหลายเรื่องในบรรทัดเดียว

ลองคิดก่อน · dry run

ใช้รหัสเทียมแปลงนาทีด้านบนกับ Input 200 จะแสดงอะไร

ดูคำตอบ

200 ÷ 60 = 3 เศษ 20 → แสดง 3 ชั่วโมง 20 นาที

1.3 สัญลักษณ์และลำดับของ Flowchart

Flowchart (ผังงาน) คือแผนภาพแสดงลำดับการทำงาน ลูกศรบอกทิศทาง และรูปทรงบอกหน้าที่ของแต่ละขั้น เหมาะสำหรับมองภาพรวมและอธิบายให้คนอื่นเข้าใจ โดยเฉพาะเมื่อมีทางแยกหรือการวนซ้ำ

สัญลักษณ์หน้าที่ตัวอย่างตรงกับ Java (จะได้เรียน)
วงรีเริ่มต้นหรือสิ้นสุดเริ่มต้น, จบmain เริ่ม / จบ
สี่เหลี่ยมด้านขนานรับข้อมูลหรือแสดงผลรับความกว้าง, แสดงพื้นที่Scanner, println
สี่เหลี่ยมผืนผ้าประมวลผลหรือกำหนดค่าพื้นที่ = กว้าง × ยาวarea = w * h;
สี่เหลี่ยมข้าวหลามตัดตรวจสอบเงื่อนไข (ใช่/ไม่ใช่)คะแนน ≥ 50?if, while
ลูกศรเชื่อมและกำหนดทิศทางบนลงล่างหรือซ้ายไปขวาลำดับคำสั่ง
ขั้นตอนวาด Flowchart จากรหัสเทียม
  1. วาดวงรี “เริ่มต้น” ด้านบนสุด
  2. แปลงบรรทัด รับ/แสดง เป็นสี่เหลี่ยมด้านขนาน
  3. แปลงบรรทัด คำนวณ/กำหนดค่า เป็นสี่เหลี่ยมผืนผ้า
  4. แปลงบรรทัด ถ้า… เป็นข้าวหลามตัด แล้วเขียนป้ายบนลูกศรขาออกทั้งสองเส้น (ใช่/ไม่ใช่)
  5. เชื่อมทุกรูปด้วยลูกศร ตรวจว่าทุกเส้นทางไปถึงวงรี “จบ” ได้

1.4 ทางเลือกและการทำซ้ำในผังงาน

เมื่อมี ทางเลือก ให้ใช้รูปข้าวหลามตัดเขียนคำถามที่ตอบได้ว่า ใช่/ไม่ใช่ แล้ววาดลูกศรแยกทาง ส่วน การทำซ้ำ ใช้ลูกศรวนกลับไปยังเงื่อนไขที่ต้องตรวจใหม่ โปรแกรมเกือบทุกโปรแกรมประกอบจาก 3 โครงสร้างนี้: ลำดับ (sequence), ทางเลือก (selection) และ การทำซ้ำ (repetition)

ทางเลือก 2 ทาง: ตรวจสอบการสอบผ่าน
(เริ่มต้น) → / รับ score / → ◇ score ≥ 50 ?

                                  ↘             ↙
                                       (จบ)

การวนซ้ำ: รวมตัวเลขจนกว่าจะป้อน 0

เมื่อป้อนค่าที่ไม่ใช่ 0 ให้บวกเข้าผลรวม แล้วกลับไปรับค่าถัดไป; เมื่อป้อน 0 จึงออกจากวงซ้ำ

[กำหนด total = 0] → / รับ number / → ◇ number ≠ 0 ?
                                      ↙ ใช่          ไม่ใช่ ↘
                         [total = total + number]   / แสดง total /
                                      ↓                 ↓
                                / รับ number /        (จบ)
                                      ↖ กลับไปตรวจเงื่อนไข

วงซ้ำต้องมีทางออก ในตัวอย่างนี้ค่า 0 เป็นค่าหยุด (sentinel) ถ้าไม่มีวันป้อน 0 โปรแกรมก็จะรับข้อมูลต่อไปเรื่อย ๆ

Java source · SumUntilZero.java
import java.util.Scanner;

public class SumUntilZero {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int total = 0;
        System.out.print("Number (0 = stop): ");
        int number = input.nextInt();

        while (number != 0) {
            total = total + number;
            System.out.print("Number (0 = stop): ");
            number = input.nextInt();
        }
        System.out.println("Total = " + total);
    }
}

  2. รับ 12 → total = 17

Exercise 1.2IPO ของพื้นที่และเส้นรอบวงกลม★ ง่าย

รับรัศมีของวงกลม แล้วแสดงทั้ง พื้นที่ (πr²) และ เส้นรอบวง (2πr) ใช้ π = 3.14159

สิ่งที่ต้องทำ

  2. ระบุ Process สองสูตร และบอกว่า π เป็น Input หรือค่าคงที่
  3. ระบุ Output (มีกี่ค่า?)
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

import java.util.Scanner;

public class CircleIPO {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        final double PI = 3.14159;
        System.out.print("Radius: ");
        double r = input.nextDouble();
        double area = PI * r * r;
        double circumference = 2 * PI * r;
        System.out.println("Area = " + area);
        System.out.println("Circumference = " + circumference);
    }
}

import java.util.Scanner;

Exercise 1.7ค่าจ้างและค่าล่วงเวลา★★ ปานกลาง

ค่าจ้างปกติชั่วโมงละ 100 บาท สำหรับ 40 ชั่วโมงแรก ชั่วโมงที่เกิน 40 ได้ชั่วโมงละ 150 บาท รับจำนวนชั่วโมงทำงานในสัปดาห์ แล้วแสดงค่าจ้างรวม

สิ่งที่ต้องทำ
  1. แยกกรณี “ไม่เกิน 40” และ “เกิน 40”
  2. กรณีเกิน: ค่าจ้าง = 40 × 100 + (ชั่วโมง − 40) × 150
  3. dry run ด้วย 38 และ 45 ชั่วโมง
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
ครั้งที่ 1
Hours worked: 38
Pay = 3800 baht
ครั้งที่ 2
Hours worked: 45
Pay = 4750 baht

ตัวอย่างคำตอบ

เริ่มต้น
    รับ hours
    ถ้า hours ≤ 40
        pay = hours × 100
    มิฉะนั้น
        pay = 40 × 100 + (hours − 40) × 150
    แสดง pay
จบ

45 ชั่วโมง: 4000 + 5 × 150 = 4750 บาท

import java.util.Scanner;

public class OvertimePay {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Hours worked: ");
        int hours = input.nextInt();
        int pay;
        if (hours <= 40) {
            pay = hours * 100;
        } else {
            pay = 40 * 100 + (hours - 40) * 150;
        }
        System.out.println("Pay = " + pay + " baht");
    }
}

Exercise 1.8สรุปผลสอบและเกรด★★★ ท้าทาย

รับคะแนน 3 วิชา (เต็มวิชาละ 100) หาค่าเฉลี่ย แล้วตัดเกรดตามเกณฑ์: ≥ 80 ได้ A, ≥ 70 ได้ B, ≥ 60 ได้ C, ≥ 50 ได้ D, ต่ำกว่า 50 ได้ F พร้อมแสดง “ผ่าน” ถ้าเกรดไม่ใช่ F

สิ่งที่ต้องทำ
  1. เขียน IPO
  2. เขียนรหัสเทียมที่ตรวจช่วงคะแนนจากสูงไปต่ำ
  3. วาด Flowchart ที่มีข้าวหลามตัดต่อกันหลายชั้น
  4. อธิบายว่าทำไมต้องตรวจจากสูงลงต่ำ
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
ครั้งที่ 1
Subject 1: 85
Subject 2: 78
Subject 3: 90
Average = 84.33
Grade = A
ผ่าน
ครั้งที่ 2
Subject 1: 40
Subject 2: 55
Subject 3: 50
Average = 48.33
Grade = F
ไม่ผ่าน

ตัวอย่างคำตอบ

เริ่มต้น
    รับ s1, s2, s3
    avg = (s1 + s2 + s3) ÷ 3
    ถ้า avg ≥ 80 → grade = A
    มิฉะนั้น ถ้า avg ≥ 70 → grade = B
    มิฉะนั้น ถ้า avg ≥ 60 → grade = C
    มิฉะนั้น ถ้า avg ≥ 50 → grade = D
    มิฉะนั้น → grade = F
    แสดง avg, grade
    ถ้า grade = F แสดง "ไม่ผ่าน" มิฉะนั้น แสดง "ผ่าน"
จบ

ถ้าตรวจจากต่ำไปสูง เช่น ตรวจ ≥ 50 ก่อน คะแนน 90 ก็จะได้ D ทันที เพราะ 90 ≥ 50 เป็นจริงและไม่ตรวจต่อ

import java.util.Scanner;

public class ExamSummary {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Subject 1: ");
        double s1 = input.nextDouble();
        System.out.print("Subject 2: ");
        double s2 = input.nextDouble();
        System.out.print("Subject 3: ");
        double s3 = input.nextDouble();
        double avg = (s1 + s2 + s3) / 3;
        String grade;
        if (avg >= 80) grade = "A";
        else if (avg >= 70) grade = "B";
        else if (avg >= 60) grade = "C";
        else if (avg >= 50) grade = "D";
        else grade = "F";
        System.out.printf("Average = %.2f%n", avg);
        System.out.println("Grade = " + grade);
        if (grade.equals("F")) System.out.println("ไม่ผ่าน");
        else System.out.println("ผ่าน");
    }
}

Exercise 1.9รวม นับ และเฉลี่ยจนกว่าจะป้อน 0★★★ ท้าทาย

รับจำนวนเต็มบวกไปเรื่อย ๆ จนกว่าผู้ใช้จะป้อน 0 (ค่า 0 ไม่นับเป็นข้อมูล) จากนั้นแสดง ผลรวม, จำนวนค่าที่ป้อน และ ค่าเฉลี่ย ถ้าป้อน 0 ตั้งแต่แรกให้แสดง “ไม่มีข้อมูล”

สิ่งที่ต้องทำ
  1. วาด Flowchart ที่มีลูกศรวนกลับ
  2. ต้องมีตัวแปรอย่างน้อย 2 ตัวที่เปลี่ยนค่าในวงซ้ำ (ผลรวม, ตัวนับ)
  3. จัดการกรณีไม่มีข้อมูล เพื่อไม่ให้หารด้วย 0
  4. ทำ trace table กับข้อมูล 4, 10, 7, 0
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
ครั้งที่ 1
Number: 4
Number: 10
Number: 7
Number: 0
Sum = 21
Count = 3
Average = 7.0
ครั้งที่ 2
Number: 0
ไม่มีข้อมูล

ตัวอย่างคำตอบ

เริ่มต้น
    total = 0, count = 0
    รับ number
    ขณะที่ number ≠ 0
        total = total + number
        count = count + 1
        รับ number
    ถ้า count = 0
        แสดง "ไม่มีข้อมูล"
    มิฉะนั้น
        แสดง total, count, total ÷ count
จบ
import java.util.Scanner;

public class SumCountAverage {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int total = 0;
        int count = 0;
        System.out.print("Number: ");
        int number = input.nextInt();
        while (number != 0) {
            total = total + number;
            count = count + 1;
            System.out.print("Number: ");
            number = input.nextInt();
        }
        if (count == 0) {
            System.out.println("ไม่มีข้อมูล");
        } else {
            System.out.println("Sum = " + total);
            System.out.println("Count = " + count);
            System.out.println("Average = " + (double) total / count);
        }
    }
}

Exercise 1.10ตู้กดน้ำทอนเหรียญ★★★ ท้าทาย

ตู้กดน้ำขายน้ำขวดละ ราคาที่ผู้ใช้กำหนด รับราคาและเงินที่หยอด (จำนวนเต็ม) ถ้าเงินไม่พอให้แสดง “เงินไม่พอ ขาดอีก … บาท” ถ้าพอให้ทอนเงินโดยใช้เหรียญ 10, 5, 1 บาท ให้จำนวนเหรียญน้อยที่สุด

สิ่งที่ต้องทำ
  1. เขียน IPO
  2. ออกแบบรหัสเทียมที่มีทั้งทางเลือก (เงินพอ/ไม่พอ) และขั้นตอนทอนเหรียญแบบ “หาร แล้วเก็บเศษ”
  3. dry run กับราคา 13 เงิน 50 และราคา 25 เงิน 20
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
ครั้งที่ 1
Price: 13
Paid: 50
Change = 37
10 baht x 3
5 baht x 1
1 baht x 2
ครั้งที่ 2
Price: 25
Paid: 20
เงินไม่พอ ขาดอีก 5 บาท

ตัวอย่างคำตอบ

เริ่มต้น
    รับ price, paid
    ถ้า paid < price
        แสดง "เงินไม่พอ ขาดอีก" (price − paid)
    มิฉะนั้น
        change = paid − price
        ten = change ÷ 10 (ส่วนจำนวนเต็ม);  change = เศษ
        five = change ÷ 5;  change = เศษ
        one = change
        แสดง ten, five, one
จบ

เงินทอน 37: 10 × 3 (เหลือ 7) → 5 × 1 (เหลือ 2) → 1 × 2

import java.util.Scanner;

public class VendingChange {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Price: ");
        int price = input.nextInt();
        System.out.print("Paid: ");
        int paid = input.nextInt();
        if (paid < price) {
            System.out.println("เงินไม่พอ ขาดอีก " + (price - paid) + " บาท");
        } else {
            int change = paid - price;
            System.out.println("Change = " + change);
            int ten = change / 10;
            change = change % 10;
            int five = change / 5;
            change = change % 5;
            int one = change;
            System.out.println("10 baht x " + ten);
            System.out.println("5 baht x " + five);
            System.out.println("1 baht x " + one);
        }
    }
}
