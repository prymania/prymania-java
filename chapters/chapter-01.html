บทที่ 1 · เริ่มจากการแก้ปัญหา

คิดแก้ปัญหาและออกแบบ Flowchart

การเขียนโปรแกรมเริ่มก่อนเปิด IDE: ทำความเข้าใจว่าโจทย์ต้องการอะไร วางขั้นตอนให้ชัด แล้วจึงแปลงเป็นคำสั่งของภาษา Java

เมื่อจบบทนี้ นิสิตจะทำได้
  • แยกข้อมูลเข้า วิธีประมวลผล และผลลัพธ์
  • เขียนขั้นตอนวิธีและรหัสเทียม
  • เลือกใช้สัญลักษณ์ Flowchart
  • ติดตามทางเลือกและการทำซ้ำบนผังงาน

1. จากโจทย์ไปสู่ขั้นตอน

โปรแกรมคือชุดคำสั่งที่บอกคอมพิวเตอร์ให้ทำงานเป็นลำดับ คอมพิวเตอร์ทำตามคำสั่งตรงตัวและไม่เดาใจเรา เราจึงต้องกำหนดให้ชัดว่าเริ่มจากข้อมูลใด ต้องประมวลผลอะไร และต้องแสดงคำตอบแบบไหน

กระบวนการแก้ปัญหา 4 ขั้น (ใช้ได้ทุกบท)
  1. เข้าใจโจทย์ — โจทย์ให้อะไรมา และถามอะไร (แยกเป็น Input/Output)
  2. วางแผน — คิดวิธีเปลี่ยน Input ให้เป็น Output เขียนเป็นรหัสเทียมหรือ Flowchart
  3. ลงมือเขียน — แปลงแผนเป็นคำสั่ง Java ทีละขั้น
  4. ทดสอบ — ลองข้อมูลหลายแบบ เทียบผลกับการคำนวณด้วยมือ ถ้าไม่ตรงให้ย้อนกลับไปขั้นที่ 2
เกี่ยวกับตัวอย่าง Java ในบทนี้

บทนี้เน้นการคิด ตัวอย่างหลายชิ้นจึงแสดง รหัสเทียมคู่กับโปรแกรม Java เพื่อให้เห็นว่าแผนที่คิดไว้กลายเป็นโค้ดได้อย่างไร ยังไม่ต้องจำไวยากรณ์ Java ตอนนี้ ให้สังเกตว่าแต่ละขั้นของแผนตรงกับบรรทัดใดของโค้ด ไวยากรณ์จะเรียนอย่างละเอียดตั้งแต่บทที่ 2

1.1 แยกโจทย์ด้วย Input · Process · Output

ก่อนเขียนโค้ด ให้แยกโจทย์เป็น 3 ส่วน: Input ข้อมูลที่ต้องมีก่อนเริ่ม, Process สูตรหรือกฎที่ใช้คำนวณ และ Output คำตอบที่โจทย์ถาม

โจทย์InputProcessOutput
ซื้อสมุด 3 เล่ม เล่มละ 18 บาท จ่ายเท่าไรจำนวนเล่ม, ราคาต่อเล่มรวม = จำนวน × ราคาราคารวม
หาพื้นที่สี่เหลี่ยมผืนผ้ากว้าง, ยาวพื้นที่ = กว้าง × ยาวพื้นที่
หาคะแนนเฉลี่ยจากสอบ 3 ครั้งคะแนน 3 ค่าเฉลี่ย = (ค1 + ค2 + ค3) ÷ 3คะแนนเฉลี่ย
ซื้อครบ 500 บาทลด 10% ต้องจ่ายเท่าไรยอดซื้อถ้ายอด ≥ 500 ลด 10%ยอดที่ต้องจ่าย
วิธีหา IPO

หาคำถามของโจทย์ก่อน (มักอยู่ท้ายประโยค เช่น “จงหา…”) นั่นคือ Output แล้วถามตัวเองว่า “ต้องรู้อะไรบ้างจึงจะคำนวณได้” นั่นคือ Input ที่เหลือคือ Process

จาก IPO สู่โค้ด

แต่ละส่วนของ IPO กลายเป็นโค้ดหนึ่งกลุ่ม ยังไม่ต้องจำไวยากรณ์ Java ตอนนี้ ให้สังเกตว่าแผนตรงกับบรรทัดไหน

ตัวอย่าง 1.1.1IPO ของราคาสมุด

NotebookPrice.java
public class NotebookPrice {
    public static void main(String[] args) {
        // Input
        int quantity = 3;                      // จำนวนเล่ม
        int pricePerBook = 18;                 // ราคาต่อเล่ม

        // Process
        int total = quantity * pricePerBook;   // 3 × 18 = 54

        // Output
        System.out.println("Total = " + total + " baht");
    }
}
ผลลัพธ์
Total = 54 baht
ข้อผิดพลาดที่พบบ่อย

อย่าใส่คำตอบไว้ใน Input (คำตอบคือสิ่งที่ได้หลังคำนวณ) และเขียน Process เป็นสูตรชัด ๆ เช่น “รวม = จำนวน × ราคา” ไม่ใช่ “คำนวณราคา” ส่วนค่าที่รู้อยู่แล้ว เช่น ภาษี 7% เป็นค่าคงที่ใน Process ไม่ต้องรับจากผู้ใช้

ตัวอย่างเพิ่มเติม: รับ Input จากผู้ใช้

โจทย์จริงมักให้ผู้ใช้ป้อน Input แทนการเขียนค่าตายตัว ผลลัพธ์จึงเปลี่ยนตามข้อมูลที่ป้อน

ตัวอย่าง 1.1.2คะแนนเฉลี่ย 3 ครั้ง

AverageScore.java
import java.util.Scanner;

public class AverageScore {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);     // เตรียมรับข้อมูลจากคีย์บอร์ด
        System.out.print("Score 1: ");
        double s1 = input.nextDouble();
        System.out.print("Score 2: ");
        double s2 = input.nextDouble();
        System.out.print("Score 3: ");
        double s3 = input.nextDouble();

        double average = (s1 + s2 + s3) / 3;        // วงเล็บ: บวกให้ครบก่อน แล้วจึงหาร
        System.out.println("Average = " + average);
    }
}

Score 1: 70
Score 2: 85
Score 3: 90
Average = 81.66666666666667

ถ้าลบวงเล็บเป็น s1 + s2 + s3 / 3 จะได้ 70 + 85 + 30 = 185 ซึ่งผิด เพราะการหารทำก่อนการบวก

ลองคิดก่อน · ค่าน้ำประปา

“ค่าน้ำหน่วยละ 12 บาท บวกค่าบริการรายเดือน 30 บาท จงหาค่าน้ำที่ต้องจ่ายเมื่อทราบจำนวนหน่วยที่ใช้” — Input, Process, Output คืออะไร

ดูคำตอบ

Input: จำนวนหน่วยที่ใช้ · Process: ค่าน้ำ = หน่วย × 12 + 30 (12 และ 30 เป็นค่าคงที่ ไม่ใช่ Input) · Output: ค่าน้ำที่ต้องจ่าย

1.2 ขั้นตอนวิธีและรหัสเทียม (Pseudocode)

ขั้นตอนวิธี (algorithm) คือวิธีแก้ปัญหาที่เรียงเป็นขั้น ส่วน รหัสเทียม (pseudocode) คือการเขียนขั้นตอนนั้นด้วยภาษาคนอย่างเป็นระเบียบ ช่วยให้คิด logic ได้โดยยังไม่ต้องกังวลเรื่อง ; หรือวงเล็บ

ขั้นตอนวิธีที่ดีต้องตัวอย่าง
ชัดเจน ตีความได้แบบเดียว“เติมเกลือ 1 ช้อนชา” ไม่ใช่ “เติมเกลือนิดหน่อย”
มีลำดับแน่นอนรับข้อมูลก่อน แล้วจึงคำนวณ
มีจุดจบทำครบแล้วหยุดได้เสมอ
ให้ผลถูกต้องทุก Input ที่ถูกต้องได้ Output ที่ถูกต้อง

เขียนรหัสเทียม

เริ่มด้วย เริ่มต้น จบด้วย จบ ใช้คำกริยาชัด ๆ คือ รับ (Input), คำนวณ หรือ ตัวแปร = สูตร (Process) และ แสดง (Output) บรรทัดละหนึ่งเรื่อง

รหัสเทียม
เริ่มต้น
    รับ totalMinutes
    hours = totalMinutes หารเอาส่วนจำนวนเต็มด้วย 60
    minutes = totalMinutes เศษจากการหารด้วย 60
    แสดง hours และ minutes
จบ

แต่ละบรรทัดของรหัสเทียมกลายเป็นคำสั่ง Java หนึ่งบรรทัด “หารเอาส่วนจำนวนเต็ม” คือ / และ “เศษ” คือ %

ตัวอย่าง 1.2.1แปลงนาทีเป็นชั่วโมงและนาที

MinutesToHours.java
import java.util.Scanner;

public class MinutesToHours {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Total minutes: ");
        int totalMinutes = input.nextInt();     // รับ totalMinutes  → 135

        int hours = totalMinutes / 60;          // หารเอาส่วนจำนวนเต็ม → 2
        int minutes = totalMinutes % 60;        // เศษจากการหาร → 15

        System.out.println(hours + " hours " + minutes + " minutes");   // แสดง
    }
}

ตัวอย่าง 1.2.2ทอนเงินเป็นธนบัตร

BanknoteChange.java
import java.util.Scanner;

public class BanknoteChange {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Amount: ");
        int amount = input.nextInt();      // 1370

        int thousand = amount / 1000;      // 1 ใบ
        amount = amount % 1000;            // เหลือ 370
        int hundred = amount / 100;        // 3 ใบ
        amount = amount % 100;             // เหลือ 70
        int twenty = amount / 20;          // 3 ใบ
        amount = amount % 20;              // เหลือ 10 เป็นเหรียญ

        System.out.println("1000 x " + thousand);
        System.out.println("100 x " + hundred);
        System.out.println("20 x " + twenty);
        System.out.println("coins left: " + amount);
    }
}

1.3 สัญลักษณ์และลำดับของ Flowchart

Flowchart (ผังงาน) คือแผนภาพลำดับการทำงาน รูปทรงบอกหน้าที่ของแต่ละขั้น และลูกศรบอกทิศทาง เหมาะกับการมองภาพรวม โดยเฉพาะเมื่อมีทางแยกหรือการวนซ้ำ

    }

import java.util.Scanner;

public class PassOrFail {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Score: ");
        int score = input.nextInt();

        if (score >= 50) {                       // ◇ score ≥ 50 ?
            System.out.println("ผ่าน");          // ทาง "ใช่"

            System.out.println("ไม่ผ่าน");       // ทาง "ไม่ใช่" ← 42 มาทางนี้

        System.out.println("จบการตรวจ");        // ทั้งสองทางมาบรรจบที่นี่
    }
}

SumUntilZero.java
import java.util.Scanner;

public class SumUntilZero {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int total = 0;                            // ผลรวมเริ่มที่ 0
        System.out.print("Number (0 = stop): ");
        int number = input.nextInt();             // รับค่าแรกก่อนเข้าวงซ้ำ

        while (number != 0) {                     // ◇ number ≠ 0 ?
            total = total + number;               // บวกสะสม
            System.out.print("Number (0 = stop): ");
            number = input.nextInt();             // รับค่าใหม่ แล้ววนกลับไปตรวจ
        }
        System.out.println("Total = " + total);   // ออกจากวงเมื่อป้อน 0
    }
}

Exercise 1.2IPO ของพื้นที่และเส้นรอบวงกลม★ ง่าย

รับรัศมีของวงกลม แล้วแสดงทั้ง พื้นที่ (πr²) และ เส้นรอบวง (2πr) ใช้ π = 3.14159

สิ่งที่ต้องทำ
  1. ระบุ Input (มีกี่ค่า?)
  2. ระบุ Process สองสูตร และบอกว่า π เป็น Input หรือค่าคงที่
  3. ระบุ Output (มีกี่ค่า?)
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

Area = 153.93791
Circumference = 43.98226

ตัวอย่างคำตอบ

Input: รัศมี r (ค่าเดียว) · Process: พื้นที่ = π × r × r, เส้นรอบวง = 2 × π × r โดย π เป็นค่าคงที่ ไม่ต้องรับจากผู้ใช้ · Output: 2 ค่า คือพื้นที่และเส้นรอบวง

CircleIPO.java
import java.util.Scanner;

public class CircleIPO {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        final double PI = 3.14159;  // ค่าคงที่ ไม่ใช่ Input
        System.out.print("Radius: ");
        double r = input.nextDouble();
        double area = PI * r * r;           // πr²
        double circumference = 2 * PI * r;  // 2πr
        System.out.println("Area = " + area);
        System.out.println("Circumference = " + circumference);
    }
}

import java.util.Scanner;

public class SecondsToMinutes {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Seconds: ");
        int totalSeconds = input.nextInt();
        // หารเอาส่วนจำนวนเต็ม

        int seconds = totalSeconds % 60;  // เศษจากการหาร

}

import java.util.Scanner;

public class GardenFence {

        double width = input.nextDouble();

import java.util.Scanner;

Exercise 1.7ค่าจ้างและค่าล่วงเวลา★★ ปานกลาง

ค่าจ้างปกติชั่วโมงละ 100 บาท สำหรับ 40 ชั่วโมงแรก ชั่วโมงที่เกิน 40 ได้ชั่วโมงละ 150 บาท รับจำนวนชั่วโมงทำงานในสัปดาห์ แล้วแสดงค่าจ้างรวม

สิ่งที่ต้องทำ
  1. แยกกรณี “ไม่เกิน 40” และ “เกิน 40”
  2. กรณีเกิน: ค่าจ้าง = 40 × 100 + (ชั่วโมง − 40) × 150
  3. dry run ด้วย 38 และ 45 ชั่วโมง
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
ครั้งที่ 1
Hours worked: 38
Pay = 3800 baht
ครั้งที่ 2
Hours worked: 45
Pay = 4750 baht

ตัวอย่างคำตอบ

รหัสเทียม
เริ่มต้น
    รับ hours
    ถ้า hours ≤ 40
        pay = hours × 100
    มิฉะนั้น
        pay = 40 × 100 + (hours − 40) × 150
    แสดง pay
จบ

45 ชั่วโมง: 4000 + 5 × 150 = 4750 บาท

OvertimePay.java
import java.util.Scanner;

public class OvertimePay {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Hours worked: ");
        int hours = input.nextInt();
        int pay;
        if (hours <= 40) {
            pay = hours * 100;  // อัตราปกติทั้งหมด
        } else {
            // 40 ชม.แรก + ส่วนที่เกิน
            pay = 40 * 100 + (hours - 40) * 150;
        }
        System.out.println("Pay = " + pay + " baht");
    }
}

Exercise 1.8สรุปผลสอบและเกรด★★★ ท้าทาย

รับคะแนน 3 วิชา (เต็มวิชาละ 100) หาค่าเฉลี่ย แล้วตัดเกรดตามเกณฑ์: ≥ 80 ได้ A, ≥ 70 ได้ B, ≥ 60 ได้ C, ≥ 50 ได้ D, ต่ำกว่า 50 ได้ F พร้อมแสดง “ผ่าน” ถ้าเกรดไม่ใช่ F

สิ่งที่ต้องทำ
  1. เขียน IPO
  2. เขียนรหัสเทียมที่ตรวจช่วงคะแนนจากสูงไปต่ำ
  3. วาด Flowchart ที่มีข้าวหลามตัดต่อกันหลายชั้น
  4. อธิบายว่าทำไมต้องตรวจจากสูงลงต่ำ
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
ครั้งที่ 1
Subject 1: 85
Subject 2: 78
Subject 3: 90
Average = 84.33
Grade = A
ผ่าน
ครั้งที่ 2
Subject 1: 40
Subject 2: 55
Subject 3: 50
Average = 48.33
Grade = F
ไม่ผ่าน

ตัวอย่างคำตอบ

รหัสเทียม
เริ่มต้น
    รับ s1, s2, s3
    avg = (s1 + s2 + s3) ÷ 3
    ถ้า avg ≥ 80 → grade = A
    มิฉะนั้น ถ้า avg ≥ 70 → grade = B
    มิฉะนั้น ถ้า avg ≥ 60 → grade = C
    มิฉะนั้น ถ้า avg ≥ 50 → grade = D
    มิฉะนั้น → grade = F
    แสดง avg, grade
    ถ้า grade = F แสดง "ไม่ผ่าน" มิฉะนั้น แสดง "ผ่าน"
จบ

ถ้าตรวจจากต่ำไปสูง เช่น ตรวจ ≥ 50 ก่อน คะแนน 90 ก็จะได้ D ทันที เพราะ 90 ≥ 50 เป็นจริงและไม่ตรวจต่อ

ExamSummary.java
import java.util.Scanner;

public class ExamSummary {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Subject 1: ");
        double s1 = input.nextDouble();
        System.out.print("Subject 2: ");
        double s2 = input.nextDouble();
        System.out.print("Subject 3: ");
        double s3 = input.nextDouble();
        double avg = (s1 + s2 + s3) / 3;
        String grade;
        if (avg >= 80) grade = "A";  // ตรวจจากสูงลงต่ำ
        else if (avg >= 70) grade = "B";
        else if (avg >= 60) grade = "C";
        else if (avg >= 50) grade = "D";
        else grade = "F";
        // ทศนิยม 2 ตำแหน่ง
        System.out.printf("Average = %.2f%n", avg);
        System.out.println("Grade = " + grade);
        if (grade.equals("F")) System.out.println("ไม่ผ่าน");
        else System.out.println("ผ่าน");
    }
}

Exercise 1.9รวม นับ และเฉลี่ยจนกว่าจะป้อน 0★★★ ท้าทาย

รับจำนวนเต็มบวกไปเรื่อย ๆ จนกว่าผู้ใช้จะป้อน 0 (ค่า 0 ไม่นับเป็นข้อมูล) จากนั้นแสดง ผลรวม, จำนวนค่าที่ป้อน และ ค่าเฉลี่ย ถ้าป้อน 0 ตั้งแต่แรกให้แสดง “ไม่มีข้อมูล”

สิ่งที่ต้องทำ
  1. วาด Flowchart ที่มีลูกศรวนกลับ
  2. ต้องมีตัวแปรอย่างน้อย 2 ตัวที่เปลี่ยนค่าในวงซ้ำ (ผลรวม, ตัวนับ)
  3. จัดการกรณีไม่มีข้อมูล เพื่อไม่ให้หารด้วย 0
  4. ทำ trace table กับข้อมูล 4, 10, 7, 0
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
ครั้งที่ 1
Number: 4
Number: 10
Number: 7
Number: 0
Sum = 21
Count = 3
Average = 7.0
ครั้งที่ 2
Number: 0
ไม่มีข้อมูล

ตัวอย่างคำตอบ

รหัสเทียม
เริ่มต้น
    total = 0, count = 0
    รับ number
    ขณะที่ number ≠ 0
        total = total + number
        count = count + 1
        รับ number
    ถ้า count = 0
        แสดง "ไม่มีข้อมูล"
    มิฉะนั้น
        แสดง total, count, total ÷ count
จบ
SumCountAverage.java
import java.util.Scanner;

public class SumCountAverage {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int total = 0;  // ผลรวม
        int count = 0;  // ตัวนับจำนวนค่า
        System.out.print("Number: ");
        int number = input.nextInt();
        while (number != 0) {  // 0 คือค่าหยุด (sentinel)
            total = total + number;
            count = count + 1;
            System.out.print("Number: ");
            number = input.nextInt();
        }
        if (count == 0) {  // ป้องกันการหารด้วย 0
            System.out.println("ไม่มีข้อมูล");
        } else {
            System.out.println("Sum = " + total);
            System.out.println("Count = " + count);
            // แปลงเป็น double ก่อนหาร
            System.out.println("Average = " + (double) total / count);
        }
    }
}

Exercise 1.10ตู้กดน้ำทอนเหรียญ★★★ ท้าทาย

ตู้กดน้ำขายน้ำขวดละ ราคาที่ผู้ใช้กำหนด รับราคาและเงินที่หยอด (จำนวนเต็ม) ถ้าเงินไม่พอให้แสดง “เงินไม่พอ ขาดอีก … บาท” ถ้าพอให้ทอนเงินโดยใช้เหรียญ 10, 5, 1 บาท ให้จำนวนเหรียญน้อยที่สุด

สิ่งที่ต้องทำ
  1. เขียน IPO
  2. ออกแบบรหัสเทียมที่มีทั้งทางเลือก (เงินพอ/ไม่พอ) และขั้นตอนทอนเหรียญแบบ “หาร แล้วเก็บเศษ”
  3. dry run กับราคา 13 เงิน 50 และราคา 25 เงิน 20
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
ครั้งที่ 1
Price: 13
Paid: 50
Change = 37
10 baht x 3
5 baht x 1
1 baht x 2
ครั้งที่ 2
Price: 25
Paid: 20
เงินไม่พอ ขาดอีก 5 บาท

ตัวอย่างคำตอบ

รหัสเทียม
เริ่มต้น
    รับ price, paid
    ถ้า paid < price
        แสดง "เงินไม่พอ ขาดอีก" (price − paid)
    มิฉะนั้น
        change = paid − price
        ten = change ÷ 10 (ส่วนจำนวนเต็ม);  change = เศษ
        five = change ÷ 5;  change = เศษ
        one = change
        แสดง ten, five, one
จบ

เงินทอน 37: 10 × 3 (เหลือ 7) → 5 × 1 (เหลือ 2) → 1 × 2

VendingChange.java
import java.util.Scanner;

public class VendingChange {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Price: ");
        int price = input.nextInt();
        System.out.print("Paid: ");
        int paid = input.nextInt();
        if (paid < price) {  // ◇ เงินไม่พอ ?
            System.out.println("เงินไม่พอ ขาดอีก " + (price - paid) + " บาท");
        } else {
            int change = paid - price;
            System.out.println("Change = " + change);
            int ten = change / 10;  // เหรียญใหญ่ก่อน
            change = change % 10;   // เก็บเศษไว้คิดต่อ
            int five = change / 5;
            change = change % 5;
            int one = change;  // ที่เหลือเป็นเหรียญ 1 บาททั้งหมด
            System.out.println("10 baht x " + ten);
            System.out.println("5 baht x " + five);
            System.out.println("1 baht x " + one);
        }
    }
}
