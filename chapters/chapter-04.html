บทที่ 4 · โปรแกรมเริ่มโต้ตอบได้

รับข้อมูลและแสดงผล

ใช้ข้อความถามผู้ใช้ รับค่าจากแป้นพิมพ์ คำนวณ และจัดรูปแบบคำตอบให้อ่านง่าย

เมื่อจบบทนี้ นิสิตจะทำได้
  • เลือกระหว่าง print, println และ printf
  • รับจำนวนเต็ม ทศนิยม และข้อความด้วย Scanner
  • อ่านชื่อหรือประโยคที่มีช่องว่างได้
  • ป้องกันปัญหาบรรทัดค้างหลังอ่านตัวเลข

4. สร้างบทสนทนาระหว่างโปรแกรมกับผู้ใช้

โปรแกรมที่รับข้อมูลจากผู้ใช้ต้องแจ้งให้รู้ว่าต้องป้อนอะไร และหลังคำนวณเสร็จต้องแสดงคำตอบพร้อมหน่วยหรือคำอธิบายที่ชัดเจน

4.1 แสดงผลด้วย print, println และ printf

print แสดงข้อความโดยไม่ขึ้นบรรทัดใหม่, println แสดงแล้วขึ้นบรรทัดใหม่ ส่วน printf ใช้รูปแบบกำหนดตำแหน่งและจำนวนทศนิยม

ตัวอย่างการจัดรูปแบบ
String name = "Mali";
int score = 87;
double average = 3.456;
System.out.print("Student: ");
System.out.println(name);
System.out.printf("Score: %d%n", score);
System.out.printf("Average: %.2f%n", average);

%s แทนข้อความ, %d แทนจำนวนเต็ม, %.2f แสดงทศนิยม 2 ตำแหน่ง และ %n ขึ้นบรรทัดใหม่

ตัวอย่าง 4.1.1 · print ต่อกับ println

แก้ข้อความใน source แล้วส่งเข้า Java IDE เพื่อรันจริง

ผลลัพธ์ตัวอย่าง
Good morning
      Next line
กดแล้วจะเปิด IDE ด้านล่าง · โค้ดจะถูกส่งไป JDoodle
ระวังชนิดของ placeholder

ให้ placeholder ตรงกับชนิดข้อมูล เช่น %d กับ int, %f กับ double และ %s กับข้อความ

ตัวอย่าง 4.1.2 · จัดรูปแบบราคารวม

ลองเปลี่ยนจำนวนสินค้าและราคา แล้วสังเกตว่าผลรวมและจำนวนทศนิยมเปลี่ยนตาม

ผลลัพธ์ตัวอย่าง
Total: 37.50 baht
ลองเปลี่ยน %.2f เป็น %.1f แล้วเปรียบเทียบผล

Exercise 4.1พิมพ์ผลคะแนน

มีชื่อนักศึกษา Beam และคะแนน 91 จงแสดงบรรทัด Student: Beam และ Score: 91 points โดยใช้ทั้ง println และ printf

ตัวอย่างคำตอบ

String studentName = "Beam";
int score = 91;
System.out.println("Student: " + studentName);
System.out.printf("Score: %d points%n", score);

เครื่องหมาย + ต่อข้อความกับค่าในตัวแปรได้

4.2 รับข้อมูลตัวเลขด้วย Scanner

สร้าง Scanner จาก System.in แล้วเรียกเมธอดให้ตรงกับชนิดข้อมูล: nextInt() อ่านจำนวนเต็ม, nextDouble() อ่านทศนิยม และ next() อ่านข้อความจนถึงช่องว่างถัดไป

รับความกว้างและความยาว
import java.util.Scanner;

public class RectangleArea {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Width: ");
        double width = input.nextDouble();
        System.out.print("Height: ");
        double height = input.nextDouble();
        double area = width * height;
        System.out.printf("Area: %.2f%n", area);
    }
}

ถ้าป้อน 4.5 และ 2 จะได้พื้นที่ 9.00

ตัวอย่าง 4.2.1 · รับตัวเลขแล้วคำนวณ

หลัง Run ให้เปิด I/O ใน Java IDE แล้วป้อน 4.5 และ 2 คนละบรรทัด

ผลลัพธ์เมื่อป้อน 4.5 แล้ว 2
Width: 4.5
      Height: 2
      Area: 9.00
ตัวอย่างนี้ใช้ stdin ผ่านแถบ I/O ของ IDE
รับค่าตามลำดับที่ถาม

ชนิดของตัวแปรต้องตรงกับเมธอดอ่านข้อมูล และผู้ใช้ต้องป้อนค่าตามลำดับที่โปรแกรมถาม ในตัวอย่างทศนิยมให้ป้อนโดยใช้จุด เช่น 4.5

ตัวอย่าง 4.2.2 · ป้อนชนิดข้อมูลไม่ตรง

โปรแกรมคาดว่าจะได้จำนวนเต็ม แต่ถ้าป้อน 12.5 ให้สังเกต error ที่เกิดขึ้น

ผลที่คาดเมื่อป้อน 12.5
InputMismatchException
      nextInt() ต้องอ่าน token ที่เป็นจำนวนเต็ม
      แก้ได้โดยป้อน 12 หรือเปลี่ยนชนิดเป็น double และใช้ nextDouble()
ข้อความ stack trace อาจต่างกันเล็กน้อยตาม JDK

Exercise 4.2คำนวณพื้นที่สี่เหลี่ยม

เขียนโปรแกรมรับความกว้างและความยาวเป็นทศนิยม แล้วแสดงพื้นที่ด้วยทศนิยม 2 ตำแหน่ง

ตัวอย่างคำตอบ

import java.util.Scanner;

public class Area {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Width: ");
        double width = input.nextDouble();
        System.out.print("Length: ");
        double length = input.nextDouble();
        double area = width * length;
        System.out.printf("Area = %.2f%n", area);
    }
}

ใช้ double เพื่อเก็บค่าทศนิยม และ %.2f เพื่อแสดงผลสองตำแหน่ง

4.3 อ่านข้อความและจัดการบรรทัด

next() อ่านเพียงคำเดียว ถ้าข้อความมีช่องว่างให้ใช้ nextLine() ซึ่งอ่านทั้งบรรทัด หากอ่านตัวเลขด้วย nextInt() ก่อน ตัวกด Enter ที่ตามมาอาจยังค้างอยู่และถูก nextLine() อ่านทันที

อ่านตัวเลขก่อน แล้วจึงอ่านชื่อเต็ม
Scanner input = new Scanner(System.in);
System.out.print("Age: ");
int age = input.nextInt();
input.nextLine(); // อ่าน Enter ที่เหลือให้หมดบรรทัด
System.out.print("Full name: ");
String fullName = input.nextLine();
System.out.printf("%s is %d years old.%n", fullName, age);

หลังอ่านตัวเลข บรรทัด input.nextLine() แรกใช้ทิ้งส่วนที่เหลือของบรรทัดรวมถึง Enter ก่อนรออ่านข้อความจริง

ตัวอย่าง 4.3.1 · อ่านชื่อเต็ม

ใน I/O ป้อนอายุ 20 แล้วป้อนชื่อ Mali Nida สังเกตว่าช่องว่างในชื่อยังอยู่ครบ

ผลลัพธ์ตัวอย่าง
Age: 20
      Full name: Mali Nida
      Hello, Mali Nida!
      Age: 20
ส่งข้อมูลทั้งสองบรรทัดใน I/O
จำเป็นคู่

ใช้ next() สำหรับ token เดียว เช่น รหัสที่ไม่มีช่องว่าง และใช้ nextLine() สำหรับชื่อเต็มหรือประโยค อย่าเรียก nextLine() ต่อจาก nextInt() โดยไม่จัดการ Enter ที่ค้าง

ตัวอย่าง 4.3.2 · บั๊กอ่านชื่อได้เป็นค่าว่าง

ลองรันโค้ดนี้ก่อน แล้วดูเหตุผลที่บรรทัดอ่านชื่อได้ค่าว่าง จากนั้นเติม input.nextLine(); หลัง nextInt() เพื่อแก้

ผลลัพธ์เมื่อป้อน 20 แล้ว Mali
Age: 20
      Full name: Name is []
หลัง nextInt() อ่านตัวขึ้นบรรทัดใหม่ที่ค้างอยู่ทันที

Exercise 4.3อ่านชื่อเต็ม

โปรแกรมถามอายุก่อน แล้วถามชื่อ-นามสกุลที่อาจมีช่องว่าง จากนั้นพิมพ์ข้อความทักทาย เขียนส่วนรับข้อมูลและแสดงผล

ตัวอย่างคำตอบ

import java.util.Scanner;

public class StudentGreeting {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Age: ");
        int age = input.nextInt();
        input.nextLine();
        System.out.print("Full name: ");
        String fullName = input.nextLine();
        System.out.printf("Hello, %s! You are %d.%n", fullName, age);
    }
}

บรรทัด input.nextLine() หลังอ่านอายุช่วยไม่ให้ชื่อถูกข้าม

แบบฝึกหัดท้ายบท

เขียนโปรแกรมรับข้อมูลตามลำดับที่ถาม คำนวณ แล้วตรวจรูปแบบผลลัพธ์ด้วยค่าทดลอง

Exercise 4.4แปลงอุณหภูมิ

รับอุณหภูมิองศาเซลเซียส คำนวณฟาเรนไฮต์ด้วยสูตร F = C × 9 / 5 + 32 แล้วแสดงคำตอบทศนิยม 1 ตำแหน่ง

ตัวอย่างคำตอบ

import java.util.Scanner;

public class Temperature {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Celsius: ");
        double celsius = input.nextDouble();
        double fahrenheit = celsius * 9.0 / 5 + 32;
        System.out.printf("Fahrenheit: %.1f%n", fahrenheit);
    }
}

ใช้ 9.0 เพื่อให้การคำนวณเกิดเป็นทศนิยม

Exercise 4.5ใบเสร็จสินค้า

รับชื่อสินค้า จำนวนชิ้น และราคาต่อชิ้น แล้วแสดงชื่อสินค้า ยอดรวม และยอดรวมที่จัดเป็นทศนิยม 2 ตำแหน่ง

ตัวอย่างคำตอบ

import java.util.Scanner;

public class SimpleReceipt {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Product: ");
        String product = input.nextLine();
        System.out.print("Quantity: ");
        int quantity = input.nextInt();
        System.out.print("Unit price: ");
        double unitPrice = input.nextDouble();
        double total = quantity * unitPrice;
        System.out.printf("%s x %d = %.2f baht%n", product, quantity, total);
    }
}

อ่านชื่อด้วย nextLine() ก่อน แล้วจึงอ่านตัวเลขตามชนิดข้อมูล

Exercise 4.6บัตรแนะนำตัว

ถามอายุเป็นจำนวนเต็มก่อน แล้วถามชื่อเต็มที่มีช่องว่าง แสดงประโยคแนะนำตัวที่มีทั้งชื่อและอายุ

ตัวอย่างคำตอบ

import java.util.Scanner;

public class Introduction {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Age: ");
        int age = input.nextInt();
        input.nextLine();
        System.out.print("Full name: ");
        String fullName = input.nextLine();
        System.out.printf("My name is %s and I am %d years old.%n", fullName, age);
    }
}

การอ่าน Enter หลังอายุทำให้ nextLine() ถัดไปหยุดรอรับชื่อจริง ๆ
