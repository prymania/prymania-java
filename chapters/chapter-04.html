บทที่ 4 · โปรแกรมเริ่มโต้ตอบได้

รับข้อมูลและแสดงผล

ใช้ข้อความถามผู้ใช้ รับค่าจากแป้นพิมพ์ คำนวณ และจัดรูปแบบคำตอบให้อ่านง่าย

เมื่อจบบทนี้ นิสิตจะทำได้
  • เลือกระหว่าง print, println และ printf
  • รับจำนวนเต็ม ทศนิยม และข้อความด้วย Scanner
  • อ่านชื่อหรือประโยคที่มีช่องว่างได้
  • ป้องกันปัญหาบรรทัดค้างหลังอ่านตัวเลข

4. สร้างบทสนทนาระหว่างโปรแกรมกับผู้ใช้

โปรแกรมที่รับข้อมูลจากผู้ใช้ต้องแจ้งให้รู้ว่าต้องป้อนอะไร (prompt) และหลังคำนวณเสร็จต้องแสดงคำตอบพร้อมหน่วยหรือคำอธิบายที่ชัดเจน ในตัวอย่างที่มีการรับข้อมูล ช่อง Output จะแสดงค่าที่ผู้ใช้พิมพ์แบบขีดเส้นใต้ เหมือนที่เห็นในหน้าต่าง console จริง

4.1 แสดงผลด้วย print, println และ printf

printf (print formatted) พิมพ์ตามแม่แบบ ที่มีช่องให้เติมค่า เรียกว่า format specifier ช่วยกำหนดจำนวนทศนิยม ความกว้าง และการจัดชิดได้ ต่างจาก println ที่พิมพ์ค่าตามจริง

specifierใช้กับตัวอย่างผลลัพธ์
%dจำนวนเต็มprintf("%d", 42)42
%.2fทศนิยม 2 ตำแหน่ง (ปัดเศษ)printf("%.2f", 3.456)3.46
%sข้อความprintf("%s", "JHope")JHope
%cอักขระprintf("%c", 'A')A
%nขึ้นบรรทัดใหม่printf("A%nB")A↵B
%,dคั่นหลักพันprintf("%,d", 1500000)1,500,000
%%เครื่องหมาย % หนึ่งตัวprintf("15%%")15%

ตัวอย่าง 4.1.1แม่แบบหนึ่งชุด เติมค่าตามลำดับ

PrintfBasics.java
public class PrintfBasics {
    public static void main(String[] args) {
        String name = "JHope";
        int score = 87;
        double average = 3.456;
        System.out.printf("Student: %s%n", name);                 // Student: JHope
        System.out.printf("Score: %d points%n", score);           // Score: 87 points
        System.out.printf("Average: %.2f%n", average);            // Average: 3.46
        System.out.printf("%s got %d (avg %.1f)%n", name, score, average);
    }
}
ผลลัพธ์
Student: JHope
Score: 87 points
Average: 3.46
JHope got 87 (avg 3.5)
คำแนะนำ

ค่าที่ส่งตามหลังแม่แบบจับคู่กับ specifier ตามลำดับ ตัวแรกเข้า % ตัวแรก และ printf ไม่ขึ้นบรรทัดเอง ต้องใส่ %n ท้ายแม่แบบ

ตัวอย่างเพิ่มเติม: print ไม่ขึ้นบรรทัด

ตัวอย่าง 4.1.2print ต่อกับ println

        System.out.println("Next line");
    }

เพราะ print ไม่ขึ้นบรรทัด จึงใช้ทำข้อความถาม (prompt) ที่ให้ผู้ใช้พิมพ์ต่อท้ายในบรรทัดเดียวกัน

จัดรูปแบบเงินและตาราง

ใส่ตัวเลขความกว้างหน้า specifier: %-10s ข้อความกว้าง 10 ช่องชิดซ้าย, %5d ตัวเลขกว้าง 5 ชิดขวา, %8.2f กว้าง 8 ทศนิยม 2 คอลัมน์จะตรงกันทุกบรรทัด

ตัวอย่าง 4.1.3ราคาและตารางที่คอลัมน์ตรงกัน

AlignedTable.java
public class AlignedTable {
    public static void main(String[] args) {
        double total = 3 * 12.5;
        System.out.println("println: " + total);                  // println: 37.5
        System.out.printf("printf : %.2f baht%n", total);         // printf : 37.50 baht
        System.out.printf("Salary : %,.2f%n", 1234567.891);       // Salary : 1,234,567.89
        System.out.printf("Discount %d%%%n", 15);                 // Discount 15%
        System.out.println();

        System.out.printf("%-10s %5s %8s%n", "Item", "Qty", "Price");
        System.out.printf("%-10s %5d %8.2f%n", "Pen", 12, 5.5);
        System.out.printf("%-10s %5d %8.2f%n", "Notebook", 3, 45.0);
        System.out.printf("%-10s %5d %8.2f%n", "Bag", 1, 399.75);
        System.out.println("-".repeat(25));                       // เส้น 25 ตัว
    }
}

println: 37.5
printf : 37.50 baht
Salary : 1,234,567.89
Discount 15%

Item         Qty    Price
Pen           12     5.50

Bag            1   399.75

specifier ต้องตรงชนิด

printf ตรวจชนิดตอนรัน ใช้ %d กับค่า double โปรแกรมจะหยุดด้วย IllegalFormatConversionException จำคู่: %d ↔ int, %f ↔ double, %s ↔ String

ดูตัวอย่าง: error เมื่อ specifier ไม่ตรงชนิด

    }

4.2 รับข้อมูลตัวเลขด้วย Scanner

Scanner อ่านสิ่งที่ผู้ใช้พิมพ์ ต้อง import java.util.Scanner; ไว้บนสุดของไฟล์ สร้างครั้งเดียวด้วย new Scanner(System.in) แล้วเรียกเมธอดอ่านให้ตรงกับชนิด

เมธอดอ่านอะไรเก็บใน
nextInt()จำนวนเต็มหนึ่งค่าint
nextDouble()ทศนิยมหนึ่งค่า (ป้อน 2 ได้ จะเป็น 2.0)double
next()ข้อความหนึ่งคำ (ถึงช่องว่าง)String
nextLine()ข้อความทั้งบรรทัด (มีช่องว่างได้)String

ตัวอย่าง 4.2.1ถาม รอ แล้วคำนวณ

AgeFromYear.java
import java.util.Scanner;

public class AgeFromYear {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);          // สร้างครั้งเดียว
        System.out.print("Birth year (A.D.): ");          // print → ผู้ใช้พิมพ์ต่อบรรทัดเดิม
        int birthYear = input.nextInt();                  // หยุดรอจนผู้ใช้กด Enter
        int age = 2026 - birthYear;                       // 2026 - 2007 = 19
        System.out.println("You are about " + age + " years old.");
    }
}
ผลลัพธ์ · ตัวที่ขีดเส้นใต้คือค่าที่ผู้ใช้พิมพ์
Birth year (A.D.): 2007
You are about 19 years old.

รับหลายค่า

nextInt / nextDouble อ่านทีละ token (คำที่คั่นด้วยช่องว่างหรือ Enter) ผู้ใช้จึงพิมพ์หลายค่าในบรรทัดเดียวได้

ตัวอย่าง 4.2.2ป้อน 3 คะแนนในบรรทัดเดียว

ThreeScores.java
import java.util.Scanner;

public class ThreeScores {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter 3 scores: ");
        int a = input.nextInt();             // 8    ส่วน "9 10" ยังค้างรอ
        int b = input.nextInt();             // 9    ไม่ต้องรอผู้ใช้อีก
        int c = input.nextInt();             // 10
        int sum = a + b + c;
        double average = sum / 3.0;          // 3.0 ทำให้ได้ทศนิยม
        System.out.printf("Sum = %d, Average = %.2f%n", sum, average);
    }
}
ผลลัพธ์ · ตัวที่ขีดเส้นใต้คือค่าที่ผู้ใช้พิมพ์
Enter 3 scores: 8 9 10
Sum = 27, Average = 9.00
ตัวอย่างเพิ่มเติม: รับทศนิยมสองค่า

import java.util.Scanner;

4.3 อ่านข้อความและจัดการบรรทัด

next() อ่านแค่คำเดียว ถ้าข้อความมีช่องว่าง เช่น ชื่อ-นามสกุล ให้ใช้ nextLine() ซึ่งอ่านทั้งบรรทัด

ตัวอย่าง 4.3.1next() กับ nextLine()

NextWord.java
import java.util.Scanner;

public class NextWord {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Full name: ");
        String first = input.next();             // "JHope"   แค่คำแรก
        String rest = input.nextLine();          // " RM"     ส่วนที่เหลือของบรรทัด
        System.out.println("next()     = [" + first + "]");
        System.out.println("nextLine() = [" + rest + "]");
    }
}
ผลลัพธ์ · ตัวที่ขีดเส้นใต้คือค่าที่ผู้ใช้พิมพ์
Full name: JHope RM
next()     = [JHope]
nextLine() = [ RM]

ปัญหา Enter ค้าง

nextInt() อ่านตัวเลขแต่ไม่อ่านปุ่ม Enter ที่ตามมา ถ้าเรียก nextLine() ต่อทันที มันจะอ่าน Enter ที่ค้างนั้นได้ข้อความว่าง

แผนภาพ

nextLine() →  อ่านถึง ⏎ แรก = ""  (ค่าว่าง!)
----------------------------------------------------------
แก้: เรียก nextLine() ทิ้งหนึ่งครั้งหลัง nextInt()
nextLine() →  ทิ้ง ⏎            เหลือ:  J H o p e ␣ R M ⏎
nextLine() →  "JHope RM"  ✔

import java.util.Scanner;

public class TempConvert {

Exercise 4.7เวลาเดินทาง★★ ปานกลาง

รับระยะทาง (กิโลเมตร) และความเร็วเฉลี่ย (กม./ชม.) คำนวณเวลาที่ใช้ แล้วแสดงเป็น ชั่วโมงทศนิยม และในรูป ชั่วโมง + นาที (ปัดนาทีเป็นจำนวนเต็มด้วย Math.round)

สิ่งที่ต้องทำ

  2. แปลงเป็นนาทีทั้งหมด = Math.round(เวลา × 60) แล้วแยกชั่วโมงและนาทีด้วย / และ %

TravelTime.java
import java.util.Scanner;

public class TravelTime {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Distance (km): ");
        double distance = input.nextDouble();
        System.out.print("Speed (km/h): ");
        double speed = input.nextDouble();
        // เวลา = ระยะทาง ÷ ความเร็ว
        double hours = distance / speed;
        // แปลงเป็นนาทีแล้วปัดเศษ
        int totalMinutes = (int) Math.round(hours * 60);
        System.out.printf("Time: %.2f hours%n", hours);
        // / 60 = ชั่วโมง, % 60 = นาทีที่เหลือ
        System.out.printf("Time: %d h %d min%n", totalMinutes / 60, totalMinutes % 60);
    }
}

Exercise 4.8แบ่งจ่ายค่าอาหาร★★★ ท้าทาย

กลุ่มเพื่อนไปทานอาหาร รับยอดค่าอาหาร จำนวนคน และเปอร์เซ็นต์ทิป คำนวณค่าทิป ยอดรวม และค่าใช้จ่ายต่อคน ร้านรับเฉพาะเงินจำนวนเต็ม จึงให้แต่ละคนจ่ายเป็นจำนวนเต็มที่ปัดขึ้น แล้วบอกว่าเงินที่เก็บได้เกินยอดจริงเท่าไร

สิ่งที่ต้องทำ
  1. ทิป = ยอด × เปอร์เซ็นต์ ÷ 100
  2. ต่อคน = ยอดรวม ÷ จำนวนคน
  3. ปัดขึ้นด้วย (int) Math.ceil(ต่อคน)
  4. เงินเกิน = ปัดขึ้น × จำนวนคน − ยอดรวม
  5. จัดผลลัพธ์เป็นตารางตามตัวอย่าง
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

SplitBill.java
import java.util.Scanner;

public class SplitBill {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Food total: ");
        double food = input.nextDouble();
        System.out.print("People: ");
        int people = input.nextInt();
        System.out.print("Tip (%): ");
        double tipPercent = input.nextDouble();

        // ทิปคิดเป็น % ของค่าอาหาร
        double tip = food * tipPercent / 100;
        double total = food + tip;
        // ค่าที่แต่ละคนต้องจ่ายจริง
        double each = total / people;
        // ceil ปัดขึ้นเป็นจำนวนเต็ม
        int eachRounded = (int) Math.ceil(each);
        // เงินที่เก็บเกินมา
        double extra = eachRounded * people - total;

        System.out.printf("%-16s %10.2f%n", "Tip", tip);
        System.out.printf("%-16s %10.2f%n", "Total", total);
        System.out.printf("%-16s %10.2f%n", "Exact per person", each);
        System.out.printf("%-16s %10d%n", "Each pays", eachRounded);
        System.out.printf("%-16s %10.2f%n", "Extra collected", extra);
    }
}

Exercise 4.9สรุปผลการเรียนรายวิชา★★★ ท้าทาย

รับชื่อวิชา (มีช่องว่าง) ชื่อนักศึกษา (มีช่องว่าง) และคะแนน 3 ส่วน: เก็บ (เต็ม 40) กลางภาค (เต็ม 30) ปลายภาค (เต็ม 30) คำนวณคะแนนรวม ร้อยละของแต่ละส่วนเทียบกับคะแนนเต็มของส่วนนั้น แล้วพิมพ์รายงานตามตัวอย่าง

สิ่งที่ต้องทำ
  1. ลำดับการถาม: ชื่อวิชา → ชื่อนักศึกษา → คะแนน 3 ส่วนในบรรทัดเดียว
  2. ร้อยละ = คะแนน ÷ คะแนนเต็ม × 100 แสดงทศนิยม 1 ตำแหน่ง
  3. รายงานมีกรอบด้วย = และคอลัมน์ตรงกัน
  4. ใช้ %% แสดงเครื่องหมาย %
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

CourseReport.java
import java.util.Scanner;

public class CourseReport {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Course: ");
        String course = input.nextLine();
        System.out.print("Student: ");
        String student = input.nextLine();
        System.out.print("Scores (work mid final): ");
        // 3 ค่าอยู่ในบรรทัดเดียวกันได้
        double work = input.nextDouble();
        double mid = input.nextDouble();
        double fin = input.nextDouble();
        double total = work + mid + fin;

        System.out.println("=".repeat(36));
        System.out.printf("%s%n%s%n", course, student);
        System.out.println("-".repeat(36));
        // %% ในข้อความ = เครื่องหมาย %
        System.out.printf("%-8s %6.1f / 40  (%5.1f%%)%n", "Work", work, work / 40 * 100);
        System.out.printf("%-8s %6.1f / 30  (%5.1f%%)%n", "Midterm", mid, mid / 30 * 100);
        System.out.printf("%-8s %6.1f / 30  (%5.1f%%)%n", "Final", fin, fin / 30 * 100);
        System.out.println("-".repeat(36));
        System.out.printf("%-8s %6.1f / 100%n", "Total", total);
        System.out.println("=".repeat(36));
    }
}

ชื่อวิชาและชื่อนักศึกษาอ่านด้วย nextLine() ก่อนตัวเลข จึงไม่มีปัญหา Enter ค้าง คะแนน 3 ส่วนอ่านด้วย nextDouble() ได้แม้อยู่ในบรรทัดเดียว

Exercise 4.10ผ่อนชำระสินค้า★★★ ท้าทาย

ร้านให้ผ่อนสินค้าแบบดอกเบี้ยคงที่ รับชื่อสินค้า (มีช่องว่าง) ราคา เงินดาวน์ (%) จำนวนเดือน และดอกเบี้ยต่อเดือน (%) แล้วคำนวณ

  • เงินดาวน์ = ราคา × ดาวน์% ÷ 100
  • ยอดจัด = ราคา − เงินดาวน์
  • ดอกเบี้ยรวม = ยอดจัด × ดอกเบี้ย% ÷ 100 × จำนวนเดือน
  • ค่างวด = (ยอดจัด + ดอกเบี้ยรวม) ÷ จำนวนเดือน
  • ราคารวมที่จ่ายจริง = เงินดาวน์ + ยอดจัด + ดอกเบี้ยรวม
สิ่งที่ต้องทำ
  1. ทุกจำนวนเงินแสดงด้วย %,.2f
  2. แสดงว่าจ่ายแพงกว่าราคาเงินสดกี่บาท และคิดเป็นกี่ %
  3. ทดสอบตามตัวอย่าง แล้วลองดาวน์ 0% ด้วย
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

Installment.java
import java.util.Scanner;

public class Installment {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Product: ");
        String product = input.nextLine();
        System.out.print("Price: ");
        double price = input.nextDouble();
        System.out.print("Down payment (%): ");
        double downPercent = input.nextDouble();
        System.out.print("Months: ");
        int months = input.nextInt();
        System.out.print("Interest per month (%): ");
        double rate = input.nextDouble();

        // เงินดาวน์
        double down = price * downPercent / 100;
        // ยอดที่ต้องผ่อน
        double financed = price - down;
        // ดอกเบี้ยคงที่ต่อเดือน × จำนวนเดือน
        double interest = financed * rate / 100 * months;
        // ค่างวดต่อเดือน
        double monthly = (financed + interest) / months;
        double paid = down + financed + interest;
        double extra = paid - price;  // จ่ายเกินราคาเท่าไร

        System.out.println("== " + product + " ==");
        System.out.printf("Down payment : %,12.2f%n", down);
        System.out.printf("Financed     : %,12.2f%n", financed);
        System.out.printf("Interest     : %,12.2f%n", interest);
        System.out.printf("Monthly x %-3d: %,12.2f%n", months, monthly);
        System.out.printf("Total paid   : %,12.2f%n", paid);
        System.out.printf("Extra cost   : %,12.2f (%.2f%%)%n", extra, extra / price * 100);
    }
}
