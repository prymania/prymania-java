บทที่ 4 · โปรแกรมเริ่มโต้ตอบได้

รับข้อมูลและแสดงผล

ใช้ข้อความถามผู้ใช้ รับค่าจากแป้นพิมพ์ คำนวณ และจัดรูปแบบคำตอบให้อ่านง่าย

เมื่อจบบทนี้ นิสิตจะทำได้
  • เลือกระหว่าง print, println และ printf
  • รับจำนวนเต็ม ทศนิยม และข้อความด้วย Scanner
  • อ่านชื่อหรือประโยคที่มีช่องว่างได้
  • ป้องกันปัญหาบรรทัดค้างหลังอ่านตัวเลข

4. สร้างบทสนทนาระหว่างโปรแกรมกับผู้ใช้

โปรแกรมที่รับข้อมูลจากผู้ใช้ต้องแจ้งให้รู้ว่าต้องป้อนอะไร (prompt) และหลังคำนวณเสร็จต้องแสดงคำตอบพร้อมหน่วยหรือคำอธิบายที่ชัดเจน ในตัวอย่างที่มีการรับข้อมูล ช่อง Output จะแสดงค่าที่ผู้ใช้พิมพ์แบบขีดเส้นใต้ เหมือนที่เห็นในหน้าต่าง console จริง

4.1 แสดงผลด้วย print, println และ printf

print แสดงข้อความโดยไม่ขึ้นบรรทัดใหม่, println แสดงแล้วขึ้นบรรทัดใหม่ ส่วน printf (print formatted) ใช้แม่แบบ (format string) ที่มีช่องว่างให้เติมค่า เรียกว่า format specifier ทำให้กำหนดจำนวนทศนิยม ความกว้าง และการจัดชิดได้

Format specifier ที่ใช้บ่อย

specifierใช้กับตัวอย่างผลลัพธ์
%dจำนวนเต็ม (int, long)printf("%d", 42)42
%fทศนิยม (double) ค่าเริ่มต้น 6 ตำแหน่งprintf("%f", 3.5)3.500000
%.2fทศนิยม 2 ตำแหน่ง (ปัดเศษ)printf("%.2f", 3.456)3.46
%sข้อความ (String)printf("%s", "Mali")Mali
%cอักขระ (char)printf("%c", 'A')A
%nขึ้นบรรทัดใหม่printf("A%nB")A↵B
%,dจำนวนเต็มมีจุลภาคคั่นหลักพันprintf("%,d", 1500000)1,500,000
%8d / %-8sกว้าง 8 ช่อง ชิดขวา / ชิดซ้าย (มี -)printf("[%5d]", 42)[   42]

ตัวอย่าง 4.1.1 · print ต่อกับ println พื้นฐาน

แนวคิด: print ไม่ขึ้นบรรทัด จึงใช้ทำ prompt ที่ให้ผู้ใช้พิมพ์ต่อท้ายในบรรทัดเดียวกัน

Java source · PrintExample.java
public class PrintExample {
    public static void main(String[] args) {
        System.out.print("Good ");
        System.out.println("morning");
        System.out.println("Next line");
    }
}
Output
Good morning
Next line
อธิบายทีละขั้น
  1. print "Good " แล้วเคอร์เซอร์รออยู่บรรทัดเดิม
  2. println "morning" ต่อท้าย แล้วขึ้นบรรทัด
  3. "Next line" อยู่บรรทัดใหม่

ตัวอย่าง 4.1.2 · printf กับ specifier พื้นฐาน พื้นฐาน

แนวคิด: เขียนแม่แบบหนึ่งชุด แล้วส่งค่าตามลำดับ specifier ตัวที่ 1 ได้ค่าแรก ตัวที่ 2 ได้ค่าที่สอง …

Java source · PrintfBasics.java
public class PrintfBasics {
    public static void main(String[] args) {
        String name = "Mali";
        int score = 87;
        double average = 3.456;
        System.out.printf("Student: %s%n", name);
        System.out.printf("Score: %d points%n", score);
        System.out.printf("Average: %.2f%n", average);
        System.out.printf("%s got %d (avg %.1f)%n", name, score, average);
    }
}
Output
Student: Mali
Score: 87 points
Average: 3.46
Mali got 87 (avg 3.5)
อธิบายทีละขั้น
  1. %s ถูกแทนด้วย Mali
  2. %d ถูกแทนด้วย 87
  3. %.2f ปัด 3.456 → 3.46
  4. บรรทัดสุดท้ายมี 3 specifier จับคู่กับ name, score, average ตามลำดับ
  5. %n ขึ้นบรรทัด (printf ไม่ขึ้นบรรทัดเองเหมือน println)

ตัวอย่าง 4.1.3 · จัดรูปแบบราคารวม ต่อยอด

แนวคิด: เงินควรแสดง 2 ตำแหน่งเสมอ และตัวเลขใหญ่ควรมีจุลภาคคั่นหลักพัน

Java source · PrintTotal.java
public class PrintTotal {
    public static void main(String[] args) {
        int quantity = 3;
        double unitPrice = 12.5;
        double total = quantity * unitPrice;
        System.out.println("Total (println): " + total);
        System.out.printf("Total (printf): %.2f baht%n", total);

        double salary = 1234567.891;
        System.out.printf("Salary: %,.2f baht%n", salary);
        System.out.printf("Discount: %d%%%n", 15);
    }
}
Output
Total (println): 37.5
Total (printf): 37.50 baht
Salary: 1,234,567.89 baht
Discount: 15%
อธิบายทีละขั้น
  1. println แสดง 37.5 (ทศนิยมตามค่าจริง)
  2. printf %.2f แสดง 37.50
  3. %,.2f → 1,234,567.89
  4. ถ้าต้องการแสดงเครื่องหมาย % ให้เขียน %%

เปลี่ยน %.2f เป็น %.1f หรือ %.0f แล้วเปรียบเทียบผล

ตัวอย่าง 4.1.4 · ตารางที่คอลัมน์ตรงกันด้วยความกว้าง ประยุกต์

แนวคิด: ใส่ตัวเลขความกว้างหน้า specifier: %-10s ข้อความกว้าง 10 ชิดซ้าย, %5d ตัวเลขกว้าง 5 ชิดขวา, %8.2f กว้าง 8 ทศนิยม 2

Java source · AlignedTable.java
public class AlignedTable {
    public static void main(String[] args) {
        System.out.printf("%-10s %5s %8s%n", "Item", "Qty", "Price");
        System.out.printf("%-10s %5d %8.2f%n", "Pen", 12, 5.5);
        System.out.printf("%-10s %5d %8.2f%n", "Notebook", 3, 45.0);
        System.out.printf("%-10s %5d %8.2f%n", "Bag", 1, 399.75);
        System.out.println("-".repeat(25));
        System.out.printf("%-10s %14.2f%n", "Total", 12 * 5.5 + 3 * 45.0 + 399.75);
    }
}
Output
Item         Qty    Price
Pen           12     5.50
Notebook       3    45.00
Bag            1   399.75
-------------------------
Total              600.75
อธิบายทีละขั้น
  1. ชื่อสินค้าชิดซ้ายกว้าง 10 ช่อง ไม่ว่าชื่อยาวเท่าไร คอลัมน์ถัดไปก็เริ่มที่เดียวกัน
  2. ตัวเลขชิดขวา หลักหน่วยจึงตรงกัน อ่านง่าย
  3. "-".repeat(25) สร้างเส้น 25 ตัว

ทดลอง error 4.1.5 · specifier ไม่ตรงชนิด ท้าทาย

แนวคิด: printf ตรวจชนิดตอนรัน ไม่ใช่ตอนคอมไพล์ ถ้าใช้ %d กับ double โปรแกรมจะหยุดด้วย IllegalFormatConversionException

Java source · WrongSpecifier.java
public class WrongSpecifier {
    public static void main(String[] args) {
        double price = 19.5;
        System.out.printf("Price: %.2f%n", price);
        System.out.printf("Price: %d%n", price);
    }
}
Output + Runtime error
Price: 19.50
Price:
Exception in thread "main" java.util.IllegalFormatConversionException: d != java.lang.Double
	at WrongSpecifier.main(WrongSpecifier.java:5)
อธิบายทีละขั้น
  1. บรรทัดแรกถูกต้อง พิมพ์ 19.50
  2. บรรทัดที่สองใช้ %d กับ double → d != java.lang.Double
  3. จำคู่: %d ↔ int, %f ↔ double, %s ↔ String
ลองคิดก่อน · ทำนาย printf
System.out.printf("[%6.1f]%n", 3.14159);
System.out.printf("[%-6s]%n", "ab");
System.out.printf("%d + %d = %d%n", 2, 3, 2 + 3);
ดูคำตอบ
[   3.1]
[ab    ]
2 + 3 = 5

4.2 รับข้อมูลตัวเลขด้วย Scanner

ขั้นตอนใช้ Scanner
  1. นำเข้าคลาสไว้บนสุดของไฟล์: import java.util.Scanner;
  2. สร้างออบเจ็กต์หนึ่งครั้งใน main: Scanner input = new Scanner(System.in);
  3. พิมพ์ prompt ด้วย print เพื่อบอกผู้ใช้ว่าต้องป้อนอะไร
  4. เรียกเมธอดอ่านให้ตรงกับชนิด แล้วเก็บในตัวแปร: int age = input.nextInt();
  5. นำค่าไปคำนวณและแสดงผล
เมธอดอ่านอะไรเก็บใน
nextInt()จำนวนเต็มหนึ่งค่า (token)int
nextDouble()ทศนิยมหนึ่งค่า (รับ 2 ก็ได้ จะกลายเป็น 2.0)double
next()ข้อความหนึ่งคำ (จนถึงช่องว่าง)String
nextLine()ข้อความทั้งบรรทัด (รวมช่องว่าง)String
nextBoolean()true หรือ falseboolean

ตัวอย่าง 4.2.1 · รับจำนวนเต็มหนึ่งค่า พื้นฐาน

แนวคิด: โปรแกรมหยุดรอที่ nextInt() จนผู้ใช้พิมพ์แล้วกด Enter

Java source · AgeFromYear.java
import java.util.Scanner;

public class AgeFromYear {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Birth year (A.D.): ");
        int birthYear = input.nextInt();
        int age = 2026 - birthYear;
        System.out.println("You are about " + age + " years old.");
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Birth year (A.D.): 2007
You are about 19 years old.
อธิบายทีละขั้น
  1. พิมพ์ prompt แล้วรอ
  2. ผู้ใช้ป้อน 2007 → birthYear = 2007
  3. age = 2026 − 2007 = 19

ตัวอย่าง 4.2.2 · รับทศนิยมสองค่าแล้วคำนวณ ต่อยอด

แนวคิด: ผู้ใช้ต้องป้อนตามลำดับที่โปรแกรมถาม และใช้จุดเป็นทศนิยม (4.5)

Java source · RectangleArea.java
import java.util.Scanner;

public class RectangleArea {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Width: ");
        double width = input.nextDouble();
        System.out.print("Height: ");
        double height = input.nextDouble();
        double area = width * height;
        double perimeter = 2 * (width + height);
        System.out.printf("Area: %.2f%n", area);
        System.out.printf("Perimeter: %.2f%n", perimeter);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Width: 4.5
Height: 2
Area: 9.00
Perimeter: 13.00
อธิบายทีละขั้น
  1. width = 4.5
  2. height = 2 (nextDouble รับเลขจำนวนเต็มได้ กลายเป็น 2.0)
  3. พื้นที่ 9.00 และเส้นรอบรูป 13.00

ตัวอย่าง 4.2.3 · ป้อนหลายค่าในบรรทัดเดียว ประยุกต์

แนวคิด: nextInt/nextDouble อ่านทีละ token (คั่นด้วยช่องว่างหรือ Enter) ผู้ใช้จึงพิมพ์ 8 9 10 ในบรรทัดเดียวได้

Java source · ThreeScores.java
import java.util.Scanner;

public class ThreeScores {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter 3 scores: ");
        int a = input.nextInt();
        int b = input.nextInt();
        int c = input.nextInt();
        int sum = a + b + c;
        double average = sum / 3.0;
        System.out.printf("Sum = %d, Average = %.2f%n", sum, average);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Enter 3 scores: 8 9 10
Sum = 27, Average = 9.00
อธิบายทีละขั้น
  1. nextInt ครั้งแรกได้ 8 ส่วน "9 10" ยังค้างใน input
  2. ครั้งที่สองได้ 9 และครั้งที่สามได้ 10 โดยไม่ต้องรอผู้ใช้อีก
  3. หารด้วย 3.0 เพื่อให้ได้ทศนิยม

ทดลอง error 4.2.4 · ป้อนชนิดข้อมูลไม่ตรง ประยุกต์

แนวคิด: โปรแกรมคาดว่าจะได้จำนวนเต็ม ถ้าผู้ใช้ป้อน 12.5 จะเกิด InputMismatchException ระหว่างรัน

Java source · ReadInteger.java
import java.util.Scanner;

public class ReadInteger {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter an integer: ");
        int value = input.nextInt();
        System.out.println("Value: " + value);
    }
}
Output + Runtime error
Enter an integer: 12.5
Exception in thread "main" java.util.InputMismatchException
	at ReadInteger.main(ReadInteger.java:7)
อธิบายทีละขั้น
  1. nextInt พบ token "12.5" ซึ่งไม่ใช่จำนวนเต็ม
  2. โปรแกรมหยุดทันที บรรทัด Value ไม่ทำงาน
  3. แก้: ป้อน 12 หรือเปลี่ยนเป็น double + nextDouble() (บทที่ 10 จะสอนดักจับ error แบบนี้)
ใช้ Scanner ตัวเดียวทั้งโปรแกรม

สร้าง new Scanner(System.in) เพียงครั้งเดียวแล้วใช้ซ้ำ ไม่ต้องสร้างใหม่ทุกครั้งที่จะอ่าน และไม่ต้องเรียก close() กับ Scanner ของ System.in ในโปรแกรมฝึกหัด

ลองคิดก่อน · token

ถ้าโปรแกรมเรียก nextInt() 2 ครั้ง แล้วผู้ใช้พิมพ์ 5 7 9 กด Enter ครั้งเดียว ค่าที่อ่านได้คืออะไร และ 9 ไปไหน

ดูคำตอบ

ได้ 5 และ 7 ส่วน 9 ยังค้างอยู่ใน input รอให้คำสั่งอ่านถัดไป (ถ้ามี) อ่านต่อ

4.3 อ่านข้อความและจัดการบรรทัด

next() อ่านเพียงคำเดียว ถ้าข้อความมีช่องว่างให้ใช้ nextLine() ซึ่งอ่านทั้งบรรทัด หากอ่านตัวเลขด้วย nextInt() ก่อน ตัวกด Enter ที่ตามมาจะยังค้างอยู่และถูก nextLine() อ่านทันที

ภาพในหน่วยความจำ: เกิดอะไรขึ้นกับ Enter
ผู้ใช้พิมพ์:   2 0 ⏎ M a l i ␣ N i d a ⏎
nextInt()  →  อ่าน "20"         เหลือ:  ⏎ M a l i ␣ N i d a ⏎
nextLine() →  อ่านถึง ⏎ แรก = ""  (ค่าว่าง!)
----------------------------------------------------------
แก้: เรียก nextLine() ทิ้งหนึ่งครั้งหลัง nextInt()
nextLine() →  ทิ้ง ⏎            เหลือ:  M a l i ␣ N i d a ⏎
nextLine() →  "Mali Nida"  ✔

ตัวอย่าง 4.3.1 · next() อ่านแค่คำแรก พื้นฐาน

แนวคิด: เมื่อชื่อมีช่องว่าง next() จะได้แค่คำแรก ส่วนที่เหลือค้างอยู่

Java source · NextWord.java
import java.util.Scanner;

public class NextWord {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Full name: ");
        String first = input.next();
        String rest = input.nextLine();
        System.out.println("next()     = [" + first + "]");
        System.out.println("nextLine() = [" + rest + "]");
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Full name: Mali Nida
next()     = [Mali]
nextLine() = [ Nida]
อธิบายทีละขั้น
  1. next() ได้ "Mali"
  2. nextLine() อ่านส่วนที่เหลือของบรรทัดคือ " Nida" (มีช่องว่างนำหน้า)
  3. วงเล็บ [ ] ช่วยให้เห็นช่องว่างชัดเจน

ทดลองบั๊ก 4.3.2 · อ่านชื่อได้ค่าว่าง ต่อยอด

แนวคิด: nextLine() ต่อจาก nextInt() ทันที จะอ่านได้ Enter ที่ค้าง → ค่าว่าง และโปรแกรมไม่รอให้ผู้ใช้พิมพ์ชื่อ

Java source · EmptyNameBug.java
import java.util.Scanner;

public class EmptyNameBug {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Age: ");
        int age = input.nextInt();
        System.out.print("Full name: ");
        String name = input.nextLine();
        System.out.println("Name is [" + name + "]");
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Age: 20
Full name: Name is []
อธิบายทีละขั้น
  1. nextInt อ่าน 20 แต่ไม่อ่าน Enter
  2. nextLine อ่านถึง Enter ที่ค้าง → "" ทันที
  3. Output เห็น "Full name: " ตามด้วย "Name is []" โดยที่ชื่อ Mali ไม่ถูกอ่านเลย

ตัวอย่าง 4.3.3 · แก้บั๊กด้วย nextLine() ทิ้งหนึ่งครั้ง ต่อยอด

แนวคิด: หลังอ่านตัวเลข ให้เรียก input.nextLine(); เปล่า ๆ เพื่อเคลียร์ Enter ก่อนอ่านข้อความทั้งบรรทัด

Java source · FullName.java
import java.util.Scanner;

public class FullName {

  2. Integer.parseInt("20") แปลงข้อความเป็น int 20
  3. Double.parseDouble("3.75") แปลงเป็น double

จำเป็นคู่

ใช้ next() สำหรับ token เดียว เช่น รหัสที่ไม่มีช่องว่าง และใช้ nextLine() สำหรับชื่อเต็มหรือประโยค อย่าเรียก nextLine() ต่อจาก nextInt()/nextDouble() โดยไม่จัดการ Enter ที่ค้าง

ลองคิดก่อน · Enter ค้าง

โปรแกรมเรียก nextDouble() แล้วตามด้วย next() จะเจอปัญหา Enter ค้างหรือไม่

ดูคำตอบ

ไม่ เพราะ next() ข้ามช่องว่างและ Enter ที่อยู่ข้างหน้าก่อนอ่าน token ปัญหาเกิดกับ nextLine() เท่านั้น

import java.util.Scanner;

public class CafeReceipt {

        System.out.printf("%-14s %10.2f%n", "VAT 7%", vat);
        System.out.printf("%-14s %10.2f%n", "Total", total);
        System.out.println("=".repeat(28));
    }
}

import java.util.Scanner;

public class CurrencyExchange {
    public static void main(String[] args) {
        final double FEE_RATE = 0.015;
        Scanner input = new Scanner(System.in);
        System.out.print("Customer: ");
        String customer = input.nextLine();
        System.out.print("Thai baht: ");
        double baht = input.nextDouble();
        System.out.print("Rate (THB per USD): ");
        double rate = input.nextDouble();

        double fee = baht * FEE_RATE;
        double usd = (baht - fee) / rate;

        System.out.printf("Hello %s%n", customer);
        System.out.printf("Amount : %,10.2f THB%n", baht);
        System.out.printf("Fee    : %,10.2f THB%n", fee);
        System.out.printf("You get: %,10.2f USD%n", usd);
    }
}

        System.out.print("Tip (%): ");
        double tipPercent = input.nextDouble();

        double tip = food * tipPercent / 100;
        double total = food + tip;
        double each = total / people;
        int eachRounded = (int) Math.ceil(each);
        double extra = eachRounded * people - total;

        System.out.printf("%-16s %10.2f%n", "Tip", tip);
        System.out.printf("%-16s %10.2f%n", "Total", total);
        System.out.printf("%-16s %10.2f%n", "Exact per person", each);
        System.out.printf("%-16s %10d%n", "Each pays", eachRounded);
        System.out.printf("%-16s %10.2f%n", "Extra collected", extra);
    }
}

Exercise 4.9สรุปผลการเรียนรายวิชา★★★ ท้าทาย

รับชื่อวิชา (มีช่องว่าง) ชื่อนักศึกษา (มีช่องว่าง) และคะแนน 3 ส่วน: เก็บ (เต็ม 40) กลางภาค (เต็ม 30) ปลายภาค (เต็ม 30) คำนวณคะแนนรวม ร้อยละของแต่ละส่วนเทียบกับคะแนนเต็มของส่วนนั้น แล้วพิมพ์รายงานตามตัวอย่าง

สิ่งที่ต้องทำ
  1. ลำดับการถาม: ชื่อวิชา → ชื่อนักศึกษา → คะแนน 3 ส่วนในบรรทัดเดียว
  2. ร้อยละ = คะแนน ÷ คะแนนเต็ม × 100 แสดงทศนิยม 1 ตำแหน่ง
  3. รายงานมีกรอบด้วย = และคอลัมน์ตรงกัน
  4. ใช้ %% แสดงเครื่องหมาย %
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

Computer Programming
Mali Jaidee
------------------------------------
Work       35.0 / 40  ( 87.5%)
Midterm    21.5 / 30  ( 71.7%)

ตัวอย่างคำตอบ

import java.util.Scanner;

public class CourseReport {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Course: ");
        String course = input.nextLine();
        System.out.print("Student: ");
        String student = input.nextLine();
        System.out.print("Scores (work mid final): ");
        double work = input.nextDouble();
        double mid = input.nextDouble();
        double fin = input.nextDouble();
        double total = work + mid + fin;

        System.out.println("=".repeat(36));
        System.out.printf("%s%n%s%n", course, student);
        System.out.println("-".repeat(36));
        System.out.printf("%-8s %6.1f / 40  (%5.1f%%)%n", "Work", work, work / 40 * 100);
        System.out.printf("%-8s %6.1f / 30  (%5.1f%%)%n", "Midterm", mid, mid / 30 * 100);
        System.out.printf("%-8s %6.1f / 30  (%5.1f%%)%n", "Final", fin, fin / 30 * 100);
        System.out.println("-".repeat(36));
        System.out.printf("%-8s %6.1f / 100%n", "Total", total);
        System.out.println("=".repeat(36));
    }
}

Exercise 4.10ผ่อนชำระสินค้า★★★ ท้าทาย

ร้านให้ผ่อนสินค้าแบบดอกเบี้ยคงที่ รับชื่อสินค้า (มีช่องว่าง) ราคา เงินดาวน์ (%) จำนวนเดือน และดอกเบี้ยต่อเดือน (%) แล้วคำนวณ

  • เงินดาวน์ = ราคา × ดาวน์% ÷ 100
  • ยอดจัด = ราคา − เงินดาวน์
  • ดอกเบี้ยรวม = ยอดจัด × ดอกเบี้ย% ÷ 100 × จำนวนเดือน
  • ค่างวด = (ยอดจัด + ดอกเบี้ยรวม) ÷ จำนวนเดือน
  • ราคารวมที่จ่ายจริง = เงินดาวน์ + ยอดจัด + ดอกเบี้ยรวม
สิ่งที่ต้องทำ
  1. ทุกจำนวนเงินแสดงด้วย %,.2f
  2. แสดงว่าจ่ายแพงกว่าราคาเงินสดกี่บาท และคิดเป็นกี่ %
  3. ทดสอบตามตัวอย่าง แล้วลองดาวน์ 0% ด้วย
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

import java.util.Scanner;

public class Installment {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Product: ");
        String product = input.nextLine();
        System.out.print("Price: ");
        double price = input.nextDouble();
        System.out.print("Down payment (%): ");
        double downPercent = input.nextDouble();
        System.out.print("Months: ");
        int months = input.nextInt();
        System.out.print("Interest per month (%): ");
        double rate = input.nextDouble();

        double down = price * downPercent / 100;
        double financed = price - down;
        double interest = financed * rate / 100 * months;
        double monthly = (financed + interest) / months;
        double paid = down + financed + interest;
        double extra = paid - price;

        System.out.println("== " + product + " ==");
        System.out.printf("Down payment : %,12.2f%n", down);
        System.out.printf("Financed     : %,12.2f%n", financed);
        System.out.printf("Interest     : %,12.2f%n", interest);
        System.out.printf("Monthly x %-3d: %,12.2f%n", months, monthly);
        System.out.printf("Total paid   : %,12.2f%n", paid);
        System.out.printf("Extra cost   : %,12.2f (%.2f%%)%n", extra, extra / price * 100);
    }
}
