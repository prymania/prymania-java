Components และ Layout

เลือก component ให้ตรงกับข้อมูล และใช้ layout manager จัดตำแหน่งโดยไม่กำหนดพิกัดทุกชิ้นด้วยตัวเอง

เมื่อจบบทนี้ นิสิตจะทำได้
  • เลือก JLabel, JButton, JTextField และ JTextArea
  • ใช้ JScrollPane กับเนื้อหาที่ยาว
  • รับตัวเลือกด้วย JComboBox, JCheckBox, JRadioButton
  • เลือกระหว่าง Flow, Border, Grid และ Box layout แล้วประกอบหลาย panel

15. ประกอบหน้าจอจากชิ้นส่วน Swing

หน้าจอแบ่งเป็น component ที่แสดงหรือรับข้อมูล กับ container ที่บรรจุ component อีกที แต่ละ container มี layout manager คำนวณตำแหน่งให้ตามขนาดหน้าต่าง ทำให้หน้าจอยังดูดีเมื่อผู้ใช้ย่อขยายหน้าต่างหรือใช้ฟอนต์ต่างกัน บทนี้ยังไม่ทำให้ปุ่มตอบสนอง (บทที่ 16) แต่บางภาพจำลองการพิมพ์หรือเลือกค่าเพื่อให้เห็นสถานะของ component

15.1 JLabel, JButton และ JPanel

Componentใช้ทำอะไรเมธอดที่ใช้บ่อย
JLabelแสดงข้อความ (ผู้ใช้แก้ไม่ได้)setText, getText, setFont, setForeground
JButtonปุ่มให้ผู้ใช้กดsetText, setEnabled, setToolTipText, addActionListener (บทที่ 16)
JPanelcontainer จัดกลุ่มadd, setLayout, setBorder, setBackground

ตัวอย่าง 15.1.1 · label และปุ่มหลายสถานะ พื้นฐาน

แนวคิด: ปุ่มที่ setEnabled(false) จะเป็นสีเทาและกดไม่ได้ ใช้บอกผู้ใช้ว่ายังทำขั้นนั้นไม่ได้

LabelButtons.java
import javax.swing.*;

public class LabelButtons {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Step 1 of 3");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JPanel panel = new JPanel();
            panel.add(new JLabel("Welcome to registration"));
            JButton back = new JButton("Back");
            back.setEnabled(false);  // ปุ่มกดไม่ได้ (สีจาง)
            JButton next = new JButton("Next");
            // ข้อความเมื่อชี้เมาส์ค้าง
            next.setToolTipText("Go to step 2");
            panel.add(back);
            panel.add(next);
            frame.add(panel);
            frame.pack();
            frame.setVisible(true);
        });
    }
}
หน้าต่างที่ได้ (ภาพจากโปรแกรมจริง)
อธิบายทีละขั้น
  1. Back ถูกปิดเพราะอยู่หน้าแรก
  2. Next มี tooltip แสดงเมื่อเอาเมาส์ชี้

ตัวอย่าง 15.1.2 · label แบบ HTML และการจัดแนว ต่อยอด

แนวคิด: JLabel รับข้อความ HTML อย่างง่ายได้ (ขึ้นบรรทัดด้วย <br>, ตัวหนา, สี) และจัดแนวข้อความด้วย SwingConstants

HtmlLabel.java
import javax.swing.*;
import java.awt.*;

public class HtmlLabel {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Notice");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            // JLabel ใช้ HTML จัดรูปแบบได้
            JLabel label = new JLabel("<html><b>Exam schedule</b><br>Midterm: 12 Oct<br>"
                + "<font color='red'>Final: 15 Dec</font></html>");
            // จัดข้อความกึ่งกลาง
            label.setHorizontalAlignment(SwingConstants.CENTER);
            label.setBorder(BorderFactory.createEmptyBorder(12, 30, 12, 30));
            frame.add(label, BorderLayout.CENTER);
            frame.pack();
            frame.setVisible(true);
        });
    }
}
หน้าต่างที่ได้ (ภาพจากโปรแกรมจริง)
อธิบายทีละขั้น
  1. ข้อความขึ้นต้น <html> จะถูกตีความเป็น HTML
  2. <br> ขึ้นบรรทัด <b> ตัวหนา <font color> สี
  3. ใช้เท่าที่จำเป็น: ข้อความธรรมดาอ่านและดูแลง่ายกว่า

15.2 JTextField, JTextArea และ JScrollPane

JTextField เหมาะกับข้อความบรรทัดเดียว เช่น ชื่อหรือรหัส; JPasswordField สำหรับรหัสผ่าน; JTextArea รับข้อความหลายบรรทัด และควรใส่ใน JScrollPane เพื่อเลื่อนดูเมื่อข้อความยาว ค่าที่อ่านได้จากช่องเหล่านี้เป็น String เสมอ (ตัวเลขต้อง parse แบบบทที่ 9)

ตัวอย่าง 15.2.1 · ช่องกรอกบรรทัดเดียวพร้อมข้อความที่ผู้ใช้พิมพ์ พื้นฐาน

แนวคิด: JTextField(คอลัมน์) กำหนดความกว้างโดยประมาณ ภาพนี้จำลองว่าผู้ใช้พิมพ์ข้อมูลลงไปแล้ว

public class TextFields {
    public static void main(String[] args) {

            panel.add(new JLabel("ID:"));
            panel.add(new JTextField(7));
            frame.add(panel);
            frame.pack();

}

  2. ค่าที่พิมพ์อ่านได้ด้วย getText() (บทที่ 16–17)

ตัวอย่าง 15.2.2 · JTextArea ใน JScrollPane ต่อยอด

แนวคิด: ตั้งจำนวนแถว/คอลัมน์ เปิดการตัดคำด้วย setLineWrap(true) และ setWrapStyleWord(true) แล้วห่อด้วย JScrollPane

NotesArea.java
import javax.swing.*;
import java.awt.*;

public class NotesArea {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Notes");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            // 5 แถว 24 คอลัมน์
            JTextArea notes = new JTextArea(5, 24);
            // ตัดบรรทัดเมื่อยาวเกิน
            notes.setLineWrap(true);
            // ตัดที่ช่องว่างระหว่างคำ
            notes.setWrapStyleWord(true);
            StringBuilder sb = new StringBuilder();
            for (int i = 1; i <= 8; i++) {
                sb.append("Line ").append(i).append(": remember to practice Java every day.\n");
            }
            // ใส่ข้อความทั้งหมด
            notes.setText(sb.toString());
            // เลื่อนเคอร์เซอร์ไปต้นข้อความ
            notes.setCaretPosition(0);
            // ห่อด้วย JScrollPane จึงเลื่อนดูได้
            frame.add(new JScrollPane(notes), BorderLayout.CENTER);
            frame.add(new JLabel("8 lines - scroll to read more"), BorderLayout.SOUTH);
            frame.pack();
            frame.setVisible(true);
        });
    }
}
หน้าต่างที่ได้ (ภาพจากโปรแกรมจริง)
อธิบายทีละขั้น
  1. JTextArea(5, 24) แสดง 5 แถว กว้าง 24 คอลัมน์
  2. ข้อความ 8 บรรทัดยาวเกิน จึงมี scrollbar
  3. setCaretPosition(0) เลื่อนไปบนสุด
  4. ถ้าไม่ห่อด้วย JScrollPane หน้าต่างจะขยายหรือข้อความล้น

ตัวอย่าง 15.2.3 · ช่องอ่านอย่างเดียว ช่องรหัสผ่าน และการจัดแนว ประยุกต์

แนวคิด: setEditable(false) ใช้แสดงค่าที่คำนวณได้, JPasswordField แสดงจุดแทนตัวอักษร, setHorizontalAlignment จัดตัวเลขชิดขวา

FieldVariants.java
import javax.swing.*;
import java.awt.*;

public class FieldVariants {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Field types");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            // ตาราง 3 แถว 2 คอลัมน์
            JPanel panel = new JPanel(new GridLayout(3, 2, 6, 6));
            panel.setBorder(BorderFactory.createEmptyBorder(10, 10, 10, 10));
            JTextField total = new JTextField("1,250.00");
            // อ่านอย่างเดียว
            total.setEditable(false);
            // ตัวเลขชิดขวา
            total.setHorizontalAlignment(JTextField.RIGHT);
            panel.add(new JLabel("Total (read-only):"));
            panel.add(total);
            panel.add(new JLabel("Password:"));
            // ช่องรหัสผ่าน แสดงเป็นจุด
            panel.add(new JPasswordField(10));
            JTextField qty = new JTextField("3");
            qty.setHorizontalAlignment(JTextField.RIGHT);
            panel.add(new JLabel("Quantity:"));
            panel.add(qty);
            frame.add(panel);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

อธิบายทีละขั้น
  1. ช่อง Total พื้นเทา แก้ไม่ได้ แต่คัดลอกได้
  2. JPasswordField ซ่อนตัวอักษร — อ่านค่าด้วย getPassword() ซึ่งคืน char[]
  3. GridLayout(3, 2) จัดป้ายกับช่องเป็นคู่ ๆ

15.3 ตัวเลือก: JComboBox, JCheckBox และ JRadioButton

Componentเหมาะกับอ่านค่า

ตัวอย่าง 15.3.1 · JComboBox จากอาเรย์ พื้นฐาน

แนวคิด: สร้าง combo box จากอาเรย์ String ภาพจำลองว่าผู้ใช้เลือกรายการที่ index 2

FacultyCombo.java
import javax.swing.*;

public class FacultyCombo {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Faculty");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

            frame.add(panel);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

  1. JComboBox<String> ใช้ generic เหมือน ArrayList
  2. ค่าเริ่มต้นเลือกตัวแรก

15.4 Layout Manager: Flow, Border, Grid และ Box

Layoutจัดอย่างไรเหมาะกับ
FlowLayoutเรียงซ้าย→ขวา ตัดบรรทัดเมื่อเต็ม ขนาดตาม preferred sizeแถวปุ่ม, แถบเครื่องมือเล็ก ๆ
BorderLayout5 พื้นที่: NORTH, SOUTH, EAST, WEST, CENTER (CENTER ยืดเต็มที่เหลือ)โครงหน้าจอหลัก
GridLayout(r, c)ตารางที่ทุกช่องขนาดเท่ากันปุ่มเครื่องคิดเลข, ฟอร์มป้าย–ช่อง
BoxLayoutเรียงแนวตั้งหรือแนวนอนแถวเดียว ไม่ยืดเท่ากันรายการแนวตั้ง, ฟอร์มที่ต้องการระยะห่างอิสระ

ตัวอย่าง 15.4.1 · BorderLayout: 5 พื้นที่ พื้นฐาน

แนวคิด: ใส่ปุ่มทั้ง 5 ตำแหน่งให้เห็นว่าแต่ละพื้นที่ขยายตัวอย่างไร — CENTER ได้พื้นที่ที่เหลือทั้งหมด

  2. WEST/EAST ยืดเต็มความสูงที่เหลือ กว้างเท่าที่จำเป็น
  3. CENTER ได้พื้นที่ที่เหลือทั้งหมด
  4. BorderLayout(4, 4) เว้นช่องว่างระหว่างพื้นที่

ตัวอย่าง 15.4.3 · BoxLayout แนวตั้งพร้อมระยะห่าง ประยุกต์

แนวคิด: BoxLayout.Y_AXIS วางเป็นแนวตั้ง ใช้ Box.createVerticalStrut(n) เว้นระยะ และ setAlignmentX จัดชิดซ้าย

BoxDemo.java
import javax.swing.*;
import java.awt.*;

public class BoxDemo {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Settings");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JPanel box = new JPanel();
            // เรียงจากบนลงล่าง
            box.setLayout(new BoxLayout(box, BoxLayout.Y_AXIS));
            box.setBorder(BorderFactory.createEmptyBorder(12, 16, 12, 16));
            JLabel title = new JLabel("Notifications");
            // ตัวหนา ขนาด 15
            title.setFont(title.getFont().deriveFont(Font.BOLD, 15f));
            box.add(title);
            // ช่องว่างแนวตั้ง 8 พิกเซล
            box.add(Box.createVerticalStrut(8));
            box.add(new JCheckBox("Email me when grades are posted", true));
            box.add(new JCheckBox("Remind me before deadlines", true));
            box.add(new JCheckBox("Weekly summary"));
            box.add(Box.createVerticalStrut(12));
            box.add(new JButton("Save"));
            // จัดชิดซ้ายทุก component
            for (Component c : box.getComponents()) {
                // แปลงเป็น JComponent เพื่อเรียก setAlignmentX
                ((JComponent) c).setAlignmentX(Component.LEFT_ALIGNMENT);
            }
            frame.setContentPane(box);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

  1. component เรียงลงมาทีละแถว ขนาดตามธรรมชาติ (ไม่ยืดเท่ากันแบบ Grid)
  2. strut เว้นระยะแนวตั้งคงที่
  3. ทุก component ต้อง alignment เดียวกัน ไม่เช่นนั้นจะเยื้องกัน

15.5 ประกอบหลาย panel เป็นหน้าจอเดียว

ขั้นตอนออกแบบหน้าจอ
  1. ร่างหน้าจอบนกระดาษ แล้วตีกรอบเป็นสี่เหลี่ยมตามกลุ่มของข้อมูล
  2. แต่ละกรอบคือ panel หนึ่งตัว เลือก layout ตามลักษณะของกรอบนั้น (ฟอร์ม → Grid, แถวปุ่ม → Flow, รายการ → Box)
  3. panel ใหญ่ที่สุด (content pane) มักใช้ BorderLayout วางกรอบย่อยตามตำแหน่ง
  4. แยกการสร้างแต่ละ panel เป็นเมธอด เช่น buildForm(), buildButtons()
  5. ทดสอบย่อ/ขยายหน้าต่าง ว่าส่วนที่ควรยืดยืดจริง

ตัวอย่าง 15.5.1 · ฟอร์มลงทะเบียนจาก 3 panel ประยุกต์

แนวคิด: หัวเรื่อง (NORTH) + ฟอร์ม GridLayout (CENTER) + แถวปุ่ม FlowLayout (SOUTH) แต่ละส่วนสร้างในเมธอดของตัวเอง

RegistrationForm.java
import javax.swing.*;
import java.awt.*;

public class RegistrationForm {
    public static void main(String[] args) {
        // เรียกเมธอด show บน EDT
        SwingUtilities.invokeLater(RegistrationForm::show);
    }

    static void show() {
        JFrame frame = new JFrame("Registration");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        // layout หลักของหน้าต่าง
        JPanel root = new JPanel(new BorderLayout(8, 8));
        root.setBorder(BorderFactory.createEmptyBorder(10, 12, 10, 12));
        // แต่ละส่วนสร้างจากเมธอดของตัวเอง
        root.add(buildHeader(), BorderLayout.NORTH);
        root.add(buildForm(), BorderLayout.CENTER);
        root.add(buildButtons(), BorderLayout.SOUTH);
        frame.setContentPane(root);
        frame.pack();
        frame.setVisible(true);
    }

    static JComponent buildHeader() {
        JLabel title = new JLabel("Workshop Registration");
        title.setFont(title.getFont().deriveFont(Font.BOLD, 16f));
        return title;
    }

    static JComponent buildForm() {
        // แผงซ้อนแผง
        JPanel form = new JPanel(new BorderLayout(6, 6));
        // ป้าย + ช่องกรอก 3 คู่
        JPanel fields = new JPanel(new GridLayout(3, 2, 6, 6));
        fields.add(new JLabel("Full name:"));
        fields.add(new JTextField(16));
        fields.add(new JLabel("Email:"));
        fields.add(new JTextField(16));
        fields.add(new JLabel("Session:"));
        // ตัวเลือกจากอาเรย์
        fields.add(new JComboBox<>(new String[]{"Morning", "Afternoon", "Evening"}));
        form.add(fields, BorderLayout.NORTH);
        JTextArea note = new JTextArea(3, 20);
        note.setLineWrap(true);
        // ห่อด้วย JScrollPane
        JScrollPane scroll = new JScrollPane(note);
        scroll.setBorder(BorderFactory.createTitledBorder("Note"));
        form.add(scroll, BorderLayout.CENTER);
        return form;
    }

    static JComponent buildButtons() {
        // ชิดขวา เว้นระยะ 6
        JPanel buttons = new JPanel(new FlowLayout(FlowLayout.RIGHT, 6, 0));
        buttons.add(new JButton("Clear"));
        buttons.add(new JButton("Submit"));
        return buttons;
    }
}

  1. แต่ละเมธอดคืน component ที่ประกอบเสร็จ อ่านง่ายและแก้แยกได้
  2. ฟอร์มซ้อน: GridLayout สำหรับป้าย–ช่อง ภายใน BorderLayout ที่มี Note ยืดตรงกลาง

import javax.swing.*;
import java.awt.*;
import java.util.Arrays;
import java.util.List;

public class SeatMap {
    public static void main(String[] args) {
        // ที่นั่งที่ถูกจองแล้ว
        List<String> booked = Arrays.asList("A3", "A4", "C5", "E1");
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Seat Map");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JLabel screen = new JLabel("SCREEN", SwingConstants.CENTER);
            // ต้อง setOpaque ก่อน สีพื้นหลังจึงแสดง
            screen.setOpaque(true);
            screen.setBackground(Color.DARK_GRAY);
            screen.setForeground(Color.WHITE);
            // 5 แถว 8 คอลัมน์
            JPanel seats = new JPanel(new GridLayout(5, 8, 3, 3));
            // วนตัวอักษรแถว A ถึง E
            for (char row = 'A'; row <= 'E'; row++) {
                for (int n = 1; n <= 8; n++) {
                    // "" + ทำให้ char ต่อกับตัวเลขเป็นข้อความ
                    String code = "" + row + n;
                    JButton b = new JButton(code);
                    // ลดระยะขอบในปุ่ม
                    b.setMargin(new Insets(2, 4, 2, 4));
                    // ที่นั่งที่จองแล้วกดไม่ได้
                    if (booked.contains(code)) b.setEnabled(false);
                    seats.add(b);
                }
            }
            JPanel root = new JPanel(new BorderLayout(0, 10));
            root.setBorder(BorderFactory.createEmptyBorder(10, 10, 10, 10));
            root.add(screen, BorderLayout.NORTH);
            root.add(seats, BorderLayout.CENTER);
            frame.setContentPane(root);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

import javax.swing.*;

public class CalculatorLayout {

        SwingUtilities.invokeLater(() -> {

            JScrollPane historyPane = new JScrollPane(history);
            historyPane.setBorder(BorderFactory.createTitledBorder("History"));

            JPanel bottom = new JPanel(new FlowLayout(FlowLayout.LEFT, 4, 0));
            bottom.add(new JButton("C"));
            bottom.add(new JButton("Clear history"));

            JPanel root = new JPanel(new BorderLayout(6, 6));

            // จอด้านบน
            root.add(display, BorderLayout.NORTH);
            // ปุ่มตรงกลาง
