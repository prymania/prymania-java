Components และ Layout

เลือก component ให้ตรงกับข้อมูล และใช้ layout manager จัดตำแหน่งโดยไม่กำหนดพิกัดทุกชิ้นด้วยตัวเอง

เมื่อจบบทนี้ นิสิตจะทำได้
  • เลือก JLabel, JButton, JTextField และ JTextArea
  • ใช้ JScrollPane กับเนื้อหาที่ยาว
  • รับตัวเลือกด้วย JComboBox
  • เลือกระหว่าง Flow, Border, Grid และ Box layout
  • ประกอบ panel ย่อยเป็นหน้าจอเดียว

15. ประกอบหน้าจอจากชิ้นส่วน

Swing แบ่งเป็น component ที่แสดงหรือรับข้อมูล กับ container ที่บรรจุ component อีกที แต่ละ container มี layout manager คำนวณตำแหน่งให้ตามขนาดหน้าต่าง

15.1 JLabel, JButton และ JPanel

JLabel ใช้แสดงข้อความหรือไอคอน, JButton เป็นปุ่มที่ผู้ใช้กด และ JPanel เป็น container ย่อยสำหรับจัดกลุ่มสิ่งที่เกี่ยวข้อง

เพิ่ม label และปุ่มลง panel
JPanel panel = new JPanel();
JLabel title = new JLabel("Welcome");
JButton nextButton = new JButton("Next");
panel.add(title);
panel.add(nextButton);
frame.setContentPane(panel);

JPanel ใช้ FlowLayout โดยปริยาย จึงวาง component ต่อกันตามลำดับที่ add

ปุ่มยังไม่ทำงานจนกว่าจะผูก event

บทนี้สร้างรูปร่างและตำแหน่งของปุ่มก่อน การตอบสนองต่อการคลิกจะเรียนในบทถัดไป

Exercise 15.1หัวหน้าต่างโปรไฟล์

สร้าง JPanel ที่มี JLabel แสดงชื่อหน้าและ JButton ชื่อ Edit

ตัวอย่างคำตอบ

JPanel panel = new JPanel();
panel.add(new JLabel("Student Profile"));
panel.add(new JButton("Edit"));

15.2 JTextField, JTextArea และ JScrollPane

JTextField เหมาะกับข้อความบรรทัดเดียว เช่น ชื่อหรือรหัส; JTextArea รับข้อความหลายบรรทัด และมักใส่ใน JScrollPane เพื่อเลื่อนดูเมื่อข้อความยาว

สร้างช่องกรอกและกล่องข้อความ
JTextField nameField = new JTextField(18);
JTextArea noteArea = new JTextArea(5, 18);
noteArea.setLineWrap(true);
noteArea.setWrapStyleWord(true);
JScrollPane noteScroll = new JScrollPane(noteArea);
panel.add(new JLabel("Name:"));
panel.add(nameField);
panel.add(noteScroll);

ตัวเลขใน constructor บอกขนาดที่ต้องการโดยประมาณ ไม่ใช่จำนวนตัวอักษรสูงสุด

Password field

ข้อมูลรหัสผ่านควรใช้ JPasswordField ซึ่งแสดงอักขระแทนค่าจริง และอ่านผ่าน getPassword() แทนการใช้ JTextField ปกติ

Exercise 15.2กล่องบันทึกคำอธิบาย

เพิ่ม JTextField สำหรับหัวข้อ และ JTextArea ที่เลื่อนอ่านได้สำหรับรายละเอียด

ตัวอย่างคำตอบ

JTextField titleField = new JTextField(20);
JTextArea details = new JTextArea(6, 20);
details.setLineWrap(true);
JScrollPane scroll = new JScrollPane(details);
panel.add(titleField);
panel.add(scroll);

15.3 JComboBox สำหรับตัวเลือก

ใช้ JComboBox เมื่อผู้ใช้ควรเลือกหนึ่งค่าจากรายการที่กำหนดไว้ ช่วยลด input ที่สะกดไม่ตรงและใช้พื้นที่น้อยกว่าแสดงทุกตัวเลือกพร้อมกัน

เติมรายการและกำหนดค่าเริ่มต้น
String[] levels = {"Beginner", "Intermediate", "Advanced"};
JComboBox<String> levelBox = new JComboBox<>(levels);
levelBox.setSelectedIndex(0);
panel.add(new JLabel("Level:"));
panel.add(levelBox);

อ่านตัวเลือกที่เลือกภายหลังด้วย getSelectedItem(); ค่าที่คืนมีชนิด Object จึงอาจต้องแปลงชนิดตามที่ประกาศ

Exercise 15.3เลือกสาขาวิชา

สร้าง ComboBox สำหรับ Computer Science, Information Technology และ Data Science โดยเลือก Computer Science เป็นค่าเริ่มต้น

ตัวอย่างคำตอบ

String[] majors = {"Computer Science", "Information Technology", "Data Science"};
JComboBox<String> majorBox = new JComboBox<>(majors);
majorBox.setSelectedIndex(0);

15.4 Layout Manager เลือกตามรูปแบบหน้าจอ

หลีกเลี่ยงการกำหนดตำแหน่งด้วยพิกัด absolute เพราะหน้าต่างปรับขนาดไม่ได้ดี Layout manager จัดตำแหน่งใหม่ตามขนาด container และ preferred size

Layoutวิธีจัดเหมาะกับ
FlowLayoutเรียงต่อกันตามแนว แล้วขึ้นบรรทัดแถบปุ่มหรือรายการสั้น
BorderLayoutแบ่ง North, South, East, West, Centerโครงหน้าต่างหลัก
GridLayoutตารางแถว/คอลัมน์ ขนาดช่องเท่ากันเครื่องคิดเลขหรือปุ่มตัวเลข
BoxLayoutเรียงแนวตั้งหรือแนวนอนฟอร์มที่จัดเป็นแนวเดียว
BorderLayout แบ่งพื้นที่หลัก
JPanel panel = new JPanel(new BorderLayout(8, 8));
panel.add(new JLabel("Header"), BorderLayout.NORTH);
panel.add(new JScrollPane(new JTextArea()), BorderLayout.CENTER);
panel.add(new JButton("Save"), BorderLayout.SOUTH);

BorderLayout รับ component ได้หนึ่งชิ้นต่อ region; ถ้าต้องมีหลายชิ้นใน region ให้สร้าง JPanel ย่อย

Exercise 15.4เลือก Layout

เลือก layout ที่เหมาะกับ (1) ปุ่ม 12 ปุ่มในตาราง 3×4 (2) แถบปุ่ม Save/Cancel เรียงกัน (3) พื้นที่เนื้อหากลางหน้าต่าง

แนวคำตอบ

  1. GridLayout(3, 4)
  2. FlowLayout หรือ BoxLayout แนวนอน
  3. BorderLayout.CENTER

15.5 ประกอบหลาย JPanel และใช้ pack()

หน้าจอจริงมักใช้ panel ซ้อนกัน แต่ละ panel ดูแล layout ส่วนของตัวเอง แล้วนำไปวางใน JFrame ที่ใช้ BorderLayout เป็นโครงหลัก

จัด header, form และ footer แยกหน้าที่
JPanel header = new JPanel(new FlowLayout(FlowLayout.LEFT));
header.add(new JLabel("Student Form"));

JPanel form = new JPanel(new GridLayout(2, 2, 8, 8));
form.add(new JLabel("Name:"));
form.add(new JTextField(16));
form.add(new JLabel("Major:"));
form.add(new JComboBox<>(new String[]{"CS", "IT"}));

frame.add(header, BorderLayout.NORTH);
frame.add(form, BorderLayout.CENTER);
frame.pack();

จัด panel ย่อยก่อน แล้วประกอบเข้าพื้นที่หลัก; pack ปรับขนาดหน้าต่างให้พอดีกับ component

Exercise 15.5หน้าจอค้นหาหนังสือ

ออกแบบหน้าจอด้วย JPanel: ด้านบนมีช่องค้นหาและปุ่ม, ตรงกลางเป็นพื้นที่ผลลัพธ์เลื่อนดูได้ และใช้ pack กำหนดขนาดตามเนื้อหา

แนวโครงสร้าง

JPanel searchBar = new JPanel(new FlowLayout(FlowLayout.LEFT));
searchBar.add(new JTextField(18));
searchBar.add(new JButton("Search"));
JTextArea results = new JTextArea(8, 24);
frame.add(searchBar, BorderLayout.NORTH);
frame.add(new JScrollPane(results), BorderLayout.CENTER);
frame.pack();

แบบฝึกหัดท้ายบท

ร่าง component tree และเลือก layout ก่อนเขียน code

Exercise 15.6ออกแบบฟอร์มลงทะเบียน

สร้างหน้าต่างมีชื่อ, รหัสนักศึกษา, สาขา, หมายเหตุหลายบรรทัด และปุ่ม Clear/Submit แบ่งกลุ่มด้วย JPanel และใช้ JScrollPane กับหมายเหตุ

โครงสร้างตัวอย่าง

JPanel form = new JPanel(new GridLayout(3, 2, 8, 8));
form.add(new JLabel("Name:")); form.add(new JTextField(18));
form.add(new JLabel("Student ID:")); form.add(new JTextField(18));
form.add(new JLabel("Major:")); form.add(new JComboBox<>(majors));
JPanel buttons = new JPanel(new FlowLayout(FlowLayout.RIGHT));
buttons.add(new JButton("Clear")); buttons.add(new JButton("Submit"));
frame.add(form, BorderLayout.CENTER);
frame.add(new JScrollPane(new JTextArea(4, 20)), BorderLayout.SOUTH);
frame.add(buttons, BorderLayout.PAGE_END);
frame.pack();

ในงานจริงอาจปรับ layout ย่อยเพื่อไม่ให้ footer ซ้ำ region กับ South
