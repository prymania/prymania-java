Components และ Layout

เลือก component ให้ตรงกับข้อมูล และใช้ layout manager จัดตำแหน่งโดยไม่กำหนดพิกัดทุกชิ้นด้วยตัวเอง

เมื่อจบบทนี้ นิสิตจะทำได้
  • เลือก JLabel, JButton, JTextField และ JTextArea
  • ใช้ JScrollPane กับเนื้อหาที่ยาว
  • รับตัวเลือกด้วย JComboBox, JCheckBox, JRadioButton
  • เลือกระหว่าง Flow, Border, Grid และ Box layout แล้วประกอบหลาย panel

15. ประกอบหน้าจอจากชิ้นส่วน Swing

หน้าจอแบ่งเป็น component ที่แสดงหรือรับข้อมูล กับ container ที่บรรจุ component อีกที แต่ละ container มี layout manager คำนวณตำแหน่งให้ตามขนาดหน้าต่าง ทำให้หน้าจอยังดูดีเมื่อผู้ใช้ย่อขยายหน้าต่างหรือใช้ฟอนต์ต่างกัน บทนี้ยังไม่ทำให้ปุ่มตอบสนอง (บทที่ 16) แต่บางภาพจำลองการพิมพ์หรือเลือกค่าเพื่อให้เห็นสถานะของ component

15.1 JLabel, JButton และ JPanel

สามชิ้นส่วนพื้นฐานที่แทบทุกหน้าจอมี: ป้ายข้อความ ปุ่ม และ panel ที่บรรจุทั้งสองอย่าง

Componentใช้ทำอะไรเมธอดที่ใช้บ่อย
JLabelแสดงข้อความ (ผู้ใช้แก้ไม่ได้)setText, getText, setFont, setForeground
JButtonปุ่มให้ผู้ใช้กดsetText, setEnabled, setToolTipText, addActionListener (บทที่ 16)
JPanelcontainer จัดกลุ่มadd, setLayout, setBorder, setBackground

ตัวอย่าง 15.1.1ปุ่มที่กดได้และกดไม่ได้

LabelButtons.java
import javax.swing.*;

public class LabelButtons {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Step 1 of 3");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JPanel panel = new JPanel();
            panel.add(new JLabel("Welcome to registration"));
            JButton back = new JButton("Back");
            back.setEnabled(false);                       // สีจาง กดไม่ได้ (อยู่หน้าแรก)
            JButton next = new JButton("Next");
            next.setToolTipText("Go to step 2");          // แสดงเมื่อชี้เมาส์ค้าง
            panel.add(back);
            panel.add(next);
            frame.add(panel);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

label หลายบรรทัดด้วย HTML

ข้อความใน JLabel ที่ขึ้นต้นด้วย <html> จะถูกตีความเป็น HTML อย่างง่าย: <br> ขึ้นบรรทัด, <b> ตัวหนา, <font color> สี ใช้เท่าที่จำเป็น ข้อความธรรมดาดูแลง่ายกว่า

ตัวอย่าง 15.1.2ป้ายประกาศกำหนดสอบ

HtmlLabel.java
import javax.swing.*;
import java.awt.*;

public class HtmlLabel {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Notice");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JLabel label = new JLabel("<html><b>Exam schedule</b><br>Midterm: 12 Oct<br>"
                + "<font color='red'>Final: 15 Dec</font></html>");
            label.setHorizontalAlignment(SwingConstants.CENTER);          // จัดกึ่งกลาง
            label.setBorder(BorderFactory.createEmptyBorder(12, 30, 12, 30));
            frame.add(label, BorderLayout.CENTER);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

ข้อความหลายบรรทัด

JTextArea(แถว, คอลัมน์) กำหนดขนาด เปิดการตัดบรรทัดที่ช่องว่างระหว่างคำด้วย setLineWrap(true) และ setWrapStyleWord(true) แล้วห่อด้วย JScrollPane เสมอ ไม่เช่นนั้นข้อความยาวจะล้นหรือดันหน้าต่างให้ขยาย

ตัวอย่าง 15.2.2JTextArea ใน JScrollPane

NotesArea.java
import javax.swing.*;
import java.awt.*;

public class NotesArea {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Notes");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JTextArea notes = new JTextArea(5, 24);               // เห็น 5 แถว กว้าง 24 คอลัมน์
            notes.setLineWrap(true);                              // ตัดบรรทัดเมื่อยาวเกิน
            notes.setWrapStyleWord(true);                         // ตัดที่ช่องว่างระหว่างคำ
            StringBuilder sb = new StringBuilder();
            for (int i = 1; i <= 8; i++) {
                sb.append("Line ").append(i).append(": remember to practice Java every day.\n");
            }
            notes.setText(sb.toString());                         // 8 บรรทัด เกิน 5 → มี scrollbar
            notes.setCaretPosition(0);                            // เลื่อนไปบนสุด
            frame.add(new JScrollPane(notes), BorderLayout.CENTER);
            frame.add(new JLabel("8 lines - scroll to read more"), BorderLayout.SOUTH);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

15.3 ตัวเลือก: JComboBox, JCheckBox และ JRadioButton

ถ้าคำตอบมีตัวเลือกจำกัด ให้ผู้ใช้เลือกแทนการพิมพ์ ข้อมูลจะไม่ผิดรูปแบบ

Componentเหมาะกับอ่านค่า
JComboBox<String>เลือก 1 จากรายการยาว (เมนูดรอปดาวน์)getSelectedItem(), getSelectedIndex()
JRadioButton + ButtonGroupเลือก 1 จากตัวเลือกน้อย ๆ ที่อยากให้เห็นทั้งหมดisSelected()
JCheckBoxเปิด/ปิดแต่ละตัวเลือกอิสระ (เลือกได้หลายอัน)isSelected()

ตัวอย่าง 15.3.1JComboBox จากอาเรย์

FacultyCombo.java
import javax.swing.*;

public class FacultyCombo {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Faculty");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            String[] faculties = {"Science", "Engineering", "Education", "Arts"};
            JComboBox<String> combo = new JComboBox<>(faculties);  // generic เหมือน ArrayList
            JPanel panel = new JPanel();
            panel.add(new JLabel("Faculty:"));

            frame.add(panel);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

import javax.swing.*;
import java.awt.*;

public class DrinkOptions {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Drink options");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JRadioButton small = new JRadioButton("Small", true);     // true = เลือกไว้ก่อน
            JRadioButton medium = new JRadioButton("Medium");
            JRadioButton large = new JRadioButton("Large");
            ButtonGroup sizes = new ButtonGroup();                    // กลุ่ม: เลือกได้ทีละหนึ่ง
            sizes.add(small);
            sizes.add(medium);
            sizes.add(large);

            JPanel sizePanel = new JPanel();
            sizePanel.setBorder(BorderFactory.createTitledBorder("Size"));   // กรอบพร้อมหัวข้อ
            sizePanel.add(small);
            sizePanel.add(medium);
            sizePanel.add(large);

            JPanel extraPanel = new JPanel();
            extraPanel.setBorder(BorderFactory.createTitledBorder("Extras"));
            extraPanel.add(new JCheckBox("Extra shot"));              // แต่ละตัวอิสระ
            extraPanel.add(new JCheckBox("Oat milk"));
            extraPanel.add(new JCheckBox("Less sugar"));

            frame.add(sizePanel, BorderLayout.NORTH);
            frame.add(extraPanel, BorderLayout.SOUTH);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

15.4 Layout Manager: Flow, Border, Grid และ Box

layout manager คำนวณตำแหน่งและขนาดของ component ให้ใหม่ทุกครั้งที่หน้าต่างเปลี่ยนขนาด เลือกด้วย new JPanel(layout) หรือ panel.setLayout(layout)

Layoutจัดอย่างไรเหมาะกับ
FlowLayoutเรียงซ้าย→ขวา ตัดบรรทัดเมื่อเต็ม ขนาดตาม preferred sizeแถวปุ่ม, แถบเครื่องมือเล็ก ๆ
BorderLayout5 พื้นที่: NORTH, SOUTH, EAST, WEST, CENTER (CENTER ยืดเต็มที่เหลือ)โครงหน้าจอหลัก
GridLayout(r, c)ตารางที่ทุกช่องขนาดเท่ากันปุ่มเครื่องคิดเลข, ฟอร์มป้าย–ช่อง
BoxLayoutเรียงแนวตั้งหรือแนวนอนแถวเดียว ไม่ยืดเท่ากันรายการแนวตั้ง, ฟอร์มที่ต้องการระยะห่างอิสระ

BorderLayout: 5 พื้นที่

NORTH/SOUTH ยืดเต็มความกว้างแต่สูงเท่าที่จำเป็น WEST/EAST ยืดเต็มความสูงที่เหลือ และ CENTER ได้พื้นที่ที่เหลือทั้งหมด

ตัวอย่าง 15.4.1ปุ่มครบ 5 ตำแหน่ง

BoxDemo.java
import javax.swing.*;
import java.awt.*;

public class BoxDemo {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Settings");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JPanel box = new JPanel();
            box.setLayout(new BoxLayout(box, BoxLayout.Y_AXIS));     // บนลงล่าง
            box.setBorder(BorderFactory.createEmptyBorder(12, 16, 12, 16));
            JLabel title = new JLabel("Notifications");
            title.setFont(title.getFont().deriveFont(Font.BOLD, 15f));
            box.add(title);
            box.add(Box.createVerticalStrut(8));                     // ช่องว่าง 8 พิกเซล
            box.add(new JCheckBox("Email me when grades are posted", true));
            box.add(new JCheckBox("Remind me before deadlines", true));
            box.add(new JCheckBox("Weekly summary"));
            box.add(Box.createVerticalStrut(12));
            box.add(new JButton("Save"));
            for (Component c : box.getComponents()) {               // ชิดซ้ายทุกตัว
                ((JComponent) c).setAlignmentX(Component.LEFT_ALIGNMENT);
            }
            frame.setContentPane(box);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

15.5 ประกอบหลาย panel เป็นหน้าจอเดียว

หน้าจอจริงไม่ได้ใช้ layout เดียว แต่ซ้อน panel หลายชั้น แต่ละชั้นใช้ layout ที่เหมาะกับส่วนนั้น

ขั้นตอนออกแบบหน้าจอ
  1. ร่างหน้าจอบนกระดาษ แล้วตีกรอบเป็นสี่เหลี่ยมตามกลุ่มของข้อมูล
  2. แต่ละกรอบคือ panel หนึ่งตัว เลือก layout ตามลักษณะของกรอบนั้น (ฟอร์ม → Grid, แถวปุ่ม → Flow, รายการ → Box)
  3. panel ใหญ่ที่สุด (content pane) มักใช้ BorderLayout วางกรอบย่อยตามตำแหน่ง
  4. แยกการสร้างแต่ละ panel เป็นเมธอด เช่น buildForm(), buildButtons()
  5. ทดสอบย่อ/ขยายหน้าต่าง ว่าส่วนที่ควรยืดยืดจริง

ตัวอย่าง 15.5.1ฟอร์มลงทะเบียนจาก 3 panel

RegistrationForm.java
import javax.swing.*;
import java.awt.*;

public class RegistrationForm {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(RegistrationForm::show);
    }

    static void show() {
        JFrame frame = new JFrame("Registration");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        JPanel root = new JPanel(new BorderLayout(8, 8));         // โครงหลัก
        root.setBorder(BorderFactory.createEmptyBorder(10, 12, 10, 12));
        root.add(buildHeader(), BorderLayout.NORTH);              // หัวเรื่อง
        root.add(buildForm(), BorderLayout.CENTER);               // ฟอร์ม
        root.add(buildButtons(), BorderLayout.SOUTH);             // แถวปุ่ม
        frame.setContentPane(root);
        frame.pack();
        frame.setVisible(true);
    }

    static JComponent buildHeader() {
        JLabel title = new JLabel("Workshop Registration");
        title.setFont(title.getFont().deriveFont(Font.BOLD, 16f));
        return title;
    }

    static JComponent buildForm() {
        JPanel form = new JPanel(new BorderLayout(6, 6));
        JPanel fields = new JPanel(new GridLayout(3, 2, 6, 6));   // ป้าย | ช่อง 3 คู่
        fields.add(new JLabel("Full name:"));
        fields.add(new JTextField(16));
        fields.add(new JLabel("Email:"));
        fields.add(new JTextField(16));
        fields.add(new JLabel("Session:"));
        fields.add(new JComboBox<>(new String[]{"Morning", "Afternoon", "Evening"}));
        form.add(fields, BorderLayout.NORTH);
        JTextArea note = new JTextArea(3, 20);
        note.setLineWrap(true);
        JScrollPane scroll = new JScrollPane(note);
        scroll.setBorder(BorderFactory.createTitledBorder("Note"));
        form.add(scroll, BorderLayout.CENTER);                    // Note ยืดตามหน้าต่าง
        return form;
    }

    static JComponent buildButtons() {
        JPanel buttons = new JPanel(new FlowLayout(FlowLayout.RIGHT, 6, 0));
        buttons.add(new JButton("Clear"));
        buttons.add(new JButton("Submit"));
        return buttons;
    }
}

ออกแบบหน้าจอสั่งอาหารที่ประกอบด้วย panel อย่างน้อย 4 ส่วน:

  • หัว (NORTH): ชื่อร้านพื้นสีเข้มตัวอักษรขาว
  • ซ้าย (WEST): รายการเมนูใน JList (อย่างน้อย 6 รายการ) อยู่ใน JScrollPane ที่มี TitledBorder “Menu”
  • กลาง (CENTER): ตัวเลือก ขนาด (radio), เพิ่มเติม (check box 3 ตัว), จำนวน (spinner 1–10) และหมายเหตุ (text area)
  • ล่าง (SOUTH): ป้ายยอดรวม “Total: 0.00 baht” ชิดซ้าย และปุ่ม Add to cart ชิดขวา
สิ่งที่ต้องทำ
  1. แยกการสร้างแต่ละส่วนเป็นเมธอด
  2. ใช้ layout อย่างน้อย 3 ชนิด
  3. หน้าต่างขนาดประมาณ 560 × 360 และส่วนกลางยืดได้

Exercise 15.8เครื่องคิดเลขแบบมีประวัติ★★★ ท้าทาย

สร้างหน้าจอเครื่องคิดเลขที่มี (1) ช่องแสดงผลด้านบน อ่านอย่างเดียว ตัวเลขชิดขวา ฟอนต์ใหญ่ (2) ปุ่มตัวเลขและเครื่องหมาย 4 × 4 ตรงกลาง (3) แผงประวัติการคำนวณทางขวาเป็น JTextArea อ่านอย่างเดียวใน JScrollPane ที่มีหัว “History” โดยใส่ข้อความตัวอย่างประวัติ 3 บรรทัด และ (4) แถวล่างมีปุ่ม C และ Clear history

สิ่งที่ต้องทำ
  1. root ใช้ BorderLayout: NORTH, CENTER, EAST, SOUTH
  2. ปุ่มสร้างด้วยลูปจากอาเรย์
  3. ให้ปุ่มเครื่องหมาย (/ * - + =) มีสีพื้นต่างจากปุ่มตัวเลข
  4. ยังไม่ต้องคำนวณจริง
