บทที่ 9 · จัดการข้อมูลตัวอักษร

ข้อความและ String

เปรียบเทียบ ค้นหา ตัด แปลง และสร้างข้อความ เพื่อจัดการข้อมูลที่ผู้ใช้ป้อนเข้ามาให้ถูกต้อง

เมื่อจบบทนี้ นิสิตจะทำได้
  • เปรียบเทียบและต่อข้อความอย่างถูกวิธี
  • ค้นหาและตัดข้อความด้วย indexOf และ substring
  • แปลงข้อความเป็นตัวเลขและกลับกัน
  • ทำงานกับ char และสร้างข้อความด้วย StringBuilder

9. ข้อความคือชุดของอักขระที่มีตำแหน่ง

String คือลำดับของอักขระ (char) แต่ละตัวมีตำแหน่ง (index) เริ่มที่ 0 เหมือนอาเรย์ สิ่งสำคัญที่ต้องจำคือ String เป็น immutable — สร้างแล้วเปลี่ยนไม่ได้ เมธอดอย่าง toUpperCase() หรือ replace() จะคืนข้อความใหม่ ข้อความเดิมยังเหมือนเดิม

String s = "Java Code";
index:   0 1 2 3 4 5 6 7 8
char:    J a v a   C o d e        s.length() = 9   (ต่างจากอาเรย์: length มีวงเล็บ)

9.1 เปรียบเทียบและต่อข้อความ

เมธอดทำอะไรตัวอย่างผล
length()จำนวนอักขระ"Hello".length()5
equals(s)เนื้อหาเท่ากันไหม"abc".equals("abc")true
equalsIgnoreCase(s)เท่ากันโดยไม่สนตัวพิมพ์"Yes".equalsIgnoreCase("YES")true
compareTo(s)เทียบลำดับพจนานุกรม (<0, 0, >0)"apple".compareTo("banana")ค่าลบ
toUpperCase() / toLowerCase()แปลงตัวพิมพ์"Java".toUpperCase()JAVA
trim() / strip()ตัดช่องว่างหัวท้าย" hi ".trim()hi
isEmpty() / isBlank()ว่างไหม / มีแต่ช่องว่างไหม" ".isBlank()true

ตัวอย่าง 9.1.1 · เมธอดพื้นฐานและ immutability พื้นฐาน

แนวคิด: เรียกเมธอดแล้วต้องเก็บผลลัพธ์ ไม่เช่นนั้นข้อความเดิมจะไม่เปลี่ยน

Java source · StringBasics.java
public class StringBasics {
    public static void main(String[] args) {
        String name = "  Mali Jaidee  ";
        System.out.println("[" + name + "] length " + name.length());
        name.trim();
        System.out.println("after name.trim(): [" + name + "]");
        name = name.trim();
        System.out.println("after name = name.trim(): [" + name + "]");
        System.out.println(name.toUpperCase());
        System.out.println(name.toLowerCase());
        System.out.println("name still: " + name);
    }
}
Output
[  Mali Jaidee  ] length 15
after name.trim(): [  Mali Jaidee  ]
after name = name.trim(): [Mali Jaidee]
MALI JAIDEE
mali jaidee
name still: Mali Jaidee
อธิบายทีละขั้น
  1. ความยาวนับรวมช่องว่างหัวท้าย = 15
  2. name.trim(); เฉย ๆ ไม่มีผล เพราะไม่ได้เก็บค่าที่คืน
  3. name = name.trim(); จึงเปลี่ยน name ให้ชี้ข้อความใหม่
  4. toUpperCase/toLowerCase คืนข้อความใหม่ name ยังเดิม

ตัวอย่าง 9.1.2 · equals, equalsIgnoreCase และ compareTo ต่อยอด

แนวคิด: ใช้ equals เทียบเนื้อหา ใช้ compareTo เมื่อต้องการรู้ว่าคำไหนมาก่อนตามลำดับตัวอักษร

Java source · CompareStrings.java
import java.util.Scanner;

public class CompareStrings {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Continue? ");
        String answer = input.next();
        System.out.println("equals(\"YES\")           : " + answer.equals("YES"));
        System.out.println("equalsIgnoreCase(\"YES\") : " + answer.equalsIgnoreCase("YES"));

        System.out.print("A fruit: ");
        String fruit = input.next();
        int result = fruit.compareTo("cherry");
        System.out.println("compareTo(\"cherry\") = " + result);
        if (result < 0) System.out.println(fruit + " comes before cherry");
        else if (result > 0) System.out.println(fruit + " comes after cherry");
        else System.out.println("same word");
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Continue? yes
equals("YES")           : false
equalsIgnoreCase("YES") : true
A fruit: banana
compareTo("cherry") = -1
banana comes before cherry
อธิบายทีละขั้น
  1. "yes".equals("YES") → false เพราะตัวพิมพ์ต่าง
  2. equalsIgnoreCase → true
  3. compareTo คืนค่าลบเมื่อคำแรกมาก่อน ('b' มาก่อน 'c')
  4. ใช้เฉพาะเครื่องหมายของผลลัพธ์ ไม่ต้องสนใจตัวเลขจริง

ตัวอย่าง 9.1.3 · ต่อข้อความ: + , concat และ String.format ต่อยอด

แนวคิด: + ต่อได้ทุกชนิด, String.format ทำงานเหมือน printf แต่คืนเป็น String เก็บไว้ใช้ต่อได้

Java source · JoinStrings.java
public class JoinStrings {
    public static void main(String[] args) {
        String first = "Mali";
        String last = "Jaidee";
        int age = 19;
        double gpa = 3.456;

        String full = first + " " + last;
        String info = full + " (" + age + ")";
        String card = String.format("%-12s GPA %.2f", full, gpa);
        String joined = String.join(", ", "Math", "Science", "English");

        System.out.println(full);
        System.out.println(info);
        System.out.println("[" + card + "]");
        System.out.println(joined);
        System.out.println("Ha".repeat(3));
    }
}
Output
Mali Jaidee
Mali Jaidee (19)
[Mali Jaidee  GPA 3.46]
Math, Science, English
HaHaHa
อธิบายทีละขั้น
  1. + ต่อ String กับ int ได้อัตโนมัติ
  2. String.format จัดรูปแบบแล้วเก็บในตัวแปร card
  3. String.join ต่อหลายคำด้วยตัวคั่น
  4. repeat ทำซ้ำข้อความ

ตัวอย่าง 9.2.1 · charAt, indexOf และ substring พื้นฐาน

แนวคิด: substring(a, b) รวมตำแหน่ง a แต่ไม่รวม b — ความยาวผลลัพธ์คือ b − a

ตัวอย่าง 9.2.2 · แยกชื่อ-นามสกุลและอีเมล ต่อยอด

แนวคิด: ใช้ indexOf หาตำแหน่งตัวคั่น แล้วใช้ substring ตัดส่วนซ้ายและขวาของตัวคั่น

Java source · SplitParts.java
import java.util.Scanner;

public class SplitParts {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Full name: ");
        String full = input.nextLine().trim();
        int space = full.indexOf(' ');
        String first = full.substring(0, space);
        String last = full.substring(space + 1);
        System.out.println("First: " + first + ", Last: " + last);
        System.out.println("Initials: " + first.charAt(0) + "." + last.charAt(0) + ".");

        System.out.print("Email: ");
        String email = input.nextLine().trim();
        int at = email.indexOf('@');
        System.out.println("User: " + email.substring(0, at));
        System.out.println("Domain: " + email.substring(at + 1));
        System.out.println("Ends with .th? " + email.endsWith(".th"));
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Full name: Mali Jaidee
First: Mali, Last: Jaidee
Initials: M.J.
Email: mali.j@example.co.th
User: mali.j
Domain: example.co.th
Ends with .th? true
อธิบายทีละขั้น
  1. ช่องว่างอยู่ที่ index 4 → first = substring(0, 4) = "Mali"
  2. last = substring(5) ตั้งแต่หลังช่องว่าง
  3. อีเมล: ตัดซ้ายและขวาของ @
  4. ถ้าชื่อไม่มีช่องว่าง indexOf คืน −1 แล้ว substring(0, −1) จะ error — ควรตรวจก่อน

ตัวอย่าง 9.2.3 · split: แยกข้อมูลที่คั่นด้วยเครื่องหมาย ประยุกต์

แนวคิด: ข้อมูลแบบ CSV (คั่นด้วยจุลภาค) แยกได้ด้วย split(",") ได้อาเรย์ของ String

Java source · SplitCsv.java
import java.util.Scanner;

public class SplitCsv {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("CSV: ");
        String line = input.nextLine();
        String[] parts = line.split(",");
        System.out.println("Fields: " + parts.length);
        for (int i = 0; i < parts.length; i++) {
            System.out.println("  [" + i + "] " + parts[i]);
        }
        String sentence = "  Java   is   really fun  ";
        String[] words = sentence.trim().split("\\s+");
        System.out.println("Word count: " + words.length);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
CSV: Mali,19,3.45,Science
Fields: 4
  [0] Mali
  [1] 19
  [2] 3.45
  [3] Science
Word count: 4
อธิบายทีละขั้น
  1. split(",") แยกได้ 4 ส่วน
  2. แต่ละส่วนยังเป็น String (หัวข้อ 9.3 จะแปลงเป็นตัวเลข)
  3. "\\s+" คือ regular expression แปลว่า “ช่องว่างหนึ่งตัวขึ้นไป” ใช้นับคำที่มีช่องว่างหลายตัว
  4. ต้อง trim ก่อน ไม่เช่นนั้นจะได้คำว่างที่ต้นอาเรย์

ตัวอย่าง 9.2.4 · นับจำนวนครั้งที่พบคำ ท้าทาย

แนวคิด: วนใช้ indexOf(word, from) โดยเลื่อน from ไปหลังตำแหน่งที่เพิ่งพบ จนกว่าจะได้ −1

Java source · CountOccurrences.java
import java.util.Scanner;

public class CountOccurrences {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Text: ");
        String text = input.nextLine();
        System.out.print("Find: ");
        String word = input.nextLine();

        int count = 0;
        int pos = text.indexOf(word);
        while (pos != -1) {
            System.out.println("found at " + pos);
            count++;
            pos = text.indexOf(word, pos + word.length());
        }
        System.out.println("Total: " + count);
        System.out.println(text.replace(word, word.toUpperCase()));
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Text: the cat and the hat and the bat
Find: the
found at 0
found at 12
found at 24
Total: 3
THE cat and THE hat and THE bat
อธิบายทีละขั้น
  1. ค้นครั้งแรกจาก index 0 → 0
  2. ค้นต่อจาก 0 + 3 → 12
  3. ค้นต่อ → 24 แล้วต่อไปได้ −1 → หยุด
  4. replace แทนที่ทุกตำแหน่งในครั้งเดียว

ตัวอย่าง 9.3.1 · แปลงข้อความเป็นตัวเลขแล้วคำนวณ พื้นฐาน

แนวคิด: "10" + "20" คือการต่อข้อความ ต้องแปลงเป็นตัวเลขก่อนจึงบวกได้

Java source · ParseNumbers.java
public class ParseNumbers {
    public static void main(String[] args) {
        String a = "10";
        String b = "20";
        System.out.println("a + b (String) = " + a + b);
        int x = Integer.parseInt(a);
        int y = Integer.parseInt(b);
        System.out.println("x + y (int) = " + (x + y));

        double price = Double.parseDouble("49.75");
        System.out.println("price * 2 = " + price * 2);

        String back = String.valueOf(x + y);
        System.out.println("length of \"" + back + "\" = " + back.length());
    }
}
Output
a + b (String) = 1020
x + y (int) = 30
price * 2 = 99.5
length of "30" = 2
อธิบายทีละขั้น
  1. ต่อข้อความ → "1020"
  2. parseInt แล้วบวก → 30
  3. String.valueOf แปลงกลับเป็น String เพื่อใช้เมธอดของ String เช่น length

ตัวอย่าง 9.3.2 · แยก CSV แล้วแปลงแต่ละช่อง ต่อยอด

แนวคิด: รวม split กับ parse: ช่องที่เป็นตัวเลขต้อง parse ก่อนนำไปใช้

Java source · CsvRecord.java
import java.util.Scanner;

public class CsvRecord {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("name,age,gpa: ");
        String[] p = input.nextLine().split(",");
        String name = p[0].trim();
        int age = Integer.parseInt(p[1].trim());
        double gpa = Double.parseDouble(p[2].trim());
        System.out.printf("%s will be %d next year. GPA x 25 = %.1f%n", name, age + 1, gpa * 25);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
name,age,gpa: Mali,19,3.45
Mali will be 20 next year. GPA x 25 = 86.3
อธิบายทีละขั้น
  1. split ได้ {"Mali", "19", "3.45"}
  2. trim แต่ละช่องเผื่อมีช่องว่าง
  3. parse แล้วคำนวณ age + 1 และ gpa × 25

9.4 char และคลาส Character

char เก็บอักขระหนึ่งตัวในเครื่องหมาย ' ' และเก็บเป็นรหัสตัวเลข (Unicode) จึงเปรียบเทียบด้วย ==, < และบวกลบได้ คลาส Character มีเมธอดตรวจชนิดอักขระ

เมธอดตรวจ/ทำอะไร
Character.isDigit(ch)เป็นตัวเลข 0–9
Character.isLetter(ch)เป็นตัวอักษร
Character.isUpperCase(ch) / isLowerCaseตัวพิมพ์ใหญ่/เล็ก
Character.isWhitespace(ch)ช่องว่าง แท็บ ขึ้นบรรทัด
Character.toUpperCase(ch)แปลงเป็นตัวพิมพ์ใหญ่
Character.getNumericValue(ch)'7' → 7

ตัวอย่าง 9.4.1 · วนอ่านทีละอักขระและนับประเภท พื้นฐาน

แนวคิด: ใช้ลูป for กับ charAt(i) อ่านทีละตัว แล้วใช้ Character ตรวจประเภท

Java source · CountChars.java
import java.util.Scanner;

public class CountChars {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Text: ");
        String text = input.nextLine();
        int letters = 0, digits = 0, spaces = 0, upper = 0, others = 0;
        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);
            if (Character.isLetter(ch)) {
                letters++;
                if (Character.isUpperCase(ch)) upper++;
            } else if (Character.isDigit(ch)) {
                digits++;
            } else if (Character.isWhitespace(ch)) {
                spaces++;
            } else {
                others++;
            }
        }
        System.out.println("Letters: " + letters + " (upper " + upper + ")");
        System.out.println("Digits: " + digits);
        System.out.println("Spaces: " + spaces);
        System.out.println("Others: " + others);
    }
}

Letters: 11 (upper 2)
Digits: 2
Spaces: 3
Others: 1

  2. แต่ละตัวจัดเข้ากลุ่มเดียวด้วย else-if
  3. ตัวพิมพ์ใหญ่ J, G นับซ้อนในกลุ่มตัวอักษร

แนวคิด: char คือตัวเลข: 'A' = 65, 'a' = 97, '0' = 48 จึงคำนวณตำแหน่งตัวอักษรหรือแปลงตัวเลขได้

ตัวอย่าง 9.4.3 · รหัสซีซาร์ (Caesar cipher) ประยุกต์

แนวคิด: เลื่อนตัวอักษรไป k ตำแหน่ง วนกลับเมื่อเกิน Z ด้วย % 26 อักขระอื่นคงเดิม

Java source · Caesar.java
import java.util.Scanner;

public class Caesar {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Text: ");
        String text = input.nextLine();
        System.out.print("Shift: ");
        int k = input.nextInt();
        String encoded = shift(text, k);
        System.out.println("Encoded: " + encoded);
        System.out.println("Decoded: " + shift(encoded, 26 - k));
    }

    static String shift(String s, int k) {
        String result = "";
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (Character.isUpperCase(ch)) {
                ch = (char) ('A' + (ch - 'A' + k) % 26);
            } else if (Character.isLowerCase(ch)) {
                ch = (char) ('a' + (ch - 'a' + k) % 26);
            }
            result += ch;
        }
        return result;
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Text: Hello, World!
Shift: 3
Encoded: Khoor, Zruog!
Decoded: Hello, World!
อธิบายทีละขั้น
  1. 'H' → ตำแหน่ง 7 + 3 = 10 → 'K'
  2. 'o' → 14 + 3 = 17 → 'r'
  3. 'W' → 22 + 3 = 25 → 'Z'; ถ้าเป็น 'X' จะได้ 26 % 26 = 0 → 'A'
  4. ถอดรหัสด้วยการเลื่อน 26 − k
ลองคิดก่อน · char

char ch = 'b'; ค่าของ ch + 1, (char)(ch + 1) และ Character.toUpperCase(ch) คืออะไร

ดูคำตอบ

99 (int), 'c', 'B'

Java source · PalindromeText.java
import java.util.Scanner;

public class PalindromeText {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Text: ");
        String text = input.nextLine();
        StringBuilder clean = new StringBuilder();
        for (char ch : text.toCharArray()) {
            if (Character.isLetterOrDigit(ch)) {
                clean.append(Character.toLowerCase(ch));
            }
        }
        String forward = clean.toString();
        String backward = clean.reverse().toString();
        System.out.println("Cleaned : " + forward);
        System.out.println("Reversed: " + backward);
        System.out.println(forward.equals(backward) ? "Palindrome!" : "Not a palindrome");
    }
}

Palindrome!

        String last = words[words.length - 1];
        String lastCap = last.substring(0, 1).toUpperCase() + last.substring(1).toLowerCase();
        String firstPart = formatted.substring(0, formatted.lastIndexOf(' '));
        System.out.println("Proper  : " + formatted);
        System.out.println("Initials: " + initials);
        System.out.println("Listing : " + lastCap + ", " + firstPart);
    }
}

Exercise 9.5ตรวจความแข็งแรงของรหัสผ่าน★★ ปานกลาง

รับรหัสผ่านแล้วตรวจตามเกณฑ์ 5 ข้อ: (1) ยาวอย่างน้อย 8 ตัว (2) มีตัวพิมพ์ใหญ่ (3) มีตัวพิมพ์เล็ก (4) มีตัวเลข (5) มีอักขระพิเศษ (ไม่ใช่ตัวอักษรหรือตัวเลข) แสดงผลแต่ละข้อเป็น ✓/✗ และระดับ: ผ่าน 5 ข้อ = Strong, 3–4 ข้อ = Medium, น้อยกว่านั้น = Weak

สิ่งที่ต้องทำ
  1. วนตรวจทีละอักขระด้วย Character.isUpperCase ฯลฯ
  2. ใช้ตัวแปร boolean สำหรับแต่ละเกณฑ์
  3. นับจำนวนเกณฑ์ที่ผ่าน
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
ครั้งที่ 1
Password: abc123
✗ 8+ characters
✗ uppercase
✓ lowercase
✓ digit
✗ special char
Strength: Weak (2/5)
ครั้งที่ 2
Password: Java@2026
✓ 8+ characters
✓ uppercase
✓ lowercase
✓ digit
✓ special char
Strength: Strong (5/5)

ตัวอย่างคำตอบ

import java.util.Scanner;

public class PasswordStrength {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Password: ");
        String pw = input.nextLine();
        boolean upper = false, lower = false, digit = false, special = false;
        for (char ch : pw.toCharArray()) {
            if (Character.isUpperCase(ch)) upper = true;
            else if (Character.isLowerCase(ch)) lower = true;
            else if (Character.isDigit(ch)) digit = true;
            else special = true;
        }
        boolean longEnough = pw.length() >= 8;
        boolean[] checks = {longEnough, upper, lower, digit, special};
        String[] labels = {"8+ characters", "uppercase", "lowercase", "digit", "special char"};
        int passed = 0;
        for (int i = 0; i < checks.length; i++) {
            System.out.println((checks[i] ? "✓ " : "✗ ") + labels[i]);
            if (checks[i]) passed++;
        }
        String level = passed == 5 ? "Strong" : passed >= 3 ? "Medium" : "Weak";
        System.out.println("Strength: " + level + " (" + passed + "/5)");
    }
}

Exercise 9.6นับคำและหาคำที่ยาวที่สุด★★ ปานกลาง

รับประโยคภาษาอังกฤษ นับจำนวนคำ หาคำที่ยาวที่สุด (ถ้ายาวเท่ากันเอาคำแรก) และความยาวเฉลี่ยของคำ โดยตัดเครื่องหมายวรรคตอน . , ! ? ออกก่อน

สิ่งที่ต้องทำ
  1. ใช้ replace หรือ replaceAll ลบเครื่องหมาย
  2. split ด้วย "\\s+" หลัง trim
  3. แสดงความยาวเฉลี่ย 2 ตำแหน่ง
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

ตัวอย่างคำตอบ

import java.util.Scanner;

public class WordStats {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Sentence: ");
        String text = input.nextLine().replaceAll("[.,!?]", "").trim();
        String[] words = text.split("\\s+");
        String longest = words[0];
        int totalLetters = 0;
        for (String w : words) {
            totalLetters += w.length();
            if (w.length() > longest.length()) longest = w;
        }
        System.out.println("Words: " + words.length);
        System.out.println("Longest: " + longest + " (" + longest.length() + ")");
        System.out.printf("Average length: %.2f%n", (double) totalLetters / words.length);
    }
}

replaceAll("[.,!?]", "") ใช้ regular expression: วงเล็บเหลี่ยมหมายถึง “อักขระใดก็ได้ในกลุ่มนี้”

import java.util.Scanner;

public class ThaiIdCheck {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("ID: ");
        String id = input.nextLine().trim().replace("-", "");
        if (id.length() != 13 || !allDigits(id)) {
            System.out.println("Invalid format");
            return;
        }
        int sum = 0;
        for (int i = 0; i < 12; i++) {
            sum += (id.charAt(i) - '0') * (13 - i);
        }
        int check = (11 - sum % 11) % 10;
        int last = id.charAt(12) - '0';
        System.out.println("Computed check digit: " + check);
        System.out.println(check == last ? "Valid" : "Invalid checksum");
    }

    static boolean allDigits(String s) {
        for (char ch : s.toCharArray()) {
            if (!Character.isDigit(ch)) return false;
        }
        return true;
    }
}

return; ในเมธอด void ใช้จบเมธอดก่อนถึงบรรทัดสุดท้าย (ในที่นี้คือจบ main)

Exercise 9.8บีบอัดข้อความแบบ Run-Length★★★ ท้าทาย

เขียนเมธอด compress(String s) ที่แทนอักขระที่ซ้ำติดกันด้วยอักขระตามด้วยจำนวน เช่น aaabccdddd → a3b1c2d4 และเมธอด decompress ที่แปลงกลับ (สมมติจำนวนซ้ำไม่เกิน 9) แล้วแสดงอัตราส่วนความยาวหลังบีบอัด

สิ่งที่ต้องทำ
  1. ใช้ StringBuilder สร้างผลลัพธ์
  2. compress: นับจำนวนที่ซ้ำ เมื่อเจออักขระใหม่ให้ append ของเดิม
  3. decompress: อ่านทีละคู่ (อักขระ, ตัวเลข) แล้ว repeat
  4. จัดการกรณีข้อความว่าง
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
ครั้งที่ 1
Text: aaabccdddd
Compressed  : a3b1c2d4
Decompressed: aaabccdddd
Ratio: 10 -> 8 (80%)
ครั้งที่ 2
Text: abc
Compressed  : a1b1c1
Decompressed: abc
Ratio: 3 -> 6 (200%)

ตัวอย่างคำตอบ

import java.util.Scanner;

public class RunLength {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Text: ");
        String s = input.nextLine();
        String packed = compress(s);
        System.out.println("Compressed  : " + packed);
        System.out.println("Decompressed: " + decompress(packed));
        System.out.printf("Ratio: %d -> %d (%.0f%%)%n", s.length(), packed.length(), 100.0 * packed.length() / s.length());
    }

    static String compress(String s) {
        if (s.isEmpty()) return "";
        StringBuilder sb = new StringBuilder();
        char current = s.charAt(0);
        int count = 1;
        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) == current) {
                count++;
            } else {
                sb.append(current).append(count);
                current = s.charAt(i);
                count = 1;
            }
        }
        sb.append(current).append(count);
        return sb.toString();
    }

    static String decompress(String s) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i + 1 < s.length(); i += 2) {
            char ch = s.charAt(i);
            int n = s.charAt(i + 1) - '0';
            sb.append(String.valueOf(ch).repeat(n));
        }
        return sb.toString();
    }
}

Exercise 9.9เครื่องคิดเลขจากข้อความ★★★ ท้าทาย

รับนิพจน์บวกลบหลายตัวในบรรทัดเดียว เช่น 12 + 7 - 3 + 40 (มีช่องว่างคั่นทุก token) แล้วคำนวณผลจากซ้ายไปขวา ถ้ามี token ที่ไม่ใช่ตัวเลขในตำแหน่งตัวเลข หรือตัวดำเนินการไม่ใช่ + / − ให้แสดงข้อความ error ที่ระบุ token ที่ผิด

  2. ใช้ try-catch ดัก NumberFormatException

  4. แสดงขั้นตอนการคำนวณ

import java.util.Scanner;

public class TextCalculator {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Expression: ");
        String[] t = input.nextLine().trim().split("\\s+");
        if (t.length % 2 == 0) {
            System.out.println("Error: incomplete expression");
            return;
        }
        try {
            int result = Integer.parseInt(t[0]);
            for (int i = 1; i < t.length; i += 2) {
                String op = t[i];
                int value = Integer.parseInt(t[i + 1]);
                if (op.equals("+")) {
                    result += value;
                } else if (op.equals("-")) {
                    result -= value;
                } else {
                    System.out.println("Error: unknown operator '" + op + "'");
                    return;
                }
                System.out.println("  " + op + " " + value + " -> " + result);
            }
            System.out.println("Result = " + result);
        } catch (NumberFormatException e) {
            System.out.println("Error: not a number in " + e.getMessage());
        }
    }
}

import java.util.Scanner;

public class NumberToWords {
    static final String[] ONES = {"zero", "one", "two", "three", "four", "five", "six", "seven", "eight", "nine",
        "ten", "eleven", "twelve", "thirteen", "fourteen", "fifteen", "sixteen", "seventeen", "eighteen", "nineteen"};
    static final String[] TENS = {"", "", "twenty", "thirty", "forty", "fifty", "sixty", "seventy", "eighty", "ninety"};

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Number (0-9999): ");
        int n = input.nextInt();
        System.out.println(toWords(n));
    }

    static String toWords(int n) {
        if (n == 0) return "zero";
        StringBuilder sb = new StringBuilder();
        if (n >= 1000) {
            sb.append(ONES[n / 1000]).append(" thousand ");
            n %= 1000;
        }
        if (n > 0) sb.append(below1000(n));
        return sb.toString().trim();
    }

    static String below1000(int n) {
        StringBuilder sb = new StringBuilder();
        if (n >= 100) {
            sb.append(ONES[n / 100]).append(" hundred ");
            n %= 100;
        }
        if (n > 0) sb.append(below100(n));
        return sb.toString().trim();
    }

    static String below100(int n) {
        if (n < 20) return ONES[n];
        String word = TENS[n / 10];
        if (n % 10 != 0) word += "-" + ONES[n % 10];
        return word;
    }
}
