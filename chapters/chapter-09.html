บทที่ 9 · ทำงานกับข้อมูลข้อความ

ข้อความและ String

เปรียบเทียบ ค้นหา ตัด และแปลงข้อความ พร้อมเรียนรู้ว่า String กับ char ต่างกันอย่างไร

เมื่อจบบทนี้ นิสิตจะทำได้
  • เปรียบเทียบข้อความด้วย equals
  • ใช้ length, charAt, substring และ indexOf
  • แปลงข้อความเป็นตัวเลขและรู้จักข้อผิดพลาดที่อาจเกิด
  • สร้างข้อความหลายส่วนด้วย StringBuilder

9. ข้อความไม่ใช่เพียงตัวเลขหลายตัวมาต่อกัน

String เก็บข้อความ เช่น ชื่อหรือประโยค ส่วน char เก็บอักขระหนึ่งตัว การเลือกใช้เมธอดที่ถูกต้องช่วยให้โปรแกรมตรวจและแปลงข้อมูลข้อความได้ตรงตามโจทย์

9.1 ต่อและเปรียบเทียบข้อความ

String เป็น object ที่แทนลำดับอักขระ ใช้ + ต่อข้อความกับข้อความหรือตัวเลขได้ แต่เปรียบเทียบเนื้อหาด้วย equals ไม่ใช่ == เพราะ == สำหรับ object ตรวจว่า reference ชี้ object ตัวเดียวกันหรือไม่

ทำไม == จึงไม่ใช่การเทียบข้อความ?

ตัวแปร String เก็บ reference ไปยัง object การสร้างข้อความคนละ object อาจมีเนื้อหาเหมือนกันแต่ reference ต่างกัน ดังนั้นใช้ equals เมื่อถามว่า “ตัวอักษรเหมือนกันหรือไม่”

String first = new String("Java");
String second = new String("Java");
System.out.println(first == second);      // false: คนละ object
System.out.println(first.equals(second)); // true: เนื้อหาเหมือนกัน
เปรียบเทียบเนื้อหา
String answer = "Java";
System.out.println(answer.equals("Java")); // true
System.out.println(answer.equals("java")); // false
System.out.println(answer.equalsIgnoreCase("java")); // true

equals สนใจตัวพิมพ์เล็ก-ใหญ่ ส่วน equalsIgnoreCase ไม่สนใจความต่างนี้

ลำดับ + มีผลกับข้อความและตัวเลข
System.out.println("total=" + 2 + 3);   // total=23
System.out.println("total=" + (2 + 3)); // total=5
System.out.println(2 + 3 + " total");  // 5 total

เมื่อมี String การประเมินจากซ้ายไปขวาอาจเปลี่ยนการบวกตัวเลขเป็นการต่อข้อความ ใช้วงเล็บบอกส่วนที่ต้องคำนวณก่อน

String เปลี่ยนค่าเดิมไม่ได้ (immutable)

การต่อหรือแปลงตัวพิมพ์จะได้ String ค่าใหม่ ถ้าต้องการเก็บผลต้องกำหนดกลับ เช่น name = name.trim();

ทำนาย output ของทั้งสามบรรทัด แล้วอธิบายว่าทำไมผลไม่เหมือนกัน

คำตอบและเหตุผล

9.2 ความยาว ค้นหา และตัดข้อความ

length() คืนจำนวนอักขระ, charAt(index) อ่านอักขระหนึ่งตำแหน่ง, indexOf หาตำแหน่งข้อความย่อย และ substring(start, end) ตัดตั้งแต่ start จนก่อน end

Methodผลที่ได้ตัวอย่างกับ "Java"
length()จำนวนอักขระ4
charAt(i)char ตำแหน่ง icharAt(1) ได้ 'a'
indexOf("v")index แรกที่พบ หรือ -12
substring(a,b)ช่วง a ถึงก่อน bsubstring(1,3) ได้ "av"
ดึงนามสกุลไฟล์
String fileName = "report.pdf";
int dotPosition = fileName.lastIndexOf('.');
String extension = fileName.substring(dotPosition + 1);
System.out.println(extension); // pdf

ถ้าไม่พบตัวอักษรที่ค้นหา indexOf จะคืน -1 ต้องตรวจค่าก่อนนำไปใช้เป็น index

ตำแหน่งสิ้นสุดไม่นับรวม

สำหรับ "Java", substring(0, 2) ได้ "Ja" ใช้ index ตั้งแต่ 0 ถึง 1 ส่วน trim() ตัดช่องว่างหัวท้าย แต่ไม่ตัดช่องว่างระหว่างคำ

ไล่ index และขอบเขต
String word = "Java";
System.out.println(word.length());       // 4
System.out.println(word.charAt(0));      // J
System.out.println(word.substring(1, 3)); // av
System.out.println(word.indexOf("x"));   // -1

ตัว index ที่อ่านได้คือ 0 ถึง length - 1; end ของ substring อนุญาตให้เท่ากับ length เพราะเป็นตำแหน่ง “หลังตัวสุดท้าย”

Runtime error: charAt index ไม่อยู่ในช่วง
String word = "Java";
System.out.println(word.charAt(word.length()));

index สุดท้ายคือ length - 1; ตัวอย่างนี้ส่ง index 4 ให้ข้อความยาว 4 จึงเกิด StringIndexOutOfBoundsException

String email = "mali-campus.ac.th";

9.3 แปลงข้อความเป็นตัวเลข

ข้อมูลที่อ่านจากไฟล์หรือข้อความมักเป็น String หากต้องคำนวณให้แปลงก่อน: Integer.parseInt สำหรับจำนวนเต็ม และ Double.parseDouble สำหรับทศนิยม

แปลงข้อความแล้วคำนวณ
String quantityText = "4";
String priceText = "12.50";
int quantity = Integer.parseInt(quantityText);
double price = Double.parseDouble(priceText);
double total = quantity * price;
System.out.println(total); // 50.0

ข้อความที่ไม่ใช่รูปแบบตัวเลข เช่น "four" ทำให้เกิด NumberFormatException ภายหลังจะเรียนวิธีจัดการ exception อย่างละเอียด

Flow ของ parse
  1. รับข้อมูลเข้ามาเป็น String
  2. ตัดช่องว่างหัวท้ายด้วย trim() หากรูปแบบอนุญาต
  3. แปลงด้วย parseInt/parseDouble
  4. นำค่าตัวเลขไปคำนวณ

parse เป็นการแปลงแบบตรวจสอบ ถ้าตัวอักษรไม่ตรงรูปแบบจะเกิด runtime exception; การตรวจ/จัดการ exception จะเรียนต่อในบท exceptions

ช่องว่างหัวท้ายกับข้อความที่แปลงไม่ได้
String quantityText = " 12 ";
int quantity = Integer.parseInt(quantityText.trim()); // 12
// Integer.parseInt("12pcs") จะเกิด NumberFormatException
ระวังช่องว่างและเครื่องหมาย

ตัวเลขที่แปลงได้อาจมีเครื่องหมายบวก/ลบหรือทศนิยมตามรูปแบบ แต่ข้อความที่มีหน่วยติดท้าย เช่น "25 baht" ต้องแยกหน่วยออกก่อน

9.4 char และ Character

char ใช้เก็บอักขระหนึ่งตัวและเขียน literal ด้วย single quote เช่น 'A'; ส่วน String ใช้ double quote เช่น "A" อ่านอักขระจาก String ด้วย charAt และตรวจประเภทด้วยคลาส Character

เลือกใช้ char หรือ String
ตัวอย่างชนิดความหมาย
'A'charอักขระหนึ่งตัว
"A"Stringข้อความที่มีอักขระหนึ่งตัว
"AB"Stringข้อความสองอักขระ
อ่านและตรวจอักขระ
String code = "A7";
char first = code.charAt(0);
char second = code.charAt(1);
System.out.println(Character.isLetter(first));  // true
System.out.println(Character.isDigit(second)); // true
System.out.println(Character.toLowerCase(first)); // a
Runtime error: อ่าน charAt เกินขอบเขต
String text = "OK";
        System.out.println(text.charAt(text.length()));

ข้อความยาว 2 มี index 0 และ 1 เท่านั้น การอ่าน index 2 จึงเกิด StringIndexOutOfBoundsException

Exercise 9.4ตรวจอักขระตัวแรก

ตรวจว่าอักขระตัวแรกของข้อความเป็นตัวอักษรหรือไม่ โดยใช้ charAt และ Character.isLetter; ต้องไม่อ่าน index 0 เมื่อข้อความว่าง

ตัวอย่างคำตอบ

String text = "Java";
        boolean startsWithLetter = !text.isEmpty()
          && Character.isLetter(text.charAt(0));
        System.out.println(startsWithLetter); // true

ตรวจ isEmpty ก่อนเรียก charAt เพื่อป้องกัน string index error

9.5 StringBuilder: ต่อข้อความหลายครั้ง

String เปลี่ยนค่าเดิมไม่ได้ (immutable) การต่อ String จำนวนมากใน loop จึงสร้าง object ชั่วคราวหลายตัว StringBuilder แก้ไข buffer เดิมด้วย append แล้วแปลงเป็น String เมื่อทำเสร็จ

Syntax และ flow
StringBuilder builder = new StringBuilder();
        builder.append("ข้อความ");
        builder.append(value);
        String result = builder.toString();
  1. สร้าง builder เปล่าหนึ่งตัว
  2. append ชิ้นส่วนตามลำดับ
  3. เรียก toString เมื่อจะส่ง/แสดงผลเป็น String
ประกอบข้อความจาก loop
StringBuilder list = new StringBuilder();
        for (int i = 1; i <= 3; i++) {
            list.append("Item ").append(i).append("\n");
        }
        System.out.print(list.toString());

append คืน builder ตัวเดิม จึงต่อหลายส่วนในบรรทัดเดียวได้

Exercise 9.6นับตัวเลขในข้อความ

นับจำนวนอักขระตัวเลขในข้อความ "Room 204, floor 3" โดยใช้ Character.isDigit

ตัวอย่างคำตอบ

String text = "Room 204, floor 3";
int digitCount = 0;
for (int i = 0; i < text.length(); i++) {
    if (Character.isDigit(text.charAt(i))) {
        digitCount++;
    }
}
System.out.println(digitCount); // 4

ตัวเลขที่พบคือ 2, 0, 4 และ 3

Exercise 9.12ตรวจและจัดรูปแบบรหัสนักศึกษา

รับรหัสเป็น String ตัดช่องว่างหัวท้าย แปลงเป็นตัวพิมพ์ใหญ่ แล้วตรวจว่าขึ้นต้นด้วย CS- และมีเครื่องหมาย - อย่างน้อยสองตำแหน่ง ถ้าถูกให้แสดงส่วนท้าย ถ้าไม่ถูกให้แสดง invalid

ตัวอย่างโปรแกรม

String studentId = " cs-2026-014 ";
    String normalized = studentId.trim().toUpperCase();
    int firstDash = normalized.indexOf('-');
    int secondDash = normalized.indexOf('-', firstDash + 1);
    if (normalized.startsWith("CS-") && secondDash != -1) {
      System.out.println("Valid: " + normalized.substring(secondDash + 1));
    } else {
      System.out.println("invalid");
    }

ตัวอย่างแสดง Valid: 014; ตรวจว่าพบขีดก่อนนำ index ไปใช้ต่อ

Exercise 9.13สรุปคะแนนจากรายการข้อความ

รับคะแนนที่คั่นด้วย comma เช่น "72, 85, 91" แยกทีละค่า แปลงเป็น int แล้วแสดงผลรวมและค่าเฉลี่ย

ตัวอย่างโปรแกรม

String scoreLine = "72, 85, 91";
    String[] parts = scoreLine.split(",");
    int sum = 0;
    for (String part : parts) {
      sum += Integer.parseInt(part.trim());
    }
    double average = (double) sum / parts.length;
    System.out.println("Sum: " + sum); // 248
    System.out.println("Average: " + average); // 82.666...

trim() ตัดช่องว่างรอบแต่ละค่า ก่อนส่งให้ parseInt
