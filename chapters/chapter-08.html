บทที่ 8 · เก็บข้อมูลหลายค่าเป็นชุด

อาเรย์และชุดข้อมูล

เก็บข้อมูลชนิดเดียวกันหลายค่าในโครงสร้างเดียว แล้วใช้ index และลูปเข้าถึงสมาชิกทีละตัว

เมื่อจบบทนี้ นิสิตจะทำได้
  • ประกาศและกำหนดค่าอาเรย์
  • ใช้ index และ length อย่างถูกต้อง
  • วนอ่าน รวม และค้นหาค่าสมาชิก
  • อ่านข้อมูลแบบแถวและคอลัมน์

8. มองข้อมูลหลายค่าเป็นชุดเดียว

ถ้าต้องเก็บคะแนนนักศึกษา 100 คน การสร้างตัวแปร 100 ตัวทำให้จัดการยาก อาเรย์ให้เราใช้ชื่อตัวแปรเดียวและเลข index เพื่อเลือกสมาชิกแต่ละตำแหน่ง

8.1 สร้างและเข้าถึงอาเรย์

ชนิดอาเรย์เขียนเป็น ชนิดข้อมูล[] สมาชิกตัวแรกอยู่ที่ index 0 ไม่ใช่ 1 และอาเรย์ที่สร้างแล้วมีขนาดคงที่ ตรวจจำนวนสมาชิกได้ด้วย array.length

Syntax: ประกาศ สร้าง และอ้างสมาชิก
int[] scores;                 // ประกาศตัวแปรอาเรย์
scores = new int[3];          // สร้างพื้นที่ 3 ช่อง
scores[0] = 80;               // กำหนดสมาชิกช่องแรก

int[] otherScores = {80, 75, 92}; // ประกาศพร้อมค่าเริ่มต้น

การประกาศบอกชนิด แต่ต้องสร้างอาเรย์ก่อนใช้งาน สมาชิกของ int array ที่ยังไม่กำหนดค่าจะเริ่มเป็น 0

อาเรย์คะแนน 4 ค่า
int[] scores = {80, 75, 92, 88};
System.out.println(scores[0]);      // 80
System.out.println(scores[3]);      // 88
System.out.println(scores.length);  // 4

index ที่ถูกต้องคือ 0 ถึง length - 1; การอ่าน scores[4] เกินขอบเขต

Trace index ทีละตำแหน่ง
index0123
scores[index]80759288

คำสั่ง scores[1] = 100; เปลี่ยนค่า 75 เป็น 100; จำนวนสมาชิกยังเท่าเดิมและ length ยังเป็น 4

Index กับจำนวนสมาชิกเป็นคนละเรื่อง

อาเรย์มี 4 สมาชิก แต่ index ตัวสุดท้ายคือ 3 เพราะเริ่มนับจาก 0

Runtime error: index เกินขอบเขต
int[] scores = {80, 75, 92};
System.out.println(scores[3]); // error

length เท่ากับ 3 จึงมี index 0, 1, 2 เท่านั้น โปรแกรมคอมไพล์ผ่าน แต่ตอนรันจะเกิด ArrayIndexOutOfBoundsException เพราะพยายามอ่านช่องที่ไม่มี

Exercise 8.1เก็บอุณหภูมิ

สร้างอาเรย์เก็บอุณหภูมิ 3 วันเป็น 29, 31 และ 30 จากนั้นพิมพ์ค่าของวันที่สองและจำนวนสมาชิก

ตัวอย่างคำตอบ

int[] temperatures = {29, 31, 30};
System.out.println(temperatures[1]); // 31: วันที่สองคือ index 1
System.out.println(temperatures.length); // 3

Exercise 8.7แก้ IndexOutOfBounds

อาเรย์ {4, 8, 12, 16} มีสมาชิก 4 ตัว จงเขียน loop แสดงทุกค่าโดยไม่เกิด index เกิน และอธิบายว่าทำไมเงื่อนไขต้องใช้ < length

ตัวอย่างคำตอบ

int[] values = {4, 8, 12, 16};
for (int i = 0; i < values.length; i++) {
    System.out.println(values[i]);
}

เมื่อ i เท่ากับ length คือ 4 ไม่มี index 4 จึงต้องหยุดก่อนถึงค่านั้น

8.2 วนอ่าน รวม และค้นหาสมาชิก

ใช้ลูป for ตั้งแต่ index 0 จนก่อน length เพื่อไม่อ่านเกินตำแหน่งสุดท้าย ถ้าไม่ต้องใช้ index โดยตรง ใช้ enhanced for อ่านค่าทีละตัวได้

หาผลรวมและค่าเฉลี่ย
int[] scores = {80, 75, 95};
int sum = 0;
for (int score : scores) {
    sum += score;
}
double average = (double) sum / scores.length;
System.out.println(average); // 83.333...

enhanced for เหมาะกับการอ่านทุกค่า ส่วนการแก้ตำแหน่งเฉพาะต้องใช้ index

Trace sum ตามจำนวนรอบ
รอบscoresum ก่อนบวกsum หลังบวก
180080
27580155
395155250

หลังจบ enhanced for, sum จึงเป็นผลรวมของสมาชิกทุกตัว

ทำไมเงื่อนไขใช้ < ไม่ใช่ <=

ถ้า scores.length เท่ากับ 3 index ที่มีคือ 0, 1, 2 ดังนั้นใช้ i < scores.length เพื่อหยุดก่อน i เป็น 3

Exercise 8.2ค้นหาคะแนน

ในอาเรย์ {72, 85, 91, 68} ค้นหาคะแนน 91 แล้วแสดง index ที่พบ ถ้าไม่พบให้แสดง not found

ตัวอย่างคำตอบ

int[] scores = {72, 85, 91, 68};
int target = 91;
int foundIndex = -1;
for (int i = 0; i < scores.length; i++) {
    if (scores[i] == target) {
        foundIndex = i;
        break;
    }
}
if (foundIndex == -1) {
    System.out.println("not found");
} else {
    System.out.println(foundIndex); // 2
}

ใช้ -1 เป็นค่าพิเศษเพื่อบอกว่ายังไม่พบ และหยุดค้นเมื่อเจอแล้ว

ข้อควรระวังเมื่อแก้สมาชิก

enhanced for เช่น for (int score : scores) เหมาะกับการอ่านทุกค่า แต่ตัวแปร score เป็นค่าที่คัดลอกมา การกำหนด score = 0 ไม่ได้เปลี่ยนสมาชิกใน array; ถ้าต้องแก้ array ให้ใช้ index

Exercise 8.8สรุปคะแนนสอบ

จากคะแนนทั้งห้า {49, 50, 72, 45, 88} คำนวณค่าเฉลี่ยและนับจำนวนผู้ผ่าน (ตั้งแต่ 50 ขึ้นไป) ในการวนอ่านหนึ่งรอบ

ตัวอย่างคำตอบ

int[] scores = {49, 50, 72, 45, 88};
      int sum = 0;
      int passCount = 0;
      for (int score : scores) {
        sum += score;
        if (score >= 50) passCount++;
      }
      double average = (double) sum / scores.length;
      System.out.println("Average: " + average); // 60.8
      System.out.println("Passed: " + passCount); // 3

แยกตัวนับ passCount ออกจาก sum: ตัวแรกนับจำนวน ส่วนตัวหลังสะสมคะแนน

8.3 อาเรย์สองมิติ: แถวและคอลัมน์

อาเรย์สองมิติจัดข้อมูลเป็นตาราง ใช้ index สองตัวคือ array[row][column] จึงมักอ่านด้วยลูปซ้อน จำนวนแถวคือ matrix.length และจำนวนคอลัมน์ของแถวหนึ่งดูได้จาก matrix[row].length

อ่านตารางคะแนน 2 แถว 3 วิชา
int[][] scores = {
    {80, 75, 90},
    {68, 82, 77}
};
for (int row = 0; row < scores.length; row++) {
    for (int column = 0; column < scores[row].length; column++) {
        System.out.print(scores[row][column] + " ");
    }
    System.out.println();
}

ลูปชั้นนอกเลือกแถว ลูปชั้นในเดินผ่านคอลัมน์ของแถวนั้น

Flow ของ nested loop
  1. กำหนด row = 0 แล้วตรวจเงื่อนไข outer loop
  2. ใน row ปัจจุบัน กำหนด column = 0 ใหม่ทุกครั้ง
  3. inner loop ทำงานครบทุก column ของ row นั้น
  4. เมื่อ inner loop จบ outer loop เพิ่ม row แล้วเริ่ม inner loop รอบใหม่

ถ้ามี R แถว และแต่ละแถวมี C คอลัมน์ body ของ inner loop จะทำงานรวม R × C ครั้ง

Jagged array และ error ที่พบบ่อย

Java อนุญาตให้แต่ละแถวมีจำนวนสมาชิกไม่เท่ากันได้ (jagged array) จึงใช้ matrix[row].length ตรวจคอลัมน์ของแถวปัจจุบัน อย่าใช้ matrix[0].length แทนทุกแถว

int[][] data = {{1, 2}, {3, 4, 5}};
// ถ้า row เป็น 1 แต่ column วนถึง 2 การอ่าน data[1][2] ใช้ได้
// แต่การวนโดยอิง data[0].length จะอ่านแถวที่สองไม่ครบ

การอ้าง data[row][column] เกินจำนวนสมาชิกของแถวนั้นจะเกิด ArrayIndexOutOfBoundsException ตอน runtime

Exercise 8.3รวมค่าตาราง

จากตาราง {{1, 2, 3}, {4, 5, 6}} ใช้ลูปซ้อนหาผลรวมสมาชิกทุกตัว

ตัวอย่างคำตอบ

int[][] values = {{1, 2, 3}, {4, 5, 6}};
int sum = 0;
for (int row = 0; row < values.length; row++) {
    for (int column = 0; column < values[row].length; column++) {
        sum += values[row][column];
    }
}
System.out.println(sum); // 21

Exercise 8.9หาผลรวมแต่ละแถว

จากตารางคะแนน ใช้ nested loop แสดงผลรวมแยกตามนักศึกษาแต่ละคน

ตัวอย่างคำตอบ

int[][] scores = {{80, 70, 90}, {65, 75, 85}};
      for (int row = 0; row < scores.length; row++) {
        int rowSum = 0;
        for (int column = 0; column < scores[row].length; column++) {
          rowSum += scores[row][column];
        }
        System.out.println("Student " + (row + 1) + ": " + rowSum);
      }

rowSum ถูกกำหนดใหม่เป็น 0 ในแต่ละรอบของ outer loop

แบบฝึกหัดท้ายบท

เขียนลูปโดยใช้ length แทนการกำหนด index สุดท้ายเอง

Exercise 8.4หาคะแนนสูงสุด

หาและแสดงค่าสูงสุดในอาเรย์จำนวนเต็ม โดยไม่ใช้เมธอดสำเร็จรูป

ตัวอย่างคำตอบ

int[] values = {12, 7, 25, 18};
int maximum = values[0];
for (int i = 1; i < values.length; i++) {
    if (values[i] > maximum) {
        maximum = values[i];
    }
}
System.out.println(maximum); // 25

ตั้งต้นจากสมาชิกตัวแรก ทำให้ไม่ต้องเดาว่าค่าสูงสุดเริ่มเป็นเท่าไร

Exercise 8.5นับจำนวนคนสอบผ่าน

นับว่ามีคะแนนตั้งแต่ 50 ขึ้นไปกี่ค่าในอาเรย์

ตัวอย่างคำตอบ

int[] scores = {49, 50, 72, 45, 88};
int passCount = 0;
for (int score : scores) {
    if (score >= 50) {
        passCount++;
    }
}
System.out.println(passCount); // 3

Exercise 8.6รวมคะแนนแต่ละแถว

จากอาเรย์สองมิติ แสดงผลรวมของแต่ละแถวแยกกัน

ตัวอย่างคำตอบ

int[][] scores = {{8, 7, 9}, {6, 10, 5}};
for (int row = 0; row < scores.length; row++) {
    int rowSum = 0;
    for (int column = 0; column < scores[row].length; column++) {
        rowSum += scores[row][column];
    }
    System.out.println("Row " + row + ": " + rowSum);
}

ตัวแปร rowSum กำหนดใหม่ภายในลูปชั้นนอกเพื่อเริ่มรวมของแต่ละแถวจากศูนย์

Exercise 8.10ค้นหาที่นั่งว่าง

ตาราง boolean 3 แถว 4 คอลัมน์ใช้ true แทนที่นั่งถูกจอง จงค้นหาและแสดงพิกัดที่นั่งว่างตัวแรกตามลำดับแถวแล้วคอลัมน์

ตัวอย่างคำตอบ

boolean[][] seats = {
      {true, true, false, true},
      {true, false, false, true},
      {false, true, true, true}
    };
    boolean found = false;
    for (int row = 0; row < seats.length && !found; row++) {
      for (int column = 0; column < seats[row].length; column++) {
        if (!seats[row][column]) {
          System.out.println("Free seat: " + row + "," + column);
          found = true;
          break;
        }
      }
    }

ผลแรกที่พบคือแถว 0 คอลัมน์ 2 เพราะค้นจากซ้ายไปขวาและบนลงล่าง
