บทที่ 5 · ให้โปรแกรมเลือกทำงาน

เงื่อนไขและการตัดสินใจ

สอนให้โปรแกรมตอบสนองต่อข้อมูลที่แตกต่างกัน ด้วย boolean การเปรียบเทียบ และโครงสร้าง if หรือ switch

เมื่อจบบทนี้ นิสิตจะทำได้
  • อ่านผลนิพจน์เปรียบเทียบเป็น true หรือ false
  • รวมเงื่อนไขด้วย &&, || และ !
  • เลือกใช้ if/else กับ switch
  • จัดลำดับเงื่อนไขไม่ให้กรณีสำคัญถูกบัง

5. เปลี่ยนเงื่อนไขให้เป็นเส้นทางของโปรแกรม

เงื่อนไขคือนิพจน์ที่ให้ผลเป็น true หรือ false โปรแกรมใช้ผลนี้เลือกคำสั่งที่จะทำต่อ — เหมือนข้าวหลามตัดใน Flowchart บทที่ 1 บทนี้เริ่มจากการสร้างค่า boolean ไปจนถึงการเลือกทางหลายทาง

5.1 boolean และตัวดำเนินการเปรียบเทียบ

boolean เก็บได้เพียง true หรือ false นิพจน์เปรียบเทียบ เช่น score >= 50 จะคำนวณออกมาเป็นค่า boolean ที่นำไปเก็บในตัวแปรหรือใช้ใน if ได้

ตัวดำเนินการความหมายตัวอย่าง (x = 7)ผล
==เท่ากับx == 7true
!=ไม่เท่ากับx != 7false
>มากกว่าx > 10false
<น้อยกว่าx < 10true
>=มากกว่าหรือเท่ากับx >= 7true
<=น้อยกว่าหรือเท่ากับx <= 6false

ตัวอย่าง 5.1.1 · นิพจน์เปรียบเทียบให้ค่า boolean พื้นฐาน

แนวคิด: เปรียบเทียบได้ผลเป็นค่า true/false ที่เก็บในตัวแปรหรือพิมพ์ออกมาได้เหมือนค่าอื่น

Java source · Comparisons.java
public class Comparisons {
    public static void main(String[] args) {
        int score = 72;
        boolean passed = score >= 50;
        boolean perfect = score == 100;
        System.out.println("passed = " + passed);
        System.out.println("perfect = " + perfect);
        System.out.println("score < 80 ? " + (score < 80));
        System.out.println("score != 72 ? " + (score != 72));
    }
}
Output
passed = true
perfect = false
score < 80 ? true
score != 72 ? false
อธิบายทีละขั้น
  1. 72 ≥ 50 → true
  2. 72 == 100 → false
  3. ต้องมีวงเล็บรอบนิพจน์เปรียบเทียบเมื่อต่อข้อความ

ทดลอง error 5.1.2 · ใช้ = แทน == ต่อยอด

แนวคิด: = คือการกำหนดค่า ส่วน == คือการเปรียบเทียบ if ต้องการค่า boolean จึงคอมไพล์ไม่ผ่าน

Java source · AssignInIf.java
public class AssignInIf {
    public static void main(String[] args) {
        int score = 72;
        if (score = 100) {
            System.out.println("Perfect!");
        }
    }
}
Compile error (จาก javac จริง)
AssignInIf.java:4: error: incompatible types: int cannot be converted to boolean
        if (score = 100) {
                  ^
อธิบายทีละขั้น
  1. score = 100 มีชนิดเป็น int
  2. if ต้องการ boolean → int cannot be converted to boolean
  3. แก้เป็น score == 100

ตัวอย่าง 5.1.3 · เปรียบเทียบ String ต้องใช้ equals ประยุกต์

แนวคิด: == กับ String เปรียบเทียบว่าเป็นออบเจ็กต์เดียวกันหรือไม่ ไม่ใช่เนื้อหา ต้องใช้ .equals() (หรือ .equalsIgnoreCase() ถ้าไม่สนตัวพิมพ์)

Java source · StringCompare.java
import java.util.Scanner;

public class StringCompare {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Username: ");
        String user = input.next();
        System.out.println("user == \"admin\"      -> " + (user == "admin"));
        System.out.println("user.equals(\"admin\") -> " + user.equals("admin"));
        System.out.println("equalsIgnoreCase(\"ADMIN\") -> " + user.equalsIgnoreCase("ADMIN"));
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Username: admin
user == "admin"      -> false
user.equals("admin") -> true
equalsIgnoreCase("ADMIN") -> true
อธิบายทีละขั้น
  1. ผู้ใช้พิมพ์ admin
  2. == ได้ false เพราะ String ที่อ่านจาก Scanner เป็นคนละออบเจ็กต์กับ "admin" ในโค้ด
  3. equals เปรียบเทียบตัวอักษร → true
  4. จำไว้: String ใช้ equals เสมอ

ตัวอย่าง 5.1.4 · เปรียบเทียบ double อย่างปลอดภัย ท้าทาย

แนวคิด: double เก็บค่าแบบประมาณ ห้ามใช้ == ตรง ๆ ให้ตรวจว่า “ต่างกันน้อยมาก” ด้วย Math.abs(a - b) < 1e-9

Java source · DoubleCompare.java
public class DoubleCompare {
    public static void main(String[] args) {
        double a = 0.1 + 0.2;
        double b = 0.3;
        System.out.println("a = " + a);
        System.out.println("a == b ? " + (a == b));
        System.out.println("close enough ? " + (Math.abs(a - b) < 1e-9));
    }
}
Output
a = 0.30000000000000004
a == b ? false
close enough ? true
อธิบายทีละขั้น
  1. 0.1 + 0.2 ได้ 0.30000000000000004
  2. == จึงได้ false
  3. ผลต่าง 0.00000000000000004 น้อยกว่า 0.000000001 → ถือว่าเท่ากัน
ลองคิดก่อน · ผลของนิพจน์

ถ้า int a = 5, b = 8; ผลของ a * 2 > b, a + 3 == b, b % a != 3 คืออะไร

ดูคำตอบ

10 > 8 → true; 8 == 8 → true; 8 % 5 = 3, 3 != 3 → false

5.2 รวมเงื่อนไขด้วย AND, OR และ NOT

&& (AND) เป็นจริงเมื่อทั้งสองเงื่อนไขเป็นจริง, || (OR) เป็นจริงเมื่ออย่างน้อยหนึ่งเงื่อนไขเป็นจริง และ ! (NOT) กลับค่าจริงเป็นเท็จ

ABA && BA || B!A
truetruetruetruefalse
truefalsefalsetruefalse
falsetruefalsetruetrue
falsefalsefalsefalsetrue

ตัวอย่าง 5.2.1 · ตรวจช่วงตัวเลขด้วย && พื้นฐาน

แนวคิด: ภาษาคณิตศาสตร์เขียน 18 ≤ age ≤ 25 ได้ แต่ Java ต้องแยกเป็นสองเงื่อนไขแล้วเชื่อมด้วย &&

Java source · RangeCheck.java
public class RangeCheck {
    public static void main(String[] args) {
        int age = 19;
        boolean inRange = age >= 18 && age <= 25;
        boolean outOfRange = age < 18 || age > 25;
        System.out.println("18-25? " + inRange);
        System.out.println("outside? " + outOfRange);
        System.out.println("not in range? " + !inRange);
    }
}
Output
18-25? true
outside? false
not in range? false
อธิบายทีละขั้น
  1. 19 ≥ 18 true และ 19 ≤ 25 true → true
  2. นอกช่วงคือ “น้อยกว่า 18 หรือ มากกว่า 25” → false
  3. !inRange ให้ผลเท่ากับ outOfRange

ตัวอย่าง 5.2.2 · สิทธิ์ส่วนลด: ผสม && กับ || ต่อยอด

แนวคิด: && ทำก่อน || เสมอ ใช้วงเล็บเพื่อบอกความหมายให้ชัด

Java source · DiscountRule.java
public class DiscountRule {
    public static void main(String[] args) {
        boolean isStudent = false;
        boolean hasPass = true;
        int age = 16;

        boolean ruleA = (isStudent || hasPass) && age >= 18;
        boolean ruleB = isStudent || hasPass && age >= 18;
        boolean ruleC = isStudent || (hasPass && age >= 18);

        System.out.println("A = " + ruleA);
        System.out.println("B = " + ruleB);
        System.out.println("C = " + ruleC);
    }
}
Output
A = false
B = false
C = false
อธิบายทีละขั้น
  1. A: (false || true) = true, && (16 ≥ 18 false) → false
  2. B: ไม่มีวงเล็บ && ทำก่อน → false || (true && false) → false
  3. C: เขียนวงเล็บแบบเดียวกับ B จึงได้ผลเท่ากัน
  4. ลอง isStudent = true: A เป็น false (อายุไม่ถึง) แต่ B, C เป็น true — ความหมายต่างกันจริง

เปลี่ยน isStudent = true แล้วดูว่า A กับ B ต่างกันอย่างไร

ตัวอย่าง 5.2.3 · Short-circuit: หยุดตรวจเมื่อรู้คำตอบแล้ว ประยุกต์

แนวคิด: ถ้าด้านซ้ายของ && เป็น false Java ไม่ตรวจด้านขวาเลย ใช้ป้องกันการหารด้วยศูนย์ได้

Java source · ShortCircuit.java
public class ShortCircuit {
    public static void main(String[] args) {
        int total = 100;
        int count = 0;
        if (count != 0 && total / count > 10) {
            System.out.println("Average above 10");
        } else {
            System.out.println("No data or average too low");
        }
    }
}
Output
No data or average too low
อธิบายทีละขั้น
  1. count != 0 เป็น false
  2. เนื่องจาก false && อะไรก็ได้ = false Java จึงข้าม total / count
  3. ไม่เกิด ArithmeticException
  4. ถ้าสลับเป็น total / count > 10 && count != 0 จะ error ทันที

ตัวอย่าง 5.2.4 · ปีอธิกสุรทิน: เงื่อนไขซับซ้อน ท้าทาย

แนวคิด: ปีอธิกสุรทิน = หารด้วย 4 ลงตัว และ ไม่ลงตัวด้วย 100 หรือ หารด้วย 400 ลงตัว

Java source · LeapYear.java
public class LeapYear {
    public static void main(String[] args) {
        int[] years = {2024, 2025, 1900, 2000};
        for (int year : years) {
            boolean leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
            System.out.println(year + " leap? " + leap);
        }
    }
}
Output
2024 leap? true
2025 leap? false
1900 leap? false
2000 leap? true
อธิบายทีละขั้น
  1. 2024: หาร 4 ลงตัว ไม่ลงตัวด้วย 100 → true
  2. 2025: หาร 4 ไม่ลงตัว และไม่ลงตัวด้วย 400 → false
  3. 1900: หาร 100 ลงตัว ทำให้วงเล็บแรก false และ 1900 % 400 ≠ 0 → false
  4. 2000: หาร 400 ลงตัว → true

ตัวอย่างนี้ใช้อาเรย์และลูปวนทดสอบหลายปี (จะเรียนในบทที่ 6 และ 8) เพื่อให้เห็นทุกกรณีพร้อมกัน ตอนนี้ให้โฟกัสที่บรรทัด boolean leap

ลองคิดก่อน · De Morgan

!(a > 0 && b > 0) เขียนใหม่โดยไม่ใช้ ! ด้านนอกได้อย่างไร

ดูคำตอบ

a <= 0 || b <= 0 — กลับ && เป็น || และกลับเงื่อนไขย่อยทุกตัว (กฎของ De Morgan)

5.3 if, else if และ else

รูปแบบของ if ทั้ง 3 แบบ
if (เงื่อนไข) {              if (เงื่อนไข) {              if (เงื่อนไข1) {
    ทำเมื่อจริง                 ทำเมื่อจริง                  ...
}                           } else {                     } else if (เงื่อนไข2) {
                                ทำเมื่อเท็จ                  ...
                            }                            } else {
① ทางเลือกเดียว             ② สองทาง                         ทำเมื่อไม่ตรงข้อใด
                                                         }
                                                         ③ หลายทาง

if-else if ตรวจจากบนลงล่าง และทำเฉพาะกรณีแรกที่เป็นจริง กรณีที่เหลือถูกข้ามทั้งหมด

ตัวอย่าง 5.3.1 · if อย่างเดียว: แจ้งเตือนเมื่อเกินกำหนด พื้นฐาน

แนวคิด: เมื่อต้องทำอะไรเพิ่มเฉพาะบางกรณี และกรณีอื่นไม่ต้องทำอะไร ใช้ if อย่างเดียว

Java source · FeverAlert.java
import java.util.Scanner;

public class FeverAlert {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Temperature: ");
        double temp = input.nextDouble();
        if (temp >= 37.5) {
            System.out.println("Warning: fever!");
        }
        System.out.println("Recorded " + temp);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Temperature: 38.2
Warning: fever!
Recorded 38.2
อธิบายทีละขั้น
  1. 38.2 ≥ 37.5 → true → พิมพ์ Warning
  2. บรรทัด Recorded อยู่นอก if จึงทำทุกครั้ง

ตัวอย่าง 5.3.2 · if-else: คู่หรือคี่ พื้นฐาน

แนวคิด: สองทางที่ไม่ซ้อนทับกัน — ทำทางใดทางหนึ่งเสมอ

Java source · EvenOdd.java
import java.util.Scanner;

public class EvenOdd {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Number: ");
        int n = input.nextInt();
        if (n % 2 == 0) {
            System.out.println(n + " is even");
        } else {
            System.out.println(n + " is odd");
        }
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Number: 17
17 is odd
อธิบายทีละขั้น
  1. 17 % 2 = 1 ไม่เท่ากับ 0
  2. ไปทาง else → odd

ตัวอย่าง 5.3.3 · else-if: ตัดเกรดและลำดับเงื่อนไข ต่อยอด

แนวคิด: ตรวจจากคะแนนสูงลงต่ำ แต่ละขั้นจึงไม่ต้องเขียนขอบบน (เพราะกรณีที่สูงกว่าถูกดักไปแล้ว)

Java source · GradeIf.java
import java.util.Scanner;

public class GradeIf {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Score: ");
        int score = input.nextInt();
        String grade;
        if (score >= 80) {
            grade = "A";
        } else if (score >= 70) {
            grade = "B";
        } else if (score >= 60) {
            grade = "C";
        } else if (score >= 50) {
            grade = "D";
        } else {
            grade = "F";
        }
        System.out.println("Grade: " + grade);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Score: 85
Grade: A
อธิบายทีละขั้น
  1. 85 ≥ 80 → grade = A แล้วข้ามทั้งหมด
  2. ถ้าเรียง score ≥ 50 ไว้ก่อน คะแนน 85 จะได้ D ทันที เพราะ 85 ≥ 50 เป็นจริงก่อน
  3. else สุดท้ายรับทุกกรณีที่เหลือ ตัวแปร grade จึงมีค่าแน่นอน

ทดลองบั๊ก 5.3.4 · เงื่อนไขเรียงผิด: กรณีสำคัญถูกบัง ต่อยอด

แนวคิด: โค้ดคอมไพล์ผ่าน แต่ให้ผลผิด (logic error) เพราะเงื่อนไขที่กว้างกว่าถูกตรวจก่อน

Java source · WrongOrder.java
import java.util.Scanner;

public class WrongOrder {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Score: ");
        int score = input.nextInt();
        if (score >= 50) {
            System.out.println("Pass");
        } else if (score >= 90) {
            System.out.println("Excellent");
        }
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Score: 92
Pass
อธิบายทีละขั้น
  1. 92 ≥ 50 เป็นจริงตั้งแต่เงื่อนไขแรก → Pass
  2. เงื่อนไข ≥ 90 ไม่มีทางถูกตรวจเลย
  3. แก้: ย้าย ≥ 90 ขึ้นก่อน

ตัวอย่าง 5.3.5 · if ซ้อน และตัวดำเนินการ ?: ประยุกต์

แนวคิด: if ซ้อน (nested) ใช้เมื่อการตัดสินใจชั้นที่สองขึ้นกับชั้นแรก ส่วน เงื่อนไข ? ค่า1 : ค่า2 (ternary) ใช้เลือกค่าสั้น ๆ

Java source · ShippingFee.java
import java.util.Scanner;

public class ShippingFee {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Order total: ");
        double total = input.nextDouble();
        System.out.print("Member (y/n): ");
        String member = input.next();

        double shipping;
        if (total >= 1000) {
            shipping = 0;
        } else {
            if (member.equals("y")) {
                shipping = 20;
            } else {
                shipping = 50;
            }
        }
        String label = shipping == 0 ? "FREE" : shipping + " baht";
        System.out.println("Shipping: " + label);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Order total: 1200
Member (y/n): y
Shipping: FREE
อธิบายทีละขั้น
  1. ยอด 1200 ≥ 1000 → ส่งฟรี ไม่ต้องดูสถานะสมาชิกเลย
  2. ถ้ายอดไม่ถึง จึงค่อยตรวจสมาชิก (if ชั้นใน)
  3. ternary เลือกข้อความ: 0 → "FREE"

ป้อน 800 และ y → 20 baht, ป้อน 800 และ n → 50 baht

ใส่วงเล็บปีกกาเสมอ และอย่าใส่ ; หลัง if
if (score >= 50);              // ← ; ทำให้ if ไม่มีผลต่อบรรทัดถัดไป
    System.out.println("Pass");  // ← ทำงานทุกครั้ง!

5.4 เลือกทางด้วย switch

switch เหมาะเมื่อเปรียบเทียบค่าเดียวกับตัวเลือกที่เป็นค่าแน่นอนหลายค่า เช่น รหัสเมนู วันในสัปดาห์ ใช้กับ int, char, String ได้ (แต่ไม่ใช้กับช่วงค่า เช่น ≥ 80 — กรณีนั้นใช้ if)

switch แบบดั้งเดิม vs แบบลูกศร (Java 14+)
switch (day) {                       switch (day) {
    case 1:                              case 1 -> name = "Mon";
        name = "Mon";                    case 2 -> name = "Tue";
        break;                           default -> name = "?";
    case 2:                          }
        name = "Tue";
        break;                       // ไม่ต้องมี break ไม่มี fall-through
    default:
        name = "?";
}

ตัวอย่าง 5.4.1 · switch แบบดั้งเดิม: ชื่อวัน พื้นฐาน

แนวคิด: Java กระโดดไปที่ case ที่ค่าตรงกัน ทำคำสั่งจนเจอ break ถ้าไม่มี case ใดตรงจะไป default

Java source · DayName.java
import java.util.Scanner;

public class DayName {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Day (1-7): ");
        int day = input.nextInt();
        String name;
        switch (day) {
            case 1: name = "Monday"; break;
            case 2: name = "Tuesday"; break;
            case 3: name = "Wednesday"; break;
            case 4: name = "Thursday"; break;
            case 5: name = "Friday"; break;
            case 6: name = "Saturday"; break;
            case 7: name = "Sunday"; break;
            default: name = "Unknown day";
        }
        System.out.println(name);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Day (1-7): 3
Wednesday
อธิบายทีละขั้น
  1. day = 3 → กระโดดไป case 3
  2. name = "Wednesday" แล้ว break ออกจาก switch

ทดลองบั๊ก 5.4.2 · ลืม break: fall-through ต่อยอด

แนวคิด: ถ้าไม่มี break จะ “ไหล” ไปทำ case ถัดไปทั้งหมดจนจบหรือเจอ break

Java source · MiniCalculator.java
import java.util.Scanner;

public class MiniCalculator {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Expression (a op b): ");
        double a = input.nextDouble();
        char op = input.next().charAt(0);
        double b = input.nextDouble();

        switch (op) {
            case '+' -> System.out.println("= " + (a + b));
            case '-' -> System.out.println("= " + (a - b));
            case '*', 'x' -> System.out.println("= " + (a * b));
            case '/' -> {
                if (b == 0) {
                    System.out.println("Cannot divide by zero");
                } else {
                    System.out.println("= " + (a / b));
                }
            }
            default -> System.out.println("Unknown operator: " + op);
        }
    }
}

= 48.0

  1. อ่าน 12, "*" และ 4
  2. .charAt(0) ดึงอักขระแรกจาก String เป็น char
  3. case '*' ทำงาน → 48.0

Exercise 5.9ประเภทสามเหลี่ยม★★★ ท้าทาย

รับความยาวด้าน 3 ด้าน (จำนวนเต็ม) ตรวจก่อนว่าประกอบเป็นสามเหลี่ยมได้หรือไม่ (ผลบวกของสองด้านใด ๆ ต้องมากกว่าด้านที่เหลือ และทุกด้านต้องมากกว่า 0) ถ้าได้ ให้บอกว่าเป็น Equilateral (ด้านเท่า), Isosceles (หน้าจั่ว) หรือ Scalene (ด้านไม่เท่า) และบอกเพิ่มว่าเป็นสามเหลี่ยมมุมฉากหรือไม่ (a² + b² = c² เมื่อ c เป็นด้านยาวสุด)

สิ่งที่ต้องทำ
  1. ใช้ && และ || รวมเงื่อนไข
  2. หาด้านที่ยาวที่สุดก่อนตรวจมุมฉาก
  3. ทดสอบ 3 4 5, 5 5 5, 2 2 3, 1 2 3
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

import java.util.Scanner;

public class TriangleType {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Sides: ");
        int a = input.nextInt(), b = input.nextInt(), c = input.nextInt();
        boolean valid = a > 0 && b > 0 && c > 0 && a + b > c && a + c > b && b + c > a;
        if (!valid) {
            System.out.println("Not a triangle");
        } else {
            if (a == b && b == c) {
                System.out.println("Equilateral");
            } else if (a == b || b == c || a == c) {
                System.out.println("Isosceles");
            } else {
                System.out.println("Scalene");
            }
            int longest = Math.max(a, Math.max(b, c));
            int sumSquares = a * a + b * b + c * c - longest * longest;
            if (sumSquares == longest * longest) {
                System.out.println("Right triangle: yes");
            } else {
                System.out.println("Right triangle: no");
            }
        }
    }
}

Exercise 5.10เครื่องคิดเลข BMI พร้อมคำแนะนำ★★★ ท้าทาย

รับเพศ (M/F) น้ำหนัก (กก.) และส่วนสูง (ซม.) คำนวณ BMI แล้วจัดกลุ่มตามเกณฑ์เอเชีย: ต่ำกว่า 18.5 Underweight, 18.5–22.9 Normal, 23–24.9 Overweight, 25–29.9 Obese I, ตั้งแต่ 30 Obese II

นอกจากนี้ให้คำนวณน้ำหนักที่ควรลด/เพิ่มเพื่อให้ BMI อยู่ในช่วงปกติ (ใช้ขอบ 18.5 หรือ 22.9) และถ้าข้อมูลไม่สมเหตุสมผล (น้ำหนัก ≤ 0, ส่วนสูง < 50 หรือ > 250, เพศไม่ใช่ M/F) ให้แสดง Invalid input แล้วไม่คำนวณต่อ

สิ่งที่ต้องทำ
  1. ตรวจความถูกต้องของข้อมูลก่อน
  2. เพศใช้ char ผ่าน next().toUpperCase().charAt(0)
  3. น้ำหนักเป้าหมาย = BMI ขอบ × (ส่วนสูงเมตร)²
  4. แสดงผลทศนิยม 1–2 ตำแหน่งตามตัวอย่าง
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

import java.util.Scanner;

public class BmiAdvisor {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Gender weight height: ");
        char gender = input.next().toUpperCase().charAt(0);
        double weight = input.nextDouble();
        double heightCm = input.nextDouble();
        if ((gender != 'M' && gender != 'F') || weight <= 0 || heightCm < 50 || heightCm > 250) {
            System.out.println("Invalid input");
        } else {
            double h = heightCm / 100;
            double bmi = weight / (h * h);
            String group;
            if (bmi < 18.5) group = "Underweight";
            else if (bmi < 23) group = "Normal";
            else if (bmi < 25) group = "Overweight";
            else if (bmi < 30) group = "Obese I";
            else group = "Obese II";
            System.out.printf("BMI = %.2f (%s)%n", bmi, group);
            if (bmi < 18.5) {
                System.out.printf("Gain about %.1f kg%n", 18.5 * h * h - weight);
            } else if (bmi >= 23) {
                System.out.printf("Lose about %.1f kg%n", weight - 22.9 * h * h);
            } else {
                System.out.println("Keep it up!");
            }
        }
    }
}

Exercise 5.11วันถัดไปในปฏิทิน★★★ ท้าทาย

รับวัน เดือน ปี (ค.ศ.) แล้วแสดงวันถัดไป โดยคำนึงถึงจำนวนวันในแต่ละเดือนและปีอธิกสุรทิน (กุมภาพันธ์มี 29 วัน) ถ้าวันที่ไม่มีจริง (เช่น 31/4 หรือ 29/2/2025) ให้แสดง Invalid date

สิ่งที่ต้องทำ
  1. หาจำนวนวันของเดือนด้วย switch (เดือน 4, 6, 9, 11 มี 30 วัน, เดือน 2 ขึ้นกับปีอธิกสุรทิน, ที่เหลือ 31)
  2. ตรวจความถูกต้องของวันที่ก่อน
  3. จัดการกรณีขึ้นเดือนใหม่และขึ้นปีใหม่
  4. ทดสอบ 28/2/2024, 28/2/2025, 31/12/2025, 31/4/2025
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

import java.util.Scanner;

public class NextDay {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Date (d m y): ");
        int d = input.nextInt(), m = input.nextInt(), y = input.nextInt();
        boolean leap = (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
        int daysInMonth = switch (m) {
            case 4, 6, 9, 11 -> 30;
            case 2 -> leap ? 29 : 28;
            case 1, 3, 5, 7, 8, 10, 12 -> 31;
            default -> 0;
        };
        if (daysInMonth == 0 || d < 1 || d > daysInMonth) {
            System.out.println("Invalid date");
        } else {
            d++;
            if (d > daysInMonth) {
                d = 1;
                m++;
                if (m > 12) {
                    m = 1;
                    y++;
                }
            }
            System.out.println("Next day: " + d + "/" + m + "/" + y);
        }
    }
}
