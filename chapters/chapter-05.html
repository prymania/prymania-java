บทที่ 5 · ให้โปรแกรมเลือกทำงาน

เงื่อนไขและการตัดสินใจ

สอนให้โปรแกรมตอบสนองต่อข้อมูลที่แตกต่างกัน ด้วย boolean การเปรียบเทียบ และโครงสร้าง if หรือ switch

เมื่อจบบทนี้ นิสิตจะทำได้
  • อ่านผลนิพจน์เปรียบเทียบเป็น true หรือ false
  • รวมเงื่อนไขด้วย &&, || และ !
  • เลือกใช้ if/else กับ switch
  • จัดลำดับเงื่อนไขไม่ให้กรณีสำคัญถูกบัง

5. เปลี่ยนเงื่อนไขให้เป็นเส้นทางของโปรแกรม

เงื่อนไขคือนิพจน์ที่ให้ผลเป็น true หรือ false โปรแกรมใช้ผลนี้เลือกคำสั่งที่จะทำต่อ อย่าใส่ ; ต่อท้ายเงื่อนไขของ if เพราะจะเปลี่ยนความหมายของโปรแกรม

5.1 boolean และตัวดำเนินการเปรียบเทียบ

boolean เก็บได้เพียง true หรือ false นิพจน์เปรียบเทียบ เช่น score >= 50 จะสร้างค่า boolean ที่ใช้ใน if ได้

ตัวดำเนินการเปรียบเทียบ
  • == เท่ากับ และ != ไม่เท่ากับ
  • >, < มากกว่า / น้อยกว่า
  • >=, <= มากกว่าหรือเท่ากับ / น้อยกว่าหรือเท่ากับ
เครื่องหมาย = กับ == ทำคนละหน้าที่
int score = 72; // กำหนดค่า 72 ให้ score
boolean passed = score >= 50; // เปรียบเทียบ ได้ true

= กำหนดค่า ส่วน == เปรียบเทียบว่าเท่ากันหรือไม่

Exercise 5.1ตรวจช่วงอายุ

กำหนด age = 19 เขียนนิพจน์ boolean ที่ตรวจว่าอายุอยู่ในช่วง 18 ถึง 25 ปี รวมขอบเขตทั้งสองด้าน

ตัวอย่างคำตอบ

int age = 19;
boolean isInRange = age >= 18 && age <= 25;
System.out.println(isInRange); // true

ขอบเขตต้องใช้ >= และ <= เพราะโจทย์รวม 18 และ 25 ด้วย

5.2 รวมเงื่อนไขด้วย AND, OR และ NOT

&& เป็นจริงเมื่อทั้งสองเงื่อนไขเป็นจริง, || เป็นจริงเมื่ออย่างน้อยหนึ่งเงื่อนไขเป็นจริง และ ! ใช้กลับค่าจริงกับเท็จ

ใช้วงเล็บช่วยสื่อความหมาย

“เป็นนักศึกษาหรือมีบัตร” และ “อายุตั้งแต่ 18 ปี” เขียนเป็น (isStudent || hasPass) && age >= 18

Exercise 5.2ผ่านสิทธิ์ส่วนลด

ผู้ซื้อได้ส่วนลดเมื่อยอดซื้ออย่างน้อย 500 บาท หรือมีบัตรสมาชิก เขียนนิพจน์ boolean โดยมีตัวแปร total และ hasMemberCard

ตัวอย่างคำตอบ

double total = 420.0;
boolean hasMemberCard = true;
boolean getsDiscount = total >= 500 || hasMemberCard;

ผลเป็น true เพราะผู้ซื้อมีบัตร แม้ยอดยังไม่ถึง 500 บาท

5.3 if, else if และ else

ใช้ if เมื่อต้องทำคำสั่งเมื่อเงื่อนไขจริง, else สำหรับกรณีอื่น และ else if เมื่อต้องตรวจหลายกรณีตามลำดับ เงื่อนไขที่แคบหรือคะแนนสูงควรตรวจก่อน

จัดระดับผลสอบจากคะแนน
if (score >= 80) {
    grade = "A";
} else if (score >= 70) {
    grade = "B";
} else if (score >= 60) {
    grade = "C";
} else {
    grade = "ต้องฝึกเพิ่ม";
}

ถ้าคะแนน 85 โปรแกรมทำกรณีแรกและข้ามกรณีอื่น หากตรวจ score >= 60 ก่อน คะแนน 85 จะถูกจัดระดับ C ทันที

ใส่วงเล็บปีกกาเสมอ

แม้มีคำสั่งเดียว วงเล็บช่วยให้เห็นขอบเขตของแต่ละกรณีและลดโอกาสเพิ่มคำสั่งผิดทาง

Exercise 5.3ตรวจจำนวนบวก ลบ หรือศูนย์

กำหนดจำนวนเต็มหนึ่งจำนวน แล้วแสดง positive, negative หรือ zero

ตัวอย่างคำตอบ

int number = -4;
if (number > 0) {
    System.out.println("positive");
} else if (number < 0) {
    System.out.println("negative");
} else {
    System.out.println("zero");
}

ตรวจมากกว่าและน้อยกว่า 0; กรณีที่เหลือจึงเป็น 0

5.4 เลือกทางด้วย switch

switch เหมาะเมื่อเปรียบเทียบค่าหนึ่งกับตัวเลือกหลายค่า เช่น รหัสเมนู แต่ละ case ในรูปแบบพื้นฐานควรจบด้วย break; default รองรับค่าที่ไม่ได้ระบุ

แสดงชื่อวันจากเลขวัน
switch (day) {
    case 1:
        dayName = "Monday";
        break;
    case 2:
        dayName = "Tuesday";
        break;
    default:
        dayName = "Unknown day";
}

Exercise 5.4เลือกเครื่องดื่ม

เลข 1 แทนชา, 2 แทนกาแฟ, 3 แทนน้ำเปล่า และเลขอื่นแสดง เมนูไม่ถูกต้อง เขียนด้วย switch

ตัวอย่างคำตอบ

int choice = 2;
switch (choice) {
    case 1:
        System.out.println("ชา");
        break;
    case 2:
        System.out.println("กาแฟ");
        break;
    case 3:
        System.out.println("น้ำเปล่า");
        break;
    default:
        System.out.println("เมนูไม่ถูกต้อง");
}

เพิ่ม break หลังแต่ละตัวเลือกเพื่อไม่ให้ไหลไป case ถัดไป

แบบฝึกหัดท้ายบท

ทดสอบทั้งค่าขอบเขตและค่าที่อยู่นอกช่วงก่อนดูเฉลย

Exercise 5.5ค่าสัมบูรณ์

กำหนดจำนวนเต็ม number แล้วเปลี่ยนเป็นค่าสัมบูรณ์ด้วย if

ตัวอย่างคำตอบ

int number = -12;
if (number < 0) {
    number = -number;
}
System.out.println(number); // 12

Exercise 5.6ส่วนลดตามยอดซื้อ

ยอดซื้อตั้งแต่ 1,000 บาทลด 10%; ตั้งแต่ 500 บาทลด 5%; ต่ำกว่านั้นไม่ลด คำนวณยอดที่ต้องจ่าย

ตัวอย่างคำตอบ

double total = 780;
double discountRate;
if (total >= 1000) {
    discountRate = 0.10;
} else if (total >= 500) {
    discountRate = 0.05;
} else {
    discountRate = 0.0;
}
double amountToPay = total * (1 - discountRate);
System.out.println(amountToPay); // 741.0

ตรวจ 1,000 ก่อน 500 เพื่อไม่ให้ส่วนลดสูงถูกเงื่อนไข 500 จับไปก่อน

Exercise 5.7เครื่องคิดเลขอย่างง่าย

กำหนดตัวเลขสองค่าและเครื่องหมาย + หรือ - แล้วเลือกคำนวณด้วย switch กรณีอื่นให้แสดงข้อความว่าไม่รองรับ

ตัวอย่างคำตอบ

double first = 12;
double second = 5;
char operator = '-';
switch (operator) {
    case '+':
        System.out.println(first + second);
        break;
    case '-':
        System.out.println(first - second);
        break;
    default:
        System.out.println("เครื่องหมายนี้ยังไม่รองรับ");
}
