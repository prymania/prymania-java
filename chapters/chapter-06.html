บทที่ 6 · ให้โปรแกรมทำงานซ้ำ

การทำซ้ำด้วยลูป

ลดคำสั่งที่ต้องเขียนซ้ำ โดยกำหนดว่าจะทำซ้ำเมื่อใด ต้องปรับค่าอะไร และจะออกจากลูปอย่างไร

เมื่อจบบทนี้ นิสิตจะทำได้
  • เขียน while และ for ได้ครบองค์ประกอบ
  • เลือก do-while เมื่อต้องทำอย่างน้อยหนึ่งครั้ง
  • ใช้ลูปซ้อนกับรูปแบบข้อมูล
  • ควบคุมและป้องกันลูปไม่รู้จบ

6. ทำซ้ำโดยไม่เขียนคำสั่งเดิมหลายชุด

สมมติต้องพิมพ์คะแนนของนักศึกษา 100 คน ถ้าไม่มีลูปเราต้องเขียนคำสั่งรับและแสดงผลซ้ำ 100 ชุด ซึ่งยาว แก้ยาก และพลาดได้ง่าย ลูปช่วยให้เขียนขั้นตอนครั้งเดียวแล้วให้โปรแกรมทำซ้ำตามเงื่อนไข

ลูปช่วยอะไร
  • ลดโค้ดซ้ำ และแก้ขั้นตอนที่เดียว
  • ทำงานกับข้อมูลจำนวนมาก เช่น คะแนนในอาเรย์
  • ทำซ้ำจนกว่าจะเกิดเหตุการณ์ เช่น ผู้ใช้ป้อนค่าหยุด
  • ต้องออกแบบเงื่อนไขหยุด ไม่เช่นนั้นโปรแกรมอาจทำงานไม่จบ

6.1 while: ทำซ้ำขณะเงื่อนไขเป็นจริง

while เหมาะเมื่อยังไม่รู้จำนวนรอบแน่นอน แต่รู้เงื่อนไขที่ต้องทำต่อ เช่น “ทำต่อขณะที่ยังมีข้อมูล” ก่อน body ทุกครั้ง Java ตรวจนิพจน์ในวงเล็บ ซึ่งต้องได้ค่า boolean

Syntax ของ while
while (condition) {
        // คำสั่งที่ทำซ้ำ
        // เปลี่ยนค่าที่มีผลต่อ condition
      }
  1. ตรวจ condition ก่อนเข้ารอบ
  2. ถ้าเป็น true ทำคำสั่งในวงเล็บปีกกา
  3. เมื่อจบรอบ กลับไปตรวจ condition ใหม่
  4. ถ้าเป็น false ข้าม body แล้วทำคำสั่งถัดจากลูป

ถ้า condition เป็น false ตั้งแต่ครั้งแรก body จะไม่ทำงานเลย (zero iterations)

พิมพ์เลข 1 ถึง 5
int number = 1;
while (number <= 5) {
    System.out.println(number);
    number++;
}

เริ่มที่ 1, เพิ่มทีละ 1; เมื่อ number เป็น 6 เงื่อนไขเท็จและออกจากลูป

ตัวอย่าง 6.1.1 · while (i > 0)

ใช้เงื่อนไขนับถอยหลัง: เริ่ม 3 แล้วลด i ทุกครั้ง เมื่อ i ถึง 0 จึงหยุด

Output
3
      2
      1
      Done
แก้ค่าเริ่มต้นหรือเครื่องหมาย แล้วลองทำนายผลใหม่

ตัวอย่าง 6.1.2 · while (1 != 0) และ break

1 != 0 เป็น boolean ที่จริงเสมอ จึงต้องมี break ที่ไปถึงได้เพื่อออกจากลูป

Output
1
      2
      3
      Loop ended
ลองลบ break ใน IDE แล้วกด Stop หากลูปไม่จบ

ตัวอย่าง 6.1.3 · while (true)

true ทำให้ลูปตั้งใจทำงานต่อไปเรื่อย ๆ ในตัวอย่างนี้ break จะออกเมื่อครบ 3 รอบ

Output
Attempt 1
      Attempt 2
      Attempt 3
      Stopped safely
อย่ารัน while(true) ที่ไม่มีทางออกในโปรแกรมที่ใช้งานจริง
Compile error: เงื่อนไขต้องเป็น boolean
int i = 3;
      while (i = 3) { // error: int cannot be converted to boolean
        System.out.println(i);
      }

= คือการกำหนดค่า ทำให้ expression มีชนิด int แต่ while ต้องการ true/false; ถ้าต้องการเปรียบเทียบให้ใช้ i == 3 อย่างไรก็ตามอย่าลืมเปลี่ยนค่า i ใน body ด้วย

ทดลอง error · assignment ไม่ใช่เงื่อนไข

กด Run เพื่อดู compiler error จากนั้นเปลี่ยน i = 3 เป็น i == 3 และเพิ่มการอัปเดต i ใน body

Error ที่คาด
Compile error
        condition must be boolean
        int cannot be converted to boolean
แก้ source ในช่องซ้ายแล้ว Run ซ้ำได้
Logic error: ตัวนับวิ่งหนีเงื่อนไข
int i = 3;
      while (i > 0) {
        System.out.println(i);
        i++; // ผิดทิศ: 3, 4, 5, ... เงื่อนไขยัง true
      }

โค้ดนี้คอมไพล์ผ่าน แต่ไม่จบ เพราะ i เพิ่มขึ้นทั้งที่เงื่อนไขต้องการให้มันลดลง อย่ากด Run ตัวอย่างลูปไม่จบ ให้ trace ค่า 3 รอบแรกหรือใช้ Stop ใน IDE

ตรวจลูปไม่รู้จบ

ถ้าลืม number++ ค่า number คงเป็น 1 เงื่อนไข number <= 5 จึงจริงตลอด ลูปจะไม่จบ

Exercise 6.1รวมเลขตั้งแต่ 1 ถึง n

กำหนด n = 5 ใช้ while รวม 1 + 2 + ... + n แล้วแสดงผล

ตัวอย่างคำตอบ

int n = 5;
int number = 1;
int sum = 0;
while (number <= n) {
    sum += number;
    number++;
}
System.out.println(sum); // 15

อัปเดตตัวนับหลังบวกทุกครั้ง เพื่อให้เดินจาก 1 ไปถึง n + 1

Exercise 6.8นับถอยหลังทีละสอง

ใช้ while (i > 0) แสดง 10, 8, 6, 4, 2 แล้วแสดง Lift off! อธิบายว่าทำไมค่า 0 ไม่ถูกพิมพ์

ตัวอย่างคำตอบ

int i = 10;
      while (i > 0) {
        System.out.println(i);
        i -= 2;
      }
      System.out.println("Lift off!");

หลังพิมพ์ 2 ค่า i ลดเป็น 0 เงื่อนไข i > 0 จึง false ก่อนเข้ารอบถัดไป

Exercise 6.9เงื่อนไขไม่ผ่านตั้งแต่ต้น

กำหนด int i = 0; แล้วใช้ while (i > 0) พิมพ์ Inside และหลังลูปพิมพ์ After ให้ทำนาย output

คำตอบและเหตุผล

int i = 0;
      while (i > 0) {
        System.out.println("Inside");
      }
      System.out.println("After");

พิมพ์เพียง After เพราะตรวจ 0 > 0 ก่อนเข้าลูปแล้วได้ false; while อาจทำ 0 รอบได้

6.2 for: เมื่อรู้จำนวนรอบหรือตัวนับชัดเจน

for รวมจุดเริ่ม เงื่อนไข และการอัปเดตไว้ในบรรทัดเดียว รูปแบบคือ for (เริ่มต้น; เงื่อนไข; อัปเดต) แล้วตามด้วย body ของลูป

Syntax และ flow ของ for
for (initialization; condition; update) {
      // loop body
    }
  1. ทำ initialization ครั้งเดียวก่อนเริ่มลูป
  2. ตรวจ condition; ถ้า false ให้ออกจากลูป
  3. ถ้า true ให้ทำ body
  4. ทำ update แล้วกลับไปตรวจ condition

ตัวแปรที่ประกาศในส่วนเริ่มต้น เช่น int i ใช้ได้ภายใน for loop นั้น

ผลบวกเลขคู่ 2 ถึง 10
int sum = 0;
for (int number = 2; number <= 10; number += 2) {
    sum += number;
}
System.out.println(sum); // 30

number += 2 ทำให้ตัวนับขยับทีละ 2 รอบจึงมี 2, 4, 6, 8, 10

เลือกใช้ให้เหมาะ

ใช้ for เมื่อรู้ช่วงหรือตัวนับชัดเจน ใช้ while เมื่อทำซ้ำจนกว่าเหตุการณ์หนึ่งจะเกิด ทั้งคู่ทำงานแทนกันได้ในหลายสถานการณ์ แต่รูปแบบที่ตรงโจทย์อ่านง่ายกว่า

ตัวอย่าง 6.2.1 · อ่าน header ของ for ตามลำดับ

ก่อนรันให้ทำนายค่าเริ่มต้น, จำนวนรอบ และค่าที่ i มีเมื่อออกจากลูป

Output
i=1, sum=1
    i=2, sum=3
    i=3, sum=6
    After loop, sum=6
ลองเปลี่ยน i++ เป็น i += 2 แล้วไล่ flow ใหม่

ตัวอย่าง 6.2.2 · นับถอยหลังด้วย for

ส่วน update ลดค่าแทนการเพิ่มได้

Output
5
    4
    3
    2
    1
    Go!
ถ้าเงื่อนไขเป็น i > 1 จะเกิดผลต่างอย่างไร?
Logic error: semicolon เกินหลัง for
for (int i = 1; i <= 3; i++); {
      System.out.println("Hello");
    }

โค้ดนี้คอมไพล์ผ่าน แต่ ; ทำให้ body ของลูปว่างเปล่า บล็อกพิมพ์ Hello จึงทำเพียงครั้งเดียวหลังลูปจบ เอา semicolon ออกและใส่คำสั่งไว้ในวงเล็บปีกกา

ตัวอย่าง 6.2.3 · for(;;) ที่ออกด้วย break

for ที่ละทั้งสามช่องเป็นลูปไม่สิ้นสุดโดยตั้งใจ จึงต้องมี break ที่เข้าถึงได้

Output
1
      2
      3
ลองสังเกตว่า break ถูกตรวจที่จุดใด

ตัวอย่าง 6.2.4 · semicolon ทำให้ body ว่าง

โค้ดนี้คอมไพล์ผ่าน แต่แสดง Hello เพียงครั้งเดียว ลองลบ semicolon หลัง header แล้วรันใหม่

Output
Hello
ย้าย ; ออกแล้วสังเกตว่า Hello พิมพ์กี่ครั้ง

Exercise 6.2ตารางสูตรคูณ

กำหนด number = 7 ใช้ for พิมพ์สูตรคูณตั้งแต่ 7 × 1 ถึง 7 × 12

ตัวอย่างคำตอบ

int number = 7;
for (int multiplier = 1; multiplier <= 12; multiplier++) {
    System.out.printf("%d x %d = %d%n", number, multiplier, number * multiplier);
}

รอบแรก multiplier เป็น 1; รอบสุดท้ายเป็น 12 แล้วเพิ่มเป็น 13 จึงหยุด

Exercise 6.10รวมเลขคี่

ใช้ for รวมเลขคี่ตั้งแต่ 1 ถึง 15 โดยขยับตัวนับครั้งละ 2 แล้วแสดงผลรวม

ตัวอย่างคำตอบ

int sum = 0;
    for (int number = 1; number <= 15; number += 2) {
      sum += number;
    }
    System.out.println(sum); // 64

เลขคี่คือ 1, 3, 5, 7, 9, 11, 13, 15 รวมกันได้ 64

6.3 do-while และการทำซ้ำด้วย sentinel

do-while ตรวจเงื่อนไขหลังทำ body จึงทำอย่างน้อยหนึ่งครั้ง เหมาะกับการแสดงเมนูหรือถามข้อมูลก่อน แล้วค่อยตรวจว่าผู้ใช้ต้องการทำต่อหรือไม่

Syntax และ flow ของ do-while
do {
      // คำสั่งที่ต้องทำอย่างน้อยหนึ่งครั้ง
    } while (condition);
  1. เข้าทำ body ทันทีโดยยังไม่ตรวจเงื่อนไข
  2. ทำคำสั่งใน body และปรับค่าที่เกี่ยวข้อง
  3. ตรวจ condition ที่ท้ายลูป
  4. ถ้า true กลับไปเริ่ม body; ถ้า false ออกจากลูป

สังเกตอัฒภาค ; หลังวงเล็บของ while เป็นส่วนหนึ่งของ syntax

ถามให้ป้อนคะแนนในช่วงที่กำหนด
int score;
do {
    System.out.print("Score (0-100): ");
    score = input.nextInt();
} while (score < 0 || score > 100);

ส่วน sentinel คือค่าพิเศษที่ใช้สั่งหยุด เช่น ป้อน 0 เพื่อจบการรับข้อมูลที่เป็นจำนวนบวก

ตัวอย่าง 6.3.1 · ทำอย่างน้อยหนึ่งครั้ง

แม้เงื่อนไขท้ายเป็น false หลังรอบแรก body ก็ยังทำงานไปแล้วหนึ่งครั้ง

Output
Run 1
    Run 2
    Run 3
    Finished at 4
ลองเปลี่ยน count <= 3 เป็น count <= 0 แล้วรันใหม่
ระวังเครื่องหมายท้าย do-while

โครงสร้างต้องปิดด้วย while (เงื่อนไข); มีอัฒภาคท้ายบรรทัด ต่างจาก while ที่มี body ตามหลัง

Compile error: ลืม semicolon
do {
      count++;
    } while (count <= 3) // ขาด ;
    System.out.println("Done");

คอมไพเลอร์จะแจ้ง syntax error บริเวณคำสั่งถัดไปหรือปิดบล็อก เพราะรูปแบบ do-while ต้องลงท้ายด้วย ;

ทดลอง error · do-while ขาด semicolon

กด Run เพื่อดู syntax error จากนั้นเติม ; หลังเงื่อนไข while แล้วลองใหม่

Error ที่คาด
Compile error
      ';' expected after while condition
เมื่อเติม ; แล้ว โปรแกรมจะแสดง 1, 2, 3
Logic error: ใช้ AND แทน OR

การตรวจคะแนนนอกช่วงต้องใช้ score < 0 || score > 100 ถ้าใช้ && จะไม่มีคะแนนใดต่ำกว่า 0 และมากกว่า 100 พร้อมกัน ทำให้ลูปหยุดทันทีแม้ป้อน 150

Exercise 6.3รับคะแนนจนกว่าจะถูกต้อง

เขียนส่วนรับคะแนนด้วย do-while ให้ถามซ้ำเมื่อคะแนนต่ำกว่า 0 หรือมากกว่า 100

ตัวอย่างคำตอบ

import java.util.Scanner;
Scanner input = new Scanner(System.in);
int score;
do {
    System.out.print("Score (0-100): ");
    score = input.nextInt();
} while (score < 0 || score > 100);
System.out.println("Accepted: " + score);

ถ้าป้อน 75 จะออกจากลูป; ถ้าป้อน 120 จะถามใหม่

Exercise 6.11ยืนยันเมนูอย่างน้อยหนึ่งครั้ง

เขียน do-while ให้แสดงเมนูหนึ่งครั้ง แล้ววนต่อเมื่อ choice != 0 เริ่มต้น choice เป็น 0 ผลยังต้องแสดงเมนูหนึ่งครั้ง

ตัวอย่างคำตอบ

int choice = 0;
    do {
      System.out.println("1. Start");
      System.out.println("0. Exit");
    } while (choice != 0);

body ทำหนึ่งครั้งก่อนตรวจ choice != 0 ซึ่งเป็น false

Exercise 6.12รวมค่าจนป้อนศูนย์

รับจำนวนเต็มแล้วบวกเข้าผลรวม ทำซ้ำจนผู้ใช้ป้อน 0 โดยไม่บวก sentinel 0 เข้าไป

ตัวอย่างคำตอบ

import java.util.Scanner;
    Scanner input = new Scanner(System.in);
    int number;
    int sum = 0;
    do {
      System.out.print("Number (0 to stop): ");
      number = input.nextInt();
      if (number != 0) {
        sum += number;
      }
    } while (number != 0);
    System.out.println("Sum: " + sum);

ค่าที่ตรวจซ้ำคือ number; เมื่อเป็นศูนย์จะไม่บวกและเงื่อนไขจบการทำซ้ำ

6.4 ลูปซ้อน: เริ่มจาก output แล้วค่อยเพิ่มความต้องการ

ก่อนเขียน nested loop ให้เริ่มจากสิ่งที่ต้องการเห็น แล้วแบ่งงานเป็นรอบนอกกับงานที่ต้องทำซ้ำในแต่ละรอบ จะช่วยให้รู้ว่าลูปไหนควบคุมค่า และลูปไหนควบคุมจำนวนครั้ง

โจทย์ตั้งต้น: แสดงเลข 1–5 บรรทัดละหนึ่งเลข

ต้องการให้โปรแกรมเลือกเลขปัจจุบันหนึ่งค่า แล้วขึ้นบรรทัดใหม่เมื่อแสดงเสร็จ ดังนั้นใช้ ลูปเดียว ให้ตัวแปร i เปลี่ยนจาก 1 ถึง 5

ตัวอย่าง 6.4.1 · หนึ่งรอบต่อหนึ่งตัวเลข

outer loop ยังไม่จำเป็น เพราะหนึ่งค่าต้องแสดงเพียงครั้งเดียว

Output
1
    2
    3
    4
    5
เพิ่มความต้องการ: แสดงเลขแต่ละตัว 20 ครั้ง

ลูปเดิมยังต้องเลือกเลข 1, 2, 3, 4, 5 ทีละค่า แต่ตอนนี้ภายในแต่ละค่าต้องพิมพ์ซ้ำ 20 ครั้ง จึงแบ่งเป็นสองงาน:

  1. outer loop (i) เลือกตัวเลขทีละค่า ตั้งแต่ 1 ถึง 5
  2. inner loop (j) พิมพ์ค่า i จำนวน 20 ครั้ง ก่อนให้ outer loop ขยับไปเลขถัดไป
  3. เมื่อ inner loop จบ ให้ println() ขึ้นบรรทัดใหม่ แล้วเริ่ม inner loop ใหม่สำหรับค่า i ถัดไป

นี่เป็นคนละหน้าที่และคนละตัวนับ: i เลือกเลข ส่วน j นับจำนวนครั้งที่แสดงเลขนั้น

ตัวอย่าง 6.4.2 · inner loop พิมพ์เลขเดิม 20 ครั้ง

ตัวอย่างนี้แสดง i ซ้ำ 20 ครั้งในหนึ่งบรรทัด แล้วจึงขึ้นบรรทัดใหม่

ทำไมต้องเป็นคนละ loop?

ถ้าเขียน System.out.println(i) ใน outer loop อย่างเดียว แต่ละเลขจะแสดงเพียงครั้งเดียว ถ้าเขียนคำสั่ง print 20 บรรทัดแทน inner loop โค้ดจะยาวและเปลี่ยนจำนวนรอบยาก inner loop จึงรับผิดชอบการทำซ้ำย่อยต่อค่า i โดยตรง

เมื่อเข้าใจการแบ่งงานเป็นรอบแล้ว จึงต่อยอดไปใช้ break เพื่อออกจากลูป และ continue เพื่อข้ามรอบบางรอบได้

Flow ของ break และ continue
  • break; ออกจากลูปชั้นในสุดที่กำลังทำ แล้วไปคำสั่งหลังลูปนั้น
  • continue; หยุดรอบปัจจุบันทันทีแล้วเริ่มรอบใหม่
  • ใน for เมื่อ continue ทำงาน ส่วน update ในหัว for ยังถูกรันก่อนตรวจ condition รอบถัดไป
  • ใน while ถ้า update อยู่ท้าย body แล้ว continue มาก่อน update ค่านั้นจะถูกข้ามได้
พิมพ์สามเหลี่ยมดาว
for (int row = 1; row <= 3; row++) {
    for (int column = 1; column <= row; column++) {
        System.out.print("* ");
    }
    System.out.println();
}

ลูปชั้นนอกคุมแถว ส่วนลูปชั้นในพิมพ์ดาวตามหมายเลขแถว

ตัวอย่าง 6.4.3 · continue ข้ามเลขคู่, break ที่ 7

continue ข้ามการพิมพ์เลขคู่ ส่วน break ออกจากลูปเมื่อเจอ 7

Output
1
    3
    5
    After loop
break ออกก่อนพิมพ์ 7; continue ทำให้ข้ามเลขคู่
break ในลูปซ้อนออกจากลูปไหน?
for (int row = 1; row <= 3; row++) {
      for (int column = 1; column <= 3; column++) {
        if (column == 2) break;
        System.out.println(row + "," + column);
      }
    }

break ปกติออกจากลูปชั้นในเท่านั้น ลูป row ยังทำแถวถัดไป

Compile error: คำสั่งหลัง break ไปไม่ถึง
while (true) {
      break;
      System.out.println("never reached"); // unreachable statement
    }

เมื่อ break ทำงานทุกครั้ง คำสั่งถัดไปในบล็อกนี้ไม่มีทางทำงาน Java จึงรายงาน unreachable statement

ทดลอง error · unreachable statement

คำสั่ง print หลัง break ทำงานไม่ได้ เพราะโปรแกรมออกจากลูปก่อนเสมอ

Error ที่คาด
Compile error
      unreachable statement
ย้าย println ไปหลังลูปเพื่อให้คำสั่งทำงานได้
Logic error: continue ข้าม update ใน while
int i = 1;
    while (i <= 5) {
      if (i % 2 == 0) continue;
      System.out.println(i);
      i++;
    }

เมื่อ i เป็น 2 จะ continue ก่อน i++ ทำให้ i ค้างที่ 2 ตลอด ลูปไม่จบ ย้ายการอัปเดตไปตำแหน่งที่ทำงานทุกเส้นทาง หรือใช้ for

Exercise 6.4พิมพ์เลขคี่และหยุดก่อน 7

วนเลขตั้งแต่ 1 ถึง 10 ข้ามเลขคู่ด้วย continue และหยุดเมื่อถึง 7 ด้วย break ผลที่พิมพ์ควรเป็น 1, 3, 5

ตัวอย่างคำตอบ

for (int number = 1; number <= 10; number++) {
    if (number % 2 == 0) {
        continue;
    }
    if (number == 7) {
        break;
    }
    System.out.println(number);
}

เมื่อเป็น 7 จะไม่เข้าเงื่อนไขข้ามเลขคู่ แต่เข้า break ก่อนพิมพ์

Exercise 6.13ข้ามจำนวนที่หาร 3 ลงตัว

พิมพ์เลข 1 ถึง 12 โดยใช้ continue ข้ามจำนวนที่หาร 3 ลงตัว

ตัวอย่างคำตอบ

for (int i = 1; i <= 12; i++) {
      if (i % 3 == 0) continue;
      System.out.println(i);
    }

ส่วน update i++ อยู่ในหัว for จึงยังทำงานหลัง continue

Exercise 6.14break ออกจากลูปชั้นใด

ไล่ output ของลูปซ้อนเมื่อ row และ column มีค่า 1 ถึง 3 และสั่ง break เมื่อ row เป็น 2 และ column เป็น 2

ตัวอย่างคำตอบ

for (int row = 1; row <= 3; row++) {
      for (int column = 1; column <= 3; column++) {
        if (row == 2 && column == 2) break;
        System.out.println(row + "," + column);
      }
    }

ผลคือ 1,1; 1,2; 1,3; 2,1; 3,1; 3,2; 3,3 เพราะ break ออกจากลูป column เท่านั้น

Exercise 6.15ทำนายค่าก่อน break

ทำนายค่า total และ i ตอนจบ ก่อนเปิดเฉลย

โปรแกรมและการ trace

int i = 1;
    int total = 0;
    while (i < 4) {
      total += i;
      i++;
      if (total >= 3) break;
    }
    System.out.println("total=" + total + ", i=" + i);

รอบ 1 ได้ total=1, i=2; รอบ 2 ได้ total=3, i=3 แล้ว break จึงแสดง total=3, i=3

Exercise 6.16หาสาเหตุและแก้ลูป

โปรแกรม A ใช้ while (i = 3) ส่วนโปรแกรม B มี semicolon ต่อท้าย for (...) อธิบายว่าแต่ละโปรแกรมผิดแบบใดและแก้ให้ถูก

คำอธิบายและแนวแก้

// A: compile error เพราะ assignment ให้ค่า int ไม่ใช่ boolean
    while (i == 3) {
      System.out.println(i);
      i--;
    }

    // B: เอา semicolon ออกเพื่อให้บล็อกอยู่ใน body
    for (int i = 1; i <= 3; i++) {
      System.out.println("Hello");
    }

A เป็น compile error จากชนิดเงื่อนไขผิดและควรเปรียบเทียบด้วย ==; B คอมไพล์ผ่านแต่เป็น logic error เพราะลูปมี body ว่างและพิมพ์ Hello หลังลูปเพียงครั้งเดียว
