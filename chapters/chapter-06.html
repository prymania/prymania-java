บทที่ 6 · ให้โปรแกรมทำงานซ้ำ

การทำซ้ำด้วยลูป

ลดคำสั่งที่ต้องเขียนซ้ำ โดยกำหนดว่าจะทำซ้ำเมื่อใด ต้องปรับค่าอะไร และจะออกจากลูปอย่างไร

เมื่อจบบทนี้ นิสิตจะทำได้
  • เขียน while และ for ได้ครบองค์ประกอบ
  • เลือก do-while เมื่อต้องทำอย่างน้อยหนึ่งครั้ง
  • ใช้ลูปซ้อนกับรูปแบบข้อมูล
  • ควบคุมและป้องกันลูปไม่รู้จบ

6. ทำซ้ำโดยไม่เขียนคำสั่งเดิมหลายชุด

สมมติต้องพิมพ์คะแนนของนักศึกษา 100 คน ถ้าไม่มีลูปเราต้องเขียนคำสั่งซ้ำ 100 ชุด ซึ่งยาว แก้ยาก และพลาดได้ง่าย ลูปช่วยให้เขียนขั้นตอนครั้งเดียวแล้วให้โปรแกรมทำซ้ำตามเงื่อนไข

องค์ประกอบ 4 อย่างของลูปที่ดี
  1. ค่าเริ่มต้น (initialization) — ตัวนับหรือตัวแปรควบคุมเริ่มที่ค่าใด
  2. เงื่อนไข (condition) — ทำต่อขณะที่อะไรเป็นจริง
  3. งานที่ทำซ้ำ (body) — สิ่งที่ทำในแต่ละรอบ
  4. การอัปเดต (update) — เปลี่ยนค่าที่ทำให้เงื่อนไขเข้าใกล้ false ถ้าขาดข้อนี้จะเกิดลูปไม่รู้จบ

6.1 while: ทำซ้ำขณะเงื่อนไขเป็นจริง

while เหมาะเมื่อยังไม่รู้จำนวนรอบแน่นอน แต่รู้เงื่อนไขที่ต้องทำต่อ เช่น “ทำต่อขณะที่ยังมีข้อมูล” ก่อนเข้ารอบทุกครั้ง Java ตรวจนิพจน์ในวงเล็บ ซึ่งต้องได้ค่า boolean

ลำดับการทำงานของ while

while (condition) {
    // คำสั่งที่ทำซ้ำ
    // เปลี่ยนค่าที่มีผลต่อ condition
}

  1. ตรวจ condition ก่อนเข้ารอบ
  2. ถ้าเป็น true ทำคำสั่งในวงเล็บปีกกา
  3. จบรอบแล้วกลับไปตรวจ condition ใหม่
  4. ถ้าเป็น false ข้าม body ไปทำคำสั่งถัดจากลูป

ถ้า condition เป็น false ตั้งแต่ครั้งแรก body จะไม่ทำงานเลย (zero iterations)

ตัวอย่าง 6.1.1 · นับ 1 ถึง 5 พื้นฐาน

แนวคิด: ตัวนับเริ่มที่ 1 เพิ่มทีละ 1 และหยุดเมื่อเกิน 5

Java source · CountUp.java
public class CountUp {
    public static void main(String[] args) {
        int number = 1;
        while (number <= 5) {
            System.out.println(number);
            number++;
        }
        System.out.println("After loop: number = " + number);
    }
}
Output
1
2
3
4
5
After loop: number = 6
อธิบายทีละขั้น
  1. ตรวจ 1 ≤ 5 → พิมพ์ 1, number = 2
  2. ทำต่อจนพิมพ์ 5 แล้ว number = 6
  3. ตรวจ 6 ≤ 5 → false ออกจากลูป
  4. หลังลูป number มีค่า 6 (ไม่ใช่ 5)

ตัวอย่าง 6.1.2 · นับถอยหลังด้วย while (i > 0) พื้นฐาน

แนวคิด: เงื่อนไขต้องสอดคล้องกับทิศทางการอัปเดต: ลดค่า → ใช้ > หรือ >=

Java source · WhilePositive.java
public class WhilePositive {
    public static void main(String[] args) {
        int i = 3;
        while (i > 0) {
            System.out.println(i);
            i--;
        }
        System.out.println("Done");
    }
}
Output
3
2
1
Done
อธิบายทีละขั้น
  1. 3 > 0 → พิมพ์ 3, i = 2
  2. 2 > 0 → พิมพ์ 2, i = 1
  3. 1 > 0 → พิมพ์ 1, i = 0
  4. 0 > 0 false → ออก พิมพ์ Done

ตัวอย่าง 6.1.3 · สะสมผลรวม (accumulator) ต่อยอด

แนวคิด: รูปแบบสำคัญที่สุดของลูป: ตัวแปรผลรวมเริ่มที่ 0 แล้วบวกค่าของแต่ละรอบเข้าไป

Java source · SumToN.java
public class SumToN {
    public static void main(String[] args) {
        int n = 5;
        int number = 1;
        int sum = 0;
        while (number <= n) {
            sum += number;
            System.out.println("add " + number + " -> sum = " + sum);
            number++;
        }
        System.out.println("1 + ... + " + n + " = " + sum);
    }
}
Output
add 1 -> sum = 1
add 2 -> sum = 3
add 3 -> sum = 6
add 4 -> sum = 10
add 5 -> sum = 15
1 + ... + 5 = 15
อธิบายทีละขั้น
  1. sum เริ่ม 0 (ถ้าเริ่มค่าอื่นผลรวมจะผิด)
  2. แต่ละรอบ sum += number
  3. พิมพ์ระหว่างทางช่วยให้เห็นการเปลี่ยนแปลง (เทคนิค debug)
  4. ผลรวม 15 ตรงกับสูตร n(n+1)/2

ตัวอย่าง 6.1.4 · ไม่รู้จำนวนรอบ: นับหลักของตัวเลข ประยุกต์

แนวคิด: จำนวนรอบขึ้นกับข้อมูล — หาร 10 ไปเรื่อย ๆ จนเหลือ 0 นี่คือจุดที่ while เหมาะกว่า for

Java source · CountDigits.java
import java.util.Scanner;

public class CountDigits {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Number: ");
        int n = input.nextInt();
        int digits = 0;
        int digitSum = 0;
        int temp = n;
        while (temp > 0) {
            digitSum += temp % 10;
            temp /= 10;
            digits++;
        }
        System.out.println(n + " has " + digits + " digits, digit sum = " + digitSum);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
Number: 907215
907215 has 6 digits, digit sum = 24
อธิบายทีละขั้น
  1. temp = 907215 → หลักหน่วย 5, temp = 90721
  2. ทำซ้ำ: 1, 2, 7, 0, 9
  3. temp เป็น 0 → หยุด นับได้ 6 หลัก ผลรวม 24
  4. ใช้ temp แทน n เพื่อเก็บค่าเดิมไว้แสดงผล

ตัวอย่าง 6.1.5 · while (true) กับ break ประยุกต์

แนวคิด: บางครั้งเขียนลูปที่ตั้งใจไม่หยุดเอง แล้วใช้ break ออกเมื่อถึงเงื่อนไข — ต้องแน่ใจว่า break ไปถึงได้จริง

Java source · WhileTrueBreak.java
public class WhileTrueBreak {
    public static void main(String[] args) {
        int attempt = 1;
        while (true) {
            System.out.println("Attempt " + attempt);
            if (attempt >= 3) {
                break;
            }
            attempt++;
        }
        System.out.println("Stopped safely");
    }
}
Output
Attempt 1
Attempt 2
Attempt 3
Stopped safely
อธิบายทีละขั้น
  1. ลูปพิมพ์ Attempt 1, 2, 3
  2. เมื่อ attempt = 3 เงื่อนไข if จริง → break
  3. ไปทำคำสั่งหลังลูป

ทดลอง error 6.1.6 · assignment ไม่ใช่เงื่อนไข ประยุกต์

แนวคิด: while (i = 3) เป็นการกำหนดค่า ได้ชนิด int ไม่ใช่ boolean

  1. compiler แจ้ง int cannot be converted to boolean
  2. ต้องการเปรียบเทียบใช้ == แต่ในกรณีนี้ควรเป็น i > 0
Logic error: ลูปไม่รู้จบ (อย่ากด Run)
int i = 3;
while (i > 0) {
    System.out.println(i);
    i++;       // ผิดทิศ: 3, 4, 5, ... เงื่อนไข true ตลอด
}

int number = 1;
while (number <= 5) {
    System.out.println(number);
    // ลืม number++  → number = 1 ตลอดไป
}

ทั้งสองแบบคอมไพล์ผ่าน แต่ไม่จบ ถ้าเผลอรันใน IDE ให้กดปุ่ม Stop (■) วิธีป้องกันคือ trace 3 รอบแรกด้วยมือและตรวจว่าค่าเคลื่อนเข้าหาเงื่อนไขหยุด

ลองคิดก่อน · นับรอบ
int x = 20;
int rounds = 0;
while (x > 1) {
    x = x / 2;
    rounds++;
}

เมื่อจบลูป x และ rounds มีค่าเท่าไร

ดูคำตอบ

x: 20 → 10 → 5 → 2 → 1 → หยุด ดังนั้น x = 1, rounds = 4

6.2 for: เมื่อรู้จำนวนรอบหรือตัวนับชัดเจน

for รวมจุดเริ่ม เงื่อนไข และการอัปเดตไว้ในบรรทัดเดียว ทำให้อ่านแล้วรู้จำนวนรอบทันที

Syntax และ flow ของ for

for (initialization; condition; update) {
    // loop body
}

  1. ทำ initialization ครั้งเดียวก่อนเริ่มลูป
  2. ตรวจ condition; ถ้า false ออกจากลูป
  3. ถ้า true ทำ body
  4. ทำ update แล้วกลับไปข้อ 2

ตัวแปรที่ประกาศในส่วนเริ่มต้น เช่น int i ใช้ได้เฉพาะภายในลูปนั้น

ตัวอย่าง 6.2.1 · อ่าน header ของ for ตามลำดับ พื้นฐาน

แนวคิด: ก่อนรัน ให้ทำนายค่าเริ่มต้น จำนวนรอบ และผลรวม

Java source · ForFlow.java
public class ForFlow {
    public static void main(String[] args) {
        int sum = 0;
        for (int i = 1; i <= 3; i++) {
            sum += i;
            System.out.println("i=" + i + ", sum=" + sum);
        }
        System.out.println("After loop, sum=" + sum);
    }
}
Output
i=1, sum=1
i=2, sum=3
i=3, sum=6
After loop, sum=6
อธิบายทีละขั้น
  1. i = 1 → ตรวจ 1 ≤ 3 → body → i++
  2. i = 2, 3 ทำเช่นเดียวกัน
  3. i = 4 → เงื่อนไข false → ออก
  4. i ใช้นอกลูปไม่ได้ เพราะประกาศใน header

ตัวอย่าง 6.2.2 · ขยับทีละมากกว่า 1 และนับถอยหลัง พื้นฐาน

แนวคิด: ส่วน update เป็นนิพจน์ใดก็ได้ เช่น i += 2, i--, i *= 2

Java source · ForSteps.java
public class ForSteps {
    public static void main(String[] args) {
        System.out.print("Even: ");
        for (int i = 2; i <= 10; i += 2) {
            System.out.print(i + " ");
        }
        System.out.println();

        System.out.print("Countdown: ");
        for (int i = 5; i >= 1; i--) {
            System.out.print(i + " ");
        }
        System.out.println("Go!");

        System.out.print("Powers of 2: ");
        for (int p = 1; p <= 100; p *= 2) {
            System.out.print(p + " ");
        }
        System.out.println();
    }
}
Output
Even: 2 4 6 8 10 
Countdown: 5 4 3 2 1 Go!
Powers of 2: 1 2 4 8 16 32 64
อธิบายทีละขั้น
  1. i += 2 → 2, 4, 6, 8, 10
  2. i-- → 5, 4, 3, 2, 1
  3. p *= 2 → 1, 2, 4, …, 64 (128 เกิน 100)

ตัวอย่าง 6.2.4 · หาค่ามาก/น้อยสุดและค่าเฉลี่ยจากข้อมูล n ค่า ประยุกต์

แนวคิด: รูปแบบ “ติดตามค่าที่ดีที่สุด”: กำหนดค่าเริ่มจากข้อมูลตัวแรก แล้วเทียบกับตัวถัดไปทีละตัว

Java source · MinMaxAverage.java
import java.util.Scanner;

public class MinMaxAverage {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("How many scores? ");
        int n = input.nextInt();
        System.out.print("Scores: ");
        int first = input.nextInt();
        int max = first, min = first, sum = first;
        for (int i = 2; i <= n; i++) {
            int score = input.nextInt();
            sum += score;
            if (score > max) max = score;
            if (score < min) min = score;
        }
        System.out.printf("Max=%d Min=%d Avg=%.2f%n", max, min, (double) sum / n);
    }
}
Output (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)
How many scores? 5
Scores: 72 88 65 91 79
Max=91 Min=65 Avg=79.00
อธิบายทีละขั้น
  1. อ่านค่าแรก (72) ก่อนลูป ตั้งเป็น max, min, sum
  2. ลูปเริ่ม i = 2 อ่านค่าที่เหลืออีก 4 ค่า
  3. แต่ละรอบปรับ max/min ถ้าเจอค่าที่ดีกว่า
  4. cast sum เป็น double ก่อนหาร

ทดลองบั๊ก 6.2.5 · semicolon ทำให้ body ว่าง ประยุกต์

แนวคิด: โค้ดคอมไพล์ผ่าน แต่ ; หลัง header ทำให้ลูปไม่มี body บล็อกถัดไปทำครั้งเดียว

อธิบายทีละขั้น
  1. ลูปวน 3 รอบโดยไม่ทำอะไร
  2. บล็อก { } เป็นบล็อกธรรมดาหลังลูป → พิมพ์ Hello ครั้งเดียว
  3. แก้: ลบ ; หลังวงเล็บ
เลือก for หรือ while

ใช้ for เมื่อรู้ช่วงหรือจำนวนรอบชัดเจน (นับ 1–100, วนตามจำนวนข้อมูล) ใช้ while เมื่อทำซ้ำจนกว่าเหตุการณ์หนึ่งจะเกิด (ผู้ใช้ป้อน 0, ตัวเลขหารจนเหลือ 0) ทั้งคู่ทำงานแทนกันได้ แต่รูปแบบที่ตรงโจทย์อ่านง่ายกว่า

ลองคิดก่อน · นับรอบของ for

for (int i = 10; i < 50; i += 7) ทำกี่รอบ และ i ค่าสุดท้ายที่เข้า body คือเท่าไร

ดูคำตอบ

i = 10, 17, 24, 31, 38, 45 → 6 รอบ ค่าสุดท้ายคือ 45 (52 ไม่ผ่านเงื่อนไข)

6.3 do-while และการทำซ้ำด้วย sentinel

do-while ตรวจเงื่อนไขหลังทำ body จึงทำอย่างน้อยหนึ่งครั้ง เหมาะกับการแสดงเมนูหรือถามข้อมูลก่อน แล้วค่อยตรวจว่าต้องทำต่อหรือไม่ ส่วน sentinel คือค่าพิเศษที่ใช้สั่งหยุด เช่น ป้อน 0 หรือ -1

Syntax และ flow ของ do-while

do {
    // คำสั่งที่ต้องทำอย่างน้อยหนึ่งครั้ง
} while (condition);   // ← มี ; ปิดท้าย

  1. เข้าทำ body ทันทีโดยยังไม่ตรวจเงื่อนไข
  2. ทำคำสั่งใน body และปรับค่าที่เกี่ยวข้อง
  3. ตรวจ condition ที่ท้ายลูป
  4. ถ้า true กลับไปเริ่ม body; ถ้า false ออกจากลูป

ตัวอย่าง 6.3.1 · ทำอย่างน้อยหนึ่งครั้ง พื้นฐาน

แนวคิด: แม้เงื่อนไขเป็น false ตั้งแต่แรก body ก็ทำไปแล้วหนึ่งครั้ง — ต่างจาก while

public class PrimesUpTo50 {
    public static void main(String[] args) {
        int count = 0;
        for (int n = 2; n <= 50; n++) {
            boolean isPrime = true;
            for (int d = 2; d * d <= n; d++) {
                if (n % d == 0) {
                    isPrime = false;
                    break;          // ออกเฉพาะลูป d
                }
            }
            if (isPrime) {
                System.out.print(n + " ");
                count++;
            }
        }
        System.out.println();
        System.out.println("Total primes: " + count);
    }
}

import java.util.Scanner;

public class ScoreStats {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int count = 0, sum = 0, passed = 0;
        int max = Integer.MIN_VALUE, min = Integer.MAX_VALUE;
        System.out.print("Scores (-1 to stop): ");
        int score = input.nextInt();
        while (score != -1) {
            count++;
            sum += score;
            if (score > max) max = score;
            if (score < min) min = score;
            if (score >= 50) passed++;
            score = input.nextInt();
        }
        if (count == 0) {
            System.out.println("No data");
        } else {
            System.out.println("Count: " + count);
            System.out.println("Max: " + max + ", Min: " + min);
            System.out.printf("Average: %.2f%n", (double) sum / count);
            System.out.println("Passed: " + passed);
        }
    }

import java.util.Scanner;

public class ReverseNumber {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Number: ");
        int n = input.nextInt();
        int temp = n, reversed = 0;
        while (temp > 0) {
            reversed = reversed * 10 + temp % 10;
            temp /= 10;
        }
        System.out.println("Reversed: " + reversed);
        System.out.println(n == reversed ? "Palindrome" : "Not palindrome");

import java.util.Scanner;

public class GuessNumber {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int secret = 37;
        boolean found = false;
        for (int attempt = 1; attempt <= 6; attempt++) {
            System.out.print("Guess #" + attempt + ": ");
            int guess = input.nextInt();
            if (guess == secret) {
                System.out.println("Correct! You used " + attempt + " guesses.");

        }
    }

import java.util.Scanner;

public class NumberDiamond {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("h = ");

        for (int k = 1; k <= h; k++) printRow(k, h);

        System.out.println();
    }

import java.util.Scanner;

public class PrimeAndPerfect {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Range a b: ");
        int a = input.nextInt(), b = input.nextInt();
        int primeCount = 0, perfectCount = 0;
        System.out.print("Primes: ");
        for (int n = a; n <= b; n++) {
            if (n < 2) continue;
            boolean prime = true;
            for (int d = 2; d * d <= n; d++) {
                if (n % d == 0) { prime = false; break; }
            }
            if (prime) { System.out.print(n + " "); primeCount++; }
        }
        System.out.println("(" + primeCount + ")");
        System.out.print("Perfect: ");
        for (int n = Math.max(a, 2); n <= b; n++) {
            int sum = 0;
            for (int d = 1; d < n; d++) {
                if (n % d == 0) sum += d;
            }
            if (sum == n) { System.out.print(n + " "); perfectCount++; }
        }
        System.out.println("(" + perfectCount + ")");
    }
}

import java.util.Scanner;

public class CompoundSavings {
    public static void main(String[] args) {
        final double YEARLY_DEPOSIT = 12000;
        Scanner input = new Scanner(System.in);
        System.out.print("Principal: ");
