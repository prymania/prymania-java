บทที่ 16 · ทำให้ GUI โต้ตอบได้

เหตุการณ์และการตอบสนอง

ปุ่มไม่รู้เองว่าต้องทำอะไร เราต้องลงทะเบียน listener เพื่อบอกว่าเมื่อเกิด event แล้วให้โปรแกรมเรียกคำสั่งใด

เมื่อจบบทนี้ นิสิตจะทำได้
  • อธิบาย event source, event และ listener
  • ผูก ActionListener กับ JButton
  • เขียน handler ด้วย lambda
  • แยก event handler จากงานคำนวณและอัปเดต UI

16. หน้าต่างตอบสนองเมื่อมีเหตุการณ์

โปรแกรม console มักทำงานตามบรรทัดจากบนลงล่าง แต่ GUI ใช้ event-driven flow: สร้างหน้าจอและ listener ก่อน จากนั้นรอให้ผู้ใช้คลิกหรือพิมพ์ แล้วจึงเรียก handler ที่ผูกไว้

16.1 Event source, event และ listener

source คือ component ที่เกิดเหตุการณ์ เช่น JButton; event คือข้อมูลการกระทำ เช่น action ที่เกิดจากคลิก; listener คือ object/คำสั่งที่รอรับ event

ลำดับเหตุการณ์เมื่อผู้ใช้คลิก
  1. โปรแกรมสร้าง JButton
  2. ลงทะเบียน listener ให้ปุ่ม
  3. หน้าต่างแสดงและรอ event
  4. ผู้ใช้คลิก ปุ่มสร้าง ActionEvent
  5. listener เรียก handler เพื่อทำงาน

การลงทะเบียน listener ไม่ได้เรียก handler ทันที แต่บอกว่า “ถ้าเกิด event ในอนาคต ให้เรียกคำสั่งนี้”

แยก source ออกจาก handler
JButton button = new JButton("Count");
button.addActionListener(event -> {
    System.out.println("Button was clicked");
});

button เป็น source; lambda เป็น handler ที่ทำงานเมื่อมี action event

Exercise 16.1วิเคราะห์ event

ในปุ่ม Login ให้ระบุ source, event และงานที่ควรทำใน listener อย่างน้อยสองอย่าง

ตัวอย่าง

source คือ JButton Login; event คือ ActionEvent จากการคลิก; listener อ่านข้อมูลในฟอร์ม ตรวจข้อมูล แล้วแสดงผลหรือข้อความตอบกลับ

16.2 ActionListener แบบ anonymous class

ActionListener เป็น interface สำหรับรับ action event เมธอดหลักชื่อ actionPerformed รูปแบบ anonymous class เหมาะสำหรับเห็นโครงสร้าง listener ก่อนย่อเป็น lambda

เขียน handler แบบเต็ม
button.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent event) {
        statusLabel.setText("Saved");
    }
});

ต้อง import java.awt.event.ActionListener และ java.awt.event.ActionEvent; handler ถูกเรียกตอนผู้ใช้กดปุ่ม

อย่ารอ input ใน handler

handler ทำงานบน EDT ควรทำงานสั้น ๆ ถ้ารอ network หรือคำนวณนาน หน้าต่างจะค้าง; งานเบื้องหลังจะเรียนในบทเสริมเรื่อง Thread

Exercise 16.2ปุ่มเปลี่ยนข้อความ

เขียน ActionListener ให้ปุ่มเปลี่ยนข้อความ JLabel จาก Not clicked เป็น Clicked

ตัวอย่างคำตอบ

JLabel status = new JLabel("Not clicked");
button.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent event) {
        status.setText("Clicked");
    }
});

16.3 Lambda เป็นรูปแบบย่อของ callback

เมื่อ interface มี method เดียว เช่น ActionListener สามารถแทน anonymous class ด้วย lambda เพื่อให้เห็นงานที่เกิดหลัง event ชัดขึ้น

เทียบสองรูปแบบ
// แบบ anonymous class
button.addActionListener(new ActionListener() {
    public void actionPerformed(ActionEvent event) {
        status.setText("Ready");
    }
});

// แบบ lambda ที่ทำงานเดียวกัน
button.addActionListener(event -> status.setText("Ready"));

event เป็น parameter; ถ้า body มีหลายคำสั่งให้ใช้วงเล็บปีกกา

handler หลายคำสั่ง
button.addActionListener(event -> {
    String name = nameField.getText().trim();
    statusLabel.setText("Hello, " + name);
});

lambda เป็น callback: ส่งพฤติกรรมให้ button เก็บไว้ แล้วเรียกภายหลังเมื่อเกิด event

Exercise 16.3ย่อ listener

แปลง anonymous ActionListener ของข้อ 16.2 ให้เป็น lambda ที่ทำงานเหมือนเดิม

คำตอบ

button.addActionListener(event -> status.setText("Clicked"));

16.4 อัปเดต Swing component บน EDT

event จาก Swing มาถึงบน Event Dispatch Thread อยู่แล้ว จึงแก้ label, field หรือ model ของหน้าจอจาก handler ได้โดยตรง แต่ไม่ควรทำงานหนักบน thread นี้

handler สั้นและแยกงานคำนวณ
button.addActionListener(event -> {
    int total = calculateTotal(quantityField.getText());
    resultLabel.setText("Total: " + total);
});

สำหรับงานคำนวณสั้น handler อ่านค่า เรียก method แล้วอัปเดตผลได้ ส่วนงานที่ใช้เวลานานต้องทำใน worker thread และกลับมาอัปเดต UI บน EDT

สร้าง GUI บน EDT

จุดเริ่มของ Swing ควรใช้ SwingUtilities.invokeLater(() -> createAndShowGui()); event handler จะถูกรันบน EDT โดย framework

Exercise 16.4นับจำนวนคลิก

ใช้ตัวแปร count เพิ่มทีละ 1 เมื่อคลิกปุ่ม และแสดงค่าปัจจุบันใน JLabel

แนวคำตอบ

int[] count = {0};
button.addActionListener(event -> {
    count[0]++;
    countLabel.setText("Clicks: " + count[0]);
});

ถ้าประกาศตัวแปร local ใน lambda ต้องไม่เปลี่ยนค่าโดยตรงหลัง capture; อีกแบบคือใช้ field ใน class

แบบฝึกหัดท้ายบท

ให้ event handler ทำงานสั้น แยกการคำนวณไปยัง method ที่ทดสอบแยกได้

Exercise 16.5เครื่องคิดเลขบวกเลข

มี JTextField สองช่อง ปุ่ม Add และ JLabel แสดงผล เมื่อคลิกให้แปลง input เป็นจำนวนเต็มแล้วแสดงผลบวก

แนวคำตอบ

addButton.addActionListener(event -> {
    int first = Integer.parseInt(firstField.getText().trim());
    int second = Integer.parseInt(secondField.getText().trim());
    resultLabel.setText("Sum: " + (first + second));
});

การจัดการข้อความผิดรูปแบบและแจ้งเตือนอย่างเหมาะสมจะต่อในบทฟอร์ม

Exercise 16.6ปุ่มล้างฟอร์ม

สร้างปุ่ม Clear ที่ล้าง JTextField สองช่องและตั้ง JLabel กลับเป็น Ready

แนวคำตอบ

clearButton.addActionListener(event -> {
    firstField.setText("");
    secondField.setText("");
    resultLabel.setText("Ready");
});
