บทที่ 13 · เลือกโครงสร้างเก็บข้อมูล

ArrayList และชุดข้อมูล

ใช้รายการที่เพิ่มหรือลบสมาชิกได้ เรียก operation ผ่าน method และเลือกโครงสร้างให้เหมาะกับจำนวนข้อมูลที่เปลี่ยนระหว่างโปรแกรมทำงาน

เมื่อจบบทนี้ นิสิตจะทำได้
  • อธิบายความต่างระหว่าง array กับ ArrayList
  • ประกาศ generic type และเข้าใจ boxing เบื้องต้น
  • เพิ่ม อ่าน แก้ และลบสมาชิก
  • วนอ่าน List และเก็บ object ที่สร้างเอง

13. รายการข้อมูลที่โตและหดได้

array มีความยาวคงที่หลังสร้าง ส่วน ArrayList เพิ่มและลบสมาชิกได้ เหมาะเมื่อยังไม่รู้จำนวนข้อมูลแน่นอน เช่น รายชื่อที่ผู้ใช้เพิ่มทีละรายการ

13.1 Array กับ ArrayList เลือกใช้อย่างไร

ทั้งสองเก็บสมาชิกตามลำดับและเข้าถึงด้วย index แต่ใช้วิธีประกาศและจัดการขนาดต่างกัน Array มี length; ArrayList ใช้ size()

หัวข้อArrayArrayList
ขนาดกำหนดตอนสร้างเปลี่ยนตาม add/remove
จำนวนสมาชิกlengthsize()
เข้าถึงสมาชิกvalues[i]values.get(i)
เหมาะกับจำนวนคงที่และโครงสร้างพื้นฐานรายการที่เพิ่ม/ลบบ่อย
ArrayList ปรับจำนวนสมาชิก
import java.util.ArrayList;
ArrayList<String> names = new ArrayList<>();
names.add("Mali");
names.add("Nida");
System.out.println(names.size()); // 2

เริ่มจากรายการว่าง แล้ว size เปลี่ยนตามจำนวนครั้งที่ add/remove

13.2 Generic type และชนิดข้อมูลที่เก็บ

ArrayList<String> ระบุว่ารายการนี้เก็บ String เท่านั้น ช่วยให้ compiler ตรวจชนิดและไม่ต้อง cast ตอนอ่าน Generic type ใช้ reference type; สำหรับเลข primitive ใช้ wrapper class เช่น Integer แทน int

int ถูกแปลงเป็น Integer โดยอัตโนมัติ
ArrayList<Integer> scores = new ArrayList<>();
scores.add(90); // autoboxing: int → Integer
int firstScore = scores.get(0); // unboxing: Integer → int

เรียกสิ่งนี้ว่า autoboxing/unboxing; ถ้า List ว่างแล้วอ่าน get(0) จะเกิด IndexOutOfBoundsException

ระบุชนิดให้ตรงกับงาน

เลือก ArrayList<String> สำหรับข้อความ, ArrayList<Integer> สำหรับจำนวนเต็ม และ ArrayList<Student> สำหรับ object Student

Exercise 13.2ประกาศรายการอุณหภูมิ

ประกาศ ArrayList สำหรับเก็บ double แล้วเพิ่มอุณหภูมิ 29.5 และ 31.0 พร้อมพิมพ์จำนวนรายการ

ตัวอย่างคำตอบ

import java.util.ArrayList;
ArrayList<Double> temperatures = new ArrayList<>();
temperatures.add(29.5);
temperatures.add(31.0);
System.out.println(temperatures.size()); // 2

13.3 add, get, set และ size

เพิ่มสมาชิกด้วย add(value), อ่านด้วย get(index), แก้สมาชิกด้วย set(index, value) และดูจำนวนด้วย size() โดย index เริ่มจาก 0 เหมือน array

operation แต่ละตัวเปลี่ยนรายการอย่างไร
ArrayList<String> tasks = new ArrayList<>();
tasks.add("Read");       // [Read]
tasks.add("Practice");   // [Read, Practice]
tasks.set(0, "Review");  // [Review, Practice]
System.out.println(tasks.get(1)); // Practice
System.out.println(tasks.size()); // 2
get/set ที่ index ไม่มีจะเกิดอะไร?

ถ้า size เท่ากับ 2 จะเข้าถึง index 0 และ 1 ได้ การเรียก get(2) หรือ set(2, ...) เกิด IndexOutOfBoundsException; ถ้าต้องการเพิ่มท้าย List ให้ใช้ add

Exercise 13.3จัดรายการซื้อของ

เพิ่ม "Rice" และ "Eggs", เปลี่ยนสมาชิก index 0 เป็น "Brown rice" แล้วแสดงสมาชิกทั้งสอง

ตัวอย่างคำตอบ

ArrayList<String> items = new ArrayList<>();
items.add("Rice");
items.add("Eggs");
items.set(0, "Brown rice");
System.out.println(items.get(0)); // Brown rice
System.out.println(items.get(1)); // Eggs

13.4 remove และ index ที่เลื่อน

remove(index) ลบสมาชิกตำแหน่งนั้น แล้วสมาชิกด้านขวาจะเลื่อนมาทางซ้ายหนึ่งตำแหน่ง size จึงลดลง 1

ตำแหน่งหลังลบเปลี่ยน
ArrayList<String> names = new ArrayList<>();
names.add("A"); names.add("B"); names.add("C");
names.remove(0);
System.out.println(names); // [B, C]
System.out.println(names.get(0)); // B
remove กับ Integer มี overload

สำหรับ ArrayList<Integer>, remove(1) อาจหมายถึงลบที่ index 1; ถ้าต้องการลบค่า Integer 1 ให้ระบุ object ชัด ๆ ด้วย Integer.valueOf(1)

ArrayList<Integer> values = new ArrayList<>(List.of(1, 2, 1));
values.remove(1); // ลบสมาชิก index 1 (ค่า 2)
values.remove(Integer.valueOf(1)); // ลบ object ที่มีค่า 1 ตัวแรก

13.5 วนอ่านรายการและลบอย่างปลอดภัย

อ่านทุกสมาชิกได้ด้วย for-index หรือ enhanced for หากต้องลบระหว่างวนด้วย index ให้เริ่มจากท้ายมาหน้า เพื่อไม่ให้การเลื่อน index ทำให้ข้ามสมาชิกถัดไป

ลบคะแนนที่ต่ำกว่า 50 จากท้าย
for (int i = scores.size() - 1; i >= 0; i--) {
    if (scores.get(i) < 50) {
        scores.remove(i);
    }
}

เมื่อเอาสมาชิก index สูงออก ตำแหน่งด้านหน้าที่เรายังไม่ตรวจจะไม่เปลี่ยน

อย่าแก้ขนาดระหว่าง enhanced for

การ add/remove จาก List ระหว่าง enhanced for อาจทำให้เกิด ConcurrentModificationException; ใช้ index loop, สร้างรายการใหม่ หรือ Iterator เมื่อต้องลบระหว่างวน

Exercise 13.5ลบค่าซ้ำตามเงื่อนไข

มี ArrayList คะแนนหลายค่า ลบคะแนนที่ต่ำกว่า 50 โดยห้ามข้ามสมาชิกที่เลื่อนตำแหน่ง

ตัวอย่างคำตอบ

ArrayList<Integer> scores = new ArrayList<>(List.of(40, 45, 70, 30, 90));
for (int i = scores.size() - 1; i >= 0; i--) {
    if (scores.get(i) < 50) scores.remove(i);
}
System.out.println(scores); // [70, 90]

13.6 เก็บ object ใน ArrayList

ArrayList ใช้เก็บ object ที่สร้างเองได้ ทำให้รายการเป็นชุดข้อมูลของชนิดเดียวกัน เช่น Student หลายคน แล้วใช้ method ของแต่ละ object ทำงานต่อ

วนแสดง Student ทุกคน
ArrayList<Student> students = new ArrayList<>();
students.add(new Student("Mali", 82));
students.add(new Student("Nida", 95));
for (Student student : students) {
    student.printSummary();
}
