บทที่ 11 · เริ่มต้นการเขียนโปรแกรมเชิงวัตถุ

คลาสและออบเจ็กต์

รวมข้อมูลและพฤติกรรมที่เกี่ยวข้องไว้ด้วยกันเป็นคลาส แล้วสร้างออบเจ็กต์หลายตัวที่มีสถานะของตัวเอง

เมื่อจบบทนี้ นิสิตจะทำได้
  • อธิบายความต่างของ class กับ object
  • สร้าง object ด้วย new และเรียก method
  • เขียน constructor และใช้ this
  • จัดการหลาย object ที่มี state แยกกัน

11. จากตัวแปรหลายตัว สู่ออบเจ็กต์เดียว

ถ้าต้องเก็บข้อมูลนักศึกษา 3 คน คนละ ชื่อ รหัส คะแนน เราอาจใช้อาเรย์คู่ขนาน 3 ชุด (บทที่ 8) ซึ่งต้องระวังให้ index ตรงกันเสมอ การเขียนโปรแกรมเชิงวัตถุ (OOP) ให้เรารวมข้อมูลที่เกี่ยวข้องเป็นก้อนเดียว พร้อมเมธอดที่ทำงานกับข้อมูลนั้น

คำศัพท์หลัก
  • class — พิมพ์เขียว บอกว่าวัตถุชนิดนี้มีข้อมูล (field) และพฤติกรรม (method) อะไร
  • object / instance — ของจริงที่สร้างจากพิมพ์เขียว แต่ละตัวมีค่า field ของตัวเอง
  • field (attribute) — ตัวแปรที่อยู่ในออบเจ็กต์ เช่น name, balance
  • method — สิ่งที่ออบเจ็กต์ทำได้ เช่น deposit(), describe()
  • state — ค่าของ field ทั้งหมด ณ ขณะหนึ่ง

11.1 class เป็นพิมพ์เขียว

โครงสร้างของคลาส
class Student {               // ชื่อคลาส: PascalCase
    String name;              // field (ข้อมูล)
    int score;

    void describe() {         // method (พฤติกรรม) — ไม่มี static
        System.out.println(name + ": " + score);
    }
}

เมธอดในคลาสไม่ใส่ static เพราะเป็นของแต่ละออบเจ็กต์ และใช้ field ของออบเจ็กต์ที่ถูกเรียกได้โดยตรง ในตัวอย่างบทนี้วางคลาสหลายคลาสไว้ในไฟล์เดียว (มีเพียงคลาสที่มี main เป็น public) — ในโปรเจกต์จริงนิยมแยกคลาสละไฟล์

ตัวอย่าง 11.1.1 · คลาสแรก: Book พื้นฐาน

แนวคิด: ประกาศคลาส Book มี field 3 ตัว แล้วสร้างออบเจ็กต์ใน main กำหนดค่า field และพิมพ์ออกมา

Java source · BookDemo.java
public class BookDemo {
    public static void main(String[] args) {
        Book b = new Book();
        b.title = "Java Basics";
        b.author = "Mali";
        b.pages = 320;
        System.out.println(b.title + " by " + b.author + ", " + b.pages + " pages");
    }
}

class Book {
    String title;
    String author;
    int pages;
}
Output
Java Basics by Mali, 320 pages
อธิบายทีละขั้น
  1. class Book บอกว่าหนังสือมี title, author, pages
  2. new Book() สร้างออบเจ็กต์ใหม่ในหน่วยความจำ
  3. b.title = ... ใช้จุด (.) เข้าถึง field ของออบเจ็กต์ b

ตัวอย่าง 11.1.2 · เพิ่มพฤติกรรมด้วย method ต่อยอด

แนวคิด: เมธอดในคลาสใช้ field ได้ทันทีโดยไม่ต้องส่งเป็น parameter เพราะรู้อยู่แล้วว่าเป็นของออบเจ็กต์ไหน

Java source · BookMethods.java
public class BookMethods {
    public static void main(String[] args) {
        Book b = new Book();
        b.title = "Java Basics";
        b.pages = 320;
        b.describe();
        System.out.println("Reading time: " + b.readingHours(40) + " hours");
        System.out.println("Thick book? " + b.isThick());
    }
}

class Book {
    String title;
    int pages;

    void describe() {
        System.out.println("Book: " + title + " (" + pages + " pages)");
    }

    double readingHours(int pagesPerHour) {
        return (double) pages / pagesPerHour;
    }

    boolean isThick() {
        return pages > 300;
    }
}
Output
Book: Java Basics (320 pages)
Reading time: 8.0 hours
Thick book? true
อธิบายทีละขั้น
  1. b.describe() — เรียกเมธอดของออบเจ็กต์ b ข้างในใช้ title และ pages ของ b
  2. readingHours รับ parameter เพิ่มได้ตามปกติ และคืนค่า
  3. isThick คืน boolean จากข้อมูลของตัวเอง

ทดลอง error 11.1.3 · เรียก instance method จาก static context ประยุกต์

แนวคิด: เมธอดที่ไม่มี static ต้องเรียกผ่านออบเจ็กต์ เรียกจากชื่อคลาสตรง ๆ ไม่ได้ เพราะไม่รู้ว่าจะใช้ field ของออบเจ็กต์ไหน

Java source · StaticContext.java
public class StaticContext {
    public static void main(String[] args) {
        Counter.increase();
    }
}

class Counter {
    int value;

    void increase() {
        value++;
    }
}
Compile error (จาก javac จริง)
StaticContext.java:3: error: non-static method increase() cannot be referenced from a static context
        Counter.increase();
               ^
อธิบายทีละขั้น
  1. non-static method increase() cannot be referenced from a static context
  2. แก้: สร้างออบเจ็กต์ก่อน Counter c = new Counter(); c.increase();
ลองคิดก่อน · class vs object

ในประโยค “แมวชื่อส้มของฉัน อายุ 3 ปี” อะไรคือ class อะไรคือ object และอะไรคือ field

ดูคำตอบ

class = Cat (แมวทั่วไป), object = แมวตัวที่ชื่อส้ม, field = name ("ส้ม") และ age (3)

11.2 สร้าง object ด้วย new และตัวแปรอ้างอิง

ตัวแปรชนิดคลาส (เช่น Book b) ไม่ได้เก็บออบเจ็กต์ไว้ข้างใน แต่เก็บการอ้างอิง (reference) ที่ชี้ไปยังออบเจ็กต์ในหน่วยความจำ — เหมือนอาเรย์ในบทที่ 8 field ที่ยังไม่กำหนดค่าจะได้ค่าเริ่มต้น (0, 0.0, false, null)

ตัวอย่าง 11.2.1 · ค่าเริ่มต้นของ field พื้นฐาน

แนวคิด: ต่างจากตัวแปร local ใน main ซึ่งต้องกำหนดค่าก่อนใช้ field ได้ค่าเริ่มต้นอัตโนมัติ

Java source · DefaultFields.java
public class DefaultFields {
    public static void main(String[] args) {
        Product p = new Product();
        System.out.println("name = " + p.name);
        System.out.println("price = " + p.price);
        System.out.println("stock = " + p.stock);
        System.out.println("onSale = " + p.onSale);
    }
}

class Product {
    String name;
    double price;
    int stock;
    boolean onSale;
}
Output
name = null
price = 0.0
stock = 0
onSale = false
อธิบายทีละขั้น
  1. String → null
  2. double → 0.0, int → 0
  3. boolean → false
  4. constructor ในหัวข้อถัดไปช่วยกำหนดค่าเริ่มต้นที่มีความหมาย

ตัวอย่าง 11.2.2 · สองตัวแปรชี้ออบเจ็กต์เดียวกัน ต่อยอด

แนวคิด: b = a คัดลอกการอ้างอิง ไม่ได้สร้างออบเจ็กต์ใหม่ แก้ผ่าน b ก็เห็นผ่าน a

Java source · SharedReference.java
public class SharedReference {
    public static void main(String[] args) {
        Product a = new Product();
        a.name = "Pen";
        a.stock = 10;

        Product b = a;
        b.stock = 3;

        Product c = new Product();
        c.name = "Pen";
        c.stock = 3;

        System.out.println("a.stock = " + a.stock);
        System.out.println("a == b ? " + (a == b));
        System.out.println("a == c ? " + (a == c));
    }
}

class Product {
    String name;
    int stock;
}
Output
a.stock = 3
a == b ? true
a == c ? false
อธิบายทีละขั้น
  1. a และ b ชี้ออบเจ็กต์เดียว แก้ b.stock → a.stock เป็น 3 ด้วย
  2. c เป็นออบเจ็กต์ใหม่แม้ค่าเหมือนกัน
  3. == เทียบว่าชี้ตัวเดียวกันหรือไม่ (เหมือน String ในบทที่ 9)

ตัวอย่าง 11.2.3 · ส่งออบเจ็กต์ให้เมธอด ประยุกต์

แนวคิด: เมธอดที่รับออบเจ็กต์ได้รับสำเนาของการอ้างอิง จึงแก้ field ของออบเจ็กต์ตัวจริงได้

Java source · PassObject.java
public class PassObject {
    public static void main(String[] args) {
        Product p = new Product();
        p.name = "Notebook";
        p.price = 40;
        applyDiscount(p, 25);
        System.out.println(p.name + " now costs " + p.price);
    }

    static void applyDiscount(Product item, double percent) {
        item.price = item.price * (100 - percent) / 100;
    }
}

class Product {
    String name;
    double price;
}
Output
Notebook now costs 30.0
อธิบายทีละขั้น
  1. main ส่ง p ไปยัง applyDiscount
  2. item ชี้ออบเจ็กต์เดียวกับ p
  3. แก้ item.price → p.price เปลี่ยนจริงเป็น 30.0
  4. ต่างจากการส่ง int ในบทที่ 7 ซึ่งแก้ค่าเดิมไม่ได้

ทดลอง error 11.2.4 · NullPointerException: ลืม new ประยุกต์

แนวคิด: ประกาศตัวแปรคลาสแล้วยังไม่สร้างออบเจ็กต์ ค่าเป็น null — เข้าถึง field หรือเมธอดไม่ได้

Java source · ForgotNew.java
public class ForgotNew {
    public static void main(String[] args) {
        Product[] shelf = new Product[2];
        shelf[0] = new Product();
        shelf[0].name = "Pen";
        System.out.println(shelf[0].name);
        shelf[1].name = "Ruler";
    }
}

class Product {
    String name;
}
Output + Runtime error
Pen
Exception in thread "main" java.lang.NullPointerException: Cannot assign field "name" because "shelf[1]" is null
	at ForgotNew.main(ForgotNew.java:7)
อธิบายทีละขั้น
  1. new Product[2] สร้างอาเรย์ 2 ช่องที่เป็น null — ยังไม่มี Product สักตัว
  2. shelf[0] ถูก new แล้ว ใช้ได้
  3. shelf[1] ยังเป็น null → NullPointerException
ลองคิดก่อน · reference
Product x = new Product(); x.stock = 5;
Product y = x;
y.stock += 2;
x = new Product(); x.stock = 1;
// y.stock = ?
ดูคำตอบ

7 — y ยังชี้ออบเจ็กต์ตัวแรก (5 + 2) ส่วน x ถูกเปลี่ยนให้ชี้ออบเจ็กต์ใหม่

11.3 constructor และ this

constructor คือเมธอดพิเศษที่ทำงานอัตโนมัติตอน new ใช้กำหนดค่าเริ่มต้นให้ field มีชื่อเดียวกับคลาส และไม่มีชนิดผลลัพธ์ (ไม่มี void) คำว่า this หมายถึง “ออบเจ็กต์ตัวนี้” ใช้แยก field ออกจาก parameter ที่ชื่อเหมือนกัน

รูปแบบ constructor
class Student {
    String name;
    int score;

    Student(String name, int score) {   // ชื่อเดียวกับคลาส ไม่มี return type
        this.name = name;               // this.name = field, name = parameter
        this.score = score;
    }
}

Student s = new Student("Mali", 85);    // argument ส่งไปยัง constructor

ตัวอย่าง 11.3.1 · constructor กำหนดค่าตั้งแต่สร้าง พื้นฐาน

แนวคิด: สร้างและกำหนดค่าในบรรทัดเดียว ออบเจ็กต์ไม่มีช่วงที่ field เป็นค่าว่าง

Java source · ConstructorDemo.java
public class ConstructorDemo {
    public static void main(String[] args) {
        Student a = new Student("Mali", 85);
        Student b = new Student("Beam", 72);
        a.describe();
        b.describe();
    }
}

class Student {
    String name;
    int score;

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    void describe() {
        System.out.println(name + " scored " + score);
    }
}
Output
Mali scored 85
Beam scored 72
อธิบายทีละขั้น
  1. new Student("Mali", 85) เรียก constructor
  2. this.name = name เก็บ parameter ลง field
  3. describe ใช้ field ได้ทันที

ทดลองบั๊ก 11.3.2 · ลืม this: field ไม่ถูกกำหนดค่า ต่อยอด

แนวคิด: ถ้าเขียน name = name; ทั้งสองฝั่งคือ parameter (ตัวที่ใกล้ที่สุด) field จึงยังเป็นค่าเริ่มต้น

Java source · ForgotThis.java
public class ForgotThis {
    public static void main(String[] args) {
        Student s = new Student("Mali", 85);
        System.out.println(s.name + " " + s.score);
    }
}

class Student {
    String name;
    int score;

    Student(String name, int score) {
        name = name;
        score = score;
    }
}
Output
null 0
อธิบายทีละขั้น
  1. คอมไพล์ผ่าน แต่ได้ null 0
  2. parameter บัง (shadow) field ที่ชื่อเดียวกัน
  3. แก้: ใช้ this.name = name

ตัวอย่าง 11.3.3 · หลาย constructor (overloading) และ this(...) ประยุกต์

แนวคิด: มีหลาย constructor ได้ตามจำนวน/ชนิด parameter ใช้ this(...) เรียก constructor อีกตัวเพื่อไม่เขียนโค้ดซ้ำ

Java source · OverloadedConstructors.java
public class OverloadedConstructors {
    public static void main(String[] args) {
        Rectangle a = new Rectangle(4, 3);
        Rectangle b = new Rectangle(5);
        Rectangle c = new Rectangle();
        System.out.println(a.info());
        System.out.println(b.info());
        System.out.println(c.info());
    }
}

class Rectangle {
    double width;
    double height;

    Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    Rectangle(double side) {
        this(side, side);
    }

    Rectangle() {
        this(1);
    }

    double area() {
        return width * height;
    }

    String info() {
        return width + " x " + height + " = " + area();
    }
}
Output
4.0 x 3.0 = 12.0
5.0 x 5.0 = 25.0
1.0 x 1.0 = 1.0
อธิบายทีละขั้น
  1. Rectangle(4, 3) ใช้ constructor หลัก
  2. Rectangle(5) เรียก this(5, 5) → จัตุรัส
  3. Rectangle() เรียก this(1) → this(1, 1)
  4. info() เรียก area() ของออบเจ็กต์เดียวกันได้ตรง ๆ

ตัวอย่าง 11.3.4 · toString: ให้ออบเจ็กต์อธิบายตัวเอง ท้าทาย

แนวคิด: ถ้าคลาสมีเมธอด public String toString() การพิมพ์ออบเจ็กต์ด้วย println หรือต่อกับ String จะเรียกเมธอดนี้อัตโนมัติ

Java source · ToStringDemo.java
public class ToStringDemo {
    public static void main(String[] args) {
        Point p = new Point(3, 4);
        Point q = new Point(-1, 2);
        System.out.println(p);
        System.out.println("q is " + q);
        System.out.printf("distance = %.2f%n", p.distanceTo(q));
    }
}

class Point {
    int x;
    int y;

    Point(int x, int y) {
        this.x = x;
        this.y = y;
    }

    double distanceTo(Point other) {
        int dx = x - other.x;
        int dy = y - other.y;
        return Math.sqrt(dx * dx + dy * dy);
    }

    @Override
    public String toString() {
        return "(" + x + ", " + y + ")";
    }
}
Output
(3, 4)
q is (-1, 2)
distance = 4.47
อธิบายทีละขั้น
  1. println(p) เรียก p.toString() → (3, 4)
  2. ต่อ String ก็เรียก toString อัตโนมัติ
  3. distanceTo รับออบเจ็กต์ชนิดเดียวกัน เข้าถึง other.x ได้
  4. @Override บอก compiler ว่าตั้งใจเขียนทับเมธอด toString ที่มีอยู่แล้ว (บทที่ 12)

ลบเมธอด toString ออก แล้วดูว่า println(p) พิมพ์อะไร (เช่น Point@1b6d3586)

ลองคิดก่อน · constructor

ถ้าคลาสมีเฉพาะ constructor Car(String model) คำสั่ง new Car() จะคอมไพล์ผ่านหรือไม่

ดูคำตอบ

ไม่ผ่าน — Java สร้าง constructor ไม่มี parameter ให้อัตโนมัติก็ต่อเมื่อคลาสไม่มี constructor เลย เมื่อเราเขียนเองแล้ว ต้องเขียน Car() เพิ่มเองถ้าต้องการ

11.4 หลาย object หลาย state

ออบเจ็กต์แต่ละตัวมี field ของตัวเอง การเรียกเมธอดบนออบเจ็กต์หนึ่งเปลี่ยนเฉพาะ state ของตัวนั้น ส่วน field ที่ประกาศเป็น static เป็นของคลาส ใช้ร่วมกันทุกออบเจ็กต์ (เช่น ตัวนับจำนวนออบเจ็กต์ที่ถูกสร้าง)

ตัวอย่าง 11.4.1 · บัญชีธนาคารสองบัญชี ต่อยอด

แนวคิด: deposit/withdraw บนบัญชีหนึ่งไม่กระทบอีกบัญชี เพราะ balance เป็นของแต่ละออบเจ็กต์

Java source · TwoAccounts.java
public class TwoAccounts {
    public static void main(String[] args) {
        BankAccount mali = new BankAccount("Mali", 1000);
        BankAccount beam = new BankAccount("Beam", 500);
        mali.deposit(250);
        beam.withdraw(200);

class Temperature {
    double celsius;

    Temperature(double celsius) {
        this.celsius = celsius;

        return celsius * 9 / 5 + 32;

    double toKelvin() {
        return celsius + 273.15;

}

public class ClockApp {
    public static void main(String[] args) {
        Clock a = new Clock(23, 58);
        for (int i = 0; i < 3; i++) {
            a.tick();
            System.out.println("tick -> " + a);
        }
        Clock b = new Clock(9, 45);
        b.addMinutes(135);
        System.out.println("09:45 + 135 min = " + b);
    }
}

class Clock {
    int hour;
    int minute;

    Clock(int hour, int minute) {
        this.hour = hour;
        this.minute = minute;
    }

    void tick() {
        minute++;
        if (minute == 60) {
            minute = 0;
            hour = (hour + 1) % 24;
        }
    }

    void addMinutes(int m) {
        int total = hour * 60 + minute + m;
        hour = (total / 60) % 24;
        minute = total % 60;
    }

    public String toString() {
        return String.format("%02d:%02d", hour, minute);
    }
}

public class FractionApp {
    public static void main(String[] args) {
        Fraction a = new Fraction(1, 2);
        Fraction b = new Fraction(1, 3);
        System.out.println(a + " + " + b + " = " + a.add(b));
        Fraction c = new Fraction(3, 4), d = new Fraction(5, 6);
        System.out.println(c + " - " + d + " = " + c.subtract(d));
        Fraction e = new Fraction(2, 3), f = new Fraction(9, 4);
        System.out.println(e + " * " + f + " = " + e.multiply(f));
        Fraction g = new Fraction(-3, 4);
        System.out.println(a + " / " + g + " = " + a.divide(g));
        System.out.println("6/-8 = " + new Fraction(6, -8));
    }

class Fraction {
    int num;
    int den;

    Fraction(int num, int den) {
        if (den < 0) {
            num = -num;
            den = -den;
        }
        int g = gcd(Math.abs(num), den);
        this.num = num / g;
        this.den = den / g;
    }

    static int gcd(int a, int b) {
        while (b != 0) {
            int t = a % b;
            a = b;
            b = t;
        }
        return a == 0 ? 1 : a;
    }

    Fraction add(Fraction o) {
        return new Fraction(num * o.den + o.num * den, den * o.den);
    }

    Fraction subtract(Fraction o) {
        return new Fraction(num * o.den - o.num * den, den * o.den);
    }

    Fraction multiply(Fraction o) {
        return new Fraction(num * o.num, den * o.den);
    }

    Fraction divide(Fraction o) {
        return new Fraction(num * o.den, den * o.num);
    }

    public String toString() {
        return den == 1 ? String.valueOf(num) : num + "/" + den;
    }
}

การคืนออบเจ็กต์ใหม่แทนการแก้ตัวเดิมทำให้ a, b ยังมีค่าเดิมหลังคำนวณ (immutable style แบบเดียวกับ String)

Exercise 11.9ระบบจองห้องประชุม★★★ ท้าทาย

สร้างคลาส Room (ชื่อห้อง, ความจุ, อาเรย์ boolean[] booked ขนาด 9 สำหรับช่วงเวลา 9:00–17:00 ชั่วโมงละช่อง) มีเมธอด book(int hour, int people) คืนข้อความผลการจอง (สำเร็จ / เวลานอกช่วง / คนเกินความจุ / ช่วงนี้ถูกจองแล้ว) และ freeHours() คืน String รายชั่วโมงที่ว่าง จากนั้นสร้าง 2 ห้องและทดลองจองตามตัวอย่าง

สิ่งที่ต้องทำ
  1. index ของ booked = hour − 9
  2. ตรวจเงื่อนไขตามลำดับ: เวลา → ความจุ → ว่างหรือไม่
  3. freeHours ใช้ StringBuilder ต่อเลขชั่วโมงที่ว่าง
ตัวอย่างผลลัพธ์
Small 10:00 -> booked for 4
Small 10:00 -> already booked
Small 13:00 -> too many people (max 6)
Hall 13:00 -> booked for 25
Hall 18:00 -> outside opening hours
Small free: 9 11 12 13 14 15 16 17
Hall free: 9 10 11 12 14 15 16 17

ตัวอย่างคำตอบ

public class RoomBooking {
    public static void main(String[] args) {
        Room small = new Room("Small", 6);
        Room hall = new Room("Hall", 40);
        System.out.println(small.book(10, 4));
        System.out.println(small.book(10, 3));
        System.out.println(small.book(13, 8));
        System.out.println(hall.book(13, 25));
        System.out.println(hall.book(18, 10));
        System.out.println(small.name + " free: " + small.freeHours());
        System.out.println(hall.name + " free: " + hall.freeHours());
    }
}

class Room {
    String name;
    int capacity;
    boolean[] booked = new boolean[9];

    Room(String name, int capacity) {
        this.name = name;
        this.capacity = capacity;
    }

    String book(int hour, int people) {
        if (hour < 9 || hour > 17) return name + " " + hour + ":00 -> outside opening hours";
        if (people > capacity) return name + " " + hour + ":00 -> too many people (max " + capacity + ")";
        if (booked[hour - 9]) return name + " " + hour + ":00 -> already booked";
        booked[hour - 9] = true;
        return name + " " + hour + ":00 -> booked for " + people;
    }

    String freeHours() {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < booked.length; i++) {
            if (!booked[i]) sb.append(i + 9).append(" ");
        }
        return sb.toString().trim();
    }
}

Exercise 11.10เกมต่อสู้แบบผลัดตา★★★ ท้าทาย

สร้างคลาส Fighter (ชื่อ, hp, attack, defense) มีเมธอด isAlive(), takeDamage(int raw) (ความเสียหายจริง = raw − defense แต่ไม่น้อยกว่า 1; hp ไม่ต่ำกว่า 0) และ attack(Fighter target) ที่ทำความเสียหายเท่ากับ attack ของตัวเองให้เป้าหมายและพิมพ์ผล จากนั้นจำลองการต่อสู้ระหว่างนักสู้ 2 คนผลัดกันโจมตีจนมีคนแพ้ แสดงทุกเทิร์นและผู้ชนะ

สิ่งที่ต้องทำ
  1. attack ต้องเรียก target.takeDamage — ไม่แก้ hp ของ target ตรง ๆ
  2. ใช้ while วนจนมีคนไม่ alive
  3. สลับผู้โจมตีด้วยตัวแปรอ้างอิง (attacker/defender) แล้วสลับกันทุกเทิร์น
  4. แสดง hp หลังทุกการโจมตี
ตัวอย่างผลลัพธ์
Turn 1: Knight hits Orc for 10 (Orc HP 40)
Turn 2: Orc hits Knight for 6 (Knight HP 34)
Turn 3: Knight hits Orc for 10 (Orc HP 30)
Turn 4: Orc hits Knight for 6 (Knight HP 28)
Turn 5: Knight hits Orc for 10 (Orc HP 20)
Turn 6: Orc hits Knight for 6 (Knight HP 22)
Turn 7: Knight hits Orc for 10 (Orc HP 10)
Turn 8: Orc hits Knight for 6 (Knight HP 16)
Turn 9: Knight hits Orc for 10 (Orc HP 0)
Winner: Knight with 16 HP

ตัวอย่างคำตอบ

public class Battle {
    public static void main(String[] args) {
        Fighter a = new Fighter("Knight", 40, 12, 4);
        Fighter b = new Fighter("Orc", 50, 10, 2);
        Fighter attacker = a, defender = b;
        int turn = 1;
        while (a.isAlive() && b.isAlive()) {
            System.out.print("Turn " + turn + ": ");
            attacker.attack(defender);
            Fighter temp = attacker;
            attacker = defender;
            defender = temp;
            turn++;
        }
        Fighter winner = a.isAlive() ? a : b;
        System.out.println("Winner: " + winner.name + " with " + winner.hp + " HP");
    }
}

class Fighter {
    String name;
    int hp, attack, defense;

    Fighter(String name, int hp, int attack, int defense) {
        this.name = name;
        this.hp = hp;
        this.attack = attack;
        this.defense = defense;
    }

    boolean isAlive() {
        return hp > 0;
    }

    int takeDamage(int raw) {
        int damage = Math.max(1, raw - defense);
        hp = Math.max(0, hp - damage);
        return damage;
    }

    void attack(Fighter target) {
        int dmg = target.takeDamage(attack);
        System.out.println(name + " hits " + target.name + " for " + dmg + " (" + target.name + " HP " + target.hp + ")");
    }
}

การสลับ attacker/defender ใช้เทคนิค temp เหมือนสลับค่า int แต่ที่สลับคือการอ้างอิงไปยังออบเจ็กต์
