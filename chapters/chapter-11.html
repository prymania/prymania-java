บทที่ 11 · รวมข้อมูลกับพฤติกรรม

คลาสและออบเจ็กต์

เปลี่ยนจากตัวแปรที่กระจายอยู่หลายจุด มาเป็น object ที่รวมข้อมูลของสิ่งหนึ่งและงานที่สิ่งนั้นทำได้ไว้ด้วยกัน

เมื่อจบบทนี้ นิสิตจะทำได้
  • อธิบายความต่างระหว่าง class กับ object
  • ประกาศ field และ method พื้นฐาน
  • สร้าง object ด้วย new และเข้าถึงสมาชิก
  • ใช้ constructor กำหนดค่าเริ่มต้น

11. เก็บข้อมูลและพฤติกรรมไว้ในหน่วยเดียว

ถ้าโปรแกรมจัดการนักศึกษาหลายคน การมีตัวแปรแยก name, id และ score อาจทำให้จับคู่ผิด class ช่วยกำหนดรูปแบบข้อมูลหนึ่งชนิด ส่วน object แต่ละตัวเก็บค่าจริงของคนละคน

11.1 Class เป็นพิมพ์เขียวของ object

class อธิบายว่าสิ่งชนิดนี้มีข้อมูลอะไรและทำงานอะไรได้; object คือ instance ที่สร้างจาก class แล้วและมีค่าของตัวเอง

ส่วนประกอบเบื้องต้น
  • field เก็บสถานะของ object เช่น ชื่อ คะแนน
  • method กำหนดพฤติกรรมหรือสิ่งที่ object ทำได้
  • ชื่อ class ใช้ UpperCamelCase; ชื่อ field/method ใช้ lowerCamelCase
แบบของนักศึกษา
class Student {
    String name;
    int score;

    void printSummary() {
        System.out.println(name + ": " + score);
    }
}

class ยังไม่ได้ระบุนักศึกษาคนใดโดยเฉพาะ แต่บอกว่า Student ทุก object มี name, score และ printSummary

เทียบกับพิมพ์เขียว

class เหมือนแบบพิมพ์เขียวบ้าน; object แต่ละหลังสร้างจากแบบเดียวกันได้ แต่มีสีและเจ้าของต่างกัน

Exercise 11.1ออกแบบ Book

ระบุ field อย่างน้อย 3 ค่าและ method หนึ่งอย่างที่เหมาะกับ class หนังสือ โดยยังไม่ต้องสร้าง object

ตัวอย่างแบบ

class Book {
    String title;
    String author;
    int pageCount;

    void printDetails() {
        System.out.println(title + " by " + author);
    }
}

field/method อาจต่างกันได้ตามหน้าที่ของโปรแกรม

11.2 สร้าง object ด้วย new

ประกาศชนิดตัวแปรเป็นชื่อ class แล้วใช้ new เพื่อสร้าง object ตัวแปรจะเก็บ reference สำหรับเข้าถึง field และ method ผ่าน dot operator

Syntax และลำดับการทำงาน
Student student = new Student();
student.name = "Mali";
student.printSummary();
  1. ประกาศตัวแปร student ที่เก็บ reference ชนิด Student
  2. new Student() สร้าง object และกำหนดค่าเริ่มต้น
  3. ใช้ . เข้าถึงสมาชิกของ object
สอง object จาก class เดียว
Student first = new Student();
first.name = "Mali";
first.score = 82;

Student second = new Student();
second.name = "Nida";
second.score = 95;

first.printSummary();  // Mali: 82
second.printSummary(); // Nida: 95

first กับ second อ้างถึง object คนละตัว การเปลี่ยน field ของตัวหนึ่งไม่เปลี่ยนอีกตัว

null กับ object ที่สร้างแล้ว

ตัวแปร local ที่ประกาศแต่ยังไม่กำหนด object ใช้งานไม่ได้จนกว่าจะได้ reference ถ้าเรียก method ผ่าน null จะเกิด NullPointerException

Exercise 11.2สร้างหนังสือสองเล่ม

จาก class Book ในข้อก่อน สร้าง object สองเล่มที่มีชื่อและผู้เขียนต่างกัน แล้วเรียก printDetails() ทั้งคู่

ตัวอย่างคำตอบ

Book first = new Book();
first.title = "Java Basics";
first.author = "A. Writer";
first.printDetails();

Book second = new Book();
second.title = "Data Structures";
second.author = "B. Writer";
second.printDetails();

11.3 Constructor และ this

constructor เป็นชุดคำสั่งพิเศษที่ทำงานตอนสร้าง object ชื่อเหมือน class ไม่มี return type ใช้กำหนดสถานะเริ่มต้นให้ object อยู่ในสภาพพร้อมใช้

constructor ที่รับค่าเริ่มต้น
class Student {
    String name;
    int score;

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }
}

this.name หมายถึง field ของ object ปัจจุบัน; name ที่ไม่มี this คือ parameter ที่รับเข้ามา

ถ้าสร้าง constructor เอง

Java จะไม่สร้าง default no-argument constructor ให้อีก ถ้าต้องการให้เรียก new Student() ได้ ต้องประกาศ constructor ไม่มี parameter เพิ่มเอง

Exercise 11.3เพิ่ม constructor ให้ Book

กำหนด title, author และ pageCount ผ่าน constructor แล้วสร้าง object หนึ่งเล่ม

ตัวอย่างคำตอบ

class Book {
    String title;
    String author;
    int pageCount;

    Book(String title, String author, int pageCount) {
        this.title = title;
        this.author = author;
        this.pageCount = pageCount;
    }
}

Book javaBook = new Book("Java Basics", "A. Writer", 240);

11.4 State ของแต่ละ object แยกจากกัน

instance field เป็นสถานะของ object แต่ละตัว ส่วน local variable มีอายุเฉพาะตอน method ทำงาน การมี class เดียวกันไม่ได้แปลว่า object ใช้ข้อมูลชุดเดียวกัน

method เปลี่ยน state ของ object ปัจจุบัน
class Counter {
    int value;

    Counter(int start) {
        value = start;
    }

    void increment() {
        value++;
    }
}

การเรียก first.increment() เปลี่ยน first.value เท่านั้น; counter อีกตัวมี state ของตัวเอง

Exercise 11.4ทำนาย state ของ counter

สร้าง Counter สองตัว เริ่มที่ 0 และ 10 เรียก increment กับตัวแรกสองครั้งและตัวที่สองหนึ่งครั้ง ค่าใดควรแสดง

คำตอบ

Counter first = new Counter(0);
Counter second = new Counter(10);
first.increment();
first.increment();
second.increment();
System.out.println(first.value);  // 2
System.out.println(second.value); // 11

แต่ละ object มี instance field value แยกกัน

แบบฝึกหัดท้ายบท

รวมข้อมูลและพฤติกรรมให้เป็น object ที่สร้างหลาย instance ได้

Exercise 11.5บัตรบัญชีธนาคาร

สร้าง class BankAccount มี owner, balance, constructor, deposit และ printBalance แล้วสร้างสองบัญชีที่มียอดแยกกัน

แนวคำตอบ

มี instance fields owner และ balance; constructor กำหนดทั้งสองค่า; deposit เพิ่มยอดเฉพาะบัญชีที่เรียก method

class BankAccount {
    String owner;
    double balance;
    BankAccount(String owner, double balance) {
        this.owner = owner;
        this.balance = balance;
    }
    void deposit(double amount) { balance += amount; }
    void printBalance() {
        System.out.println(owner + ": " + balance);
    }
}

Exercise 11.6รายการสินค้าแบบ object

สร้าง class Product มี name, price และ method คำนวณราคารวมตามจำนวน จากนั้นคำนวณสินค้าสองชนิด

แนวคำตอบ

class Product {
    String name;
    double price;
    Product(String name, double price) {
        this.name = name;
        this.price = price;
    }
    double totalFor(int quantity) {
        return price * quantity;
    }
}
