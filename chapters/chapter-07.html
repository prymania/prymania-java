บทที่ 7 · จัดกลุ่มคำสั่งให้เรียกใช้ซ้ำ

เมธอด: แบ่งโปรแกรมเป็นส่วน

เมธอดช่วยตั้งชื่อให้การทำงานหนึ่งอย่าง เรียกใช้ซ้ำได้ และทำให้ main ไม่ต้องรับผิดชอบทุกขั้นตอนเอง

เมื่อจบบทนี้ นิสิตจะทำได้
  • ประกาศและเรียกใช้ static method
  • ส่งข้อมูลผ่าน parameter
  • คืนผลลัพธ์ด้วย return
  • อธิบายขอบเขตของตัวแปรและการ overload

7. ย้ายงานย่อยไปไว้ในเมธอด

เมธอด (method) คือชุดคำสั่งที่ตั้งชื่อไว้เพื่อทำงานหนึ่งอย่าง เช่น คำนวณราคา หรือพิมพ์ใบเสร็จ เมื่อโปรแกรมยาวขึ้น เราแยกงานเป็นเมธอดเล็ก ๆ เพื่อให้อ่านง่าย เรียกซ้ำได้ และตรวจข้อผิดพลาดทีละส่วนได้

7.1 ประกาศและเรียกใช้เมธอด

เมธอดที่ประกาศเป็น static สามารถเรียกจาก main ได้โดยตรง รูปแบบพื้นฐานคือ static void ชื่อเมธอด() { ... } โดย void หมายถึงเมธอดนี้ไม่ส่งค่ากลับ

แยกส่วนของ method declaration
static void printWelcome() {
        System.out.println("Welcome");
      }
  • static บอกว่าเรียกผ่านคลาสได้โดยยังไม่ต้องสร้าง object (ใช้ในบทพื้นฐานนี้)
  • void คือชนิดผลลัพธ์: ไม่มีค่าคืนกลับ
  • printWelcome เป็นชื่อ method ใช้ lower camelCase และตั้งชื่อตามการกระทำ
  • () เป็นตำแหน่ง parameter; ตอนนี้ยังไม่มี parameter
  • วงเล็บปีกกาครอบ body ซึ่งเป็นคำสั่งที่ทำเมื่อถูกเรียก
แยกการแสดงข้อความออกจาก main
public class Welcome {
    public static void main(String[] args) {
        printWelcome();
        printWelcome();
    }

    static void printWelcome() {
        System.out.println("Welcome to Java");
    }
}

เมธอดถูกประกาศอยู่ภายในคลาส แต่อยู่นอกเมธอด main ส่วนการเรียกใช้เขียนชื่อเมธอดตามด้วย ()

ลำดับตำแหน่งที่ทำงานสิ่งที่เกิดขึ้น
1mainเจอ printWelcome() จึงพัก main ชั่วคราว
2printWelcomeพิมพ์ Welcome to Java แล้วจบ body
3mainกลับมาทำบรรทัดถัดจากจุดเรียก
4mainเรียกครั้งที่สอง จึงพิมพ์ข้อความอีกครั้ง
void ไม่ได้แปลว่าไม่มี output
static void showTotal() {
        System.out.println(2 + 3);
      }

method นี้ไม่มี return value แต่ยังพิมพ์ output ได้ การแสดงผลกับการคืนค่าเป็นคนละหน้าที่

ทำไมไม่ใส่ทุกอย่างใน main

แยกเมธอดทำให้แต่ละช่วงอ่านและทดสอบง่ายขึ้น และแก้คำสั่งที่ใช้ซ้ำได้จากตำแหน่งเดียว

static void printMark() {

7.2 พารามิเตอร์และ argument

parameter คือช่องรับค่าที่ประกาศใน method ส่วน argument คือข้อมูลจริงที่ส่งเข้ามาตอนเรียก แต่ละ argument ถูกจับคู่กับ parameter ตามลำดับจากซ้ายไปขวา

Syntax ของ method ที่รับค่า
static void methodName(Type first, Type second) {
        // ใช้ first และ second ทำงาน
      }

      methodName(value1, value2);

จำนวนและลำดับชนิดของ argument ตอนเรียกต้องตรงกับ parameter ใน declaration เช่น (String, int) ไม่ใช่ (int, String)

รับชื่อแล้วทักทาย
static void greet(String name) {
    System.out.println("Hello, " + name);
}

greet("Mali"); // argument คือ "Mali"
greet("Nida");

name เป็น parameter; ค่าข้อความแต่ละครั้งเป็น argument

รับหลายค่าและคำนวณ
static void showRectangle(double width, double height) {
        double area = width * height;
        System.out.println("Area = " + area);
      }

      showRectangle(4.0, 3.0);

ตอนเรียก 4.0 จับคู่กับ width และ 3.0 จับคู่กับ height ตามลำดับ

ชนิดและจำนวนต้องตรงกัน

เมธอดที่รับ String หนึ่งค่า ต้องถูกเรียกพร้อม argument ที่เข้ากันได้หนึ่งค่า เมธอดอาจรับหลาย parameter โดยคั่นด้วย comma

เขียนเมธอด printTotal รับราคาต่อชิ้นและจำนวนชิ้น แล้วแสดงราคารวม เรียกใช้ด้วยราคา 25 บาท จำนวน 4 ชิ้น

เขียนโปรแกรมรับชื่อสินค้า ราคา และจำนวนผ่าน argument ของ method printReceipt แล้วแสดงชื่อสินค้า จำนวน และยอดรวม

7.3 return value: ส่งผลลัพธ์กลับไปให้ผู้เรียก

ถ้า method คำนวณแล้วผู้เรียกต้องนำผลไปใช้ต่อ ให้ระบุ return type แทน void และใช้ return ส่งค่ากลับ return จะจบการทำงานของ method ทันที

Syntax และ flow ของ return
static ReturnType methodName(ParameterType input) {
        // คำนวณค่า
        return result;
      }
  1. ผู้เรียกส่ง argument ให้ parameter
  2. method คำนวณ local variables
  3. return ส่งค่าชนิดที่ตรงกับ ReturnType กลับ
  4. ผู้เรียกทำงานต่อหลังจุดเรียก หรือใช้ค่ากลับใน expression

method ที่ไม่ใช่ void ต้องคืนค่าทุกเส้นทางที่ทำงานได้

คำนวณพื้นที่แล้วนำผลไปใช้ต่อ
static double rectangleArea(double width, double height) {
    double area = width * height;
    return area;
}

double result = rectangleArea(4.0, 3.0);
System.out.println(result); // 12.0

ชนิดที่ return ต้องตรงกับชนิดที่ประกาศ และทุกเส้นทางในเมธอดที่ไม่ใช่ void ต้องส่งค่ากลับให้ครบ

ใช้ผลลัพธ์เป็นส่วนหนึ่งของ expression
static double tax(double amount) {
        return amount * 0.07;
      }

      double total = 100.0 + tax(100.0);
      System.out.println(total); // 107.0

ผลจาก tax(100.0) ถูกคืนกลับมาแล้วนำไปบวกต่อได้ ต่างจาก void method ที่ใช้เป็นค่าของ expression ไม่ได้

Compile error: ลืม return
static int larger(int first, int second) {
        if (first > second) {
          return first;
        }
        // ถ้า first <= second ไม่มีค่าถูกคืน
      }

ทุก branch ต้องคืน int; เพิ่ม return second; หลัง if เพื่อครอบคลุมกรณีที่เหลือ

return ไม่ใช่ println

println แสดงค่าบนหน้าจอ แต่ return ส่งค่าไปให้โค้ดที่เรียกเมธอดนำไปคำนวณหรือเก็บต่อได้

Scope: local variable อยู่ใน method/block

ตัวแปรที่ประกาศใน body ของ method ใช้ได้เฉพาะภายในวงเล็บปีกกานั้น หากผู้เรียกต้องใช้ค่าจาก method ให้ส่งออกด้วย return ไม่ใช่อ้างชื่อ local variable ตรง ๆ

static int addFive(int value) {
    int result = value + 5;
    return result;
}
int answer = addFive(10); // answer ได้ 15

เขียนเมธอด maxOf รับจำนวนเต็มสองค่าแล้วคืนค่าที่มากกว่า ถ้าค่าเท่ากันคืนค่าใดค่าหนึ่งก็ได้

7.4 เมธอดชื่อเดียวกัน (overloading)

Java อนุญาตให้เมธอดชื่อเดียวกันได้ ถ้ารายการ parameter ต่างกัน เช่น จำนวนหรือชนิดต่างกัน เรียกว่า method overloading การเปลี่ยนแค่ชนิด return อย่างเดียวไม่พอให้ overload

compiler เลือก overload จากอะไร?

Java เลือกจากชื่อ method และชนิด/จำนวน/ลำดับของ arguments ตอน compile time ไม่ได้เลือกจากค่าผลลัพธ์

static void show(int number) { System.out.println("int"); }
static void show(double number) { System.out.println("double"); }
show(5);   // เลือก show(int)
show(5.0); // เลือก show(double)

ถ้ามี overload ที่รับได้พอดีกับ argument compiler จะเลือกอันนั้น; signature ซ้ำกันแต่ return type ต่างกันอย่างเดียวถือว่าประกาศซ้ำ

หาพื้นที่จากรูปแบบ input ที่ต่างกัน
static double area(double side) {
    return side * side;
}

static double area(double width, double height) {
    return width * height;
}

double square = area(4.0);
double rectangle = area(4.0, 3.0);

Exercise 7.4ตรวจเลขคู่

เขียนเมธอด isEven รับจำนวนเต็ม แล้วคืนค่า true เมื่อเลขนั้นหาร 2 ลงตัว

ตัวอย่างคำตอบ

static boolean isEven(int number) {
    return number % 2 == 0;
}

System.out.println(isEven(14)); // true
System.out.println(isEven(9));  // false

นิพจน์ number % 2 == 0 เป็น boolean จึง return ได้ตรง ๆ

Exercise 7.11สร้าง overload สำหรับพื้นที่

สร้าง area(double side) สำหรับสี่เหลี่ยมจัตุรัส และ area(double width, double height) สำหรับสี่เหลี่ยมผืนผ้า เรียกทั้งสองแบบ

ตัวอย่างคำตอบ

static double area(double side) {
    return side * side;
}
static double area(double width, double height) {
    return width * height;
}
System.out.println(area(4.0)); // 16.0
System.out.println(area(4.0, 3.0)); // 12.0

จำนวน parameters ต่างกัน จึงเลือก overload ได้ชัดเจน

7.5 ออกแบบโปรแกรมจากหลายเมธอด

method ที่ดีแบ่งงานตามหน้าที่ เช่น อ่านโจทย์และกำหนด input ใน main, คำนวณผลใน method ที่คืนค่า, และแสดงรายงานใน method ที่ไม่คืนค่า main จึงทำหน้าที่เรียงลำดับงานแทนการรวมโค้ดทั้งหมดไว้ที่เดียว

ขั้นตอนแยกงาน
  1. กำหนด input และ output ของโปรแกรม
  2. ระบุงานย่อยและตั้งชื่อเป็นคำกริยา
  3. กำหนด parameter ที่แต่ละงานต้องใช้
  4. ตัดสินใจว่า method จะคืนค่าอะไร หรือเป็น void
  5. เรียก method จาก main และทดสอบค่าตัวอย่าง
ตัวอย่าง: รายงานผลสอบ

main เรียก method หาค่าเฉลี่ย → ใช้ค่าเฉลี่ยหาระดับ → ส่งข้อมูลให้ method พิมพ์รายงาน

public class GradeReport {
    public static void main(String[] args) {
        double average = averageOf(80, 70, 90);
        String grade = gradeOf(average);
        printReport("Mali", average, grade);
    }
    static double averageOf(double a, double b, double c) {
        return (a + b + c) / 3.0;
    }
    static String gradeOf(double average) {
        if (average >= 80) return "A";
        if (average >= 70) return "B";
        return "C";
    }
    static void printReport(String name, double average, String grade) {
        System.out.printf("%s: %.1f (%s)%n", name, average, grade);
    }
}

โค้ดใน main อ่านเป็นขั้นตอนได้ เพราะรายละเอียดของแต่ละงานถูกตั้งชื่อแยกไว้

Exercise 7.13โปรแกรมสรุปค่าน้ำมัน

สร้าง method คำนวณระยะทางจากลิตร × km/L, method คำนวณค่าใช้จ่ายจากลิตร × ราคา/ลิตร และ method พิมพ์สรุป ใช้ 25 ลิตร, 12 km/L และ 36 บาท/ลิตร

ตัวอย่างคำตอบ

public class FuelSummary {
    public static void main(String[] args) {
        double liters = 25;
        double distance = calculateDistance(liters, 12);
        double cost = calculateCost(liters, 36);
        printSummary(distance, cost);
    }
    static double calculateDistance(double liters, double kmPerLiter) {
        return liters * kmPerLiter;
    }
    static double calculateCost(double liters, double pricePerLiter) {
        return liters * pricePerLiter;
    }
    static void printSummary(double distance, double cost) {
        System.out.printf("Distance: %.1f km%nFuel cost: %.2f baht%n", distance, cost);
    }
}

ผลคือ 300 km และ 900.00 บาท; method คำนวณไม่ต้องทำหน้าที่พิมพ์รายงาน

แบบฝึกหัดท้ายบท

ออกแบบชื่อเมธอดให้บอกหน้าที่ และแยกค่าที่รับเข้าออกจากค่าที่คืนกลับ

Exercise 7.5คำนวณภาษี

สร้างเมธอดรับยอดก่อนภาษีและอัตราภาษี แล้วคืนยอดรวมภาษี ทดสอบยอด 100 บาท อัตรา 7%

static double totalWithTax(double subtotal, double taxRate) {

System.out.println(totalWithTax(100.0, 0.07)); // 107.0

Exercise 7.6แปลงอุณหภูมิ

เขียนเมธอดคืนค่าอุณหภูมิฟาเรนไฮต์จากเซลเซียส ใช้สูตร F = C × 9 / 5 + 32

ตัวอย่างคำตอบ

static double toFahrenheit(double celsius) {

System.out.println(toFahrenheit(0)); // 32.0

เขียนเมธอดคืนค่าเฉลี่ยของคะแนน 3 จำนวน แล้วเรียกเมธอดเพื่อแสดงผล

ตัวอย่างคำตอบ

static double averageOf(double first, double second, double third) {
    return (first + second + third) / 3.0;
}

double average = averageOf(80, 90, 100);
System.out.println(average); // 90.0
