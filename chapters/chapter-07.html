บทที่ 7 · จัดกลุ่มคำสั่งให้เรียกใช้ซ้ำ

เมธอด: แบ่งโปรแกรมเป็นส่วน

เมธอดช่วยตั้งชื่อให้การทำงานหนึ่งอย่าง เรียกใช้ซ้ำได้ และทำให้ main ไม่ต้องรับผิดชอบทุกขั้นตอนเอง

เมื่อจบบทนี้ นิสิตจะทำได้
  • ประกาศและเรียกใช้ static method
  • ส่งข้อมูลผ่าน parameter
  • คืนผลลัพธ์ด้วย return
  • อธิบายขอบเขตของตัวแปรและการ overload

7. ย้ายงานย่อยไปไว้ในเมธอด

เมธอด (method) คือชุดคำสั่งที่ตั้งชื่อไว้เพื่อทำงานหนึ่งอย่าง เช่น คำนวณราคา หรือพิมพ์ใบเสร็จ เมื่อโปรแกรมยาวขึ้น เราแยกงานเป็นเมธอดเล็ก ๆ เพื่อให้อ่านง่าย เรียกซ้ำได้ และตรวจข้อผิดพลาดทีละส่วนได้ จริง ๆ แล้วเราใช้เมธอดมาตั้งแต่บทแรก: main, println, nextInt, Math.sqrt ล้วนเป็นเมธอด บทนี้จะเขียนเมธอดของเราเอง

7.1 ประกาศและเรียกใช้เมธอด

แยกส่วนของ method declaration
static  void  printWelcome  ( )  {
  ①      ②         ③        ④   ⑤ body ...
}
  1. static — เรียกผ่านคลาสได้โดยไม่ต้องสร้าง object (ใช้ในบทพื้นฐานนี้ ความหมายเต็มอยู่ในบทที่ 11–12)
  2. void — ชนิดผลลัพธ์: ไม่มีค่าคืนกลับ
  3. ชื่อเมธอด — lowerCamelCase ขึ้นต้นด้วยคำกริยา เช่น printReceipt, calculateTax
  4. ( ) — ตำแหน่ง parameter ตอนนี้ยังว่าง
  5. { } — body คือคำสั่งที่ทำเมื่อถูกเรียก

เมธอดประกาศภายในคลาส แต่นอกเมธอดอื่น (ไม่ซ้อนอยู่ใน main) และลำดับการประกาศไม่สำคัญ

ตัวอย่าง 7.1.1 · แยกการแสดงข้อความออกจาก main พื้นฐาน

แนวคิด: ประกาศครั้งเดียว เรียกกี่ครั้งก็ได้ด้วยชื่อตามด้วย ()

Java source · Welcome.java
public class Welcome {
    public static void main(String[] args) {
        printWelcome();
        System.out.println("(main continues)");
        printWelcome();
    }

    static void printWelcome() {
        System.out.println("Welcome to Java");
    }
}
Output
Welcome to Java
(main continues)
Welcome to Java
อธิบายทีละขั้น
  1. main เจอ printWelcome() จึงพัก main ชั่วคราวแล้วกระโดดไปที่เมธอด
  2. เมธอดพิมพ์ข้อความแล้วจบ body
  3. กลับมาที่ main บรรทัดถัดจากจุดเรียก
  4. เรียกครั้งที่สองก็ทำซ้ำแบบเดิม

ตัวอย่าง 7.1.2 · เมธอดเรียกเมธอดอื่นต่อได้ ต่อยอด

แนวคิด: เมธอดหนึ่งเรียกเมธอดอื่นได้ โปรแกรมจะจำว่าต้องกลับไปที่ใด (call stack) ลองไล่ลำดับก่อนดู output

Java source · CallChain.java
public class CallChain {
    public static void main(String[] args) {
        System.out.println("main: start");
        printHeader();
        System.out.println("main: end");
    }

    static void printHeader() {
        printLine();
        System.out.println("  REPORT");
        printLine();
    }

    static void printLine() {
        System.out.println("==========");
    }
}
Output
main: start
==========
  REPORT
==========
main: end
อธิบายทีละขั้น
  1. main พิมพ์ start แล้วเรียก printHeader
  2. printHeader เรียก printLine → พิมพ์เส้น → กลับมา printHeader
  3. พิมพ์ REPORT แล้วเรียก printLine อีกครั้ง
  4. printHeader จบ → กลับมา main พิมพ์ end

ตัวอย่าง 7.1.3 · แบ่ง main เป็นขั้นตอนที่มีชื่อ ประยุกต์

แนวคิด: main ที่ดีควรอ่านเหมือนสารบัญ: แต่ละบรรทัดบอกว่าทำอะไร รายละเอียดอยู่ในเมธอด

Java source · ShopSteps.java
public class ShopSteps {
    public static void main(String[] args) {
        showBanner();
        showMenu();
        showFooter();
    }

    static void showBanner() {
        System.out.println("*** JAVA CAFE ***");
    }

    static void showMenu() {
        System.out.println("1. Espresso   45");
        System.out.println("2. Latte      55");
        System.out.println("3. Mocha      60");
    }

    static void showFooter() {
        System.out.println("Open 8:00-18:00");
    }
}
Output
*** JAVA CAFE ***
1. Espresso   45
2. Latte      55
3. Mocha      60
Open 8:00-18:00
อธิบายทีละขั้น
  1. อ่าน main แล้วรู้ทันทีว่าโปรแกรมมี 3 ส่วน
  2. ถ้าต้องแก้เมนู แก้เฉพาะ showMenu
void ไม่ได้แปลว่าไม่มี output

เมธอด void พิมพ์ข้อความได้ตามปกติ “void” หมายถึงไม่ส่งค่ากลับไปให้ผู้เรียกนำไปใช้ต่อ การแสดงผล (print) กับการคืนค่า (return) เป็นคนละเรื่อง — จะเห็นชัดในหัวข้อ 7.3

ลองคิดก่อน · ลำดับการเรียก
static void a() { System.out.print("A"); b(); System.out.print("a"); }
static void b() { System.out.print("B"); }
// ใน main:
a(); b();
ดูคำตอบ

ABaB — a พิมพ์ A, เรียก b พิมพ์ B, กลับมาพิมพ์ a, แล้ว main เรียก b อีกครั้งพิมพ์ B

7.2 พารามิเตอร์และ argument

parameter คือตัวแปรที่ประกาศในวงเล็บของเมธอดเพื่อรับค่า ส่วน argument คือค่าจริงที่ส่งเข้าไปตอนเรียก เมื่อเรียก Java จะคัดลอกค่า argument ไปใส่ parameter ตามลำดับตำแหน่ง

parameter vs argument
static void greet(String name, int times) { ... }   // name, times = parameter
greet("Mali", 3);                                  // "Mali", 3   = argument
        │      └──→ times = 3
        └──────────→ name  = "Mali"
  • จำนวน ชนิด และลำดับของ argument ต้องตรงกับ parameter
  • argument เป็นตัวแปร ค่าคงที่ หรือนิพจน์ก็ได้ เช่น greet(user, n + 1)

ตัวอย่าง 7.2.1 · parameter หนึ่งตัว พื้นฐาน

แนวคิด: เมธอดเดียวทำงานกับข้อมูลต่างกันได้ ขึ้นอยู่กับ argument ที่ส่งมา

Java source · GreetParam.java
public class GreetParam {
    public static void main(String[] args) {
        greet("Mali");
        greet("Beam");
        String friend = "Nida";
        greet(friend);
    }

    static void greet(String name) {
        System.out.println("Hello, " + name + "!");
    }
}
Output
Hello, Mali!
Hello, Beam!
Hello, Nida!
อธิบายทีละขั้น
  1. ครั้งแรก name = "Mali"
  2. ครั้งที่สอง name = "Beam"
  3. ครั้งที่สามส่งตัวแปร friend → name ได้ค่า "Nida"

ตัวอย่าง 7.2.2 · หลาย parameter และลูปในเมธอด ต่อยอด

แนวคิด: parameter ใช้ได้เหมือนตัวแปรปกติภายในเมธอด รวมถึงเป็นขอบเขตของลูป

Java source · DrawLine.java
public class DrawLine {
    public static void main(String[] args) {
        drawLine('*', 10);
        drawLine('-', 4);
        drawLine('=', 2 * 6);
    }

    static void drawLine(char symbol, int length) {
        for (int i = 0; i < length; i++) {
            System.out.print(symbol);
        }
        System.out.println();
    }
}
Output
**********
----
============
อธิบายทีละขั้น
  1. symbol = '*', length = 10 → ดาว 10 ตัว
  2. argument ที่สามเป็นนิพจน์ 2 * 6 คำนวณได้ 12 ก่อนส่ง
  3. ลำดับสำคัญ: drawLine(10, '*') จะคอมไพล์ไม่ผ่าน

ตัวอย่าง 7.2.3 · pass-by-value: เมธอดแก้ค่าตัวแปรของผู้เรียกไม่ได้ ประยุกต์

แนวคิด: Java ส่งสำเนาของค่า การเปลี่ยน parameter ภายในเมธอดไม่กระทบตัวแปรใน main

Java source · PassByValue.java
public class PassByValue {
    public static void main(String[] args) {
        int score = 50;
        addBonus(score);
        System.out.println("main: score = " + score);
    }

    static void addBonus(int score) {
        score = score + 10;
        System.out.println("addBonus: score = " + score);
    }
}
Output
addBonus: score = 60
main: score = 50
อธิบายทีละขั้น
  1. main ส่งค่า 50 ไป
  2. parameter score ในเมธอดเป็นตัวแปรคนละตัวแม้ชื่อเหมือนกัน
  3. เปลี่ยนเป็น 60 เฉพาะในเมธอด
  4. main ยังเป็น 50 — ถ้าต้องการผลลัพธ์ต้องใช้ return (หัวข้อถัดไป)

ทดลอง error 7.2.4 · argument ไม่ตรงกับ parameter ประยุกต์

แนวคิด: compiler ตรวจจำนวนและชนิดของ argument ทุกครั้งที่เรียก

Java source · WrongArguments.java
public class WrongArguments {
    public static void main(String[] args) {
        drawLine(5, '*');
        drawLine('*');
    }

    static void drawLine(char symbol, int length) {
        System.out.println(String.valueOf(symbol).repeat(length));
    }
}
Compile error (จาก javac จริง)
WrongArguments.java:3: error: incompatible types: possible lossy conversion from int to char
        drawLine(5, '*');
                 ^
WrongArguments.java:4: error: method drawLine in class WrongArguments cannot be applied to given types;
        drawLine('*');
        ^
  required: char,int
  found:    char
  reason: actual and formal argument lists differ in length
อธิบายทีละขั้น
  1. บรรทัด 3 สลับลำดับ: ส่ง 5 (int) ไปที่ parameter แรกซึ่งเป็น char → possible lossy conversion from int to char
  2. บรรทัด 4 ขาด argument → cannot be applied to given types
  3. required: char,int / found: char บอกว่าคาดหวังอะไรและได้อะไร
  4. แก้: drawLine('*', 5);
ลองคิดก่อน · ส่งค่า
static void show(int a, int b) { System.out.println(a + "-" + b); }
// main
int x = 3, y = 8;
show(y, x);
show(x + y, x * y);
ดูคำตอบ

8-3 และ 11-24 — ค่าจับคู่ตามตำแหน่ง ไม่ใช่ตามชื่อตัวแปร

7.3 return value: เมธอดที่คืนผลลัพธ์

เมื่อเมธอดคำนวณค่าที่ผู้เรียกต้องนำไปใช้ต่อ ให้ระบุชนิดผลลัพธ์แทน void แล้วใช้ return ค่า; ส่งค่ากลับ เมื่อเจอ return เมธอดจะจบทันที

โครงสร้างเมธอดที่คืนค่า
static double calculateArea(double width, double height) {
    double area = width * height;
    return area;                    // ส่งค่า area กลับไปยังจุดที่เรียก
}

double a = calculateArea(4, 2.5);   // นำค่าที่คืนมาเก็บในตัวแปร
System.out.println(calculateArea(3, 3) * 2);  // หรือใช้ในนิพจน์โดยตรง

คิดว่าการเรียกเมธอดที่คืนค่าคือ “นิพจน์” ที่ถูกแทนด้วยค่าที่ return ออกมา

ตัวอย่าง 7.3.1 · คืนค่าแล้วนำไปใช้ต่อ พื้นฐาน

แนวคิด: ค่าที่คืนกลับมาเก็บในตัวแปร พิมพ์ หรือใช้คำนวณต่อได้

Java source · SquareReturn.java
public class SquareReturn {
    public static void main(String[] args) {
        int a = square(4);
        System.out.println("square(4) = " + a);
        System.out.println("square(3) + square(4) = " + (square(3) + square(4)));
        System.out.println("square(square(2)) = " + square(square(2)));
    }

    static int square(int n) {
        return n * n;
    }
}
Output
square(4) = 16
square(3) + square(4) = 25
square(square(2)) = 16
อธิบายทีละขั้น
  1. square(4) คืน 16 เก็บใน a
  2. square(3) + square(4) = 9 + 16 = 25
  3. square(square(2)): ในสุดได้ 4 → square(4) = 16

ตัวอย่าง 7.3.2 · print กับ return ต่างกันอย่างไร ต่อยอด

แนวคิด: เมธอดที่พิมพ์ผลลัพธ์ให้คนเห็น แต่โปรแกรมนำค่าไปใช้ต่อไม่ได้ เมธอดที่ return ให้ค่ากับโปรแกรม

Java source · PrintVsReturn.java
public class PrintVsReturn {
    public static void main(String[] args) {
        printTotal(100, 3);
        double total = getTotal(100, 3);
        double withVat = total * 1.07;
        System.out.println("With VAT: " + withVat);
    }

    static void printTotal(double price, int qty) {
        System.out.println("Total: " + price * qty);
    }

    static double getTotal(double price, int qty) {
        return price * qty;
    }
}
Output
Total: 300.0
With VAT: 321.0
อธิบายทีละขั้น
  1. printTotal แสดง 300.0 แต่ main ไม่ได้ค่ากลับมา
  2. getTotal คืน 300.0 → main นำไปคูณ VAT ต่อได้
  3. แนวทาง: เมธอดคำนวณควร return ให้ main เป็นผู้ตัดสินใจว่าจะแสดงผลอย่างไร

ตัวอย่าง 7.3.3 · return หลายจุด และคืน boolean ประยุกต์

แนวคิด: เมธอดอาจมี return หลายจุดตามเงื่อนไข แต่ทุกเส้นทางต้องคืนค่าเสมอ เมธอดที่คืน boolean นิยมตั้งชื่อขึ้นต้นด้วย is/has/can

Java source · ReturnPaths.java
public class ReturnPaths {
    public static void main(String[] args) {
        System.out.println(gradeOf(85) + " " + gradeOf(72) + " " + gradeOf(40));
        for (int n = 1; n <= 20; n++) {
            if (isPrime(n)) {
                System.out.print(n + " ");
            }
        }
        System.out.println();
    }

    static char gradeOf(int score) {
        if (score >= 80) return 'A';
        if (score >= 70) return 'B';
        if (score >= 60) return 'C';
        return 'F';
    }

    static boolean isPrime(int n) {
        if (n < 2) return false;
        for (int d = 2; d * d <= n; d++) {
            if (n % d == 0) return false;
        }
        return true;
    }
}
Output
A B F
2 3 5 7 11 13 17 19
อธิบายทีละขั้น
  1. gradeOf(85): เจอ return 'A' แล้วจบเมธอดทันที ไม่ตรวจบรรทัดล่าง
  2. ไม่ต้องใช้ else เพราะ return ออกไปแล้ว
  3. isPrime เจอตัวหารก็ return false ทันที (ไม่ต้องใช้ break หรือ flag)
  4. ถ้าวนครบโดยไม่เจอตัวหาร จึง return true

ทดลอง error 7.3.4 · บางเส้นทางไม่มี return ท้าทาย

แนวคิด: ถ้ามีกรณีที่เมธอดจบโดยไม่ return ค่า compiler จะไม่ยอม

Java source · MissingReturn.java
public class MissingReturn {
    public static void main(String[] args) {
        System.out.println(sign(5));
    }

    static String sign(int n) {
        if (n > 0) {
            return "positive";
        } else if (n < 0) {
            return "negative";
        }
    }
}
Compile error (จาก javac จริง)
MissingReturn.java:12: error: missing return statement
    }
    ^
อธิบายทีละขั้น
  1. กรณี n == 0 หลุดออกจาก if ทั้งหมดโดยไม่มี return
  2. javac แจ้ง missing return statement
  3. แก้: เพิ่ม return "zero"; ท้ายเมธอด
ลองคิดก่อน · ค่าที่คืน
static int f(int x) {
    if (x % 2 == 0) return x / 2;
    return 3 * x + 1;
}
// f(6), f(7), f(f(5))
ดูคำตอบ

f(6) = 3, f(7) = 22, f(5) = 16 → f(16) = 8

7.4 scope ของตัวแปร และ method overloading

scope คือบริเวณที่ตัวแปรถูกมองเห็นและใช้งานได้ ตัวแปรที่ประกาศในบล็อก { } ใดใช้ได้เฉพาะในบล็อกนั้น (local variable) parameter ก็เป็น local ของเมธอดนั้น ส่วน overloading คือการมีหลายเมธอดชื่อเดียวกันแต่ parameter ต่างกัน

ตัวอย่าง 7.4.1 · ตัวแปรชื่อเดียวกันในคนละเมธอด พื้นฐาน

แนวคิด: ตัวแปรในแต่ละเมธอดแยกกันโดยสิ้นเชิง แม้ชื่อเหมือนกัน

Java source · ScopeDemo.java
public class ScopeDemo {
    public static void main(String[] args) {
        int count = 1;
        helper();
        System.out.println("main count = " + count);
    }

    static void helper() {
        int count = 99;
        System.out.println("helper count = " + count);
    }
}
Output
helper count = 99
main count = 1
อธิบายทีละขั้น

7.5 ประกอบโปรแกรมจากเมธอด

ขั้นตอนออกแบบโปรแกรมด้วยเมธอด (top-down)
  1. เขียนสิ่งที่โปรแกรมต้องทำเป็นข้อ ๆ ภาษาคน เช่น รับข้อมูล → คำนวณ → ตัดสิน → แสดงผล
  2. แต่ละข้อที่ทำงานชัดเจนหนึ่งอย่าง → ตั้งเป็นเมธอดหนึ่งตัว ตั้งชื่อด้วยคำกริยา
  3. กำหนดว่าแต่ละเมธอด ต้องรู้อะไร (parameter) และ ให้อะไรกลับ (return type)
  4. เขียน main ให้เรียกเมธอดตามลำดับเหมือนสารบัญ
  5. เขียนและทดสอบเมธอดทีละตัว โดยเรียกจาก main ด้วยค่าที่รู้คำตอบ

ตัวอย่าง 7.5.1 · เครื่องคำนวณเกรดจากเมธอดหลายตัว ประยุกต์

แนวคิด: main ประสานงาน ส่วนเมธอดแต่ละตัวทำหน้าที่เดียว: รวมคะแนน ตัดเกรด และพิมพ์รายงาน

Java source · GradeReport.java
import java.util.Scanner;

public class GradeReport {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Name: ");
        String name = input.nextLine();
        System.out.print("Work Mid Final: ");
        double work = input.nextDouble();
        double mid = input.nextDouble();
        double fin = input.nextDouble();

        double total = totalScore(work, mid, fin);
        char grade = gradeOf(total);
        printReport(name, total, grade);
    }

    static double totalScore(double work, double mid, double fin) {
        return work + mid + fin;
    }

    static char gradeOf(double total) {
        if (total >= 80) return 'A';
        if (total >= 70) return 'B';
        if (total >= 60) return 'C';
        if (total >= 50) return 'D';
        return 'F';
    }

    static void printReport(String name, double total, char grade) {
        System.out.println("-".repeat(24));
        System.out.printf("%-8s %s%n", "Name", name);
        System.out.printf("%-8s %.1f%n", "Total", total);
        System.out.printf("%-8s %c%n", "Grade", grade);
        System.out.printf("%-8s %s%n", "Result", grade == 'F' ? "Fail" : "Pass");
        System.out.println("-".repeat(24));
    }
}

Total    83.0
Grade    A
Result   Pass

  1. main อ่านแล้วเข้าใจทันที: รับข้อมูล → รวม → ตัดเกรด → รายงาน
  2. totalScore และ gradeOf คืนค่า → ทดสอบแยกได้ง่าย
  3. printReport เป็น void เพราะหน้าที่คือแสดงผล

  2. ทุกเมธอดแปลงหน่วยเป็น static double และ return ค่า
  3. แสดงผลทศนิยม 2 ตำแหน่ง

import java.util.Scanner;

public class UnitConverter {
    static final double MILE_PER_KM = 0.621371;
    static final double POUND_PER_KG = 2.20462;

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Celsius km kg: ");
        double c = input.nextDouble();
        double km = input.nextDouble();
        double kg = input.nextDouble();
        System.out.printf("%8.2f C  = %8.2f F%n", c, cToF(c));
        System.out.printf("%8.2f km = %8.2f mi%n", km, kmToMile(km));
        System.out.printf("%8.2f kg = %8.2f lb%n", kg, kgToPound(kg));
    }

    static double cToF(double c) {
        return c * 9 / 5 + 32;
    }

    static double kmToMile(double km) {
        return km * MILE_PER_KM;
    }

    static double kgToPound(double kg) {
        return kg * POUND_PER_KG;
    }
}

Exercise 7.5isEven, isPrime และนับจำนวน★★ ปานกลาง

เขียนเมธอด boolean isEven(int n) และ boolean isPrime(int n) แล้วใน main รับช่วง a ถึง b และใช้สองเมธอดนี้นับว่ามีเลขคู่กี่ตัวและจำนวนเฉพาะกี่ตัว พร้อมแสดงรายการจำนวนเฉพาะ

สิ่งที่ต้องทำ
  1. isPrime คืน false สำหรับ n < 2
  2. main ห้ามมีโค้ดตรวจจำนวนเฉพาะเอง ต้องเรียกเมธอด
  3. ทดสอบช่วง 10 ถึง 30
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

Primes: 11 13 17 19 23 29

ตัวอย่างคำตอบ

import java.util.Scanner;

public class CountWithMethods {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("a b: ");
        int a = input.nextInt(), b = input.nextInt();
        int evens = 0, primes = 0;
        System.out.print("Primes: ");
        for (int n = a; n <= b; n++) {
            if (isEven(n)) evens++;
            if (isPrime(n)) {
                primes++;
                System.out.print(n + " ");
            }
        }
        System.out.println();
        System.out.println("Even count: " + evens);
        System.out.println("Prime count: " + primes);
    }

    static boolean isEven(int n) {
        return n % 2 == 0;
    }

    static boolean isPrime(int n) {
        if (n < 2) return false;
        for (int d = 2; d * d <= n; d++) {
            if (n % d == 0) return false;
        }
        return true;
    }
}

return n % 2 == 0; คืนผลของนิพจน์ boolean ได้โดยตรง ไม่ต้องเขียน if

Exercise 7.6overload เมธอดคำนวณพื้นที่★★ ปานกลาง

เขียนเมธอดชื่อ area สามแบบ (overload): area(double r) พื้นที่วงกลม, area(double w, double h) พื้นที่สี่เหลี่ยมผืนผ้า และ area(double a, double b, double c) พื้นที่สามเหลี่ยมจากความยาวด้านด้วยสูตรเฮรอน (s = (a+b+c)/2, พื้นที่ = √(s(s−a)(s−b)(s−c)))

สิ่งที่ต้องทำ
  1. ใช้ Math.PI และ Math.sqrt
  2. เรียกทั้งสามแบบจาก main ด้วยค่าในตัวอย่าง
  3. อธิบายว่า compiler รู้ได้อย่างไรว่าต้องเรียกแบบไหน
ตัวอย่างผลลัพธ์
Circle r=3       : 28.27
Rectangle 4x6    : 24.00
Triangle 3,4,5   : 6.00

ตัวอย่างคำตอบ

public class AreaOverload {
    public static void main(String[] args) {
        System.out.printf("Circle r=3       : %.2f%n", area(3));
        System.out.printf("Rectangle 4x6    : %.2f%n", area(4, 6));
        System.out.printf("Triangle 3,4,5   : %.2f%n", area(3, 4, 5));
    }

    static double area(double r) {
        return Math.PI * r * r;
    }

    static double area(double w, double h) {
        return w * h;
    }

    static double area(double a, double b, double c) {
        double s = (a + b + c) / 2;
        return Math.sqrt(s * (s - a) * (s - b) * (s - c));
    }
}

compiler ดูจากจำนวน argument (1, 2 หรือ 3 ตัว) เพื่อเลือกเมธอดที่ signature ตรงกัน

Exercise 7.7ตารางเงินกู้ด้วยเมธอด★★ ปานกลาง

เขียนเมธอด monthlyPayment(double principal, double annualRate, int months) คืนค่างวดรายเดือนด้วยสูตร P × r / (1 − (1 + r)−n) โดย r = อัตราต่อปี ÷ 12 ÷ 100 ถ้าอัตราเป็น 0 ให้คืน principal ÷ months จากนั้นใน main แสดงค่างวดของเงินกู้ 500,000 บาทที่ระยะเวลา 12, 24, 36, 48, 60 เดือน ดอกเบี้ย 6% ต่อปี

สิ่งที่ต้องทำ
  1. ใช้ Math.pow(1 + r, -n)
  2. ใช้ลูปใน main เรียกเมธอดซ้ำ
  3. แสดงค่างวดและดอกเบี้ยรวม (ค่างวด × เดือน − เงินต้น)
ตัวอย่างผลลัพธ์
Months      Payment     Interest
    12    43,033.21    16,398.58
    24    22,160.31    31,847.32
    36    15,210.97    47,594.87
    48    11,742.51    63,640.70
    60     9,666.40    79,984.05

ตัวอย่างคำตอบ

public class LoanTable {
    public static void main(String[] args) {
        double principal = 500000;
        double rate = 6;
        System.out.printf("%6s %12s %12s%n", "Months", "Payment", "Interest");
        for (int months = 12; months <= 60; months += 12) {
            double pay = monthlyPayment(principal, rate, months);
            System.out.printf("%6d %,12.2f %,12.2f%n", months, pay, pay * months - principal);
        }
    }

    static double monthlyPayment(double principal, double annualRate, int months) {
        if (annualRate == 0) return principal / months;
        double r = annualRate / 12 / 100;
        return principal * r / (1 - Math.pow(1 + r, -months));
    }
}

Exercise 7.8เครื่องมือตัวเลข: digitSum, reverse, isPalindrome★★★ ท้าทาย

เขียนเมธอด 3 ตัวที่ทำงานกับจำนวนเต็มบวกโดยไม่ใช้ String: int digitSum(int n), int reverse(int n) และ boolean isPalindrome(int n) (ต้องเรียก reverse) จากนั้นให้ main หาจำนวนพาลินโดรมทั้งหมดในช่วง 100–200 และแสดงผลรวมหลักของแต่ละตัว

สิ่งที่ต้องทำ
  1. isPalindrome ต้องใช้ reverse ไม่เขียนลูปซ้ำ
  2. แสดงผลในรูปแบบ 121 (sum 4) บรรทัดละ 5 ตัว
  3. สรุปจำนวนพาลินโดรมที่พบ

ตัวอย่างคำตอบ

public class NumberTools {
    public static void main(String[] args) {
        int found = 0;
        for (int n = 100; n <= 200; n++) {
            if (isPalindrome(n)) {
                System.out.printf("%d (sum %d)  ", n, digitSum(n));
                found++;
                if (found % 5 == 0) System.out.println();
            }
        }
        if (found % 5 != 0) System.out.println();
        System.out.println("Found " + found + " palindromes");
    }

    static int digitSum(int n) {
        int sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        return sum;
    }

    static int reverse(int n) {
        int rev = 0;
        while (n > 0) {
            rev = rev * 10 + n % 10;
            n /= 10;
        }
        return rev;
    }

    static boolean isPalindrome(int n) {
        return n == reverse(n);
    }
}

การแก้ parameter n ใน digitSum และ reverse ไม่กระทบตัวแปร n ใน main เพราะ Java ส่งสำเนาของค่า

Exercise 7.9ตัวช่วยตรวจการรับข้อมูล★★★ ท้าทาย

เขียนเมธอด readIntInRange(Scanner in, String prompt, int min, int max) ที่ถามซ้ำจนกว่าผู้ใช้จะป้อนจำนวนเต็มในช่วง [min, max] แล้ว return ค่านั้น จากนั้นใช้เมธอดนี้สร้างโปรแกรมรับวันเกิด (วัน 1–31, เดือน 1–12, ปี ค.ศ. 1900–2026) และคำนวณอายุ ณ วันที่ 4/10/2026 (ถ้ายังไม่ถึงวันเกิดในปีนี้ให้ลบ 1)

สิ่งที่ต้องทำ
  1. ส่ง Scanner ตัวเดียวเป็น argument (ไม่สร้างใหม่ในเมธอด)
  2. แสดง Please enter min-max เมื่อป้อนผิดช่วง
  3. เขียนเมธอด ageOn(int d, int m, int y, int nowD, int nowM, int nowY) คืนอายุ
ตัวอย่างผลลัพธ์ (ตัวที่ขีดเส้นใต้ = ค่าที่ผู้ใช้พิมพ์)

Month: 13
Please enter 1-12
Month: 8

ตัวอย่างคำตอบ

import java.util.Scanner;

public class BirthdayInput {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int d = readIntInRange(in, "Day: ", 1, 31);
        int m = readIntInRange(in, "Month: ", 1, 12);
        int y = readIntInRange(in, "Year: ", 1900, 2026);
        System.out.println("Born " + d + "/" + m + "/" + y);
        System.out.println("Age on 4/10/2026: " + ageOn(d, m, y, 4, 10, 2026));
    }

    static int readIntInRange(Scanner in, String prompt, int min, int max) {
        int value;
        while (true) {
            System.out.print(prompt);
            value = in.nextInt();
            if (value >= min && value <= max) return value;
            System.out.println("Please enter " + min + "-" + max);
        }
    }

    static int ageOn(int d, int m, int y, int nowD, int nowM, int nowY) {
        int age = nowY - y;
        if (nowM < m || (nowM == m && nowD < d)) {
            age--;
        }
        return age;
    }
}

Exercise 7.10เกมลูกเต๋าแบบแบ่งเมธอด★★★ ท้าทาย

สร้างเกมลูกเต๋าสองลูกแบบ “ผลลัพธ์กำหนดไว้” (ใช้ค่าจากผู้ใช้แทนการสุ่ม เพื่อให้ทดสอบได้) ผู้เล่นป้อนผลทอยทีละคู่ กติกา: ทอยครั้งแรกได้ผลรวม 7 หรือ 11 ชนะทันที, 2, 3, 12 แพ้ทันที, ค่าอื่นกลายเป็น “แต้มเป้าหมาย” แล้วทอยต่อไปจนได้แต้มเป้าหมาย (ชนะ) หรือได้ 7 (แพ้)

สิ่งที่ต้องทำ
  1. เมธอด int readRoll(Scanner in) อ่านลูกเต๋า 2 ลูก ตรวจว่าแต่ละลูกอยู่ใน 1–6 แล้วคืนผลรวม
  2. เมธอด String firstRollResult(int sum) คืน "WIN", "LOSE" หรือ "POINT"
  3. เมธอด boolean playForPoint(Scanner in, int point) วนทอยจนรู้ผล คืน true ถ้าชนะ
  4. main เรียกเมธอดเหล่านี้และแสดงผลทุกการทอย

  sum = 8

  sum = 6

import java.util.Scanner;

public class DiceGame {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int first = readRoll(in);
        String result = firstRollResult(first);
        if (result.equals("POINT")) {
            System.out.println("Point is " + first);
            boolean win = playForPoint(in, first);
            System.out.println(win ? "You WIN!" : "You LOSE!");
        } else {
            System.out.println("You " + result + "!");
        }
    }

    static int readRoll(Scanner in) {
        while (true) {
            System.out.print("Roll (two dice): ");
            int a = in.nextInt(), b = in.nextInt();
            if (a >= 1 && a <= 6 && b >= 1 && b <= 6) {
                System.out.println("  sum = " + (a + b));
                return a + b;
            }
            System.out.println("  dice must be 1-6");
        }
    }

    static String firstRollResult(int sum) {
        if (sum == 7 || sum == 11) return "WIN";
        if (sum == 2 || sum == 3 || sum == 12) return "LOSE";
        return "POINT";
    }

    static boolean playForPoint(Scanner in, int point) {
        while (true) {
            int sum = readRoll(in);
            if (sum == point) return true;
            if (sum == 7) return false;
        }
    }
}
