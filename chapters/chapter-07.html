บทที่ 7 · จัดกลุ่มคำสั่งให้เรียกใช้ซ้ำ

เมธอด: แบ่งโปรแกรมเป็นส่วน

เมธอดช่วยตั้งชื่อให้การทำงานหนึ่งอย่าง เรียกใช้ซ้ำได้ และทำให้ main ไม่ต้องรับผิดชอบทุกขั้นตอนเอง

เมื่อจบบทนี้ นิสิตจะทำได้
  • ประกาศและเรียกใช้ static method
  • ส่งข้อมูลผ่าน parameter
  • คืนผลลัพธ์ด้วย return
  • อธิบายขอบเขตของตัวแปรและการ overload

7. ย้ายงานย่อยไปไว้ในเมธอด

เมธอด (method) คือชุดคำสั่งที่ตั้งชื่อไว้เพื่อทำงานหนึ่งอย่าง เช่น คำนวณราคา หรือพิมพ์ใบเสร็จ เมื่อโปรแกรมยาวขึ้น เราแยกงานเป็นเมธอดเล็ก ๆ เพื่อให้อ่านง่าย เรียกซ้ำได้ และตรวจข้อผิดพลาดทีละส่วนได้ จริง ๆ แล้วเราใช้เมธอดมาตั้งแต่บทแรก: main, println, nextInt, Math.sqrt ล้วนเป็นเมธอด บทนี้จะเขียนเมธอดของเราเอง

7.1 ประกาศและเรียกใช้เมธอด

แยกส่วนของ method declaration
Java
static  void  printWelcome  ( )  {
  ①      ②         ③        ④   ⑤ body ...
}
  1. static — เรียกผ่านคลาสได้โดยไม่ต้องสร้าง object (ใช้ในบทพื้นฐานนี้ ความหมายเต็มอยู่ในบทที่ 11–12)
  2. void — ชนิดผลลัพธ์: ไม่มีค่าคืนกลับ
  3. ชื่อเมธอด — lowerCamelCase ขึ้นต้นด้วยคำกริยา เช่น printReceipt, calculateTax
  4. ( ) — ตำแหน่ง parameter ตอนนี้ยังว่าง
  5. { } — body คือคำสั่งที่ทำเมื่อถูกเรียก

เมธอดประกาศภายในคลาส แต่นอกเมธอดอื่น (ไม่ซ้อนอยู่ใน main) และลำดับการประกาศไม่สำคัญ

ตัวอย่าง 7.1.1แยกการแสดงข้อความออกจาก main

แนวคิด: ประกาศครั้งเดียว เรียกกี่ครั้งก็ได้ด้วยชื่อตามด้วย ()

Welcome.java
public class Welcome {
    public static void main(String[] args) {
        // เรียกเมธอด → กระโดดไปทำ แล้วกลับมาบรรทัดถัดไป
        printWelcome();
        System.out.println("(main continues)");
        printWelcome();  // เรียกซ้ำได้หลายครั้ง
    }

    static void printWelcome() {  // static void: ไม่คืนค่า
        System.out.println("Welcome to Java");
    }
}
ผลลัพธ์
Welcome to Java
(main continues)
Welcome to Java
อธิบายทีละขั้น
  1. main เจอ printWelcome() จึงพัก main ชั่วคราวแล้วกระโดดไปที่เมธอด
  2. เมธอดพิมพ์ข้อความแล้วจบ body
  3. กลับมาที่ main บรรทัดถัดจากจุดเรียก
  4. เรียกครั้งที่สองก็ทำซ้ำแบบเดิม

ตัวอย่าง 7.1.2เมธอดเรียกเมธอดอื่นต่อได้

แนวคิด: เมธอดหนึ่งเรียกเมธอดอื่นได้ โปรแกรมจะจำว่าต้องกลับไปที่ใด (call stack) ลองไล่ลำดับก่อนดู output

CallChain.java
public class CallChain {
    public static void main(String[] args) {
        System.out.println("main: start");
        printHeader();  // main เรียก printHeader
        System.out.println("main: end");
    }

    static void printHeader() {
        printLine();  // เมธอดเรียกเมธอดอื่นต่อได้
        System.out.println("  REPORT");
        printLine();
    }

    static void printLine() {
        System.out.println("==========");
    }
}
ผลลัพธ์
main: start
==========
  REPORT
==========
main: end
อธิบายทีละขั้น
  1. main พิมพ์ start แล้วเรียก printHeader
  2. printHeader เรียก printLine → พิมพ์เส้น → กลับมา printHeader
  3. พิมพ์ REPORT แล้วเรียก printLine อีกครั้ง
  4. printHeader จบ → กลับมา main พิมพ์ end

ตัวอย่าง 7.1.3แบ่ง main เป็นขั้นตอนที่มีชื่อ

แนวคิด: main ที่ดีควรอ่านเหมือนสารบัญ: แต่ละบรรทัดบอกว่าทำอะไร รายละเอียดอยู่ในเมธอด

ShopSteps.java
public class ShopSteps {

        showBanner();  // main อ่านเหมือนสารบัญของงาน

    static void showBanner() {  // แต่ละเมธอดทำงานเดียว

    static void showMenu() {
        System.out.println("1. Espresso   45");
        System.out.println("2. Latte      55");
        System.out.println("3. Mocha      60");
    }

    static void showFooter() {
        System.out.println("Open 8:00-18:00");
    }
}

void ไม่ได้แปลว่าไม่มี output

เมธอด void พิมพ์ข้อความได้ตามปกติ “void” หมายถึงไม่ส่งค่ากลับไปให้ผู้เรียกนำไปใช้ต่อ การแสดงผล (print) กับการคืนค่า (return) เป็นคนละเรื่อง — จะเห็นชัดในหัวข้อ 7.3

ลองคิดก่อน · ลำดับการเรียก
Java
static void a() { System.out.print("A"); b(); System.out.print("a"); }
static void b() { System.out.print("B"); }
// ใน main:
a(); b();
ดูคำตอบ

ABaB — a พิมพ์ A, เรียก b พิมพ์ B, กลับมาพิมพ์ a, แล้ว main เรียก b อีกครั้งพิมพ์ B

7.2 พารามิเตอร์และ argument

parameter คือตัวแปรที่ประกาศในวงเล็บของเมธอดเพื่อรับค่า ส่วน argument คือค่าจริงที่ส่งเข้าไปตอนเรียก เมื่อเรียก Java จะคัดลอกค่า argument ไปใส่ parameter ตามลำดับตำแหน่ง

parameter vs argument
Java
static void greet(String name, int times) { ... }   // name, times = parameter
greet("JHope", 3);                                  // "JHope", 3   = argument
        │      └──→ times = 3
        └──────────→ name  = "JHope"
  • จำนวน ชนิด และลำดับของ argument ต้องตรงกับ parameter
  • argument เป็นตัวแปร ค่าคงที่ หรือนิพจน์ก็ได้ เช่น greet(user, n + 1)

ตัวอย่าง 7.2.1parameter หนึ่งตัว

แนวคิด: เมธอดเดียวทำงานกับข้อมูลต่างกันได้ ขึ้นอยู่กับ argument ที่ส่งมา

GreetParam.java
public class GreetParam {
    public static void main(String[] args) {
        // ส่ง argument "JHope" เข้า parameter name
        greet("JHope");
        greet("Suga");
        String friend = "RM";
        greet(friend);  // ส่งค่าในตัวแปรก็ได้
    }

    static void greet(String name) {  // parameter รับค่าที่ส่งมา
        System.out.println("Hello, " + name + "!");
    }
}
ผลลัพธ์
Hello, JHope!
Hello, Suga!
Hello, RM!
อธิบายทีละขั้น
  1. ครั้งแรก name = "JHope"
  2. ครั้งที่สอง name = "Suga"
  3. ครั้งที่สามส่งตัวแปร friend → name ได้ค่า "RM"

ตัวอย่าง 7.2.2หลาย parameter และลูปในเมธอด

แนวคิด: parameter ใช้ได้เหมือนตัวแปรปกติภายในเมธอด รวมถึงเป็นขอบเขตของลูป

DrawLine.java
public class DrawLine {
    public static void main(String[] args) {
        // ลำดับ argument ต้องตรงกับ parameter
        drawLine('*', 10);
        drawLine('-', 4);
        drawLine('=', 2 * 6);  // ส่งนิพจน์ได้ คำนวณก่อนส่ง
    }

    // parameter 2 ตัว: char กับ int
    static void drawLine(char symbol, int length) {
        for (int i = 0; i < length; i++) {
            System.out.print(symbol);
        }
        System.out.println();
    }
}

----
============

public class ReturnPaths {
    public static void main(String[] args) {
        System.out.println(gradeOf(85) + " " + gradeOf(72) + " " + gradeOf(40));
        for (int n = 1; n <= 20; n++) {
            if (isPrime(n)) {
                System.out.print(n + " ");
            }
        }
        System.out.println();
    }

        // return แล้วจบเมธอดทันที
        if (score >= 80) return 'A';
        if (score >= 70) return 'B';
        if (score >= 60) return 'C';
        return 'F';  // ไม่ตรงเงื่อนไขใดเลย
    }

    static boolean isPrime(int n) {
        if (n < 2) return false;  // ออกก่อนได้เมื่อรู้คำตอบ
        for (int d = 2; d * d <= n; d++) {
            // เจอตัวหาร → ไม่ใช่จำนวนเฉพาะ
            if (n % d == 0) return false;
        }
        return true;  // ไม่เจอตัวหารเลย
    }
}

    public static void main(String[] args) {

        System.out.println(max(3, 9));

        System.out.println(max(2.5, 1.75));

        System.out.println(area(4, 6));

    static int max(int a, int b) {
        return a > b ? a : b;
    }

    static double max(double a, double b) {
        return a > b ? a : b;
    }

    static int max(int a, int b, int c) {
        return max(max(a, b), c);  // เรียกเวอร์ชัน 2 ตัวซ้อนกัน
    }

    static double area(double side) {
        return side * side;
    }

    static double area(double width, double height) {
        return width * height;
    }
}

7.5 ประกอบโปรแกรมจากเมธอด

ขั้นตอนออกแบบโปรแกรมด้วยเมธอด (top-down)
  1. เขียนสิ่งที่โปรแกรมต้องทำเป็นข้อ ๆ ภาษาคน เช่น รับข้อมูล → คำนวณ → ตัดสิน → แสดงผล
  2. แต่ละข้อที่ทำงานชัดเจนหนึ่งอย่าง → ตั้งเป็นเมธอดหนึ่งตัว ตั้งชื่อด้วยคำกริยา
  3. กำหนดว่าแต่ละเมธอด ต้องรู้อะไร (parameter) และ ให้อะไรกลับ (return type)
  4. เขียน main ให้เรียกเมธอดตามลำดับเหมือนสารบัญ
  5. เขียนและทดสอบเมธอดทีละตัว โดยเรียกจาก main ด้วยค่าที่รู้คำตอบ

ตัวอย่าง 7.5.1เครื่องคำนวณเกรดจากเมธอดหลายตัว

แนวคิด: main ประสานงาน ส่วนเมธอดแต่ละตัวทำหน้าที่เดียว: รวมคะแนน ตัดเกรด และพิมพ์รายงาน

GradeReport.java
import java.util.Scanner;

public class GradeReport {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Name: ");
        String name = input.nextLine();
        System.out.print("Work Mid Final: ");
        double work = input.nextDouble();
        double mid = input.nextDouble();
        double fin = input.nextDouble();

        // แต่ละขั้นเรียกเมธอดที่ทำงานเดียว
        double total = totalScore(work, mid, fin);
        char grade = gradeOf(total);
        printReport(name, total, grade);
    }

    // รวมคะแนน
    static double totalScore(double work, double mid, double fin) {
        return work + mid + fin;
    }

    static char gradeOf(double total) {  // ตัดเกรด
        if (total >= 80) return 'A';
        if (total >= 70) return 'B';
        if (total >= 60) return 'C';
        if (total >= 50) return 'D';
        return 'F';
    }

    // แสดงรายงาน
    static void printReport(String name, double total, char grade) {
        System.out.println("-".repeat(24));
        System.out.printf("%-8s %s%n", "Name", name);
        System.out.printf("%-8s %.1f%n", "Total", total);
        System.out.printf("%-8s %c%n", "Grade", grade);
        // ?: เลือกคำว่า Pass หรือ Fail
        System.out.printf("%-8s %s%n", "Result", grade == 'F' ? "Fail" : "Pass");
        System.out.println("-".repeat(24));
    }
}

public class BmiCalculator {
    public static void main(String[] args) {
        check(50, 1.70, "Underweight");  // ทดสอบทุกกลุ่ม
        check(65, 1.70, "Normal");
        check(85, 1.70, "Overweight");
        check(100, 1.70, "Obese");
    }

    // คำนวณอย่างเดียว คืนค่า BMI
    static double bmiOf(double weightKg, double heightM) {
        return weightKg / (heightM * heightM);
    }

    // แปลงค่า BMI เป็นชื่อกลุ่ม
    static String categoryOf(double bmi) {
        // return แล้วจบเมธอดทันที
        if (bmi < 18.5) return "Underweight";
        if (bmi < 25) return "Normal";
        if (bmi < 30) return "Overweight";
        return "Obese";
    }

    // ตัวช่วยทดสอบ: เทียบผลจริงกับที่คาด
    static void check(double weight, double height, String expected) {
        double bmi = bmiOf(weight, height);
        String actual = categoryOf(bmi);
        // ตรงกัน → PASS
        String status = actual.equals(expected) ? "PASS" : "FAIL";
        System.out.printf("%-4s weight=%.1f height=%.2f -> BMI=%.1f (%s, expected %s)%n", status, weight, height, bmi, actual, expected);
    }
}

import java.util.Scanner;

public class UnitConverter {
    // ค่าคงที่ระดับคลาส ใช้ได้ทุกเมธอด
    static final double MILE_PER_KM = 0.621371;
    static final double POUND_PER_KG = 2.20462;

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Celsius km kg: ");
        double c = input.nextDouble();
        double km = input.nextDouble();
        double kg = input.nextDouble();
        // เรียกเมธอดแปลงหน่วยใน printf
        System.out.printf("%8.2f C  = %8.2f F%n", c, cToF(c));
        System.out.printf("%8.2f km = %8.2f mi%n", km, kmToMile(km));
        System.out.printf("%8.2f kg = %8.2f lb%n", kg, kgToPound(kg));
    }

    static double cToF(double c) {  // เมธอดละหนึ่งการแปลง
        return c * 9 / 5 + 32;
    }

    static double kmToMile(double km) {
        return km * MILE_PER_KM;
    }

    static double kgToPound(double kg) {
        return kg * POUND_PER_KG;
    }
}

CountWithMethods.java
import java.util.Scanner;

public class CountWithMethods {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("a b: ");
        int a = input.nextInt(), b = input.nextInt();
        int evens = 0, primes = 0;
        System.out.print("Primes: ");
        for (int n = a; n <= b; n++) {
            // ใช้เมธอดเป็นเงื่อนไขของ if
            if (isEven(n)) evens++;
            if (isPrime(n)) {
                primes++;
                System.out.print(n + " ");
            }
        }
        System.out.println();
        System.out.println("Even count: " + evens);
        System.out.println("Prime count: " + primes);
    }

    // คืนผลของนิพจน์ boolean ได้โดยตรง
    static boolean isEven(int n) {
        return n % 2 == 0;
    }

    static boolean isPrime(int n) {
        if (n < 2) return false;
        for (int d = 2; d * d <= n; d++) {
            if (n % d == 0) return false;
        }
        return true;
    }
}

Exercise 7.6overload เมธอดคำนวณพื้นที่★★ ปานกลาง

เขียนเมธอดชื่อ area สามแบบ (overload): area(double r) พื้นที่วงกลม, area(double w, double h) พื้นที่สี่เหลี่ยมผืนผ้า และ area(double a, double b, double c) พื้นที่สามเหลี่ยมจากความยาวด้านด้วยสูตรเฮรอน (s = (a+b+c)/2, พื้นที่ = √(s(s−a)(s−b)(s−c)))

  1. ใช้ Math.PI และ Math.sqrt
  2. เรียกทั้งสามแบบจาก main ด้วยค่าในตัวอย่าง
  3. อธิบายว่า compiler รู้ได้อย่างไรว่าต้องเรียกแบบไหน
ตัวอย่างผลลัพธ์
Circle r=3       : 28.27
Rectangle 4x6    : 24.00
Triangle 3,4,5   : 6.00

ตัวอย่างคำตอบ

AreaOverload.java
public class AreaOverload {
    public static void main(String[] args) {
        // เลือก area ตามจำนวน argument
        System.out.printf("Circle r=3       : %.2f%n", area(3));
        System.out.printf("Rectangle 4x6    : %.2f%n", area(4, 6));
        System.out.printf("Triangle 3,4,5   : %.2f%n", area(3, 4, 5));
    }

    static double area(double r) {  // วงกลม: πr²
        return Math.PI * r * r;
    }

    // สี่เหลี่ยม: กว้าง × ยาว
    static double area(double w, double h) {
        return w * h;
    }

    // สามเหลี่ยม: สูตรเฮรอน
    static double area(double a, double b, double c) {
        // ครึ่งหนึ่งของเส้นรอบรูป
        double s = (a + b + c) / 2;
        return Math.sqrt(s * (s - a) * (s - b) * (s - c));
    }
}

compiler ดูจากจำนวน argument (1, 2 หรือ 3 ตัว) เพื่อเลือกเมธอดที่ signature ตรงกัน

public class LoanTable {
    public static void main(String[] args) {
        double principal = 500000;
        double rate = 6;
        System.out.printf("%6s %12s %12s%n", "Months", "Payment", "Interest");
        for (int months = 12; months <= 60; months += 12) {
            // คำนวณค่างวดของแต่ละระยะเวลา
            double pay = monthlyPayment(principal, rate, months);
            System.out.printf("%6d %,12.2f %,12.2f%n", months, pay, pay * months - principal);
        }
    }

    static double monthlyPayment(double principal, double annualRate, int months) {
        // ไม่มีดอกเบี้ย → หารเท่า ๆ กัน
        if (annualRate == 0) return principal / months;
        // ดอกเบี้ยต่อเดือนเป็นทศนิยม
        double r = annualRate / 12 / 100;
        // สูตรผ่อนชำระแบบลดต้นลดดอก
        return principal * r / (1 - Math.pow(1 + r, -months));
    }
}

NumberTools.java
public class NumberTools {
    public static void main(String[] args) {
        int found = 0;
        for (int n = 100; n <= 200; n++) {
            if (isPalindrome(n)) {  // ใช้เมธอดเป็นเงื่อนไข
                System.out.printf("%d (sum %d)  ", n, digitSum(n));
                found++;
                // ขึ้นบรรทัดใหม่ทุก 5 ตัว
                if (found % 5 == 0) System.out.println();
            }
        }
        if (found % 5 != 0) System.out.println();
        System.out.println("Found " + found + " palindromes");
    }

    static int digitSum(int n) {
        int sum = 0;  // ผลรวมหลัก
        while (n > 0) {
            sum += n % 10;  // บวกหลักขวาสุด
            n /= 10;        // ตัดหลักขวาสุดทิ้ง
        }
        return sum;
    }

    static int reverse(int n) {
        int rev = 0;
        while (n > 0) {
            // เลื่อนหลักเดิมไปซ้ายแล้วเติมหลักใหม่
            rev = rev * 10 + n % 10;
            n /= 10;
        }
        return rev;
    }

    static boolean isPalindrome(int n) {
        return n == reverse(n);  // เลขกลับหน้าหลังเท่าเดิม
    }
}

การแก้ parameter n ใน digitSum และ reverse ไม่กระทบตัวแปร n ใน main เพราะ Java ส่งสำเนาของค่า

import java.util.Scanner;

public class BirthdayInput {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        // เมธอดเดียวใช้ตรวจช่วงได้หลายแบบ
        int d = readIntInRange(in, "Day: ", 1, 31);
        int m = readIntInRange(in, "Month: ", 1, 12);
        int y = readIntInRange(in, "Year: ", 1900, 2026);
        System.out.println("Born " + d + "/" + m + "/" + y);
        System.out.println("Age on 4/10/2026: " + ageOn(d, m, y, 4, 10, 2026));
    }

    // อ่านจนกว่าจะได้ค่าในช่วง
    static int readIntInRange(Scanner in, String prompt, int min, int max) {
        int value;
        while (true) {
            System.out.print(prompt);
            value = in.nextInt();
            // ค่าถูก → return ออกจากลูปและเมธอด
            if (value >= min && value <= max) return value;
            System.out.println("Please enter " + min + "-" + max);
        }
    }

    static int ageOn(int d, int m, int y, int nowD, int nowM, int nowY) {
        int age = nowY - y;
        // ยังไม่ถึงวันเกิดของปีนี้
        if (nowM < m || (nowM == m && nowD < d)) {
            age--;
        }
        return age;
    }
}

DiceGame.java
import java.util.Scanner;

public class DiceGame {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int first = readRoll(in);  // อ่านผลทอยครั้งแรก
        String result = firstRollResult(first);
        if (result.equals("POINT")) {
            System.out.println("Point is " + first);
            // ทอยต่อจนกว่าจะได้แต้มหรือ 7
            boolean win = playForPoint(in, first);
            System.out.println(win ? "You WIN!" : "You LOSE!");
        } else {
            System.out.println("You " + result + "!");
        }
    }

    // อ่านแต้มลูกเต๋า 2 ลูกจนกว่าจะถูกต้อง
    static int readRoll(Scanner in) {
        while (true) {
            System.out.print("Roll (two dice): ");
            int a = in.nextInt(), b = in.nextInt();
            if (a >= 1 && a <= 6 && b >= 1 && b <= 6) {
                System.out.println("  sum = " + (a + b));
                return a + b;
            }
            System.out.println("  dice must be 1-6");
        }
    }

    static String firstRollResult(int sum) {
        // 7 หรือ 11 ชนะทันที
        if (sum == 7 || sum == 11) return "WIN";
        // 2, 3, 12 แพ้ทันที
        if (sum == 2 || sum == 3 || sum == 12) return "LOSE";
        return "POINT";
    }

    // ทอยซ้ำจนรู้ผล
    static boolean playForPoint(Scanner in, int point) {
        while (true) {
            int sum = readRoll(in);
            // ได้แต้มเดิม → ชนะ
            if (sum == point) return true;
            if (sum == 7) return false;  // ได้ 7 → แพ้
        }
    }
}
