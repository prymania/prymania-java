บทเสริม · Random

สุ่มตัวเลขและเกมทายคำตอบ

สร้างค่าที่เปลี่ยนได้ตามการรัน แล้วนำไปฝึกเงื่อนไข ลูป และการรับข้อมูลด้วยเกมทายตัวเลข

เมื่อจบบทนี้ นิสิตจะทำได้
  • เข้าใจช่วงค่าที่ Math.random คืน
  • สุ่มจำนวนเต็มในช่วงที่กำหนด
  • ใช้ Random object
  • ออกแบบ loop เกมทายเลขพร้อมคำใบ้

สุ่มค่าอย่างตั้งใจ

ก่อนเขียนสูตร ให้ระบุขอบเขตล่างและบนก่อนว่าแต่ละค่ารวมอยู่ในช่วงหรือไม่ ความผิดพลาดเรื่อง inclusive/exclusive เป็นบั๊กที่พบบ่อย

S1.1 Math.random และช่วง [0, 1)

Math.random() คืนค่า double ตั้งแต่ 0.0 รวมถึง แต่ต่ำกว่า 1.0 จึงไม่คืน 1.0

สุ่มจำนวนเต็มตั้งแต่ 1 ถึง 6
int roll = (int) (Math.random() * 6) + 1;

คูณ 6 ได้ค่าในช่วง 0 ถึงน้อยกว่า 6; cast เป็น int ตัดเศษจึงได้ 0–5 แล้วบวก 1 เป็น 1–6

สูตรทั่วไปที่รวมขอบเขตทั้งคู่
int value = min + (int) (Math.random() * (max - min + 1));

ใช้เมื่อ min ≤ max และต้องการจำนวนเต็มทุกค่าตั้งแต่ min ถึง max

Exercise S1.1สุ่มเลขสองหลัก

สุ่มจำนวนเต็มตั้งแต่ 10 ถึง 99 โดยมีโอกาสออกได้ครบทุกค่า

คำตอบ

int number = 10 + (int) (Math.random() * 90);

ช่วง offset มี 90 ค่า: 0–89 จึงได้ 10–99

S1.2 ใช้ java.util.Random

สร้าง Random object หนึ่งตัวแล้วเรียก method ซ้ำเมื่ออยากได้ค่าใหม่ nextInt(bound) คืนจำนวนเต็มตั้งแต่ 0 รวมถึง แต่ต่ำกว่า bound

สุ่มจำนวนเต็มช่วง 20–30
import java.util.Random;

Random random = new Random();
int value = random.nextInt(11) + 20;

nextInt(11) ได้ 0–10; บวก 20 จึงได้ 20–30

ทดสอบแบบทำซ้ำได้

ส่ง seed คงที่ เช่น new Random(42) เพื่อให้ลำดับสุ่มเดิมกลับมาในการทดสอบและการดีบัก; เกมจริงทั่วไปจึงค่อยใช้ constructor เปล่า

Exercise S1.2ทอยลูกเต๋าหลายหน้า

ใช้ Random สุ่มผลลูกเต๋า 12 หน้า มีค่าตั้งแต่ 1 ถึง 12

คำตอบ

Random random = new Random();
int roll = random.nextInt(12) + 1;

S1.3 เกมทายตัวเลข

สุ่มคำตอบหนึ่งครั้งก่อนเริ่ม loop จากนั้นรับตัวเลขจากผู้เล่น เปรียบเทียบแล้วให้คำใบ้จนกว่าจะทายถูก

โครงเกมแบบ console
Random random = new Random();
int secret = random.nextInt(100) + 1;
Scanner scanner = new Scanner(System.in);
int guess = 0;

while (guess != secret) {
    System.out.print("Guess 1-100: ");
    guess = scanner.nextInt();
    if (guess < secret) System.out.println("Too low");
    else if (guess > secret) System.out.println("Too high");
}
System.out.println("Correct!");

สร้าง secret นอก loop เพื่อให้คำตอบไม่เปลี่ยนทุกครั้งที่ทาย และกำหนดช่วง input ให้ตรงกับช่วงสุ่ม

Exercise S1.3เกมคำใบ้

เพิ่มข้อความ Hint เมื่อผู้เล่นทายต่ำหรือสูง และจบ loop เมื่อทายถูก

แนวทาง

if (guess < secret) {
    System.out.println("Too low");
} else if (guess > secret) {
    System.out.println("Too high");
} else {
    System.out.println("Correct!");
}

S1.4 จำกัดจำนวนครั้งและทดสอบ

ใช้ตัวนับ attempts เพิ่มเมื่อรับคำทายแต่ละครั้ง แล้วหยุดเมื่อทายถูกหรือใช้ครบจำนวนครั้ง อย่าลืมแยกกรณีชนะกับหมดสิทธิ์

นับจำนวนครั้งสูงสุด
int attempts = 0;
int maxAttempts = 7;
while (guess != secret && attempts < maxAttempts) {
    guess = scanner.nextInt();
    attempts++;
    // แสดงคำใบ้
}
if (guess == secret) System.out.println("You win");
else System.out.println("Out of attempts. Answer: " + secret);

Exercise S1.4คิดกรณีทดสอบเกม

ระบุ test cases อย่างน้อย 4 แบบสำหรับช่วง 1–100 รวมการทายถูกครั้งแรก, ต่ำกว่า, สูงกว่า และหมดจำนวนครั้ง

แนวทาง test

  • secret=50, guess=50 → ชนะหนึ่งครั้ง
  • secret=50, guess=20 → แจ้ง Too low
  • secret=50, guess=80 → แจ้ง Too high
  • ทายผิดครบ maxAttempts → จบเกมและเฉลย secret
