บทที่ 14 · เริ่มต้น GUI ด้วย javax.swing

หน้าต่างแรกของเรา

เปลี่ยนจากโปรแกรมที่รับ/แสดงข้อความใน console ไปเป็นหน้าต่างที่มีพื้นที่วางส่วนควบคุม และตอบสนองเหตุการณ์ของผู้ใช้

เมื่อจบบทนี้ นิสิตจะทำได้

  • สร้างหน้าต่างและกำหนดการปิด
  • เพิ่ม JPanel เป็นพื้นที่จัดกลุ่ม component
  • เริ่ม GUI บน Event Dispatch Thread

14. จากผลลัพธ์ใน console สู่หน้าต่าง GUI

GUI (Graphical User Interface) ให้ผู้ใช้เห็นหน้าต่าง ปุ่ม ช่องกรอกข้อมูล และผลลัพธ์ แทนการพิมพ์คำสั่งใน console โดย Swing เป็นชุด component มาตรฐานใน Java SE สำหรับสร้าง GUI

14.1 หน้าต่าง, container และ component

JFrame เป็นหน้าต่างหลัก; container ใช้บรรจุ/จัดกลุ่ม component; component คือสิ่งที่มองเห็นหรือโต้ตอบได้ เช่น label, button และ text field

แผนผังส่วนประกอบ
JFrame (หน้าต่าง)
└── JPanel (พื้นที่จัดกลุ่ม)
    ├── JLabel (ข้อความ)
    ├── JTextField (ช่องกรอก)
    └── JButton (ปุ่มกด)

หน้าต่างทำหน้าที่เป็น root container; เรามักเพิ่ม JPanel ก่อน แล้วใส่ component ลงใน panel เพื่อจัด layout

เทียบกับโปรแกรม console

Console รอ input จาก Scanner ตามลำดับคำสั่ง ส่วน GUI เปิดรับเหตุการณ์ เช่น click หรือพิมพ์ข้อความ ผู้ใช้เป็นผู้กำหนดว่าจะเกิดเหตุการณ์ใดก่อน

Exercise 14.1จับคู่หน้าที่

จับคู่ JFrame, JPanel, JLabel และ JButton กับบทบาทของแต่ละส่วนในหน้าจอ

คำตอบ

JFrame = หน้าต่างหลัก; JPanel = container สำหรับจัดกลุ่ม; JLabel = แสดงข้อความ; JButton = ปุ่มรับการคลิก

14.2 สร้าง JFrame และกำหนดวงจรชีวิต

สร้างหน้าต่าง, ตั้งชื่อ, ขนาด และนโยบายปิด แล้วจึงทำให้มองเห็น ลำดับสำคัญคือจัดค่าให้ครบก่อนเรียก setVisible(true)

ลำดับการเปิดหน้าต่าง
  1. สร้าง JFrame
  2. ตั้ง default close operation
  3. เพิ่ม content และจัด component
  4. กำหนดขนาดหรือ pack
  5. ตั้งตำแหน่งแล้วแสดงหน้าต่าง
หน้าต่าง GUI ขั้นต่ำ
import javax.swing.JFrame;
import javax.swing.SwingUtilities;

public class Main {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("My First GUI");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            frame.setSize(480, 320);
            frame.setLocationRelativeTo(null);
            frame.setVisible(true);
        });
    }
}

EXIT_ON_CLOSE จบโปรแกรมเมื่อปิดหน้าต่าง; setLocationRelativeTo(null) วางหน้าต่างกลางจอ

setSize กับ pack

setSize(width, height) กำหนดขนาดหน้าต่างโดยตรง; pack() คำนวณขนาดจาก preferred size ของ component และ layout

Exercise 14.2ปรับหน้าต่าง

แก้ตัวอย่างให้ title เป็น Student Profile, ขนาด 600 × 400 และเปิดกลางจอ

ตัวอย่างคำตอบ

JFrame frame = new JFrame("Student Profile");
frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
frame.setSize(600, 400);
frame.setLocationRelativeTo(null);
frame.setVisible(true);

14.3 JPanel เป็น container สำหรับ component

เพิ่ม component ลง panel แล้วเพิ่ม panel ไปใน frame ทำให้เปลี่ยน layout หรือสลับเนื้อหาได้ง่ายขึ้น ใน Swing แต่ละ container มี layout manager คอยจัดตำแหน่ง

หน้าต่างมีข้อความหนึ่งบรรทัด
import javax.swing.*;
import java.awt.*;

public class Main {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Profile");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JPanel panel = new JPanel(new FlowLayout());
            panel.add(new JLabel("Student: Mali"));
            frame.setContentPane(panel);
            frame.pack();
            frame.setLocationRelativeTo(null);
            frame.setVisible(true);
        });
    }
}

FlowLayout เรียง component ตามลำดับที่เพิ่มลง panel และ pack() ปรับหน้าต่างให้พอดีกับ preferred size

Exercise 14.3วางข้อความสองส่วน

สร้าง JFrame และ JPanel แล้วเพิ่ม JLabel สองตัว: ชื่อวิชาและชื่อผู้สอน

ตัวอย่างคำตอบ

JPanel panel = new JPanel(new FlowLayout());
panel.add(new JLabel("Course: Java Programming"));
panel.add(new JLabel("Instructor: Prymania"));
frame.setContentPane(panel);
frame.pack();

14.4 Event Dispatch Thread (EDT)

Swing สร้างหน้าต่างและจัดการ event บน thread ชื่อ EDT ถ้าแก้ component จากหลาย thread โดยไม่ระวังอาจเกิดอาการกระพริบหรือ state ผิด จึงเริ่มสร้าง GUI ด้วย SwingUtilities.invokeLater

งานบน EDT ควรสั้น

EDT รับผิดชอบวาดหน้าจอและจัดการคลิก ถ้าใส่ loop ยาว, Thread.sleep หรือคำนวณหนักไว้บน EDT หน้าต่างจะตอบสนองไม่ได้ บทเสริมเรื่อง Timer/Thread จะอธิบายการทำงานเบื้องหลัง

เริ่มต้น GUI บน EDT
public static void main(String[] args) {
    SwingUtilities.invokeLater(() -> createAndShowGui());
}

static void createAndShowGui() {
    JFrame frame = new JFrame("Safe Swing Start");
    frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
    frame.setSize(400, 250);
    frame.setLocationRelativeTo(null);
    frame.setVisible(true);
}

Exercise 14.4หาความเสี่ยงของ EDT

โค้ดสร้างหน้าต่างแล้วเรียก Thread.sleep(5000) บน EDT ระบุสิ่งที่ผู้ใช้จะเห็นและตำแหน่งที่ควรย้ายงานหนัก

คำตอบ

หน้าต่างค้างและ repaint/click ไม่ตอบสนอง 5 วินาที เพราะ EDT ถูก block; งานที่ใช้เวลานานควรทำบน worker thread แล้วส่งผลกลับ EDT

แบบฝึกหัดท้ายบท

สร้างหน้าต่างที่จัดวางและปิดได้ตามต้องการ แล้วอธิบายลำดับการสร้าง

Exercise 14.5หน้าต่างชื่อของฉัน

สร้างหน้าต่างชื่อ About Me ขนาดพอดีกับข้อความ มี JLabel แสดงชื่อและวิชา ปิดหน้าต่างแล้วจบโปรแกรม

แนวคำตอบ

JPanel panel = new JPanel(new FlowLayout());
panel.add(new JLabel("Name: Your Name"));
panel.add(new JLabel("Course: Java"));
JFrame frame = new JFrame("About Me");
frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
frame.setContentPane(panel);
frame.pack();
frame.setLocationRelativeTo(null);
frame.setVisible(true);

Exercise 14.6ออกแบบโครงหน้าจอ

วาดลำดับ component tree สำหรับหน้าต่างลงทะเบียนที่มี label, text field, ปุ่มยืนยัน และข้อความสถานะ โดยยังไม่ต้องเขียน event

โครงสร้างตัวอย่าง

JFrame
└── JPanel
    ├── JLabel("Name")
    ├── JTextField
    ├── JButton("Submit")
    └── JLabel("Status")
