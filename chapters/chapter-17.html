บทที่ 17 · รับข้อมูลอย่างเป็นมิตร

ฟอร์มและการตรวจสอบข้อมูล

อ่านค่าจากทุกชนิดของ component ตรวจความถูกต้องก่อนใช้งาน แจ้งปัญหาให้ผู้ใช้เข้าใจและแก้ได้ และล้างฟอร์มเมื่อทำงานเสร็จ

เมื่อจบบทนี้ นิสิตจะทำได้
  • อ่านค่าจาก text field, combo, radio, check box, spinner
  • ตรวจข้อมูลว่าง รูปแบบ และช่วงค่า
  • แจ้ง error ด้วย JOptionPane และข้อความในฟอร์ม
  • แยก validation เป็นเมธอดและ reset ฟอร์ม

17. ฟอร์มคือสัญญาระหว่างผู้ใช้กับโปรแกรม

ผู้ใช้อาจเว้นช่องว่าง พิมพ์ตัวอักษรในช่องตัวเลข หรือป้อนค่าที่เป็นไปไม่ได้ ถ้าโปรแกรมนำค่าไปใช้ทันทีจะเกิด exception หรือบันทึกข้อมูลผิด บทนี้รวมเทคนิคจากบทที่ 9 (parse), บทที่ 10 (try-catch) และบทที่ 12 (validation) มาใช้กับ GUI

ลำดับการประมวลผลฟอร์มเมื่อกด Submit
  1. อ่านค่าจากทุก component (ยังเป็น String/สถานะ)
  2. ตรวจว่าไม่ว่าง → รูปแบบถูก → แปลงชนิด → อยู่ในช่วงที่ยอมรับ
  3. ถ้าผิด: แจ้งผู้ใช้ให้ชัดว่าช่องไหนผิดอย่างไร แล้วหยุด (ไม่บันทึก)
  4. ถ้าถูกทั้งหมด: ทำงาน (คำนวณ/บันทึก) แล้วแจ้งผลสำเร็จ และ reset ฟอร์มถ้าเหมาะสม

17.1 อ่านค่าจาก component

แต่ละ component อ่านค่าด้วยเมธอดต่างกัน และได้ชนิดข้อมูลต่างกัน จำตารางนี้ไว้ใช้ทั้งบท

Componentอ่านค่าชนิดที่ได้
JTextField / JTextAreagetText()String
JPasswordFieldgetPassword()char[] → new String(...)
JComboBox<String>getSelectedItem() / getSelectedIndex()Object (cast เป็น String) / int
JRadioButton / JCheckBoxisSelected()boolean
JSpinner (ตัวเลข)(int) spinner.getValue()Integer
JSlidergetValue()int
JListgetSelectedValue() / getSelectedValuesList()E / List<E>

ตัวอย่างนี้อ่านค่าจากทุกชนิดเมื่อคลิก Preview แล้วแสดงรวมกัน ยังไม่ตรวจความถูกต้อง

ตัวอย่าง 17.1.1อ่านทุกช่องแล้วสรุปใน text area

ReadForm.java
import javax.swing.*;
import java.awt.*;

public class ReadForm {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Read values");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JTextField name = new JTextField(12);
            JComboBox<String> year = new JComboBox<>(new String[]{"Year 1", "Year 2", "Year 3", "Year 4"});
            JRadioButton male = new JRadioButton("Male");
            JRadioButton female = new JRadioButton("Female");
            ButtonGroup g = new ButtonGroup();
            g.add(male);
            g.add(female);
            JCheckBox news = new JCheckBox("Newsletter");
            JSpinner age = new JSpinner(new SpinnerNumberModel(18, 15, 60, 1));
            JTextArea out = new JTextArea(5, 26);
            out.setEditable(false);
            JButton preview = new JButton("Preview");
            preview.addActionListener(e -> {
                String gender = male.isSelected() ? "Male"                            // ตรวจทีละปุ่ม
                              : female.isSelected() ? "Female" : "(not chosen)";     // อาจยังไม่เลือกเลย
                out.setText("Name: " + name.getText()                                 // String
                    + "\nYear: " + year.getSelectedItem() + " (index " + year.getSelectedIndex() + ")"
                    + "\nGender: " + gender
                    + "\nAge: " + (int) age.getValue()                                // Object → cast เป็น int
                    + "\nNewsletter: " + news.isSelected());                          // boolean
            });
            JPanel form = new JPanel(new GridLayout(0, 2, 4, 4));
            form.add(new JLabel("Name:")); form.add(name);
            form.add(new JLabel("Year:")); form.add(year);
            JPanel gp = new JPanel(new FlowLayout(FlowLayout.LEFT, 0, 0));
            gp.add(male); gp.add(female);
            form.add(new JLabel("Gender:")); form.add(gp);
            form.add(new JLabel("Age:")); form.add(age);
            form.add(news); form.add(preview);
            JPanel root = new JPanel(new BorderLayout(6, 6));
            root.setBorder(BorderFactory.createEmptyBorder(8, 8, 8, 8));
            root.add(form, BorderLayout.NORTH);
            root.add(new JScrollPane(out), BorderLayout.CENTER);
            frame.setContentPane(root);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

MultiSelect.java
import javax.swing.*;
import java.awt.*;
import java.util.List;

public class MultiSelect {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Electives");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            String[] courses = {"AI Basics", "Mobile Apps", "Web Design", "Databases", "Game Dev"};
            JList<String> list = new JList<>(courses);
            list.setSelectedIndices(new int[]{0, 2, 3});              // เลือกไว้ก่อน 3 รายการ
            JLabel result = new JLabel(" ");
            JButton show = new JButton("Show selected");
            show.addActionListener(e -> {
                List<String> chosen = list.getSelectedValuesList();   // ทุกรายการที่เลือก
                result.setText(chosen.size() + " chosen: " + String.join(", ", chosen));
            });
            JPanel root = new JPanel(new BorderLayout(4, 4));
            root.setBorder(BorderFactory.createEmptyBorder(8, 8, 8, 8));
            root.add(new JScrollPane(list), BorderLayout.CENTER);
            root.add(show, BorderLayout.EAST);
            root.add(result, BorderLayout.SOUTH);
            frame.setContentPane(root);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

17.2 ตรวจข้อมูลว่าง รูปแบบ และช่วงค่า

อย่าเชื่อข้อมูลจากผู้ใช้จนกว่าจะตรวจแล้ว ตรวจตามลำดับ: ว่างไหม → แปลงชนิดได้ไหม → อยู่ในช่วงไหม แต่ละขั้นให้ข้อความ error ที่ตรงกับปัญหา

การตรวจที่พบบ่อย

ตรวจวิธี
ว่างtext.trim().isEmpty() หรือ text.isBlank()
เป็นจำนวนเต็ม/ทศนิยมInteger.parseInt / Double.parseDouble ใน try-catch
ช่วงค่าvalue >= min && value <= max
ความยาวtext.length() >= 8
รูปแบบ (เช่น อีเมล, เบอร์โทร)text.matches("regex")
เลือกแล้วหรือยังcombo.getSelectedIndex() > 0 (ถ้ารายการแรกคือ “-- เลือก --”), radio ใด isSelected

เขียนการตรวจเป็นเมธอดที่รับ String และคืนข้อความ error หรือ null ถ้าผ่าน แล้วทดสอบใน console ให้ครบทุกกรณีก่อนนำไปใช้กับหน้าจอ

ตัวอย่าง 17.2.1ทดสอบเมธอดตรวจอายุใน console

Validators.java
public class Validators {
    public static void main(String[] args) {
        String[] ages = {"20", "", "  ", "abc", "-3", "150", " 45 "};   // ปกติ ว่าง ไม่ใช่ตัวเลข นอกช่วง
        for (String a : ages) {
            String err = checkAge(a);
            System.out.printf("%-8s -> %s%n", "\"" + a + "\"", err == null ? "OK" : err);
        }
    }

    static String checkAge(String text) {                 // null = ผ่าน
        if (text == null || text.isBlank()) return "Age is required";      // 1. ว่าง
        int age;
        try {
            age = Integer.parseInt(text.trim());           // 2. แปลง (" 45 " ผ่านเพราะ trim)
        } catch (NumberFormatException e) {
            return "Age must be a whole number";
        }
        if (age < 1 || age > 120) return "Age must be between 1 and 120";   // 3. ช่วงค่า
        return null;
    }
}
ผลลัพธ์
"20"     -> OK
""       -> Age is required
"  "     -> Age is required
"abc"    -> Age must be a whole number
"-3"     -> Age must be between 1 and 120
"150"    -> Age must be between 1 and 120
" 45 "   -> OK

ตรวจรูปแบบด้วย regular expression

text.matches(regex) ตรวจว่าข้อความทั้งก้อนตรงกับรูปแบบ เหมาะกับอีเมล รหัสนักศึกษา เบอร์โทร

regexความหมาย
\\dตัวเลข 1 ตัว
\\wตัวอักษร ตัวเลข หรือ _
+ตัวก่อนหน้า 1 ตัวขึ้นไป
{3}ตัวก่อนหน้า 3 ตัวพอดี
-?มีขีดหรือไม่ก็ได้
[A-Za-z]ตัวอักษรภาษาอังกฤษ

ตัวอย่าง 17.2.2อีเมล เบอร์โทร และรหัสนักศึกษา

PatternCheck.java
public class PatternCheck {
    static final String EMAIL = "[\\w.+-]+@[\\w-]+(\\.[\\w-]+)+";      // ชื่อ@โดเมน.นามสกุล
    static final String PHONE = "0\\d{1,2}-?\\d{3}-?\\d{4}";           // 0 + 1-2 หลัก, ขีดใส่หรือไม่ก็ได้
    static final String STUDENT_ID = "66\\d{6}";                       // 66 + ตัวเลข 6 ตัวพอดี

    public static void main(String[] args) {
        test("email", EMAIL, "jhope@mail.com", "jhope.j@uni.ac.th", "jhope@", "@mail.com");
        test("phone", PHONE, "081-234-5678", "0812345678", "02-123-4567", "81234");
        test("id", STUDENT_ID, "66012345", "65012345", "6601234");
    }

    static void test(String label, String regex, String... samples) {   // String... = กี่ตัวก็ได้ (อาเรย์)
        for (String s : samples) {
            System.out.printf("%-6s %-18s %s%n", label, s, s.matches(regex) ? "valid" : "INVALID");
        }
    }
}

ตัวอย่าง 17.2.3ฟอร์มลงทะเบียน 3 ช่อง

MultiFieldValidation.java
import javax.swing.*;
import java.awt.*;
import java.util.ArrayList;

public class MultiFieldValidation {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Register");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JTextField name = new JTextField(14);
            JTextField email = new JTextField(14);
            JTextField age = new JTextField(14);
            JLabel messages = new JLabel(" ");
            JButton register = new JButton("Register");
            register.addActionListener(e -> {
                ArrayList<String> errors = new ArrayList<>();                 // เก็บทุกข้อ
                if (name.getText().isBlank()) errors.add("Name is required");
                if (!email.getText().trim().matches("[\\w.+-]+@[\\w-]+(\\.[\\w-]+)+")) errors.add("Email format is invalid");
                try {
                    int a = Integer.parseInt(age.getText().trim());

                }
                frame.pack();                                                  // ปรับขนาดตามข้อความใหม่
            });
            JPanel form = new JPanel(new GridLayout(0, 2, 6, 6));
            form.add(new JLabel("Name:")); form.add(name);
            form.add(new JLabel("Email:")); form.add(email);
            form.add(new JLabel("Age:")); form.add(age);
            JPanel root = new JPanel(new BorderLayout(6, 8));
            root.setBorder(BorderFactory.createEmptyBorder(10, 10, 10, 10));
            root.add(form, BorderLayout.NORTH);
            root.add(messages, BorderLayout.CENTER);
            root.add(register, BorderLayout.SOUTH);
            frame.setContentPane(root);
            frame.pack();
            frame.setVisible(true);
        });
    }

import javax.swing.*;
import java.awt.*;

public class InlineErrors {
    static final Color ERROR = new Color(200, 30, 30);

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Sign up");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JTextField user = new JTextField(12);
            JPasswordField pass = new JPasswordField(12);
            JLabel userErr = errorLabel();                                // ข้อความ error ของแต่ละช่อง
            JLabel passErr = errorLabel();
            JButton signUp = new JButton("Sign up");
            signUp.addActionListener(e -> {
                String u = user.getText().trim();
                String p = new String(pass.getPassword());               // char[] → String
                boolean ok = mark(user, userErr, u.length() >= 4 ? null : "at least 4 characters");
                ok &= mark(pass, passErr, p.length() >= 8 && p.matches(".*\\d.*") && p.matches(".*[A-Za-z].*")
                    ? null : "8+ chars with letters and digits");        // &= ตรวจครบแม้ช่องแรกผิด
                if (ok) JOptionPane.showMessageDialog(frame, "Welcome, " + u + "!");
            });
            JPanel form = new JPanel(new GridLayout(0, 3, 6, 6));        // ป้าย | ช่อง | error
            form.setBorder(BorderFactory.createEmptyBorder(10, 10, 10, 10));
            form.add(new JLabel("Username:")); form.add(user); form.add(userErr);
            form.add(new JLabel("Password:")); form.add(pass); form.add(passErr);
            form.add(new JLabel()); form.add(signUp);
            frame.setContentPane(form);
            frame.pack();
            frame.setVisible(true);
        });
    }

    static JLabel errorLabel() {
        JLabel l = new JLabel(" ");
        l.setForeground(ERROR);
        return l;
    }

    static boolean mark(JTextField field, JLabel errorLabel, String error) {   // error == null = ผ่าน
        if (error == null) {
            field.setBorder(UIManager.getBorder("TextField.border"));         // คืนขอบปกติ
            errorLabel.setText(" ");
            return true;
        }
        field.setBorder(BorderFactory.createLineBorder(ERROR, 2));            // ขอบแดง หนา 2
        errorLabel.setText(error);
        return false;
    }
}

            }
        }
    }

import java.util.ArrayList;
import java.util.List;

public class BookingValidatorTest {
    public static void main(String[] args) {
        test("JHope", "2", "3", true);                    // ปกติ
        test("", "2", "3", true);                         // ชื่อว่าง
        test("Suga", "0", "3", false);                    // guests นอกช่วง
        test("RM", "5", "x", true);                       // nights ไม่ใช่ตัวเลข
        test("Jungkook", "11", "31", false);              // นอกช่วงทั้งคู่
    }

    static void test(String name, String guests, String nights, boolean breakfast) {
        List<String> errors = BookingValidator.validate(name, guests, nights);
        System.out.printf("%-8s g=%-3s n=%-3s -> %s%n", name, guests, nights, errors.isEmpty() ? "OK" : errors);
    }
}

class BookingValidator {
    static List<String> validate(String name, String guests, String nights) {
        List<String> errors = new ArrayList<>();
        if (name.isBlank()) errors.add("name required");
        Integer g = parseInRange(guests, 1, 10, "guests", errors);       // null เมื่อใช้ไม่ได้
        Integer n = parseInRange(nights, 1, 30, "nights", errors);
        if (g != null && n != null && g * n > 60) errors.add("too many guest-nights");   // กฎข้ามช่อง
        return errors;
    }

    private static Integer parseInRange(String text, int min, int max, String label, List<String> errors) {
        try {
            int v = Integer.parseInt(text.trim());
            if (v < min || v > max) {
                errors.add(label + " must be " + min + "-" + max);
                return null;
            }
            return v;
        } catch (NumberFormatException e) {
            errors.add(label + " must be a number");
            return null;
        }
    }
}

import javax.swing.*;
import java.awt.*;
import java.util.ArrayList;
import java.util.List;

public class BookingForm {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Hotel booking");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            JTextField name = new JTextField(12);
            JTextField guests = new JTextField(4);
            JTextField nights = new JTextField(4);
            JCheckBox breakfast = new JCheckBox("Breakfast (+250/guest/night)");
            JLabel result = new JLabel(" ");
            JButton book = new JButton("Book");
            book.addActionListener(e -> {
                List<String> errors = BookingRules.validate(name.getText(), guests.getText(), nights.getText());
                if (!errors.isEmpty()) {
                    result.setForeground(Color.RED);
                    result.setText("Please fix: " + String.join(", ", errors));
                    return;                                           // ไม่คำนวณต่อ
                }
                int g = Integer.parseInt(guests.getText().trim());    // ตรวจแล้ว แปลงได้แน่นอน
                int n = Integer.parseInt(nights.getText().trim());
                double total = BookingRules.price(g, n, breakfast.isSelected());
                result.setForeground(new Color(0, 110, 0));
                result.setText(String.format("%s: %d guests x %d nights = %,.2f baht", name.getText().trim(), g, n, total));
            });
            JPanel form = new JPanel(new GridLayout(0, 2, 6, 6));
            form.add(new JLabel("Name:")); form.add(name);
            form.add(new JLabel("Guests (1-10):")); form.add(guests);
            form.add(new JLabel("Nights (1-30):")); form.add(nights);
            form.add(breakfast); form.add(book);
            JPanel root = new JPanel(new BorderLayout(6, 8));
            root.setBorder(BorderFactory.createEmptyBorder(10, 10, 10, 10));
            root.add(form, BorderLayout.CENTER);
            root.add(result, BorderLayout.SOUTH);
            frame.setContentPane(root);
            frame.setSize(420, 190);
            frame.setVisible(true);
        });
    }
}

class BookingRules {                                          // ไม่มีโค้ด Swing
    static List<String> validate(String name, String guests, String nights) {
        List<String> errors = new ArrayList<>();
        if (name.isBlank()) errors.add("name");
        if (!inRange(guests, 1, 10)) errors.add("guests 1-10");
        if (!inRange(nights, 1, 30)) errors.add("nights 1-30");
        return errors;
    }

    static boolean inRange(String text, int min, int max) {
        try {
            int v = Integer.parseInt(text.trim());
            return v >= min && v <= max;
        } catch (NumberFormatException e) {
            return false;
        }
    }

    static double price(int guests, int nights, boolean breakfast) {
        double room = 1200 * nights * Math.ceil(guests / 2.0);            // ห้องละ 2 คน ปัดขึ้น
        return room + (breakfast ? 250.0 * guests * nights : 0);         // อาหารเช้าต่อคนต่อคืน
    }
}

import javax.swing.*;
import java.awt.*;

public class MemberEntry {
    private final JTextField name = new JTextField(12);
    private final JComboBox<String> faculty = new JComboBox<>(new String[]{"Science", "Arts", "Engineering"});
    private final JRadioButton basic = new JRadioButton("Basic", true);
    private final JRadioButton gold = new JRadioButton("Gold");
    private final JLabel error = new JLabel(" ");
    private final DefaultListModel<String> saved = new DefaultListModel<>();     // รายการที่บันทึกแล้ว

    }

    private void show() {
        JFrame frame = new JFrame("Members");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        ButtonGroup g = new ButtonGroup();
        g.add(basic);
        g.add(gold);

        JPanel form = new JPanel(new GridLayout(0, 2, 4, 4));
        form.add(new JLabel("Name:")); form.add(name);
        form.add(new JLabel("Faculty:")); form.add(faculty);

        form.add(new JLabel("Plan:")); form.add(plan);

        JPanel left = new JPanel(new BorderLayout(0, 4));
        left.add(form, BorderLayout.NORTH);
        left.add(error, BorderLayout.CENTER);
        JPanel root = new JPanel(new BorderLayout(8, 0));
        root.setBorder(BorderFactory.createEmptyBorder(8, 8, 8, 8));
        root.add(left, BorderLayout.WEST);
        JScrollPane list = new JScrollPane(new JList<>(saved));
        list.setPreferredSize(new Dimension(220, 120));
        root.add(list, BorderLayout.CENTER);
        frame.setContentPane(root);
        frame.pack();
        frame.setVisible(true);
    }

    private void save() {
        String n = name.getText().trim();
        if (n.isEmpty()) {
            error.setText("Name is required");
            name.requestFocusInWindow();                  // พาไปช่องที่ผิด
            return;                                       // ผิด → ไม่ล้างฟอร์ม

    }

    private void resetForm() {                            // คืนทุกช่องในที่เดียว
        name.setText("");
        faculty.setSelectedIndex(0);
        basic.setSelected(true);
        error.setText(" ");
        name.requestFocusInWindow();
    }
}

Exercise 17.1ตรวจช่องว่างก่อนทักทาย★ ง่าย

หน้าต่างมีช่องกรอกชื่อและปุ่ม Greet ถ้าช่องว่าง (หรือมีแต่ช่องว่าง) ให้แสดง dialog error “Please enter your name” ถ้าไม่ว่างให้แสดง dialog ข้อความ “Hello, ชื่อ!”

สิ่งที่ต้องทำ
  1. ใช้ isBlank()
  2. ใช้ JOptionPane.ERROR_MESSAGE และ INFORMATION_MESSAGE
  3. ภาพตัวอย่าง: กด Greet ทั้งที่ช่องมีแต่ช่องว่าง
ตัวอย่างหน้าจอ (ภาพจากโปรแกรมเฉลย)

Exercise 17.2เมธอดตรวจคะแนน (ทดสอบใน console)★ ง่าย

เขียนเมธอด static String checkScore(String text) คืน null ถ้าเป็นจำนวนเต็ม 0–100 มิฉะนั้นคืนข้อความ error ที่เหมาะสม 3 แบบ: ว่าง / ไม่ใช่ตัวเลข / นอกช่วง แล้วทดสอบกับข้อมูลอย่างน้อย 7 ค่าใน main

สิ่งที่ต้องทำ
  1. trim ก่อนตรวจ
  2. ทดสอบค่าขอบ 0, 100, −1, 101
  3. แสดงผลเป็นตาราง
ตัวอย่างผลลัพธ์
"85"       OK
"0"        OK
"100"      OK
"-1"       Score must be 0-100
"101"      Score must be 0-100
""         Score is required
"eighty"   Score must be a whole number
" 72 "     OK

Exercise 17.3แปลงสกุลเงินพร้อมตรวจข้อมูล★★ ปานกลาง

หน้าต่างแปลงเงินบาทเป็นสกุลที่เลือกจาก combo box (USD 35.5, EUR 38.2, JPY 0.24 บาทต่อหน่วย) ช่องจำนวนเงินต้องเป็นตัวเลขมากกว่า 0 ถ้าผิดให้แสดงข้อความสีแดงใต้ฟอร์ม (ไม่ใช้ dialog) และทำให้ขอบช่องเป็นสีแดง ถ้าถูกแสดงผลลัพธ์สีเขียว

สิ่งที่ต้องทำ
  1. อัตราแลกเปลี่ยนเก็บในอาเรย์คู่ขนานกับชื่อสกุลเงิน
  2. ผลลัพธ์ทศนิยม 2 ตำแหน่งพร้อมจุลภาค
  3. ช่องกลับเป็นขอบปกติเมื่อแก้ถูกแล้ว
ตัวอย่างหน้าจอ (ภาพจากโปรแกรมเฉลย)

ป้อน abc

ป้อน 10000 เลือก EUR

Exercise 17.4ยืนยันก่อนออกจากโปรแกรม★★ ปานกลาง

สร้างโปรแกรมบันทึกโน้ต (JTextArea) ที่มีปุ่ม Exit ถ้ามีข้อความในโน้ต ให้ถามยืนยันด้วย showConfirmDialog แบบ YES_NO_CANCEL: Yes = “บันทึก” (แสดง dialog ว่าบันทึกแล้วจำนวนกี่ตัวอักษร แล้วปิด), No = ปิดโดยไม่บันทึก, Cancel = กลับไปแก้ต่อ ถ้าโน้ตว่างให้ปิดทันที

สิ่งที่ต้องทำ
  1. ใช้ frame.dispose() แทน System.exit เพื่อปิดหน้าต่าง
  2. จัดการทั้ง YES_OPTION, NO_OPTION และกรณีอื่น (Cancel/ปิด dialog)
  3. ภาพตัวอย่าง: พิมพ์โน้ตแล้วกด Exit
ตัวอย่างหน้าจอ (ภาพจากโปรแกรมเฉลย)

Exercise 17.5ฟอร์มสมัครพร้อม error ข้างช่อง★★ ปานกลาง

ฟอร์มมีช่อง Username (4–12 ตัว ตัวอักษร/ตัวเลขเท่านั้น), Email (รูปแบบอีเมล), Phone (รูปแบบ 0XX-XXX-XXXX) และ check box “I accept the terms” (ต้องติ๊ก) แต่ละช่องมี label error สีแดงอยู่ทางขวา ปุ่ม Submit ตรวจทุกช่องพร้อมกัน แสดง error ทุกช่องที่ผิด และแสดง dialog “Registered!” เมื่อถูกทั้งหมด

สิ่งที่ต้องทำ
  1. ใช้ regex: [A-Za-z0-9]{4,12}, รูปแบบอีเมลจากหัวข้อ 17.2, 0\\d{2}-\\d{3}-\\d{4}
  2. เขียนเมธอด boolean show(JLabel err, String msg) ที่ตั้งข้อความและคืนว่าผ่านหรือไม่
  3. ภาพตัวอย่าง: username สั้นเกิน, อีเมลถูก, เบอร์ผิด, ไม่ติ๊ก
ตัวอย่างหน้าจอ (ภาพจากโปรแกรมเฉลย)

Exercise 17.6ฟอร์มสั่งซื้อพร้อมสรุปและยืนยัน★★★ ท้าทาย

ฟอร์มสั่งซื้อสินค้า: combo สินค้า (ตัวแรกเป็น “-- choose --”), spinner จำนวน 1–20, radio การจัดส่ง (Standard 40 / Express 90), ช่องที่อยู่ (JTextArea ต้องมีอย่างน้อย 10 ตัวอักษร), ช่องคูปอง (ว่างได้; ถ้ากรอกต้องเป็น SAVE10 หรือ SAVE50) ปุ่ม Place order ตรวจข้อมูลทั้งหมด แล้วแสดง confirm dialog สรุปรายการและยอดเงิน ถ้ากด Yes ให้เพิ่มลงรายการคำสั่งซื้อ (JList) และ reset ฟอร์ม

สิ่งที่ต้องทำ
  1. แยกคลาส OrderRules มีเมธอด validate และ total (ไม่มีโค้ด Swing)
  2. SAVE10 ลด 10% ของค่าสินค้า, SAVE50 ลด 50 บาท (ไม่ต่ำกว่า 0)
  3. เขียน resetForm()
  4. ภาพตัวอย่าง: เลือก Mouse จำนวน 1 ส่งแบบ Express กรอกที่อยู่ ใช้คูปอง SAVE10 แล้วกด Place order
ตัวอย่างหน้าจอ (ภาพจากโปรแกรมเฉลย)

Exercise 17.7แก้ไขรายการด้วยฟอร์มเดียว (Add / Update / Delete)★★★ ท้าทาย

สร้างโปรแกรมจัดการรายชื่อสินค้า (ชื่อ, ราคา) ที่ใช้ฟอร์มเดียวสำหรับทั้งเพิ่มและแก้ไข: คลิกรายการใน JList แล้วข้อมูลจะถูกเติมลงฟอร์ม ปุ่ม Add เพิ่มใหม่, Update แก้รายการที่เลือก, Delete ลบ (ถามยืนยัน), Clear ล้างฟอร์มและยกเลิกการเลือก ปุ่ม Update/Delete ใช้ได้เฉพาะเมื่อมีรายการถูกเลือก ชื่อห้ามว่างและห้ามซ้ำ ราคาต้องเป็นตัวเลข > 0

สิ่งที่ต้องทำ
  1. เก็บข้อมูลจริงใน ArrayList<Product> และให้ DefaultListModel แสดงผล (เรียก refreshList หลังเปลี่ยนแปลง)
  2. ตรวจชื่อซ้ำโดยไม่นับรายการที่กำลังแก้ไขอยู่
  3. ใช้ ListSelectionListener เติมฟอร์ม
  4. ภาพตัวอย่าง: เพิ่ม 3 รายการ แล้วเลือกรายการที่ 2 แก้ราคาเป็น 450
ตัวอย่างหน้าจอ (ภาพจากโปรแกรมเฉลย)
