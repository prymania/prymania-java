คิดแก้ปัญหาและออกแบบ Flowchart

  • รหัสเทียม
  • สัญลักษณ์ Flowchart
  • ทางเลือกและการทำซ้ำ
02

เริ่มต้นกับ Java และโปรแกรมแรก

รู้จักเครื่องมือและโครงสร้างโปรแกรม

  • JDK · JVM · IDE
  • โครงสร้าง main
  • Hello, Java!
  • คอมไพล์และรัน
03

ตัวแปร ชนิดข้อมูล และการคำนวณ

เก็บข้อมูลและคำนวณค่าพื้นฐานใน Java

  • ตัวแปรและการกำหนดค่า
  • ชนิดข้อมูล
  • ตัวดำเนินการ
  • ค่าคงที่และการแปลงชนิด
04

รับข้อมูลและแสดงผล

สร้างบทสนทนาระหว่างโปรแกรมกับผู้ใช้

  • print · println · printf
  • Scanner
  • ตัวเลขและข้อความ
  • จัดการบรรทัดข้อมูล
05

เงื่อนไขและการตัดสินใจ

ให้โปรแกรมเลือกทำงานตามข้อมูลและสถานการณ์

  • true / false
  • เปรียบเทียบและ AND · OR · NOT
  • if · else if · else
  • switch
  • เงื่อนไขซ้อนและขอบเขตค่า
06

การทำซ้ำด้วยลูป

สั่งให้โปรแกรมทำงานเดิมหลายครั้งอย่างมีเงื่อนไข

  • while และ do-while
  • for loop
  • ตัวนับและเงื่อนไขหยุด
  • ลูปซ้อน
  • break · continue · ลูปไม่รู้จบ
07

เมธอด: แบ่งโปรแกรมเป็นส่วน

จัดกลุ่มคำสั่งให้เรียกใช้ซ้ำและอ่านง่ายขึ้น

  • ประกาศและเรียกใช้เมธอด
  • พารามิเตอร์และ argument
  • return และ void
  • ขอบเขตตัวแปร
  • แยกปัญหาเป็นเมธอดย่อย
08

อาเรย์และชุดข้อมูล

เก็บข้อมูลหลายค่าไว้ภายใต้ชื่อตัวแปรเดียว

  • index และ length
  • สร้างและกำหนดค่า
  • อ่านค่าด้วยลูป
  • ค้นหาและหาผลรวม
  • อาเรย์สองมิติ
09

ข้อความและ String

จัดการข้อความที่รับเข้าและข้อมูลตัวอักษร

  • String กับ char
  • ต่อและเปรียบเทียบข้อความ
  • length · substring · charAt
  • แปลงข้อความเป็นตัวเลข
  • การอ่านข้อมูลทีละบรรทัด
10

ทดสอบ อ่าน error และแก้บั๊ก

เปลี่ยนข้อผิดพลาดให้เป็นเบาะแสในการแก้ปัญหา

  • Syntax · Runtime · Logic error
  • อ่านข้อความแจ้งข้อผิดพลาด
  • Trace ตารางค่าตัวแปร
  • ตั้งกรณีทดสอบ
  • ใช้ debugger ทีละบรรทัด
11

คลาสและออบเจ็กต์

เริ่มมองข้อมูลและพฤติกรรมเป็นสิ่งเดียวกัน

  • Class กับ Object
  • field และ method
  • สร้างออบเจ็กต์ด้วย new
  • constructor
  • instance กับ static เบื้องต้น
12

จัดระเบียบคลาสและปกป้องข้อมูล

เขียนโปรแกรมที่ขยายต่อและดูแลได้ง่ายขึ้น

  • public · private
  • encapsulation และ getter / setter
  • แบ่งหน้าที่ของคลาส
  • การประกอบออบเจ็กต์
  • สืบทอดและ polymorphism เบื้องต้น
13

เก็บข้อมูลแบบยืดหยุ่นด้วย ArrayList

เลือกใช้โครงสร้างข้อมูลให้เหมาะกับงาน

  • เพิ่ม · อ่าน · แก้ · ลบ
  • วนอ่านรายการ
  • Array กับ ArrayList
  • เก็บออบเจ็กต์ในรายการ
  • เลือกชนิดข้อมูลเบื้องต้น
14

เริ่มต้นสร้าง GUI ด้วย javax.swing

รู้จักหน้าต่างและแนวคิด Event Dispatch Thread

  • JFrame
  • หน้าต่างแรก
  • component และ container
  • จัดการหน้าต่างปิด
15

Components และ Layout

ประกอบส่วนควบคุมและจัดวางหน้าจอ

  • JLabel · JButton
  • JTextField · JTextArea
  • JComboBox
  • Layout Manager
16

เหตุการณ์และการตอบสนอง

เชื่อมการกระทำของผู้ใช้กับโปรแกรม

  • ActionListener
  • การคลิกปุ่ม
  • อัปเดตหน้าจอ
  • แยก logic จากหน้าจอ
17

ฟอร์มและการตรวจสอบข้อมูล

รับข้อมูลอย่างเป็นมิตรและจัดการกรณีผิดพลาด

  • อ่านค่าจากฟอร์ม
  • Validation
  • JOptionPane
  • ข้อความแจ้งเตือน
18

หลายหน้าจอและการจัดการข้อมูล

เชื่อมหน้าจอและแยกข้อมูลออกจากส่วนแสดงผล

  • สลับ JPanel
  • ส่งข้อมูลระหว่างหน้าจอ
  • แยก model กับ view
  • จัดโครงสร้างโปรแกรม

โปรเจกต์สรุป: โปรแกรม GUI

  • ออกแบบหน้าจอ

  • พัฒนาทีละส่วน
  • ทดสอบและนำเสนอ

SIDE QUESTS / เลือกอ่านเสริม

+

สุ่มตัวเลขและเกมทายคำตอบ

ใช้ Random สร้างค่าที่เปลี่ยนได้และฝึกคิดเป็นรอบ

  • Random
  • ช่วงค่าที่สุ่มได้
  • แนวคิดเกมทายตัวเลข
+

Timer, Thread และงานตามเวลา

ทำความเข้าใจการหน่วงเวลาโดยไม่ทำให้หน้าต่าง Swing ค้าง

  • javax.swing.Timer
  • Event Dispatch Thread
  • เหตุใด Thread.sleep จึงค้างหน้าจอ
